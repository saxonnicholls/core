Detailed Description

snicholls::ml joint embedding predictive architectures: the predictor's configuration, sizes, input and output, the normalised targets, the prediction losses (L2, L1, smooth L1, cosine) with their gradients, and the target encoder as an exponential moving average with its momentum schedule.

Overview. A joint embedding predictive architecture (JEPA; LeCun, 2022) learns by predicting, in representation space, the parts of a sample it was not shown (TRAINING.md T11):

  1. a mask (ml/masking.hpp) splits each sample's tokens (ml/patch.hpp) into context and targets;
  2. the context encoder, a bidirectional transformer, reads the context tokens only (gather_rows, ml/gather.hpp, with their position embeddings);
  3. the target encoder reads every token; its outputs at the targets, normalised by a layer norm without parameters (jepa_target_norm_rows), are the targets, and no gradient flows into them;
  4. the predictor, a narrower transformer, reads the context encoder's outputs projected to its width, followed by one learnable mask token per target plus that target's position embedding (jepa_predictor_input_rows), and its outputs at the targets, projected back, are the predictions (slice_rows);
  5. the loss compares predictions and targets (jepa_loss_rows), and the optimiser steps the context encoder and the predictor;
  6. the target encoder follows the context encoder as an exponential moving average, target = m · target + (1 - m) · context (ema_segments), with m rising from 0.996 to 1 over training (ema_momentum).

I-JEPA (Assran et al., 2023, "Self-Supervised Learning from Images with a Joint-Embedding Predictive Architecture") is this on image patches, with an L2 loss in the paper (its code uses smooth_l1_loss); V-JEPA (Bardes et al., 2024, "Revisiting Feature Prediction for Learning Visual Representations from Video") on video tubelets with an L1 loss (mean(|z - h|^p) / p, p = 1); V-JEPA 2 (Assran et al., 2025) adds 3-D RoPE (axial_rope_table) and an action-conditioned predictor (V-JEPA 2-AC: action and state tokens laid out frame by frame with scatter_rows, attended block-causally, attention_mask::block_causal). All three code bases update the target encoder as param_k.mul_(m).add_((1 - m) · param_q) (read 2026-11-19), which ema_rows reproduces operation for operation.

The text variant. LLM-JEPA (Huang, LeCun and Balestriero, 2025, "LLM-JEPA: Large Language Models Meet Joint Embedding Predictive Architectures", read 2026-11-19) keeps a language model's next-token loss and adds λ · d(Pred(Enc(Text)), Enc(Code)) over two views of one thing (a description and its code): Enc is the last token's hidden state of the last layer (gather_rows at each sequence's last position), Pred is the model itself run on k appended [PRED] tokens (no separate network; k = 0 is the identity), d is the cosine distance (jepa_loss::cosine, 1 - cos; the paper says "cosine similarity" and the 1 - is assumed), and there is no EMA and no stop-gradient stated, so both views take gradients (d_target). The two views run as separate sequences of one batch (causal each, padded with attention_activations::lengths), which is what the paper's block-causal packing computes. The total is lm_head_loss + jepa_loss_rows(..., weight = λ), their gradients added.

The predictor is composition: jepa_predictor_config holds its width and depth (a transformer_config with a bidirectional mask, its d_model the predictor's width), the encoder's width, and the sizes follow from it (jepa_predictor_parameters). Its pass: linear_sequence (encoder width to predictor width), jepa_predictor_input_rows, depth batched block_forward_sequences, the final norm (block_norm_rows), linear_sequence back to the encoder's width, and slice_rows at the targets; the backward the same in reverse.

// Two samples, each with 2 context rows and 1 target, in a predictor 2 wide; a grid of 4 tokens' positions
const std::array<float, 2 * 2 * 2> context{1, 1, 2, 2, 3, 3, 4, 4}; // the context encoder's rows, projected
const std::array<float, 2> mask_token{0.5f, -0.5f};
const std::array<float, 4 * 2> positions{0, 0, 10, 10, 20, 20, 30, 30};
const std::array<std::uint32_t, 4> context_index{0, 3, 1, 2};
const std::array<std::uint32_t, 2> target_index{1, 0};
std::array<float, 2 * 3 * 2> rows{}; // each sample: its context rows, then its mask token at its target's position
ml::jepa_predictor_input_rows(backend, std::span<const float>(context), std::span<const float>(mask_token), std::span<const float>(positions),
context_index, target_index, std::span<float>(rows), 2, 2);
// The backward: the context rows' gradients, and the mask token's summed over every target
std::array<float, 2 * 3 * 2> drows{};
drows.fill(1.0f);
std::array<float, 2 * 2 * 2> dcontext{};
std::array<float, 2> dmask{};
ml::jepa_predictor_input_rows_backward(backend, std::span<const float>(drows), 2, 1, std::span<float>(dcontext), std::span<float>(dmask), 2, 2);
// Targets: the target encoder's rows normalised without parameters (no gradient flows into them)
const std::array<float, 2 * 4> raw{1, 2, 3, 4, -2, 0, 2, 4};
std::array<float, 2 * 4> targets{};
ml::jepa_target_norm_rows(backend, std::span<const float>(raw), std::span<float>(targets), 4);
const std::array<float, 2 * 4> predictions{-1.0f, -0.5f, 0.5f, 1.5f, -1.5f, -0.5f, 0.5f, 1.5f};
std::array<float, 2 * 4> dpred{};
const float l2 = ml::jepa_loss_rows(backend, ml::jepa_loss::l2, std::span<const float>(predictions), std::span<const float>(targets), 4,
std::span<float>(dpred));
const float l1 = ml::jepa_loss_rows(backend, ml::jepa_loss::l1, std::span<const float>(predictions), std::span<const float>(targets), 4, std::span<float>{});
const float smooth = ml::jepa_loss_rows(backend, ml::jepa_loss::smooth_l1, std::span<const float>(predictions), std::span<const float>(targets), 4, std::span<float>{});
// LLM-JEPA: the cosine distance between two views' embeddings, weighted by lambda, both views taking gradients
std::array<float, 2 * 4> dview1{}, dview2{};
const float cosine = ml::jepa_loss_rows(backend, ml::jepa_loss::cosine, std::span<const float>(predictions), std::span<const float>(raw), 4,
std::span<float>(dview1), std::span<float>(dview2), {}, 2.0f);
// The target encoder follows the context encoder: target = m target + (1 - m) context, m from 0.996 to 1
std::array<float, 3> target_weights{1, 1, 1};
std::array<float, 2> other{0, 0};
const std::array<float, 3> context_weights{0, 2, 4};
const std::array<float, 2> other_context{8, 8};
const std::array<ml::ema_segment<float>, 2> model{{{target_weights, context_weights}, {other, other_context}}};
const double m0 = ml::ema_momentum(0, 1000), m_half = ml::ema_momentum(500, 1000),
m_cos = ml::ema_momentum(500, 1000, 0.996, 1.0, ml::momentum_schedule::cosine);
ml::ema_segments(backend, std::span<const ml::ema_segment<float>>(model), 0.5);
ml::ema_rows(backend, std::span<float>(target_weights), std::span<const float>(context_weights), 0.0); // m = 0 copies

Relationships. ml/gather.hpp, ml/masking.hpp, ml/patch.hpp, ml/collapse.hpp (the collapse diagnostics and regularisers), ml/probe.hpp (evaluation), ml/transformer_block.hpp, ml/norm.hpp, ml/optim.hpp. Group: snicholls-core.

Implementations. One each, on the host for any backend; a device library overloads the _rows and _segments functions for its own backend type (TRAINING.md T9).

Guarantees. constexpr, no allocation. Sums run in the stated order: a loss sums each row's terms in channel order, then the rows in order, then divides once. ema_rows with m = 0 copies online and with m = 1 keeps target, to the bit (finite values). jepa_predictor_config is trivially copyable and structural.

Errors. Preconditions, asserted: the sizes of the spans; lengths, when given, one per sequence and at most the rows of one; a momentum in [0, 1].

Performance. jepa_loss_rows and ema_rows against the loops by hand (benchmarks/ml/jepa_benchmark.cpp): the L2 loss with its gradient over 64 · 49 rows of 768 floats level, about 590 million elements a second; the EMA over 1M floats within 10%, about 1.8 billion a second (Xeon W-3245, Release, Apple clang 17, 2026-11-19, one thread, a machine at load average 60 to 80: differences within about 15% are noise). The other functions are once per step, not benchmarked.

Tests and demos. tests/ml/jepa_test.cpp (with a whole I-JEPA training run on random images, its loss falling without collapse), demos/ml/jepa_demo.cpp.

Dependencies. <cassert>, <cstddef>, <cstdint>, <numbers>, <span>, <type_traits>, ml/norm.hpp, ml/transformer_config.hpp.

Known issues. The losses are means over every element (PyTorch's reduction='mean'): the I-JEPA paper's L2, a sum over channels averaged over tokens, is width times jepa_loss::l2. The cosine schedule of the momentum is BYOL's (Grill et al., 2020), recalled; the JEPA code bases use the linear one.

Status. Experimental, new in 0.16.0.

One tensor of the target encoder as an exponential moving average of the context encoder's: target = target · m + (1 - m) · online, elementwise.

In T with m = T(momentum) and r = T(1 - momentum) (the complement formed in double and rounded once, as PyTorch's (1. - m) is a Python float), each element is kept = target · m, added = r · online, target = kept + added, three statements (no FMA): param_k.mul_(m).add_((1 - m) · param_q), operation for operation.

constexpr

The prediction loss over rows, with its gradients added into dpred (and dtarget if given).

Over the valid rows (all, or the first lengths[s] of each sequence's rows / sequences), count of them: elementwise kinds give weight · (Σ_rows Σ_c term(p - t)) / (count · width), cosine gives weight · Σ_rows (1 - cos(p, t)) / count with cos = p·t / (max(|p|, 1e-8) · max(|t|, 1e-8)) (PyTorch's). Each row's terms are summed in channel order, then the rows in order, then divided once. The gradient of each element is added: dpred += g · term'(p - t) with g = weight / (count · width), and dtarget -= the same; for cosine, dpred += (weight / count) · (c p / |p|² - t / (|p| |t|)) and symmetrically. Padding rows get none.

The predictor's input: each sequence's context rows plus their positions, then the mask token plus each target's position.

out(s, j) = context(s, j) + positions[context_index(s, j)] for j < kc, and out(s, kc + j) = mask_token + positions[target_index(s, j)] for j < kt, each one addition per element in that order (I-JEPA's predictor: x += pos_embed[masks_x], pred_tokens = mask_token + pos_embed[masks], cat([x, pred_tokens])).
