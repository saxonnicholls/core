Detailed Description

snicholls::metric::point, point_traits, distance_for, reducible, decomposable: the plug-and-play contract between points, metrics and the structures that search with them.

Overview. A search structure (a k-d tree, an approximate-nearest-neighbour forest, a set metric) needs two things from its caller: how to read a point, and how far apart two points are. This header defines both as customisation points, so any point type works with any metric, and any metric with any structure, as far as the metric's declared capabilities allow.

Points. point_traits<P> says how to read a point: its value_type, its dimension(p), its coordinate at(p, i), and its compile-time extent (std::dynamic_extent when only known at run time). It is provided for:

  • anything with operator[] and size(): std::array, std::vector, std::span, inplace_vector, std::basic_string_view, ...;
  • C arrays;
  • linalg::fixed_vector (and a one-row fixed_matrix).

A type of the caller's (a struct of x, y, z, a strided view into a tensor, a quantised row) becomes a point by specialising point_traits for it, as std::hash or math_limits are specialised. The point concept says whether a type is one.

Metrics. A metric is any value m with m(a, b) returning a distance. What else it offers is optional, and a structure asks for what it needs:

Capability Members Who uses it
distance_for<M, A, B> m(a, b) everything: brute force, re-ranking, set metrics

| reducible | m.reduced(a, b), m.expand(r), m.contract(d) | searches that compare in a cheaper monotone form (squared Euclidean, Σ|d|ᵖ) | | decomposable | m.term(axis, diff), m.combine(acc, t) | k-d trees and early-exit scans: one coordinate's term bounds the whole | | true_metric | static constexpr bool is_metric = true | trees that prune by the triangle inequality |

reduced_distance(m, a, b), expand(m, r) and contract(m, d) work for every metric: a metric without a cheaper form uses the distance itself. accumulate(m, a, b) and accumulate_within(m, a, b, bound) evaluate a decomposable metric term by term, the second stopping as soon as the partial sum exceeds bound.

// A point type of the caller's own: a colour. One specialisation makes it a point for every metric and structure.
struct rgb {
float r, g, b;
};
template <>
struct snicholls::metric::point_traits<rgb> {
using value_type = float;
static constexpr std::size_t extent = 3;
static constexpr std::size_t dimension(const rgb&) noexcept { return 3; }
static constexpr float at(const rgb& c, std::size_t i) noexcept { return i == 0 ? c.r : i == 1 ? c.g : c.b; }
};
namespace {
// A metric of the caller's own with only operator(): the taxicab distance rounded to whole units
struct rounded_taxicab {
template <mt::point A, mt::point B>
constexpr double operator()(const A& a, const B& b) const noexcept
{
double s = 0;
for (std::size_t i = 0; i < mt::dimension(a); ++i) {
const double d = static_cast<double>(mt::coordinate(a, i)) - static_cast<double>(mt::coordinate(b, i));
s += d < 0 ? -d : d;
}
return std::floor(s + 0.5);
}
};
// A metric of the caller's own built coordinate by coordinate: Euclidean with green counted twice (the eye is most
// sensitive to it). term / combine make it decomposable; reduced / expand / contract make it reducible.
struct weighted_colour {
static constexpr bool is_metric = true;
template <typename T>
constexpr T term(std::size_t axis, T d) const noexcept { return (axis == 1 ? T(2) : T(1)) * d * d; }
template <typename T>
constexpr T combine(T acc, T t) const noexcept { return acc + t; }
template <typename T>
T expand(T r) const noexcept { return std::sqrt(r); }
template <typename T>
constexpr T contract(T d) const noexcept { return d * d; }
template <mt::point A, mt::point B>
constexpr mt::distance_t<A, B> reduced(const A& a, const B& b) const noexcept { return mt::accumulate(*this, a, b); }
template <mt::point A, mt::point B>
mt::distance_t<A, B> operator()(const A& a, const B& b) const noexcept { return expand(reduced(a, b)); }
};
// distance_for unlocks the brute-force search, for any metric and any points
template <typename M, typename Q, typename P>
requires mt::distance_for<M, Q, P>
std::size_t nearest(const M& m, const Q& q, const std::vector<P>& points)
{
std::size_t best = 0;
for (std::size_t i = 1; i < points.size(); ++i)
if (mt::reduced_distance(m, q, points[i]) < mt::reduced_distance(m, q, points[best]))
best = i;
return best;
}
// decomposable unlocks the early-exit scan: count the points within a radius, stopping each sum once it is over
template <typename M, typename Q, typename P>
requires mt::decomposable<M, mt::distance_t<Q, P>>
std::size_t within(const M& m, const Q& q, const std::vector<P>& points, double radius)
{
std::size_t n = 0;
const auto bound = mt::contract(m, static_cast<mt::distance_t<Q, P>>(radius));
for (const auto& p : points)
n += mt::accumulate_within(m, q, p, bound) <= bound ? 1 : 0;
return n;
}
// true_metric unlocks pruning by the triangle inequality: d(q, p) >= |d(q, pivot) - d(pivot, p)|
template <typename M, typename Q, typename P>
requires mt::true_metric<M> && mt::distance_for<M, Q, P>
double lower_bound_via(const M& m, const Q& q, const P& pivot, double pivot_to_p)
{
return std::abs(static_cast<double>(m(q, pivot)) - pivot_to_p);
}
} // namespace

Relationships. metric/minkowski.hpp, metric/angular.hpp, metric/binary.hpp, metric/geodesic.hpp, metric/statistical.hpp, metric/string.hpp (the metrics), metric/sets.hpp (metrics between sets of points), containers/kd_tree.hpp and containers/ann_forest.hpp (structures that search with them), linalg/fixed.hpp. Group: snicholls-core.

Guarantees. Everything is constexpr and noexcept when the point's coordinate read and the metric's operations are. No allocation.

Errors. None: a type that is not a point, or a metric that lacks a capability a structure needs, fails to compile, with the concept named in the message.

Performance. Not benchmarked: the traits are inline reads; the metrics' benchmarks are in their headers.

Tests and demos. tests/metric/concepts_test.cpp, demos/metric/concepts_demo.cpp.

Dependencies. <array>, <concepts>, <cstddef>, <span>, <type_traits>, <utility>, linalg/fixed.hpp.

Known issues. std::vector<bool> is not a point (its operator[] returns a proxy); pack bits into words and use metric/binary.hpp.

Status. Experimental, new in 0.20.0.
