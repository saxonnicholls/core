Detailed Description

snicholls::metric::hamming, jaccard and mismatches: distances between bit vectors packed in unsigned words, and between sequences by the coordinates that differ.

Overview. Binary codes (locality-sensitive hashes, binarised embeddings, Bloom-style signatures, feature sets) are compared bit by bit. Here a bit vector is any point whose coordinates are unsigned integers (an std::array<std::uint64_t, 4> is 256 bits); the words are compared with std::popcount of their XOR, AND and OR.

Metric m(a, b) is_metric
hamming the number of differing bits, Σ popcount(aᵢ ⊕ bᵢ) yes

| jaccard | 1 - |a ∧ b| / |a ∨ b| over the set bits (Tanimoto distance); 0 for two empty sets | yes | | mismatches | the number of coordinates that differ, for points of any coordinate type | yes |

mismatches is the Hamming distance between sequences (strings, categorical vectors); hamming is the Hamming distance between their bits. Integer coordinates compare by value across signedness (std::cmp_equal), so -1 and 0xFFFFFFFFu differ.

// 128-bit codes (a locality-sensitive hash, say) as two 64-bit words; any unsigned words, any point kind
using code = std::array<std::uint64_t, 2>;
const code a{0b1011, 0xFF00};
const std::vector<std::uint16_t> b{0b0110, 0x0F00}; // the same bits, in narrower words
// XOR 0b1101, 0xF000: 7 bits differ; AND has 5 bits set, OR 12 (python3 bin().count)
std::puts("Codes {0b1011, 0xFF00} and {0b0110, 0x0F00}");
check(mt::hamming{}(a, b) == 7, "hamming = 7 differing bits", double(mt::hamming{}(a, b)));
check(mt::jaccard{}(a, b) == 1.0 - 5.0 / 12.0, "jaccard = 1 - 5/12", mt::jaccard{}(a, b));
// The nearest stored code by Hamming distance
const std::vector<code> stored{{0, 0}, {0b1111, 0xFF00}, {~0ull, ~0ull}};
std::size_t best = 0;
for (std::size_t i = 1; i < stored.size(); ++i)
if (mt::hamming{}(a, stored[i]) < mt::hamming{}(a, stored[best]))
best = i;
check(best == 1 && mt::hamming{}(a, stored[1]) == 1, "nearest stored code: {0b1111, 0xFF00}, 1 bit away", double(best));
// mismatches: the Hamming distance between sequences of any coordinate type
check(mt::mismatches{}(std::string_view("karolin"), std::string_view("kathrin")) == 3, "mismatches(karolin, kathrin) = 3", 3.0);
const std::array<int, 4> colours{0, 2, 1, 1}, other{0, 1, 1, 2};
check(mt::mismatches{}(colours, other) == 2, "mismatches of categorical vectors = 2", 2.0);

Relationships. metric/concepts.hpp, containers/ann_forest.hpp (its bit-sampling splits), containers/bloom_filter.hpp (sets as bits). Group: snicholls-core.

Guarantees. constexpr, noexcept when the coordinate reads are, no allocation. hamming and mismatches return a count (std::size_t), jaccard a double.

Errors. None. Points of different lengths are a precondition violation.

Performance. Not benchmarked: one popcount per word.

Tests and demos. tests/metric/binary_test.cpp, demos/metric/binary_demo.cpp.

Dependencies. <bit>, <concepts>, <cstddef>, <type_traits>, <utility>, metric/concepts.hpp.

Known issues. Signed words are rejected (their bits are an implementation's business): use unsigned ones.

Status. Experimental, new in 0.20.0.
