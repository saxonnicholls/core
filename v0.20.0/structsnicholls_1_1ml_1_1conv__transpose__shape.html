Detailed Description

template<std::size_t Rank>
requires (Rank >= 1 && Rank <= 3)
struct snicholls::ml::conv_transpose_shape< Rank >

The shape of a transposed convolution of rank Rank: output (in - 1) s - 2p + d (k - 1) + 1, weights [in_channels][out_channels / groups][kernel...].

Template Parameters
RankThe spatial dimensions: 1, 2 or 3.
