Detailed Description

template<std::size_t MaxDigits>
struct snicholls::ml::llama3_like_pattern< MaxDigits >

Llama 3's pattern (also DBRX, Smaug, ChatGLM 4), digits at most MaxDigits at a time: 

(?i:'s|'t|'re|'ve|'m|'ll|'d)|[^\r\n\p{L}\p{N}]?\p{L}+|\p{N}{1,3}| ?[^\s\p{L}\p{N}]+[\r\n]*|\s*[\r\n]+|\s+(?!\S)|\s+

With MaxDigits == 1 it is Qwen 2's pattern (qwen2_pattern).

Template Parameters
MaxDigitsThe digits in one piece: 3 for Llama 3, 1 for Qwen 2.
