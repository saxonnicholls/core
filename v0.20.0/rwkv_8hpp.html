Detailed Description

snicholls::ml RWKV's sequence mixing: token shift, RWKV-6's WKV with its bonus, and RWKV-7's WKV (the generalised delta rule), each forward over a sequence, backward, and one token at a time for decoding.

Overview. RWKV mixes tokens twice: a token shift, which interpolates each channel between the token and the one before it (lerp(x_t, x_{t-1}, μ) = x_t + (x_{t-1} - x_t) ⊙ μ; RWKV-6, Peng et al., 2024, eq. 3; RWKV-7, Peng et al., 2025, eq. 3; llama.cpp's graphs compute it as (x_prev - x) · μ + x), and a WKV recurrence over a matrix state per head, here laid out N key rows of P value channels (N = P, the head size).

RWKV-6 (eq. 19 and its recurrent form, eqs. 21-22): the state is read before it is updated, with a per-channel bonus u for the current token, and the decay w_t = exp(-exp(d_t)) (eq. 18) is passed as its logarithm lw = -exp(d): 

o_t[p] = Σ_n r_t[n] · (v_t[p] k_t[n] · u[n] + S_{t-1}[n][p]),     S_t[n][p] = S_{t-1}[n][p] · e^{lw_t[n]} + v_t[p] k_t[n]

RWKV-7 (eq. 17, wkv_t = wkv_{t-1}(diag(w_t) - κ̂_tᵀ(a_t ⊙ κ̂_t)) + v_tᵀ k̃_t, written here for the transposed state with ggml's general a and b: the model passes a = -κ̂ and b = κ̂ ⊙ a_t), its decay w = exp(-e^{-0.5} sigmoid(d)) (eq. 12) also passed as its logarithm: 

sa[p] = Σ_n a_t[n] S_{t-1}[n][p],   S_t[n][p] = S_{t-1}[n][p] e^{lw_t[n]} + v_t[p] k_t[n] + sa[p] b_t[n],   o_t[p] = Σ_n S_t[n][p] r_t[n]

Both are llama.cpp's GGML_OP_RWKV_WKV6 and GGML_OP_RWKV_WKV7 (commit 39039aa, ggml_compute_forward_rwkv_wkv6_f32 and _wkv7_f32's scalar paths: the same products in the same order, tested against transcriptions), with the decay as its logarithm and the state transposed.

  • token_shift(backend, xs, mu, out, sequences, states), token_shift_backward(...), token_shift_step(...).
  • wkv6_forward<C>, wkv6_backward<C>, wkv6_step<C>; wkv7_forward<C>, wkv7_backward<C>, wkv7_step<C>.
// One head of 2 channels, chunks of 2
constexpr ml::transformer_config C = [] {
auto c = ml::tiny_mamba2;
c.mixer = ml::mixer_kind::rwkv7;
c.mixer_heads = c.mixer_groups = 1;
c.mixer_state = c.mixer_head_dim = 2;
c.conv_width = 0;
c.mixer_chunk = 2;
return c;
}();
constexpr std::size_t n = 3, S = ml::wkv_state_size(C);
// Token shift: each channel halfway between the token and the one before
const std::array<double, n * 2> x{2, 4, 6, 8, 10, 12};
const std::array<double, 2> mu{0.5, 0.5};
std::array<double, n * 2> shifted{};
ml::token_shift(backend, std::span<const double>(x), std::span<const double>(mu), std::span<double>(shifted));
// RWKV-6: write value (1, 0) under key e0 at token 0, read with r = e0 at tokens 0-2; no decay; bonus u = 3
const std::array<double, n * 2> r{1, 0, 1, 0, 1, 0}, k{1, 0, 0, 0, 0, 0}, v{1, 0, 0, 0, 0, 0}, lw{0, 0, 0, 0, 0, 0};
const std::array<double, 2> u{3, 3};
std::array<double, n * 2> o6{};
std::array<double, S> s6{};
ml::wkv6_forward<C>(backend, ml::wkv6_inputs<double>{r, k, v, lw, u}, std::span<double>(o6), 1, std::span<double>(s6));
// RWKV-7: write (1, 0) under e0, then replace it with (0, 1): a = -e0, b = e0 removes what e0 held first
const std::array<double, n * 2> k7{1, 0, 1, 0, 0, 0}, v7{1, 0, 0, 1, 0, 0}, a7{0, 0, -1, 0, 0, 0}, b7{0, 0, 1, 0, 0, 0};
std::array<double, n * 2> o7{};
std::array<double, S> s7{};
ml::wkv7_forward<C>(backend, ml::wkv7_inputs<double>{r, lw, k7, v7, a7, b7}, std::span<double>(o7), 1, std::span<double>(s7));
// Decoding the next token from RWKV-7's state: it reads (0, 1)
const std::array<double, 2> r4{1, 0}, zero{0, 0};
std::array<double, 2> o4{};
ml::wkv7_step<C>(ml::wkv7_inputs<double>{r4, zero, zero, zero, zero, zero}, std::span<double>(o4), std::span<double>(s7));
// Training: RWKV-6's gradient in the bonus from the outputs' sum
const std::array<double, n * 2> dout{1, 1, 1, 1, 1, 1};
std::array<double, n * 2> dr{}, dk{}, dv{}, dlw{};
std::array<double, 2> du{};
std::array<double, ml::recurrence_checkpoints(n, C.mixer_chunk) * S> checkpoints{};
std::array<double, S> s0{}, dstate{};
ml::wkv6_forward<C>(backend, ml::wkv6_inputs<double>{r, k, v, lw, u}, std::span<double>(o6), 1, std::span<double>(s0),
std::span<double>(checkpoints));
std::array<double, ml::wkv_backward_work<C, double>()> work{};
ml::wkv6_backward<C>(backend, ml::wkv6_inputs<double>{r, k, v, lw, u}, std::span<const double>(dout),
ml::wkv6_gradients<double>{dr, dk, dv, dlw, du}, 1, std::span<const double>(checkpoints), std::span<double>(dstate),
std::span<double>(work));

Relationships. ml/recurrence.hpp (the driver), ml/gla.hpp (RWKV-6 is gated linear attention read before the update, plus the bonus), ml/delta_rule.hpp (RWKV-7 generalises it), ml/short_conv.hpp (token shift is a two-tap convolution). Group: snicholls-core.

Implementations. The recurrent forms; the token shift on rows.

Guarantees. constexpr, no allocation, the sums in ggml's order. Decoding gives the sequence forward's bits at every position (tested). Every row's input gradients are written; RWKV-6's u and the token shift's μ are parameters, added into.

Errors. Preconditions, asserted: a configuration with one key head per head and square heads (valid_mixer), the views rows · H · N, u and μ of their widths.

Performance. benchmarks/ml/rwkv_benchmark.cpp, 256 tokens of 8 heads of 64 (Release, AppleClang 17, Intel Xeon W-3245, macOS, 2026-11-19): RWKV-6 4.15 ms against 4.30 ms by hand, RWKV-7 5.61 ms against 5.56 ms (each pair checked to the bit). BENCHMARKS.md has the current numbers.

Tests and demos. tests/ml/rwkv_test.cpp, demos/ml/rwkv_demo.cpp.

Dependencies. <array>, <cassert>, <cstddef>, <span>, <type_traits>, math/constexpr_math.hpp, ml/recurrence.hpp, ml/transformer_config.hpp.

Known issues. No chunked form (RWKV-7's paper gives only the closed form, eq. 18, and says prefill is chunked; RWKV-6's chunked form is ml/gla.hpp's with a strictly causal block and the bonus), and no layer: RWKV-6's data-dependent interpolation and low-rank decay (eqs. 14-17) and RWKV-7's in-context learning rate, value residual and gate (eqs. 4-14, 20-22) are a layer's, not here.

Status. Experimental, new in 0.17.0.
