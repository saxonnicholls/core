Detailed Description

snicholls::ml::wordpiece_encode: BERT's tokenizer, its basic tokenisation (control characters removed, accents stripped, lowercased, punctuation and CJK ideographs split off) and greedy longest-match-first WordPiece with "##" continuations and [UNK]; and wordpiece_decode.

Overview. BERT and its descendants (BGE, MiniLM, E5) tokenize in two steps, done here in one pass over the text with no allocation:

  1. Basic tokenisation (Hugging Face's BertNormalizer and BertPreTokenizer): drop NUL, U+FFFD and control characters; with strip_accents, decompose canonically and drop the nonspacing marks; with lowercase, lowercase; split at whitespace, and make each punctuation character (ASCII punctuation or \p{P}) and each CJK ideograph a word of its own.
  2. WordPiece: each word is cut greedily into the longest vocabulary pieces from the left, every piece after the first spelled with the continuation prefix ("##ing"). A word that cannot be cut, or that is longer than max_word_chars, is the unknown token.

The vocabulary convention is an option: Hugging Face's vocab.txt writes word-initial pieces bare and continuations with "##" (the defaults); GGUF writes word-initial pieces with "▁" and continuations bare (word_prefix = "▁", continuation_prefix = "", and llama.cpp sets no word limit).

constexpr std::array<std::string_view, 7> pieces{"[UNK]", "[CLS]", "un", "##aff", "##able", "cafe", "!"};
constexpr auto encode(std::string_view text)
{
std::array<std::uint32_t, 7> order{};
ml::build_token_index(pieces, order);
const ml::token_trie vocab{pieces, order};
std::array<std::uint32_t, 32> out{};
std::array<char, 64> word{};
const std::size_t n = ml::wordpiece_encode(text, vocab, 0, {}, out, word).unwrap();
return std::pair{out, n};
}
// "UnAffable Café!" -> un ##aff ##able, cafe, !
static_assert(encode("UnAffable Caf\xC3\xA9!").second == 5 && encode("UnAffable Caf\xC3\xA9!").first[3] == 5);

Relationships. ml/unicode.hpp (categories, decompose, to_lower), ml/token_trie.hpp (the vocabulary; the longest match is one walk of it), ml/sentencepiece.hpp's decoding for comparison. Group: snicholls-core.

Implementations. One. The normalisation follows Hugging Face's rules, which llama.cpp approximates (llama.cpp strips every mark, \p{M}, and keeps unassigned code points; Hugging Face strips only nonspacing marks and drops \p{C} including unassigned).

Guarantees. constexpr when the callables are. No allocation: the caller's output and word scratch. Complexity: linear in the text times the trie walk (O(L log V) per piece of L bytes).

Errors. wordpiece_error::output_too_small (the tokens do not fit), scratch_too_small (a normalised word does not fit; wordpiece_scratch_size(text.size()) bytes always suffice), unknown_id (decoding an id that piece does not know).

Performance. Not benchmarked separately; the work is token_trie's walk, benchmarked in benchmarks/ml/token_trie_benchmark.cpp.

Tests and demos. tests/ml/wordpiece_test.cpp: Hugging Face's convention on a small vocabulary; accents, CJK, control characters, U+0130, long words; GGUF's convention; decoding; the errors. tests/ml/tokenizer_test.cpp: token for token llama.cpp's test vectors for BGE (bert-bge) on a committed subset of its vocabulary. demos/ml/wordpiece_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <span>, <string_view>, snicholls/core/result.hpp, ml/token_trie.hpp, ml/unicode.hpp.

Known issues. Strip-accents keeps canonical order without reordering the marks it keeps; only spacing marks with a nonzero combining class (rare, e.g. U+1D165) could differ from NFD. Hugging Face's decoder also removes spaces before punctuation (cleanup); wordpiece_decode does not.

Status. Experimental, new in 0.17.0.
