Detailed Description

snicholls::tracking::gaussian<T, N> and the measures between states: Mahalanobis distance, log-likelihood, Hellinger distance, KL divergence, the χ² gate and the confidence ellipse.

Overview. A Gaussian state is a mean and a covariance. Estimation keeps asking how far a measurement is from a prediction, in units of the prediction's uncertainty, and how alike two estimates are. These functions answer that on fixed-size values:

  • gaussian<T, N>: mean and covariance, an aggregate, trivially copyable.
  • squared_mahalanobis(r, S): rᵀ S⁻¹ r by Cholesky; whitened_squared_norm(r, L) when L = cholesky(S) is in hand; mahalanobis is its root.
  • log_likelihood(r, S): log N(r; 0, S), the association score of PDA and of GNN's likelihood costs.
  • euclidean, euclidean_weighted: metric::euclidean and metric::weighted<2> on fixed_vectors (the metric/ area has every other distance, on any point type).
  • squared_hellinger(a, b), hellinger(a, b), kl_divergence(p, q) between two Gaussians.
  • gate_threshold(probability, m) = chi_square_quantile(probability, m), and in_gate(d², threshold).
  • confidence_ellipse(P, k): the semi-axes and orientation of the k-sigma ellipse of a 2 x 2 covariance (a probability plume for a display).

Residuals with angle components are formed first with geometry::residual<Kinds>.

// A predicted position and its innovation covariance S (prediction plus sensor noise), metres
const tr::gaussian<double, 2> predicted{{{100, 50}}, {{4, 1, 1, 3}}};
const double gate = tr::gate_threshold(0.99, 2); // 9.21: a true measurement passes 99% of the time
// Two candidate measurements: one close in the units of S, one far
const v2 near_z{{101, 52}}, far_z{{106, 50}};
const double d_near = *tr::squared_mahalanobis(near_z - predicted.mean, predicted.covariance);
const double d_far = *tr::squared_mahalanobis(far_z - predicted.mean, predicted.covariance);
const bool near_in = tr::in_gate(d_near, gate), far_in = tr::in_gate(d_far, gate);
std::printf(" gate %.3f: near d2 %.3f (%s), far d2 %.3f (%s)\n", gate, d_near, near_in ? "in" : "out", d_far, far_in ? "in" : "out");
// The near one's association score, and the 95% ellipse of the prediction for a display
const double score = *tr::log_likelihood(near_z - predicted.mean, predicted.covariance);
const auto plume = tr::confidence_ellipse(predicted.covariance, std::sqrt(tr::gate_threshold(0.95, 2)));
std::printf(" log-likelihood %.4f; 95%% ellipse %.3f x %.3f m at %.1f deg\n", score, plume.semi_major, plume.semi_minor, plume.angle * 180 / std::numbers::pi);

Relationships. linalg/fixed.hpp (Cholesky), math/constexpr_math.hpp (chi_square_quantile), geometry/angle.hpp (residuals). Stone Soup's measures module (Euclidean, EuclideanWeighted, SquaredMahalanobis, Mahalanobis, SquaredGaussianHellinger, GaussianHellinger, KLDivergence). Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation. gaussian<double, N> has the size of its N + N² doubles and is trivially copyable.

Errors. The functions that factorise a covariance return linalg::error::not_positive_definite when it is not (numerically) positive definite.

Performance. Not benchmarked on its own: tracking/kalman.hpp's benchmark covers the same Cholesky.

Tests and demos. tests/tracking/gaussian_test.cpp, demos/tracking/gaussian_demo.cpp.

Dependencies. <numbers>, linalg/fixed.hpp, math/constexpr_math.hpp, metric/minkowski.hpp, result.hpp.
