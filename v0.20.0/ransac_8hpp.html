Detailed Description

snicholls::stats::ransac and ransac_iterations: a robust fit of the caller's model, ignoring the data that do not fit it.

Overview. Least squares is ruined by a few wrong correspondences (two tracks associated in error, a mismatched landmark). RANSAC fits the model to many random minimal samples, scores each fit by how many data lie within a threshold of it, and keeps the best. The model is the caller's: ransac<S> needs

  • fit(std::span<const std::size_t> sample), which returns something that tests as a model and dereferences to one (std::optional, result): the fit to S data, or nothing for a degenerate sample;
  • error(model, i), the residual of datum i (in the threshold's units).

It returns the best model, its inlier count and its inliers' indices. A final least-squares fit on the inliers is the caller's call (align_2d on them, say). The number of tries adapts: after each improvement it drops to ransac_iterations(confidence, inlier fraction, S), never above max_iterations.

// The model: align_2d on a minimal sample of two pairs. Its result tests as a model and dereferences to one
auto fit = [&](std::span<const std::size_t> s) {
const std::array<v2, 2> from{a[s[0]], a[s[1]]}, to{b[s[0]], b[s[1]]};
return geo::align_2d<double>(from, to);
};
// The residual of pair i under a model, in metres
auto residual = [&](const geo::transform_2d<double>& x, std::size_t i) { return la::norm(b[i] - x.apply(a[i])); };
std::vector<std::size_t> inliers(a.size());
const auto r = st::ransac<2>(a.size(), fit, residual, 0.1, inliers, g);
// r->model is the best two-pair fit; inliers[0 .. r->inliers) are the pairs within 0.1 m of it
// The final least-squares fit on every inlier
std::vector<v2> ia, ib;
for (std::size_t k = 0; r && k < r->inliers; ++k) {
ia.push_back(a[inliers[k]]);
ib.push_back(b[inliers[k]]);
}
const auto refined = geo::align_2d<double>(ia, ib);

Relationships. stats/random.hpp (uniform_index), geometry/alignment.hpp (a typical model), math/constexpr_math.hpp. Group: snicholls-core.

Guarantees. constexpr, no allocation (the caller passes the inlier buffer). noexcept exactly when the generator, fit and error are. Reproducible for a given generator state. Ties in the inlier count go to the lower sum of inlier residuals.

Errors. ransac_error::too_few_data: fewer than S data, or an inlier buffer shorter than the data. ransac_error::no_model: every sample was degenerate, or no model had S inliers.

Performance. Not benchmarked: the caller's fit and error dominate.

Tests and demos. tests/stats/ransac_test.cpp, demos/stats/ransac_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <span>, <type_traits>, <utility>, math/constexpr_math.hpp, result.hpp, stats/random.hpp.

Known issues. Samples are drawn with replacement across tries; within a try the S indices are distinct.

Status. Experimental, new in 0.19.0.
