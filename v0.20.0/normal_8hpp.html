Detailed Description

snicholls::stats::normal_sampler: standard normal draws from a full-range generator, with interchangeable methods (the inverse CDF, Box-Muller).

Overview. Gaussian draws for Monte Carlo, random test matrices (linalg::truncated_svd's gaussian_sketch) and noise. Different jobs want different methods, so the method is a value the caller chooses, behind one concept:

  • normal_sampler<S, G>: s(g) returns one standard normal double from a full_range_generator g.
  • normal_inverse_cdf: math::normal_quantile of one uniform, (2i + 1) 2^-53 for 52 random bits i: exact, inside (0, 1) and symmetric about 1/2, so the draws reach ±8.21 and never infinity. One generator call per draw, stateless, monotone in the uniform (so it maps a quasi-random point to a quasi-random normal), and the same on every platform. The default.
  • normal_box_muller: two uniforms give two independent normals, sqrt(-2 ln u1) (cos, sin)(2π u2); the second is kept for the next call, so a sampler is stateful (copy it per stream).

A method of the caller's own (a ziggurat, a device's generator, an antithetic or moment-matched pair) is any type that satisfies normal_sampler, and drops in wherever one is taken.

// Any method is a value behind one concept, so the code that draws does not change when the method does
template <st::normal_sampler<st::wyrand> S>
void moments(S sampler, double& mean, double& variance, int n)
{
st::wyrand g(7); // the same generator, the same seed
double m1 = 0, m2 = 0;
for (int i = 0; i < n; ++i) {
const double z = sampler(g);
m1 += z;
m2 += z * z;
}
mean = m1 / n;
variance = m2 / n - mean * mean;
}
// A method of the caller's own: draws clipped at 4 sigma (a truncated normal for stress scenarios, say)
struct clipped {
st::normal_inverse_cdf base{};
double operator()(st::wyrand& g) const
{
const double z = base(g);
return z > 4 ? 4 : z < -4 ? -4 : z;
}
};

Relationships. stats/random.hpp (the generators, uniform_real), math/constexpr_math.hpp (normal_quantile, log, sin, cos), linalg/randomized_svd.hpp (gaussian_sketch). Group: snicholls-core.

Implementations. normal_inverse_cdf: one call of the generator and one normal_quantile (a rational approximation refined by Halley's step) per draw. normal_box_muller: two calls, a logarithm, a square root, a sine and a cosine per pair.

Guarantees. constexpr, noexcept when the generator is, no allocation; the same seed gives the same draws on every platform for normal_inverse_cdf (its arithmetic is core's); normal_box_muller uses core's log, sin and cos, which follow <cmath> at run time, so its last bits may differ between standard libraries. Neither draw is ever infinite: the uniforms stay inside (0, 1).

Errors. None.

Performance. Each against the same draws written by hand over the same stream, after a bit-for-bit check, a million draws (benchmarks/stats/normal_benchmark.cpp; Release, Apple clang 17, Xeon W-3245, 2026-11-16): the inverse CDF 21.5 million draws a second (by hand 21.2), Box-Muller 82.8 million (by hand 81.3). Box-Muller is the faster by four; the inverse CDF is the default for being the same on every platform and monotone.

Tests and demos. tests/stats/normal_test.cpp, demos/stats/normal_demo.cpp.

Dependencies. <concepts>, <cstdint>, math/constexpr_math.hpp, stats/random.hpp.

Known issues. Draws are double; convert for float.

Status. Experimental, new in 0.9.0.
