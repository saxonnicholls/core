Detailed Description

snicholls::ml::self_attention_head and its backward pass: one self-attention head over a sequence (causal, bidirectional or block-causal), from its own Q, K and V projections, with no configuration and no cache.

Overview. The textbook head (Vaswani et al., 2017), on its own: for tokens x_0 ... x_{n-1} of DModel channels and projections Wq, Wk, Wv of DHead x DModel,

  1. q_t = Wq x_t, k_t = Wk x_t, v_t = Wv x_t (plus biases), from one prepared input per token;
  2. optionally RoPE at position t on q_t and k_t;
  3. out_t = softmax(q_t · K / sqrt(DHead)) · V over the keys attention_window(t, window) allows: causal, and within the last window positions if window is not 0; or, with mask, over every key (bidirectional) or whole blocks of block (block-causal), as attention_keys says (TRAINING.md T11).

It is the unit to study, test, train or put on a device: no transformer_config, no KV cache, no output projection, no other heads. The projections land in self_attention_activations, buffers the caller owns, because they are what a backward pass reads (with the log-sum-exp per position, as flash attention keeps it, never the n x n probabilities). For a model's layer, with grouped-query heads, QK norm, a soft cap, a cache and decoding one token at a time, use attention_forward (ml/attention_layer.hpp).

The weights are any weight_matrix: dense rows of float, double or bfloat16, or quantised blocks.

self_attention_head_backward is its backward pass, from what the forward saved: attend_backward per position from the log-sum-exp, rope_inverse, then linear_backward through the projections. It writes the gradients in the queries, keys and values (self_attention_gradients, the caller's buffers) and adds into those of the weights, the biases and the tokens, so micro-batches and heads sharing an input accumulate. Only dense weights train: a quantised head's backward is a compile error.

// Five tokens of 4 channels; a head of 2 channels
constexpr std::size_t d_model = 4, d_head = 2, n = 5;
std::array<float, n * d_model> x{};
for (std::size_t i = 0; i < x.size(); ++i)
x[i] = std::sin(0.7f * static_cast<float>(i));
// Wq and Wk read channels 0 and 1; Wv reads channels 2 and 3
const std::array<float, d_head * d_model> wq{1, 0, 0, 0, 0, 1, 0, 0};
const std::array<float, d_head * d_model> wv{0, 0, 1, 0, 0, 0, 0, 1};
const ml::self_attention_weights<ml::dense_weights<float>> w{{wq, d_head, d_model}, {wq, d_head, d_model},
{wv, d_head, d_model}};
// The caller owns what a backward pass would read: Q, K, V and each position's log-sum-exp
std::array<float, n * d_head> q{}, k{}, v{}, out{};
std::array<float, n> lse{};
const ml::self_attention_activations<float> act{q, k, v, lse};
// Causal: position t attends to tokens 0..t
ml::self_attention_head<d_model, d_head>(w, x, act, out);
// A sliding window of 2: position t attends to t - 1 and t
std::array<float, n * d_head> windowed{};
ml::self_attention_head<d_model, d_head>(w, x, act, windowed, 2);
// RoPE from a table the compiler builds
static constexpr ml::rope_table<float, 8, d_head> table{};
std::array<float, n * d_head> rotated{};
ml::self_attention_head<d_model, d_head>(w, x, act, rotated, 0, table);
// Training: run the causal head again (act now holds its Q, K, V and log-sum-exps), then for the loss
// L = 1/2 |out - target|^2 the gradient in out is out - target
ml::self_attention_head<d_model, d_head>(w, x, act, out);
std::array<float, n * d_head> dout{};
for (std::size_t i = 0; i < dout.size(); ++i)
dout[i] = out[i] - 0.25f; // a target of 0.25 everywhere
// Q, K, V gradients are written; the weights', biases' and tokens' are added into, so zero them first
std::array<float, n * d_head> dq{}, dk{}, dv{};
std::array<float, d_head * d_model> dwq{}, dwk{}, dwv{};
std::array<float, n * d_model> dx{};
const ml::self_attention_gradients<float> grads{dq, dk, dv, dwq, dwk, dwv};
ml::self_attention_head_backward<d_model, d_head>(w, x, act, out, dout, dx, grads);
// One step of gradient descent on Wv lowers the loss
std::array<float, d_head * d_model> wv2 = wv;
for (std::size_t i = 0; i < wv2.size(); ++i)
wv2[i] -= 0.5f * dwv[i];
const ml::self_attention_weights<ml::dense_weights<float>> stepped{w.q, w.k, {wv2, d_head, d_model}};
std::array<float, n * d_head> after{};
ml::self_attention_head<d_model, d_head>(stepped, x, act, after);

Relationships. ml/linear.hpp (the projections), ml/attention.hpp (attend, attention_window), ml/rope.hpp (rope_table is a rope source; no_rope), ml/attention_layer.hpp (the configured layer). Group: snicholls-core.

Implementations. One. Each position's attention depends only on the projections, so positions may be split across workers once the projections are written.

Guarantees. constexpr, no allocation, sizes of a head known at compile time. O(n · 3 · DHead · DModel) for the projections and O(n · visible · DHead) for attention: n² / 2 · DHead causally, n · window · DHead with a window. Each position's output is attend's to the bit, so it equals the same head decoded one token at a time.

Errors. Preconditions, asserted: the input is a whole number of tokens; the matrices are DHead x DModel; q, k, v and out have n · DHead elements, lse none or n; biases are empty or DHead; the rope source covers position n - 1; the backward pass needs the log-sum-exps saved, and its gradient buffers sized as the activations. An odd DHead with RoPE is a compile error.

Performance. Against the same projections and recurrence written by hand (benchmarks/ml/self_attention_benchmark.cpp), one causal float head of 64 channels over tokens of 128, the bits identical: within 6% at 128 tokens (3.4 ms against 3.2 ms) and 4% at 512 (23.1 ms against 22.2 ms) (Xeon W-3245, Release, Apple clang 17, 2026-11-14, one thread). The backward pass, the same way: within 10% at 128 tokens (1.94 ms against 1.76 ms) and level at 512 (20.8 ms against 20.9 ms). Both keep every sum in written order (-ffp-contract=off, no reassociation), so neither is vectorised across a reduction.

Tests and demos. tests/ml/self_attention_test.cpp, demos/ml/self_attention_demo.cpp.

Dependencies. <cassert>, <concepts>, <cstddef>, <span>, snicholls/core/math/constexpr_math.hpp, ml/attention.hpp, ml/linear.hpp, ml/rope.hpp, ml/row.hpp.

Known issues. The projections are matrix-vector products, one token at a time, as linear does them; a matrix-matrix backend for long sequences is to come. The score scale is 1 / sqrt(DHead), rounded once to T.

Status. Experimental, new in 0.9.0; mask and block new in 0.16.0.

The backward pass of self_attention_head, from what its forward pass saved.

Per position, attend_backward from the saved log-sum-exp gives the gradients in the query, and adds into the keys' and values' it saw; RoPE's are undone by rope_inverse; linear_backward takes them through the three projections. No n x n probabilities are formed.
