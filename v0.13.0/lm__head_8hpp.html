Detailed Description

snicholls::ml::lm_head_loss: a language model's loss over a sequence, the head's logits and the cross-entropy fused, and its backward pass into the hidden states and the head (tied or not).

Overview. The end of a language model in training: each position's final hidden state h_t becomes logits W h_t over the vocabulary, and the loss is the mean cross-entropy against the next tokens. The whole n x V matrix of logits is never stored: one row of V is computed, turned in place into its gradient (cross_entropy_with_gradient, llm.c's fused classifier), and taken back through the head (linear_backward) before the next position's. Memory is one row of logits whatever the sequence's length.

  • lm_head_loss(head, hs, targets, logits): the mean loss, for evaluation.
  • lm_head_loss(head, hs, targets, logits, dhs, dhead): the same loss, adding the gradients of the mean into the hidden states' and the head's.

A tied head (GPT-2, nanochat's option) is the embedding table itself, V rows of d_model, viewed as dense_weights{table, V, d_model}; its gradient then adds into the embedding's, beside embedding_backward's.

// A vocabulary of 5 tokens, 3 channels, one table for the embedding and the head (tied, as GPT-2)
constexpr std::size_t vocab = 5, d = 3;
std::vector<float> table(vocab * d);
for (std::size_t i = 0; i < table.size(); ++i)
table[i] = 0.3f * std::sin(static_cast<float>(i));
const std::vector<std::size_t> tokens{0, 1, 2, 3}, next{1, 2, 3, 4}; // learn "the next token is one more"
std::vector<float> hs(tokens.size() * d), logits(vocab), dhs(hs.size()), dtable(table.size());
float first = 0.0f, last = 0.0f;
for (int step = 0; step < 50; ++step) {
for (std::size_t t = 0; t < tokens.size(); ++t)
ml::embed(table, tokens[t], std::span<float>(hs).subspan(t * d, d)); // here the model is the embedding alone
std::fill(dhs.begin(), dhs.end(), 0.0f);
std::fill(dtable.begin(), dtable.end(), 0.0f);
const ml::dense_weights<float> head{table, vocab, d};
const float loss = ml::lm_head_loss(head, hs, next, logits, dhs, dtable); // the head's gradient into dtable
for (std::size_t t = 0; t < tokens.size(); ++t)
ml::embedding_backward(std::span<const float>(dhs).subspan(t * d, d), tokens[t], dtable); // and the embedding's
for (std::size_t i = 0; i < table.size(); ++i)
table[i] -= 0.5f * dtable[i];
(step == 0 ? first : last) = loss;
}
// Evaluation, with the trained table, needs no gradient buffers
for (std::size_t t = 0; t < tokens.size(); ++t)
ml::embed(table, tokens[t], std::span<float>(hs).subspan(t * d, d));
const float eval = ml::lm_head_loss(ml::dense_weights<float>{table, vocab, d}, hs, next, logits);

lm_head_loss_sequence(backend, head, hs, targets, logits, losses, dhs, dhead, classes) is the batched form for training on a device: the whole sequence's logits (n x V, the caller's) as one product through a linalg backend, then cross_entropy_rows, then the gradients; the same loss to the bit through core's reference (TRAINING.md T9).

// For training on a device: the whole sequence's logits as one product through a linalg backend (here core's
// reference), then the fused classifier on every row, then the gradients; the same loss as lm_head_loss
std::vector<float> all_logits(tokens.size() * vocab), losses(tokens.size()), dhs2(hs.size()), dtable2(table.size());
const std::vector<std::uint32_t> next32(next.begin(), next.end());
const float seq_loss = ml::lm_head_loss_sequence(snicholls::linalg::reference, ml::dense_weights<float>{table, vocab, d}, std::span<const float>(hs),
next32, std::span<float>(all_logits), std::span<float>(losses), std::span<float>(dhs2),
std::span<float>(dtable2));
// A head padded past its classes, as GPT-2's 50,257 tokens are laid out in 50,304 rows: the logits rows as wide as
// the padding, the loss over the classes only
std::vector<float> padded(table.size() + 3 * d, 0.0f);
std::copy(table.begin(), table.end(), padded.begin());
std::vector<float> wide_logits(tokens.size() * (vocab + 3)), dhs3(hs.size()), dpadded(padded.size());
const float padded_loss = ml::lm_head_loss_sequence(snicholls::linalg::reference, ml::dense_weights<float>{padded, vocab + 3, d},
std::span<const float>(hs), next32, std::span<float>(wide_logits), std::span<float>(losses),
std::span<float>(dhs3), std::span<float>(dpadded), vocab);

Relationships. ml/linear.hpp (linear, linear_backward), ml/softmax.hpp (cross_entropy_with_gradient), ml/embedding.hpp (a tied table), ml/transformer_block.hpp (what produces the hidden states). Group: snicholls-core.

Implementations. One.

Guarantees. constexpr, no allocation (the caller's row of logits), O(n · V · d_model) for the loss and twice that with the gradients. The gradients are added into, so micro-batches accumulate.

Errors. Preconditions, asserted: hs is n · d_model for n targets; every target is below V; logits has V; dhs has hs' size and dhead the head's. With no targets the loss is 0 and nothing is added.

Performance. Not benchmarked on its own: it is linear, cross_entropy_with_gradient and linear_backward in sequence, each benchmarked or level with llm.c's loops.

Tests and demos. tests/ml/lm_head_test.cpp, demos/ml/lm_head_demo.cpp.

Dependencies. <cassert>, <cstddef>, <span>, ml/linear.hpp, ml/row.hpp, ml/softmax.hpp.

Known issues. A soft cap on the logits (Gemma 2, nanochat's 15 · tanh(x / 15)) is not built in.

Status. Experimental, new in 0.9.0.
