Detailed Description

snicholls::signal analytic signal and Hilbert transform through the FFT, as scipy.signal.hilbert, with the envelope and the backward pass.

Overview. analytic_signal(plan, x, out, work) is scipy.signal.hilbert(x): the transform of x, the negative frequencies set to zero and the positive ones doubled (bin 0 and, for even n, bin n / 2 kept), and the inverse. Its real part is x; its imaginary part is the Hilbert transform of x (a quarter-period phase shift of every component), which hilbert_transform returns alone; its magnitude is the envelope (envelope), the amplitude of a modulated carrier. analytic_signal_backward is the adjoint of the linear map from x to the analytic signal, for training through it.

// A 50-cycle carrier modulated by a 2-cycle envelope, 1,000 samples: the envelope comes back from the analytic signal.
const std::size_t n = 1000;
std::vector<double> x(n), env(n), h(n);
for (std::size_t i = 0; i < n; ++i) {
const double t = static_cast<double>(i) / static_cast<double>(n);
x[i] = (1.0 + 0.6 * m::sin(2 * m::pi * 2 * t)) * m::cos(2 * m::pi * 50 * t);
}
std::vector<cd> storage(s::fft_plan<double>::storage_size(n));
const s::fft_plan<double> plan(n, storage);
std::vector<cd> work(n + plan.work_size()), z(n);
s::analytic_signal(plan, std::span<const double>(x), std::span<cd>(z), std::span<cd>(work)); // x + i H(x)
s::envelope(plan, std::span<const double>(x), std::span<double>(env), std::span<cd>(work)); // |x + i H(x)|
s::hilbert_transform(plan, std::span<const double>(x), std::span<double>(h), std::span<cd>(work));

Relationships. signal/fft.hpp (the plan). Group: snicholls-core.

Implementations. One: the FFT of the whole signal (scipy's), so the signal is treated as periodic.

Guarantees. constexpr, no allocation (work: plan.work_size(), plus n for hilbert_transform and envelope). Complexity: two transforms of length n.

Errors. Preconditions, asserted: the plan's length is the signal's; the outputs' sizes are n.

Performance. Not benchmarked separately: two transforms (signal/fft.hpp's benchmark).

Tests and demos. tests/signal/hilbert_test.cpp (a cosine's transform is the sine, scipy's values, the envelope of a modulated tone, the backward pass by central differences), demos/signal/hilbert_demo.cpp.

Dependencies. <cassert>, <cstddef>, <span>, <type_traits>, signal/fft.hpp.

Known issues. The ends wrap around: a signal that does not fit a whole number of periods has ringing near both ends, as with scipy. Window or pad it first.

Status. Experimental, new in 0.17.0.
