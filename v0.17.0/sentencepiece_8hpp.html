Detailed Description

snicholls::ml SentencePiece BPE (Llama 1 and 2, Mistral, Phi-3): spaces escaped to "▁" with the dummy prefix, merges by score, byte fallback to <0xNN>; and decoding of SentencePiece pieces back to text, shared with Unigram.

Overview. SentencePiece's BPE model has no merge list: a pair of adjacent pieces may merge when their concatenation is in the vocabulary, and the merge with the highest score goes first (the leftmost on ties). Text reaches it with every space written as U+2581 "▁" and, with add_dummy_prefix, one more in front, so "Hello world" is "▁Hello▁world". A character no piece covers falls back to its bytes, as the tokens <0x00> to <0xFF>.

  • sentencepiece_escape(text, out, add_dummy_prefix) writes the escaped text (empty text stays empty, as llama.cpp and SentencePiece give no tokens for it).
  • sentencepiece_bpe_encode(escaped, token, score, bytes, out, scratch) merges by score: merge_encode (ml/bpe_merges.hpp) over code points with the priority minus the merged piece's score. token and score are the vocabulary's lookups; bytes is a byte_fallback, the 256 byte tokens found once.
  • byte_fallback / make_byte_fallback(token): each byte's <0xNN> token, or, failing that, the token of the byte itself (llama.cpp's rule).
  • sentencepiece_decode(tokens, piece, kind, out, options) renders tokens as text: a normal piece with "▁" as a space, a byte token as its byte, a user-defined token as written, control and unknown tokens as nothing (unless asked), and the dummy prefix's space dropped from the first piece.
// Pieces, scores and kinds by id, as a SentencePiece model lists them ("▁" is a space)
constexpr std::array<std::string_view, 8> pieces{"<unk>", "\xE2\x96\x81", "H", "i", "Hi", "\xE2\x96\x81Hi", "<0x21>", "<0x3F>"};
constexpr std::array<float, 8> scores{0, -2, -3, -3, -1, -0.5f, 0, 0};
constexpr std::array<ml::token_kind, 8> kinds{ml::token_kind::unknown, ml::token_kind::normal, ml::token_kind::normal,
ml::token_kind::normal, ml::token_kind::normal, ml::token_kind::normal,
ml::token_kind::byte, ml::token_kind::byte};
constexpr auto encode(std::string_view text)
{
std::array<std::uint32_t, 8> order{};
ml::build_token_index(pieces, order);
const ml::token_trie vocab{pieces, order};
const ml::byte_fallback bytes = ml::make_byte_fallback(vocab); // "<0x21>" is the fallback for '!'
std::array<char, 48> escaped{};
const std::size_t e = ml::sentencepiece_escape(text, escaped, true).unwrap(); // "Hi!" -> "▁Hi!"
std::array<std::uint32_t, 48> out{};
std::array<ml::merge_entry<float>, ml::merge_scratch_size(48)> scratch{};
const auto score = [](std::uint32_t id) { return scores[id]; };
const std::size_t n = ml::sentencepiece_bpe_encode(std::string_view(escaped.data(), e), vocab, score, bytes, out, scratch).unwrap();
return std::pair{out, n};
}
// "▁Hi!": "Hi" (-1) beats "▁" + "H"; then "▁" + "Hi" is "▁Hi" (-0.5); "!" has no piece, so its byte token
static_assert(encode("Hi!").second == 2 && encode("Hi!").first[0] == 5 && encode("Hi!").first[1] == 6);

Relationships. ml/bpe_merges.hpp (the merge engine), ml/token_trie.hpp (a lookup and token_kind), ml/unigram.hpp (SentencePiece's other model, which decodes the same way), ml/pretokenize.hpp (split_added_tokens, for user-defined tokens in the raw text). Group: snicholls-core.

Implementations. One, which is llama.cpp's llm_tokenizer_spm_session: a symbol that is not a token is written as bytes, and a merged symbol always is one (llama.cpp does not resegment unused pieces as SentencePiece can, and nor does this).

Guarantees. constexpr when the lookups are. No allocation. Complexity: O(n log n) in the escaped text's code points.

Errors. bpe_error::output_too_small (escaping needs sentencepiece_escaped_size(text.size()) bytes, encoding escaped.size() tokens, decoding the rendered bytes), scratch_too_small, and unknown_bytes when a byte has no token or a token's piece is unknown to piece.

Performance. Benchmarked through merge_encode (benchmarks/ml/bpe_merges_benchmark.cpp); the scoring is one lookup per candidate pair.

Tests and demos. tests/ml/sentencepiece_test.cpp: escaping, merging by score, ties, byte fallback, decoding, the errors, at compile time. tests/ml/tokenizer_test.cpp: token for token llama.cpp's test vectors for Llama (llama-spm) and Phi-3 on committed subsets of their vocabularies, and decoding back to the text. demos/ml/sentencepiece_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <span>, <string_view>, ml/bpe_merges.hpp, ml/token_trie.hpp.

Known issues. Hugging Face's decoder also strips spaces around punctuation for some models (clean_spaces); that cleanup is not here.

Status. Experimental, new in 0.17.0.
