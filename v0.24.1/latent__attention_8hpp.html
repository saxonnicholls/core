Detailed Description

snicholls::ml multi-head latent attention (MLA, DeepSeek-V2 and V3): queries, keys and values from low-rank latents with decoupled RoPE; the training passes over sequences through a linalg backend; a KV cache holding only the latent and the rotary key; and the absorbed form for decoding.

Overview. Multi-head attention caches 2 · n_h · d_h numbers per token and layer; MLA (DeepSeek-V2, 2024, section 2.1, eqs. 9 to 19) caches d_c + d_h^R (576 in DeepSeek-V3, against 32,768 for the same heads in MHA). For a token h_t: 

c^Q = RMSNorm(W^DQ h)              q^C_i, q^R_i = W^UQ c^Q, RoPE(W^QR c^Q)      (eqs. 12 to 14)
c^KV = RMSNorm(W^DKV h)            k^R = RoPE(W^KR h), one rotary key for every head  (eqs. 9, 15)
k^C_i, v_i = W^UK c^KV, W^UV c^KV  (eqs. 10, 11)
q_i = [q^C_i; q^R_i],  k_{j,i} = [k^C_{j,i}; k^R_j]                              (eqs. 16, 17)
o_i = Σ_j softmax_j(q_i · k_{j,i} · scale) v_{j,i},   u = W^O [o_1; ...; o_{n_h}]  (eqs. 18, 19)

with scale = 1 / sqrt(d_h + d_h^R), times the square of YaRN's temperature factor when the configuration rescales RoPE (DeepSeek-V3, section 4.3; latent_attention_scale). The RMS norms after the two down-projections are the papers' "additional RMS Norm layers after the compressed latent vectors" (V2 section 3.1.2, V3 section 4.2) and the released code's q_norm and kv_norm. With q_lora_rank 0 the query is projected directly (W^UQ reads h).

The weights are laid out as DeepSeek-V3's checkpoints are, so they load as they are: q_up holds each head's d_h plain then d_h^R rotary rows; kv_down the latent's d_c rows then the rotary key's d_h^R; kv_up each head's d_h key rows then its d_v value rows. RoPE rotates the rotary channels only (a table of d_h^R), interleaved in DeepSeek-V3 (rope_kind::interleaved).

Training. latent_attention_forward_sequence(backend, w, xs, rope_src, act, out, sequences) runs a batch of sequences end to end, every projection one linear_sequence through the backend, and saves latent_attention_activations; latent_attention_backward takes the output's gradient back to every weight, the norms', the sinks' and the input's. The steps that are not products are backend calls (TRAINING.md T9): latent_attention_norm_rows, latent_attention_rope_rows, latent_attention_attend_rows and their backward passes, with a host overload for any backend that a device library overloads for its own. Attention never stores the n x n probabilities: each head folds its keys in one pass and keeps the log-sum-exp (TRAINING.md T2).

// tiny_mla: 16 wide, 2 heads of 4 plain + 2 rotary query-key channels and 4 value channels, latents of 6 and 8
constexpr auto C = ml::tiny_mla;
constexpr std::size_t d = C.d_model, h = C.n_heads, dqk = C.head_dim, dr = C.qk_rope_dim, dv = C.v_head_dim;
constexpr std::size_t dc = C.kv_lora_rank, dq = C.q_lora_rank, kvw = C.qk_nope_dim() + dv, n = 5, sequences = 2, rows = n * sequences;
const auto q_down = filled(dq * d, 0.1f), q_up = filled(h * dqk * dq, 0.2f), kv_down = filled((dc + dr) * d, 0.3f),
kv_up = filled(h * kvw * dc, 0.4f), o = filled(d * h * dv, 0.5f);
const ml::latent_attention_weights<ml::dense_weights<float>, float> w{
{q_down, dq, d}, {}, {q_up, h * dqk, dq}, {kv_down, dc + dr, d}, {}, {kv_up, h * kvw, dc}, {o, d, h * dv}, {}};
static const ml::rope_table<float, 16, dr> rope{ml::rope_base_v<C, float>}; // the rotary channels only
// The activations a backward pass reads, for every row of the batch
std::vector<float> cq_raw(rows * dq), cq(rows * dq), q(rows * h * dqk), ckv_raw(rows * (dc + dr)), ckv(rows * dc), k_rope(rows * dr),
kv(rows * h * kvw), y(rows * h * dv), lse(rows * h);
const ml::latent_attention_activations<float> act{cq_raw, cq, q, ckv_raw, ckv, k_rope, kv, y, lse, {}};
const auto xs = filled(rows * d, 1.0f);
std::vector<float> out(rows * d);
ml::latent_attention_forward_sequence<C>(snicholls::linalg::reference, w, xs, rope, act, out, sequences);
// The backward pass: every weight's gradient added into, the input's too
std::vector<float> g_q_down(q_down.size()), g_q_up(q_up.size()), g_kv_down(kv_down.size()), g_kv_up(kv_up.size()), g_o(o.size());
std::vector<float> w_y(y.size()), w_q(q.size()), w_kv(kv.size()), w_kr(k_rope.size()), w_ckv(ckv.size()), w_ckv_raw(ckv_raw.size()),
w_cq(cq.size()), w_cq_raw(cq.size()), dxs(xs.size());
const ml::latent_attention_gradients<float> grads{g_q_down, {}, g_q_up, g_kv_down, {}, g_kv_up, g_o, {},
w_y, w_q, w_kv, w_kr, w_ckv, w_ckv_raw, w_cq, w_cq_raw};
const auto dout = filled(rows * d, 2.0f);
ml::latent_attention_backward<C>(snicholls::linalg::reference, w, xs, rope, act, dout, dxs, grads, sequences);

Decoding: the absorbed form. latent_attention_forward(w, x, pos, cache, layer, rope_src, out) appends the token's latent and rotary key to a latent_kv_cache_view and attends without forming any head's keys or values: since q^C_i · (W^UK_i c_j) = ((W^UK_i)ᵀ q^C_i) · c_j and Σ_j p_j W^UV_i c_j = W^UV_i Σ_j p_j c_j, each head's query is taken into the latent space (W^UK absorbed on the query side), every head attends to the same cached rows [c_j; k^R_j] as one multi-query attention, and W^UV is applied after the weighted sum, before W^O (V2 section 2.1.2; DeepSeek-V3's attn_impl = "absorb"). The two forms are the same algebra summed in another order: equal within rounding (the scores differ by reassociating d_h · d_c products, about (d_h + d_c) · ε relative to the sum of their magnitudes; tested at 1e-12 in double and 2e-5 in float on tiny_mla). Pre-multiplying W^UK into W^UQ and W^UV into W^O is the same algebra again, with larger matrices (n_h · d_c · d_c'); it is not built.

// Decoding: each token's latent and rotary key (8 + 2 numbers) cached, each head's query taken into the latent space
ml::latent_kv_cache<C, float, 1, 16> cache;
float worst = 0.0f;
for (std::size_t t = 0; t < n; ++t) {
std::vector<float> token_out(d);
ml::latent_attention_forward<C>(w, std::span<const float>(xs).subspan(t * d, d), t, cache.view(), 0, rope, token_out);
for (std::size_t i = 0; i < d; ++i)
worst = std::fmax(worst, std::fabs(token_out[i] - out[t * d + i]));
}
// The cache per token and layer: DeepSeek-V3 keeps 576 numbers where multi-head attention would keep 32,768
constexpr std::size_t mla = ml::kv_cache_elements_per_token(ml::deepseek_v3), mha = 2 * ml::deepseek_v3.n_heads * 128;

Options. attention_sinks: a learnable logit per head (latent_attention_weights::sinks, ml/attention_sink.hpp). sparse_top_k: each query attends to the keys latent_attention_activations::selected names (DeepSeek Sparse Attention, from ml/sparse_attention.hpp's indexer and select_top_k; in decoding the selected argument). window: a sliding window, as for standard attention. KV-cache sizes are constant expressions: kv_cache_elements_per_token(c), kv_cache_elements(c, layers, positions).

Buffers. latent_attention_parameter_count, latent_attention_activation_values and latent_attention_gradient_work size a layer's buffers, and latent_attention_weights_in, latent_attention_activations_in and latent_attention_gradients_in lay them out (the norms' weights and, with attention_sinks, the sinks included), as ml/moe.hpp does for a mixture of experts.

// The same layer from one buffer of parameters, one of activations and one of working space, sized by constant
// expressions and cut into views (the norms' weights included: here 1, the parameter-free norm's values)
std::vector<float> params;
for (const auto* t : {&q_down, &q_up, &kv_down, &kv_up, &o})
params.insert(params.end(), t->begin(), t->end());
params.insert(params.begin() + std::ptrdiff_t(dq * d), dq, 1.0f); // q_norm after q_down
params.insert(params.begin() + std::ptrdiff_t(dq * d + dq + q_up.size() + kv_down.size()), dc, 1.0f); // kv_norm after kv_down
std::vector<float> values(ml::latent_attention_activation_values(C, rows)), pgrads(params.size()),
work(ml::latent_attention_gradient_work(C, rows)), out2(rows * d), dxs2(rows * d);

const auto act2 = ml::latent_attention_activations_in<C>(std::span<float>(values), rows);
ml::latent_attention_forward_sequence<C>(snicholls::linalg::reference, w2, xs, rope, act2, out2, sequences);
ml::latent_attention_backward<C>(snicholls::linalg::reference, w2, xs, rope, act2, dout, dxs2,

Relationships. ml/transformer_config.hpp (the MLA fields, deepseek_v3, tiny_mla), ml/linear.hpp, ml/norm.hpp, ml/rope.hpp (YaRN), ml/attention_sink.hpp (the recurrence), ml/latent_block.hpp (the block), ml/composed_block.hpp (the block with a mixture of experts). Group: snicholls-core.

Implementations. One, configured at compile time.

Guarantees. constexpr, no allocation (decoding keeps std::arrays of the configuration's sizes). Each head's output is attend's over its explicit keys [k^C; k^R] to the bit (tested), since the score's sum runs over the plain channels then the rotary ones, as attend's dot product over the concatenation does. Per token, training: the projections, plus n_h · visible · (d_h + d_h^R + d_v) for attention; decoding: n_h · d_h · d_c to absorb the query, n_h · visible · (d_c + d_h^R), n_h · d_c · d_v for the values.

Errors. Preconditions, asserted: the matrices have the configuration's shapes; the norms are empty or of their latent's width; the sinks have n_heads with attention_sinks; the selection has sparse_top_k per token, each in the visible range; the cache's capacity covers the visible range. An invalid configuration, or one that is not latent, is a compile error.

Performance. The training forward over 256 channels, 4 heads of 32 plain and 16 rotary query-key channels (values of 32, latents of 96 and 64), against attention_forward_sequence with the same heads and query-key widths, both through the reference backend, each after a bit-for-bit check against its loops by hand (benchmarks/ml/latent_attention_benchmark.cpp; Release, Apple clang 17, Xeon W-3245, macOS 26, 2026-11-19, medians of three on a shared machine, load average over 100):

Tokens MLA, core MLA, by hand MHA, core MHA, by hand
128 16.3 ms 14.8 ms 25.7 ms 25.7 ms
512 101 ms 100 ms 131 ms 129 ms

Level with the loops by hand within that machine's noise (10% at 128 tokens, 1% at 512). MLA's latents make its projections smaller than MHA's three full ones, so its forward is the faster at these widths; its cache is d_c + d_h^R = 80 numbers a token against MHA's 384.

Tests and demos. tests/ml/latent_attention_test.cpp, demos/ml/latent_attention_demo.cpp.

Dependencies. <algorithm>, <array>, <cassert>, <concepts>, <cstddef>, <cstdint>, <limits>, <span>, <type_traits>, linalg/backend.hpp, ml/attention.hpp, ml/attention_sink.hpp, ml/linear.hpp, ml/norm.hpp, ml/rope.hpp, ml/row.hpp, ml/transformer_config.hpp.

Known issues. Decoding needs dense kv_up weights (the absorbed query is a product by its transpose); a quantised MLA decode is to come. A paged latent cache is not built (paged_kv_cache_view covers standard attention). The released V3 weights are FP8 blocks of 128 x 128, which core does not read.

Status. Experimental, new in 0.16.0.
