Detailed Description

snicholls::sqlite_dialect and snicholls::postgres_dialect: the standard-library reference sql_dialects.

Overview. The text SQLite and PostgreSQL need, from crtp's dialects (SQL_PLAN.md D3) without their engine extras:

SQLite PostgreSQL
placeholders ?1 $1
boolean, int64, timestamp INTEGER BOOLEAN, BIGINT, BIGINT
float64 REAL DOUBLE PRECISION
text, decimal TEXT TEXT
blob, uuid BLOB BYTEA
transaction BEGIN IMMEDIATE (take the write lock now) BEGIN
clustered table WITHOUT ROWID (none)

Identifiers are quoted the standard way in both (append_quoted_identifier). Everything but the two appends is constexpr.

constexpr sqlite_dialect sqlite;
constexpr postgres_dialect postgres;
static_assert(*sqlite.column_type(sql_type::timestamp) == "INTEGER" && *postgres.column_type(sql_type::timestamp) == "BIGINT");
std::string a, b;
sqlite.append_placeholder(a, 3);
postgres.append_placeholder(b, 3);

Relationships. Model sql_dialect (concepts/sql_dialect.hpp); pass interfaces/sql_dialect_conformance.hpp directly and through interfaces/sql_dialect.hpp; sqlite_dialect is the dialect of memory_sql_connection (interfaces/sql_connection_reference.hpp). Group: snicholls-core.

Implementations / variants. The two above.

Guarantees. Stateless, empty, trivially copyable; safe from any thread.

Errors. None.

Performance. Not benchmarked.

Tests and demos. tests/interfaces/sql_dialect_reference_test.cpp, demos/interfaces/sql_dialect_reference_demo.cpp.

Dependencies. <cstddef>, <optional>, <string>, <string_view>, interfaces/sql_dialect.hpp.

Known issues. PostgreSQL has a native UUID type and NUMERIC; these dialects use BYTEA and TEXT so that the stored bytes and order are the same on both engines (crtp's open item on a native UUID stays open).

Status. New in 0.27.0.
