Detailed Description

snicholls::run_security_provider_conformance: the conformance kit of the security_provider contract.

Overview. Drives any security_provider, in either form, through the contract of concepts/security_provider.hpp and reports which check failed (interfaces/capability_conformance.hpp). The probe is a default-constructible type with

  • auto& provider(): the implementation (a provider, a security_provider_interface&, a security_provider_ref);
  • money quantity(): a positive quantity of an instrument the provider trades; money consideration(): the cash paid for it (negative);
  • void trade(std::string_view order, const money& quantity, const money& consideration): the provider fills the order now; afterwards an event_kind::security_updated event naming the order in payment_id resolves to its facts;
  • void settle(std::string_view order): the provider settles it now;
  • owned_delivery deliver(const webhook_event& e): e as the provider would sign and send it, received now; owned_delivery deliver_late(const webhook_event& e): the same, received outside the provider's time window;
  • void provider_fails(capability_errc code, std::string_view response): the next statement fails with code, as though the provider had answered response.

The checks: capabilities name the kinds it reports, a trade resolves to one fact that validates, an event that books nothing resolves to no facts, settlement moves the settled holding, a webhook verifies and carries its event, a webhook fails closed, a statement pages through every fact once, a provider failure never leaks its response.

const capability_conformance_report report = run_security_provider_conformance<probe<false>>();
for (const auto& f : report.failures)
std::printf(" failed: %.*s: %.*s\n", static_cast<int>(f.check.size()), f.check.data(),
static_cast<int>(f.expectation.size()), f.expectation.data());

Relationships. concepts/security_provider.hpp, interfaces/security_provider.hpp, interfaces/capability_conformance.hpp; the sibling interfaces/payment_provider_conformance.hpp. Group: snicholls-core.

Implementations / variants. One kit for every form; the holdings check passes without running for a provider whose capabilities say it has none.

Guarantees. As interfaces/capability_conformance.hpp: no exception escapes a check.

Errors. Failures are data.

Performance. Not benchmarked: a test kit.

Tests and demos. tests/interfaces/security_provider_conformance_test.cpp, demos/interfaces/security_provider_conformance_demo.cpp.

Dependencies. <algorithm>, <cstddef>, <string>, <string_view>, <type_traits>, <utility>, <vector>, concepts/security_provider.hpp, interfaces/capability_conformance.hpp.
