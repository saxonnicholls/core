Detailed Description

Rust's iterator and slice methods that C++20 and core lack: windows, chunks, chunks_exact, dedup (fn::rust::slice), and enumerate, step_by, find_map, max_by_key, min_by_key, max_by, min_by, nth, last, try_for_each (fn::rust::iter). All constexpr and allocation-free.

Overview. Rust's Iterator is mostly in C++ already: std::views (C++20), snicholls::zip and functional/ cover it. This header adds what is missing, under Rust's names, the range first:

// A three-day moving average and five-day bars, over a std::vector, with no copies.
const std::vector<double> close{100, 101, 103, 102, 104, 107, 106};
std::vector<double> average;
for (std::span<const double> w : slice::windows(close, 3)) average.push_back((w[0] + w[1] + w[2]) / 3);
std::size_t bars = 0;
for (std::span<const double> bar : slice::chunks(close, 5)) bars += bar.empty() ? 0 : 1;

Implementations / variants. The slice views (slice_view, step_view) are over a contiguous range, as Rust's slices are: a pointer, a length and two sizes, trivially copyable, each element a std::span (or a reference for step_by) made when it is read. They are std::ranges::views, so they compose with std::views.

Guarantees. constexpr, allocation-free, noexcept for the views. A view refers to the range it was made from and must not outlive it; only borrowed ranges (lvalues, spans) are accepted. windows(s, k) has size - k + 1 windows (none when k > size); chunks(s, k) has ceil(size / k), the last possibly shorter; chunks_exact(s, k) has size / k, and remainder() is what is left. max_by_key and max_by return the last of equal maxima and min_by_key and min_by the first of equal minima, as Rust does. try_for_each stops at the first failure.

Precondition
k > 0 and n > 0 (checked with assert; Rust panics).

Errors. None of their own: an empty range is an empty std::optional; try_for_each returns the first failure f gave.

Examples.

// The best fill by price, the first venue that filled, and every other fill, by Rust's names.
const std::array<fill, 4> fills{{{"XLON", 100.2, 300}, {"XPAR", 100.1, 0}, {"XAMS", 100.1, 200}, {"XETR", 100.3, 100}}};
const auto cheapest = iter::min_by_key(fills, [](const fill& f) { return f.price; }); // the first of equal prices
const auto first_live = iter::find_map(fills, [](const fill& f) {
return f.quantity > 0 ? std::optional<std::string_view>(f.venue) : std::nullopt;
});
int every_other = 0;
for (const fill& f : iter::step_by(fills, 2)) every_other += f.quantity;

Performance. A window is a pointer and a length made per step: the same loads as indexing by hand. benchmarks/functional/rust_iter_benchmark.cpp compares a moving sum over windows with the index loop.

Tests and demos. tests/functional/rust_iter_test.cpp, demos/functional/rust_iter_demo.cpp, demos/functional/rust_showcase_demo.cpp.

Known issues and gotchas. enumerate is a snicholls::zip of an index and the range: its elements are std::tuple<std::size_t, T&>, read with a structured binding. A view's iterator holds a copy of the view, so it stays valid when the view is moved (into a std::views pipeline).
