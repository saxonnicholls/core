Detailed Description

Type-level functional programming under functional's names: fn::types::map_t, filter_t, foldl_t, foldr_t, zip_t, zip_with_t and friends, aliases of snicholls::meta::type_list's algorithms.

Overview. A list of types is a list too. meta::type_list (meta/type_list.hpp) owns the algorithms; this header names them as the value-level functions are named, so code that moves between levels reads the same:

value level (fn::) type level (fn::types::) meta::
map(f, xs) map_t<L, F> transform_t<L, F>
filter(p, xs) filter_t<L, P> filter_t<L, P>
foldl_of(f, z, xs) foldl_t<L, Z, F> fold_left_t<L, Z, F>
foldr_of(f, z, xs) foldr_t<L, Z, F> fold_right_t<L, Z, F>
zip(a, b), zip_with zip_t<A, B>, zip_with_t<F, A, B> zip_t, zip_with_t
reverse, concat reverse_t<L>, concat_t<Ls...> the same
take<K>, drop<K> take_t<L, K>, drop_t<L, K> the same
nub, sort_by nub_t<L>, sort_by_t<L, Less> unique_t, sort_t
length, elem length_v<L>, elem_v<L, T> size_v, contains_v
using fields = ty::list<int, double, char, double>;
using pointers = ty::map_t<fields, std::add_pointer_t>;
using integral = ty::filter_t<fields, std::is_integral>;
static_assert(std::is_same_v<integral, ty::list<int, char>>);
static_assert(std::is_same_v<ty::nub_t<fields>, ty::list<int, double, char>>);
static_assert(ty::length_v<pointers> == 4 && ty::elem_v<pointers, char*>);

Relationships. meta/type_list.hpp, which owns every algorithm here (nothing is reimplemented); functional/list.hpp, the value level. Group: snicholls-core.

Implementations / variants. Aliases only.

Guarantees. Compile time only; no run-time footprint.

Errors. Those of meta::type_list.

Examples. See the overview.

Performance. Not applicable.

Tests and demos. tests/functional/types_test.cpp, demos/functional/types_demo.cpp.

Dependencies. meta/type_list.hpp.

Known issues and gotchas. The metafunctions are class templates (template <class> class F), not lambdas: a type-level function is a template, as in meta::.

Status. Experimental, new in 0.27.0.
