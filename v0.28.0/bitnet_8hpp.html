Detailed Description

snicholls::ml BitNet b1.58: absmean ternary weights, per-token absmax activations, the straight-through estimator for quantisation-aware training, the ternary x int8 dot product and BitLinear, all constexpr.

Overview. BitNet b1.58 trains and runs a transformer whose linear layers have weights in {-1, 0, +1} times one scale and 8-bit activations, so a matrix-vector product is additions and subtractions of int8 numbers and one multiplication per output. The definitions, as BitNet's code has them (microsoft/BitNet 0b341e5):

| Step | Definition | Source | |—|—|—| | weights | γ = max(mean |W|, 1e-5), W_q = clamp(round(W / γ), -1, 1), W ≈ W_q · γ | weight_quant, utils/convert-hf-to-gguf-bitnet.py, utils/preprocess-huggingface-bitnet.py | | activations, per token | s = 127 / max(max |x|, 1e-5), x_q = clamp(round(x · s), -128, 127), x ≈ x_q / s | BitLinear.quant_input, gpu/model.py | | BitLinear | y_i = (sum_j W_q,ij · x_q,j) / s · γ | bitlinear_int8xint2 epilogue, gpu/bitnet_kernels/bitnet_kernels.h | | norms | a pre-norm (RMSNorm) before wqkv and w13; SubLN, an RMSNorm, before wo (attn_sub_norm) and before w2 (ffn_sub_norm, on relu(x1)^2 · x3), eps 1e-5 | Attention, FeedForward, TransformerBlock, gpu/model.py |

round is PyTorch's, ties to even. So every BitLinear's input is the output of an RMSNorm: bitlinear_normed is the norm and the layer together, bitlinear the layer alone.

// A layer's float weights, and one token
std::array<float, rows * cols> w{};
std::array<float, cols> x{};
for (std::size_t i = 0; i < w.size(); ++i)
w[i] = 0.05f * std::sin(1.3f * float(i));
for (std::size_t j = 0; j < cols; ++j)
x[j] = std::cos(0.2f * float(j));
// Absmean: ternary codes and one scale for the matrix
std::array<std::int8_t, rows * cols> t{};
const float gamma = ml::absmean_quantize(w, t);
const ml::bitlinear_weights layer{t, rows, cols, gamma};
// BitLinear: int8 activations per token, an integer sum per output, one multiplication by the scales
std::array<float, rows> y{};
std::array<std::int8_t, cols> codes{};
ml::bitlinear(layer, x, y, codes);
// As BitNet places it: an RMSNorm (SubLN) before the layer's activation quantisation
std::array<float, cols> gain{}, normed{};
gain.fill(1.0f);
std::array<float, rows> y_normed{};
ml::bitlinear_normed(layer, gain, x, y_normed, normed, codes);
  • absmean_quantize(w, q) and absmean_fake_quantize(w, out): ternary weights, and the float values the training forward uses (round(W · s).clamp(-1, 1) / s, s = 1 / γ).
  • absmax_quantize<Bits>(x, q) and absmax_fake_quantize<Bits>(x, out): per-token activations, Bits = 8 as BitNet b1.58 (Q_b = 2^(b-1) as the BitNet paper writes it, the range [-Q_b, Q_b - 1]), 4 for a 4-bit variant.
  • ste_backward(dout, x, s, qmin, qmax, dx, mode): the gradient of a fake-quantised tensor. ste::identity is what x + (quant(x) - x).detach() gives, the form BitNet trains with (recalled from "The Era of 1-bit LLMs: Training Tips, Code and FAQ", linked from the README, not in the clone); ste::clipped zeroes the gradient where the value was clipped (x · s outside [qmin - 1/2, qmax + 1/2]), the usual variant.
  • ternary_dot(t, q): the integer dot product of ternary and int8 codes.
  • bitlinear(w, x, y), bitlinear_normed(w, norm_weight, x, y): the layer's inference forward.

Relationships. ml/bitnet_kernels.hpp (BitNet's packed I2_S, TL1 and TL2 layouts and their kernels); ml/quant_ternary.hpp (ggml's TQ1_0 and TQ2_0, which store the same ternary weights per 256); ml/norm.hpp (rms_norm); ml/linear.hpp (float and ggml-block projections). Group: snicholls-core.

Implementations. One, the scalar reference.

Guarantees. constexpr, no allocation, linear in the row (the layer in rows x columns). The integer sums are exact; the float steps are BitNet's, in its order, so a result is the reference's to the bit given the same scale. noexcept.

Errors. Preconditions, asserted: matching lengths. A row of zeros quantises to zeros with scale 127 / 1e-5 (activations) or γ = 1e-5 (weights), as the reference's clamp makes it. A NaN quantises to 0 (PyTorch's cast of NaN is undefined).

Performance. Against a hand-written loop (benchmarks/ml/bitnet_benchmark.cpp); numbers in BENCHMARKS.md.

Tests and demos. tests/ml/bitnet_test.cpp, demos/ml/bitnet_demo.cpp.

Dependencies. <bit>, <cassert>, <cmath>, <cstddef>, <cstdint>, <span>, <type_traits>, ml/norm.hpp, ml/quantize.hpp, ml/row.hpp.

Known issues. The weights' mean |W| is summed in double and rounded once; PyTorch sums floats pairwise, so for a large tensor its γ can differ in the last bit. BitNet a4.8's activations (4-bit for the inputs of attention and the FFN, sparsified 8-bit elsewhere, arXiv 2411.04965) are not defined in the clone; only the generic absmax_quantize<4> is here, and a4.8's own quantiser is deferred.

Status. Experimental, new in 0.17.0.
