Detailed Description

snicholls::holiday_calendar: anything that says whether a day is a business day.

Overview. Which days a market is open is run-time data: holidays are declared by governments and exchanges, a year or two ahead, and change by decree. Core holds none of it. It holds the rules that use it (finance/business_day.hpp: following, modified following, preceding, ...), written over this concept, so the caller's calendar plugs in: anything whose is_business_day(std::chrono::sys_days) answers bool. It is the concept half of a pair; the pure virtual half is snicholls::holiday_calendar_interface (interfaces/holiday_calendar.hpp), for a calendar chosen at run time (by market, from a trade's terms).

// the caller's calendar: sorted closures, as a server loads them; anything with is_business_day models the concept
struct exchange_calendar {
std::vector<std::chrono::sys_days> closures; // sorted
bool is_business_day(std::chrono::sys_days d) const
{
return snicholls::is_business_day(d) && !std::binary_search(closures.begin(), closures.end(), d);
}
};
static_assert(snicholls::holiday_calendar<exchange_calendar>);
