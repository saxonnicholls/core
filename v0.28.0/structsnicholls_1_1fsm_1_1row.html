Detailed Description

template<class Src, class Event, class Guard, class Action, class Dst>
struct snicholls::fsm::row< Src, Event, Guard, Action, Dst >

One row of a transition table, built by the DSL: src + event [guard] / action = dst.

Template Parameters
Srcthe source, a state_t (with its initial and history marks).
Eventthe event type, anonymous, or an entry, exit, unexpected or exception marker.
Guardthe guard, or the internal always.
Actionthe action, or the internal none.
Dstthe target state's identity, or the internal marker of an internal transition.
