Detailed Description

snicholls::ml log-probabilities of given tokens: per token from logits (fused and stable), with the entropy, summed or averaged over a sequence's response tokens, and their backward passes.

Overview. Every post-training objective (preference losses, reinforcement learning, distillation) starts from the log-probability the model gives the tokens of a response: log π(y_t | x, y_<t) at each position, then summed (or averaged) over the response's tokens, never the prompt's (TRAINING.md T13). This header is that first step:

  • token_logprob(logits, target): log softmax(logits)[target], computed as (x_target - max) - log(sum e^(x - max)), as cross_entropy does, of which it is the negation to the bit.
  • token_logprob_with_gradient(logits, target, dlogits, dlogp): the same and, in the pass, the gradient dlogp · (one_hot - softmax).
  • token_entropy(logits): H = -Σ p log p, for the entropy bonus of reinforcement learning.
  • token_logprobs_rows(backend, logits, targets, logps, entropies): every row of a batch, on the backend (TRAINING.md T9), the entropies too when asked.
  • token_logprobs_rows_backward(backend, logits, targets, dlogps, dentropies): each row replaced by its gradient, dlogp · (one_hot - p) - dH · p (log p + H), fused as the classifier of cross_entropy_rows is, so the n x V logits are their own gradient buffer.
  • sequence_logprobs(backend, token_logps, mask, out, reduction) and sequence_logprobs_backward: the masked sum (DPO, IPO, GRPO's ratios) or mean (SimPO, ORPO: length-normalised) of each row's token log-probabilities over its response tokens; a row of no response tokens gives 0 and a zero gradient.

The layout is a batch of rows sequences padded to one length: position t of row r is element r · length + t of the token log-probabilities, the targets and the mask. The target at a position is the token that follows it (the caller shifts), and the mask is 1 where that target is a response token, 0 for the prompt and padding.

// One sequence of 4 positions over a vocabulary of 3; position 0 predicts a prompt token, 1-3 the response
constexpr std::size_t length = 4, vocab = 3;
std::array<double, length * vocab> logits{2.0, 0.0, 0.0, /**/ 0.0, 3.0, 0.0, /**/ 1.0, 1.0, 1.0, /**/ 0.0, 0.0, 5.0};
const std::array<std::uint32_t, length> targets{0, 1, 2, 2};
const std::array<std::uint8_t, length> mask{0, 1, 1, 1};
std::array<double, length> token_logps{}, entropies{};
ml::token_logprobs_rows<double>(backend, logits, targets, token_logps, entropies);
std::array<double, 1> sum{}, mean{};
ml::sequence_logprobs<double>(backend, token_logps, mask, sum, ml::logprob_reduction::sum); // log pi(y | x)
ml::sequence_logprobs<double>(backend, token_logps, mask, mean, ml::logprob_reduction::mean); // per response token

Relationships. ml/softmax.hpp (cross_entropy_with_gradient, the same arithmetic), ml/lm_head.hpp (the logits), ml/preference.hpp, ml/rl.hpp, ml/distill.hpp (the users). Group: snicholls-core.

Implementations. One each, on the host. A device library overloads the backend-first functions for its own backend type, found by argument-dependent lookup (TRAINING.md T9), and is checked against these.

Guarantees. constexpr, no allocation. noexcept for the standard floating-point types. Linear in the logits: two passes over each row forward, three backward. The backward writes (it does not add): a sequence's gradient in its logits is complete after one call.

Errors. Preconditions, asserted: the targets are below the row's width; the spans' sizes agree (logits is n · V for n targets; the token log-probabilities and the mask are rows · length). A mask is 0 or 1.

Performance. token_logprobs_rows (with entropies) and its backward against the same loops by hand, after a bit-for-bit check (benchmarks/ml/logprobs_benchmark.cpp), 16 rows of 50,304 float logits: forward 8.3 ms against 7.5 ms, backward 23.8 ms against 22.9 ms, level within the noise (Xeon W-3245, -O2, Apple clang 17, 2026-11-19, one thread, CPU time, load average about 100: a record, not a quiet-machine figure).

Tests and demos. tests/ml/logprobs_test.cpp, demos/ml/logprobs_demo.cpp.

Dependencies. <cassert>, <concepts>, <cstddef>, <cstdint>, <span>, <type_traits>, snicholls/core/math/constexpr_math.hpp, ml/row.hpp, ml/softmax.hpp.

Known issues. A vocabulary padded to a hardware multiple (cross_entropy_rows' classes) is not handled here: pass the unpadded rows. A soft cap on the logits is the caller's, before this.

Status. Experimental, new in 0.16.0.
