Detailed Description

Rewriting by rules, Wolfram's /. and //. over values: rule, rules, except, replace_once, replace_repeated, and over any tree transform_up, transform_down and rewrite_up (Uniplate's transform and rewrite). All constexpr.

Overview. A rule is a function that may fire: T -> std::optional<T>, the rewritten value or nothing. Rules are built and combined as values, and applied once or until none fires:

here what it is Wolfram / Haskell
rule(p, f) fires f(x) where p(x) holds x_?p :> f[x] (PatternTest)
rules(r1, r2, ...) the first rule that fires, in the order written {r1, r2, ...}, Alternatives
except(bad, r) r, but never where bad(x) holds Except[bad, r]
replace_once(x, r) r(x) if it fires, else x x /. r (at the top)
replace_repeated(x, r, limit) r until it no longer fires, at most limit times x //. r
transform_up(children, f, x) f at every node, children first Uniplate transform
transform_down(children, f, x) f at every node, the node first Uniplate descend-based top-down
rewrite_up(children, r, x) r everywhere until it fires nowhere (a normal form) Uniplate rewrite, Wolfram //.
// Each rule fires or not; `rules` tries them in order; `except` fences one off.
constexpr auto round_odd = fn::rule([](qty q) { return q.odd >= 50; }, [](qty q) { return qty{q.lots + 1, 0}; });
constexpr auto drop_odd = fn::rule([](qty q) { return q.odd > 0 && q.odd < 50; }, [](qty q) { return qty{q.lots, 0}; });
constexpr auto cap = fn::rule([](qty q) { return q.lots > 10; }, [](qty q) { return qty{10, q.odd}; });
constexpr auto normalise = fn::rules(cap, round_odd, drop_odd);
static_assert(fn::replace_once(qty{3, 70}, normalise) == qty{4, 0});

A tree is any value type whose immediate children can be mapped: children(g, node) returns node with g applied to each child (Uniplate's descend). The tree's representation is the caller's: a variant with std::vector children, an index arena, a fixed-depth aggregate. Nothing here knows the node types:

// The tree is the caller's: `children` maps a function over a node's children. Rules fold constants.
const auto children = [](const auto& g, term t) {
for (auto& a : t.args) a = g(a);
return t;
};
const auto fold = fn::rule(
[](const term& t) {
if (t.kind == term::op::num) return false;
for (const auto& a : t.args)
if (a.kind != term::op::num) return false;
return true;
},
[](const term& t) {
double v = t.kind == term::op::add ? 0 : 1;
for (const auto& a : t.args) v = t.kind == term::op::add ? v + a.value : v * a.value;
return num(v);
});
const term notional = mul({num(1'000'000), add({num(1), mul({num(0.5), num(0.25)})})});
const term folded = fn::rewrite_up(children, fold, notional);

The idea comes from symbolic-expression-templates (SXT), whose replace and rewrite do this over expression types at compile time (a rule that fires changes the C++ type), with blanks, sequence blanks and commutative matching. Those are algebra-specific and stay in SXT; this is the value-level core of it, for simplifying an order, normalising a schedule, or folding constants in a small language.

Relationships. snicholls::fixed_point and fixed_point_result (iterate.hpp: iteration to ==, where this stops when no rule fires), functional/match.hpp (one match, no iteration), functional/recursion.hpp (folds over lists), fn::fix. Group: snicholls-core.

Implementations / variants. rule, rules and except are closures holding their parts (trivially copyable when the parts are). The tree functions recurse once per level of the tree.

Guarantees. constexpr. A rule is called with a const T&. replace_repeated makes at most limit rewrites and says whether it reached a normal form. transform_up and rewrite_up visit every node; rewrite_up re-normalises what a rule produces, so the result has no node where a rule fires.

Precondition
For rewrite_up, the rules terminate (each firing makes progress by some measure); otherwise it does not return (at compile time, the constant evaluator's step limit stops it).

Errors. None of their own; a rule's or children's exception propagates.

Examples.

// Rewrite until no rule fires: 12 lots and 60 shares is first capped, then rounded, then capped again.
constexpr auto r = fn::replace_repeated(qty{12, 60}, normalise, 10);
static_assert(r.value == qty{10, 0} && r.iterations == 3 && r.converged);

Performance. One call per rule tried per node; not benchmarked.

Tests and demos. tests/functional/rewrite_test.cpp, demos/functional/rewrite_demo.cpp, demos/functional/rewrite_simplifier_demo.cpp (an algebraic simplifier to a normal form).

Dependencies. <cstddef>, <functional>, <optional>, <type_traits>, <utility>, snicholls/core/iterate.hpp and functional/combinators.hpp.

Known issues and gotchas. The tree functions recurse on the stack, one frame per level: fine for the expression trees they are for, not for a list of a million nodes (fold those with functional/recursion.hpp). Rules see values, not patterns: matching a shape is the rule's predicate (often fn::match or a variant std::get_if).

Status. Experimental, new in 0.27.0.
