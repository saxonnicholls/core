Detailed Description

snicholls::geometry::align_2d and align_3d: the least-squares rigid or similarity transform between two sets of corresponding points (Umeyama in 2-D, Horn in 3-D).

Overview. Two sensors that watch the same targets each see the targets' tracks in their own frame. The transform that superimposes the two minimises Σ wᵢ |dᵢ - (s R sᵢ + t)|² over a rotation R, a translation t and, optionally, a scale s. That transform registers one sensor to the other: two phones watching the same swimmers, a camera against surveyed landmarks.

  • align_2d(source, target, weights, with_scale): SE(2), or Sim(2) with scale. Closed form: the angle is atan2(Σ w (s'ₓ d'_y - s'_y d'ₓ), Σ w s'·d') over the centred points.
  • align_3d(source, target, weights, with_scale): SE(3) or Sim(3), by Horn's unit quaternion, the eigenvector of the largest eigenvalue of a 4 x 4 symmetric matrix built from the cross-covariance.
  • transform_2d and transform_3d: apply(x) = s R x + t, inverse(); rms_error(x, source, target) is the weighted RMS misfit.

Wrap them in stats/ransac.hpp when some correspondences are wrong.

// Four swimmers seen by phone A (source) and phone B (target). B's frame is A's turned 30 degrees, scaled by 2
// (a different zoom) and shifted by (5, -1)
const std::array<v2, 4> seen_by_a{v2{{0, 0}}, v2{{3, 0}}, v2{{3, 1}}, v2{{0, 2}}};
const double turn = std::numbers::pi / 6;
const geo::transform_2d<double> truth{{{std::cos(turn), -std::sin(turn), std::sin(turn), std::cos(turn)}}, v2{{5, -1}}, 2.0};
std::array<v2, 4> seen_by_b{};
for (std::size_t i = 0; i < 4; ++i)
seen_by_b[i] = truth.apply(seen_by_a[i]);
// Sim(2): rotation, translation and scale. The span's element type is named, since std::array does not deduce it
const auto a_to_b = geo::align_2d<double>(seen_by_a, seen_by_b, {}, true);
// a_to_b->angle() is pi / 6, a_to_b->scale is 2; a_to_b->apply(p) maps any point of A's frame into B's
const auto b_to_a = a_to_b->inverse();

Relationships. linalg/fixed.hpp (symmetric_eigen), stats/ransac.hpp. Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation. R is a proper rotation (determinant +1, no reflection). The result is exact for noise-free points. Complexity is O(n) in the points, plus one fixed 4 x 4 eigen decomposition in 3-D.

Errors. alignment_error::too_few_points: fewer than two points in 2-D, or three in 3-D, or a weight list of the wrong length. alignment_error::degenerate: the source points coincide (no spread), or in 3-D are collinear, so the rotation is not determined.

Performance. Not benchmarked: O(n) arithmetic.

Tests and demos. tests/geometry/alignment_test.cpp, demos/geometry/alignment_demo.cpp.

Dependencies. <cstdint>, <span>, linalg/fixed.hpp, math/constexpr_math.hpp, result.hpp.

Known issues. None known.

Status. Experimental, new in 0.19.0.
