Detailed Description

The Snell envelope: the value of stopping optimally on a finite Markov chain, its stopping region, and its Doob-Meyer compensator.

Overview. Holding a right to stop (exercise an option, close a trade) and collect g(t, s) in state s at time t, the best you can do is the Snell envelope: the smallest supermartingale above the payoff. On a finite chain it is backward induction, U_T = g(T, .) and U_t = max(g(t, .), discount * E[U_{t+1} | .]); stop the first time U_t = g(t, s_t).

// A spread in five states, -2 .. 2, drifting back towards 0. Closing in state s pays s; ten days to go.
constexpr std::array<std::array<double, 5>, 5> drift_to_zero{{{0.5, 0.5, 0, 0, 0},
{0.1, 0.4, 0.5, 0, 0},
{0, 0.25, 0.5, 0.25, 0},
{0, 0, 0.5, 0.4, 0.1},
{0, 0, 0, 0.5, 0.5}}};
constexpr auto close_now = [](std::size_t, std::size_t s) { return static_cast<double>(s) - 2.0; };
constexpr auto plan = st::snell_envelope<5, 10>(drift_to_zero, close_now);
// Computed by the compiler: at the top, take the profit; anywhere below, waiting is worth more.
static_assert(plan.stops(0, 4) && !plan.stops(0, 2));

The envelope's Doob-Meyer decomposition is U = M - A with A increasing; its increment U_t - discount * E[U_{t+1}] is zero exactly where continuing is optimal, and positive where waiting loses value. compensator_increment is that increment. stops is "the payoff is at least what continuing is worth", so ties stop and stopping_time is the smallest optimal stopping time; the first time the compensator rises is the largest.

Three forms: snell_envelope<States, Horizon> takes a std::array transition matrix and is constexpr throughout, so a stopping table for a small chain is computed by the compiler; the markov_chain form takes any size at run time; and lattice_envelope<Steps> solves a recombining lattice. On a binomial (or trinomial, or any Branches-way) lattice, step t has (Branches - 1) t + 1 nodes and node j moves to j, j + 1, ..., j + Branches - 1 with the same probabilities everywhere: a fixed stencil instead of a States x States matrix. It keeps one row of std::array storage, O(Steps) state and O(Steps^2) time, and returns the value, the first two steps' values (for delta and gamma off the tree) and the early-exercise boundary: at each step, the lowest and highest node where stopping is strictly better than continuing.

// A recombining lattice: node j of step t moves to j (down) or j + 1 (up), the same stencil at every node, so one
// row of storage carries the whole backward induction. A 64-step American put, S = K = 100, 4% a year, 20% vol.
constexpr std::size_t steps = 64;
constexpr double dt = 1.0 / steps, up = snicholls::math::exp(0.2 * snicholls::math::sqrt(dt));
constexpr double p = (snicholls::math::exp(0.04 * dt) - 1 / up) / (up - 1 / up);
constexpr auto put = [](std::size_t t, std::size_t j) {
const double s = 100 * snicholls::math::pow(up, 2 * static_cast<double>(j) - static_cast<double>(t));
return s < 100 ? 100 - s : 0.0;
};
constexpr auto tree = st::lattice_envelope<steps>(std::array{1 - p, p}, put, snicholls::math::exp(-0.04 * dt));
// Computed by the compiler: worth more than exercising now, and exercised early near expiry from the bottom node up
static_assert(tree.value > put(0, 0) && !tree.exercises(0) && tree.exercises(steps - 1) && tree.first_exercise[steps - 1] == 0);

Relationships. stochastic/martingale.hpp; math/constexpr_math.hpp for payoffs at compile time. Continuous models (LSM, HJB solvers) belong in the consuming library. Group: snicholls-core.

Guarantees. O(Horizon x States^2) arithmetic; the fixed form allocates nothing. value(t, s) is at least g(t, s) and is a supermartingale along the chain. lattice_envelope is O(Steps^2 x Branches) arithmetic in O(Steps) state, constexpr, allocation-free and loop-bounded by its template arguments (fit for a GPU kernel or FPGA synthesis); its result is trivially copyable. On the same lattice written as a matrix it agrees with the dense form exactly: the same products, summed in the same order.

Errors. None.

Performance. benchmarks/stochastic/snell_benchmark.cpp, a 64-step binomial American put with its boundary: lattice_envelope 3.7 us, the same loop by hand 3.5 us, the dense snell_envelope over the lattice as a 65 x 65 matrix 205 us (Intel Xeon W-3245, macOS 26, Apple clang 17, Release, 2026-11-26). The dense form is not benchmarked otherwise.

Tests and demos. tests/stochastic/snell_test.cpp (Hull's American put; the lattice form against the dense form, binomial and trinomial), demos/stochastic/snell_demo.cpp.

Dependencies. <array>, <cstddef>, <functional>, <limits>, <span>, <type_traits>, <vector>, stochastic/martingale.hpp.

Known issues. Discrete time and finite states: discretising a diffusion is the caller's. The lattice form keeps no table of every node, so it has no stops(t, j): its boundary reports the strict stopping region's extremes per step, which describe the region exactly when it is an interval at one end of the step (a monotone payoff such as a put's or a call's). Where the full table is wanted, use the dense form.

Status. New in 0.5.0, experimental.
