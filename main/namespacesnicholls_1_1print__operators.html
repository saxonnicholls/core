Detailed Description

The stream operators core lends to a plain std::ostream, to bring into scope: using snicholls::print_operators::operator<<;.

With the declaration in scope, printable types, containers, pairs, tuples, optionals, variants, results and type_lists all stream with os << value, as they do into an acout without it, the way magic_enum's iostream_operators lends enumerations theirs. It is an opt-in namespace so that no stream in another library changes meaning by core being included. Values that have their own operator<< are not touched.
