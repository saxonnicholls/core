Detailed Description

template<class E>
class snicholls::bad_result_access< E >

Thrown by unwrap() / expect() on an error (SNICHOLLS_RESULT_THROW=1), carrying the error.

snicholls::bad_result_access carrying the error E that unwrap() / expect() found.

bad_result_access<void> is the base of every bad_result_access<E> and derives from std::logic_error (as the older Result::unwrap implementations do, so existing catch (const std::logic_error&) still works). It is thrown alone by unwrap_err() on a success and by unwrap() when E is not copyable (an exception object must be).
