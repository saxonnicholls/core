Detailed Description

snicholls::ml Hadamard rotations: the fast Walsh-Hadamard transform, the orthonormal and block forms ggml computes bit for bit, the randomised transform of QuaRot and SpinQuant, and folding a rotation into weights before quantisation, all constexpr.

Overview. A Hadamard matrix H of order n = 2^k (Sylvester's: H_ij = (-1)^popcount(i & j)) is orthogonal up to sqrt(n), and the fast transform applies it in n log2 n additions. Rotating a weight matrix and its input by the same orthonormal Q changes no product, W x = (W Q)(Q^T x), but spreads each row's outliers over all its columns, so the rotated weights and activations quantise with far less error. That is the pre-step of QuaRot and SpinQuant (Q = H D, D a diagonal of random signs), and of llama.cpp's folded weights and KV-cache rotation.

  • fwht(x): x <- H x, unnormalised, in place. hadamard(x): x <- H x / sqrt(n), orthonormal and its own inverse, as ggml computes it. block_hadamard(x, block): the same on each run of block numbers, ggml's form for a width that is not a power of two (a block-diagonal H).
  • hadamard_signs(signs, seed): the ±1 diagonal D from a seed (stats::wyrand). random_hadamard(x, signs, block): x <- H (D x), the input transform; random_hadamard_inverse(x, signs, block): x <- D (H x).
  • rotate_rows(w, cols, signs, block): each row r of a row-major W becomes r D H, so the folded W_f = W D H times the transformed input H (D x) is W x; then quantise W_f (and the transformed activations) with ml/quantize.hpp. The gain is largest where one scale covers many numbers: per-row int8 of a row with two outliers loses ten times less after rotation (tested).
  • hadamard_entry(i, j) and hadamard_matrix<T>(n, m): the matrix itself, for tests and GPU kernels; the matrix is the one llama.cpp builds (ggml_gen_hadamard), bit for bit.
// Weights with an outlier column, and an input: rotate both by H D (QuaRot's randomised Hadamard)
constexpr std::size_t rows = 4, cols = 256;
std::vector<float> w(rows * cols), a(cols);
for (std::size_t i = 0; i < w.size(); ++i)
w[i] = 0.02f * std::sin(0.37f * static_cast<float>(i)) + (i % cols == 17 ? 1.5f : 0.0f);
for (std::size_t j = 0; j < cols; ++j)
a[j] = std::cos(0.11f * static_cast<float>(j));
std::vector<std::int8_t> signs(cols);
ml::hadamard_signs(signs, 2026); // D: the same seed gives the same signs everywhere
std::vector<float> wf = w, af = a;
ml::rotate_rows(wf, cols, signs, cols); // W_f = W D H, folded once, offline
ml::random_hadamard(af, signs, cols); // x' = H (D x), at inference
// Quantise both to int8 with one scale per row (per-channel): the folded rows have no outlier left to stretch it
const auto int8_error = [](const std::vector<float>& v, std::size_t width) {
double e = 0;
std::vector<std::int8_t> q(width);
for (std::size_t r = 0; r < v.size(); r += width) {
const std::span<const float> row(v.data() + r, width);
const float scale = ml::quantize_int8(row, q);
for (std::size_t j = 0; j < width; ++j)
e += (double(q[j]) * double(scale) - double(row[j])) * (double(q[j]) * double(scale) - double(row[j]));
}
return std::sqrt(e);
};
const double plain_error = int8_error(w, cols), folded_error = int8_error(wf, cols);

Relationships. ml/quantize.hpp (what the rotation prepares for), stats/random.hpp (wyrand), ml/row.hpp. Group: snicholls-core.

Implementations. One butterfly order: the row is scaled first (orthonormal form), then passes of length 1, 2, 4, ... n / 2, each pass over pairs (i + j, i + len + j) in increasing i, then j, writing u + v and u - v. That is ggml's CPU order (ggml_compute_forward_fwht, the GGML_HINT_SRC0_IS_HADAMARD matrix product); ggml's SIMD passes give the same bits, since FMA(u, v, -1) rounds once as u - v does. Every addition rounds once in T, so the result is the same on every machine.

Guarantees. constexpr, noexcept, in place, no allocation; O(n log n) for one block, O(n log block) for a row. hadamard and block_hadamard of a float row equal ggml's bits on every case of the committed fixture (tests/fixtures/ml/hadamard_fixture.txt, from scripts/generate_hadamard_fixture.cpp built from ggml's own loop). random_hadamard_inverse undoes random_hadamard to rounding (exactly when n is a power of four and no sum rounds).

Errors. Preconditions, asserted: n (or block) is a power of two; the row length is a multiple of block; signs has the row's length and holds only ±1. NaN and infinity propagate as IEEE arithmetic says.

Performance. Against ggml's loop written by hand (benchmarks/ml/hadamard_benchmark.cpp), a row of 4,096 floats: one rotation of 4,096 level, 480 million numbers per second (8.6 us); blocks of 128, 665 against 556 million (Xeon W-3245, Release, Apple clang 17, 2026-11-19, one thread, scalar code).

Tests and demos. tests/ml/hadamard_test.cpp, demos/ml/hadamard_demo.cpp.

Dependencies. <bit>, <cassert>, <concepts>, <cstddef>, <cstdint>, <span>, snicholls/core/math/constexpr_math.hpp, ml/row.hpp, stats/random.hpp (which includes <random>).

Known issues. ggml computes the scale 1.0f / sqrtf(n) in float, but llama.cpp's rotation matrix holds 1.0 / sqrtf(n) computed in double and rounded: the two differ in the last bit for some n, and each function here follows the one it matches. A block format with a scale per 32 (Q4_0, Q8_0) already confines an outlier to its own block; rotating spreads it into every block, so on sparse outliers the rotation can raise a block format's error: rotate for per-channel or per-token scales, or measure. Non-power-of-two widths are handled only as ggml handles them, by blocks; a Hadamard matrix of order 12, 20 or 172 (Paley's) is not here.

Status. Experimental, new in 0.17.0.

Folds a randomised Hadamard rotation into a row-major weight matrix: each row r becomes r D H, so W_f (H D x) = W x.

H is symmetric, so r D H is H (D r): each row is transformed as an input is. Quantise the folded rows afterwards; at inference, transform each input with random_hadamard and the same signs and block.

Parameters
wThe matrix, rows · cols numbers, row-major.
colsThe columns: the input's length, a multiple of block.
signsThe diagonal of D, cols signs.
blockThe order of H, a power of two.
