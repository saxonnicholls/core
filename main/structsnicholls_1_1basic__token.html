Detailed Description

template<evm_chain_like Chain, basic_fixed_string Address, unsigned Decimals, basic_fixed_string Symbol>
struct snicholls::basic_token< Chain, Address, Decimals, Symbol >

A token deployed on Chain at Address, with Decimals decimals and the symbol Symbol.

Template Parameters
ChainThe chain type (chain::ethereum, chain::tron, ...); it must have an EIP-155 identifier.
AddressThe contract address in the chain's canonical text, checked at compile time.
DecimalsThe decimals of the token's smallest unit, at most max_scale.
SymbolThe issuer's symbol: capitals, digits, ., -, _.
