Detailed Description

A byte-string map over three spans the caller owns: the slots, the key arena and, optionally, the reverse table.

Size the spans with required_slots and required_arena. The view clears them when it is constructed and writes only inside them. Copying a view copies the pointers, not the table: the copies share it.
