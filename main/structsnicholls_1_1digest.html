Detailed Description

template<std::size_t N>
struct snicholls::digest< N >

N bytes produced by a hash: compared, ordered, printed and parsed as hexadecimal, all constexpr.

An aggregate: digest<4>{} is four zero bytes, digest<4>{{std::byte{1}, ...}} names them. The bytes are in the order the algorithm's specification writes them, which is the order of the hexadecimal.
