Detailed Description

The Owen value: Shapley attribution when the players come in groups (a coalition structure).

Overview. Factors often come in groups: rates, credit, equity, volatility. The Owen value shares the total first among the groups, as the Shapley value of the game between groups, and then within each group, as a Shapley value of its members given every combination of the other groups. Players in one group are switched on together in every order the groups are taken in, so a group of substitutes is not penalised for being split. With every player in its own group, or all in one, it is the Shapley value.

// Factors 0 and 1 are two duration measures that hedge the same risk: either earns 4, both still 4.
// Factors 2..3 are credit, 4..5 equity, each adding its own amount.
const auto pnl = [](game::coalition s) {
const double duration = (game::contains(s, 0) || game::contains(s, 1)) ? 4.0 : 0.0;
return duration + 1.0 * game::contains(s, 2) + 2.0 * game::contains(s, 3) + 0.5 * game::contains(s, 4) + 0.25 * game::contains(s, 5);
};
constexpr std::array<game::coalition, 3> groups{0b000011, 0b001100, 0b110000}; // rates, credit, equity
const auto owen = game::owen<6>(pnl, groups);
const auto by_group = game::shapley<3>(game::quotient_game(pnl, groups));

It does not tabulate the game. For m groups of sizes b_k it evaluates sum over k of 2^(m-1) 2^(b_k) coalitions, so 50 factors in 5 groups of 10 take about 80,000 evaluations where Shapley would take 2^50: groups are how attribution scales.

Relationships. game/shapley.hpp; combinatorics/partition.hpp for enumerating groupings (for_each_set_partition). Group: snicholls-core.

Guarantees. constexpr; full attribution; the sum over a group is that group's Shapley value in the game between groups (the quotient game). Up to 64 players.

Errors. None: groups must partition the players (is_partition_of), which is asserted.

Performance. Not benchmarked; the count of evaluations above.

Tests and demos. tests/game/owen_test.cpp, demos/game/owen_demo.cpp.

Dependencies. <array>, <bit>, <cassert>, <cstddef>, <span>, <vector>, game/coalition.hpp, game/shapley.hpp.

Known issues. None known.

Status. New in 0.5.0, experimental.
