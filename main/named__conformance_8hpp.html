Detailed Description

snicholls::check_named: the conformance kit of the has_name capability.

Overview. Drives any has_name implementation, a type or an object behind named_interface, through the contract and says which check failed: the name is not empty and is the same on every call. No test framework is included; a test asserts that the result is empty.

const auto type_form = check_named(currency::AUD{});
const named_model<currency::AUD> model;
const auto virtual_form = check_named(static_cast<const named_interface&>(model));
