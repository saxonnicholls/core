Detailed Description

snicholls::sparse::ldl_numeric and friends: the sparse A = L D Lᵀ of a quasi-definite matrix without pivoting, on a pattern analysed once, with static regularisation, solves and iterative refinement, all constexpr over the caller's storage.

Overview. An interior-point or ADMM solver for a QP solves, at every iteration, a KKT system [P + σI Aᵀ; A -ρ⁻¹I]: symmetric, indefinite, but quasi-definite (a positive definite block, a negative definite block), so it has an L D Lᵀ factorisation for every symmetric permutation, with D of known signs, and no pivoting is needed (Vanderbei, 1995). The pattern is fixed for the whole solve; only the values (ρ, the scaling, the barrier) change. So the work splits:

  • once: an ordering (amd, sparse/ordering.hpp), the permuted matrix (symmetric_permute_upper), the elimination tree and column counts (ldl_symbolic, which also gives nnz(L) to size L);
  • per iteration: ldl_numeric (the values of L and D), then ldl_solve and, when accuracy matters, ldl_refine. ldl_refactor is ldl_numeric again with new values on the same pattern.

etree alone gives the elimination tree. ldl_fixed<T, N, MaxNnzL> holds every array for a problem whose size is fixed when the program is written, and ldl_nnz<N>(a) sizes it in a constant expression, so the symbolic analysis of a fixed problem can be done by the compiler.

For a definite matrix, or with signs given, the factorisation always exists; without signs a zero (or non-finite) pivot is reported as ldl_error::zero_pivot, and an indefinite matrix that is not quasi-definite may factor inaccurately (there is no pivoting).

// min ½ xᵀ P x subject to Σ xᵢ = 1, μᵀ x = 0.08: P a covariance, x the weights. Its KKT system is
// [ P Aᵀ ] [x] [0]
// [ A -ρ⁻¹ I ] [y] = [b] (the -ρ⁻¹ I makes it quasi-definite; ρ → ∞ is the exact problem)
constexpr std::size_t nx = 4, m = 2, n = nx + m;
const double cov[nx][nx] = {{0.040, 0.006, 0.000, 0.002}, {0.006, 0.090, 0.010, 0.000}, {0.000, 0.010, 0.020, 0.000}, {0.002, 0.000, 0.000, 0.060}};
const double mu[nx] = {0.06, 0.12, 0.04, 0.09};
double rho = 1e6;
std::vector<I> ti, tj;
std::vector<double> tv;
auto add = [&](std::size_t i, std::size_t j, double v) { // upper triangle only
ti.push_back(static_cast<I>(i));
tj.push_back(static_cast<I>(j));
tv.push_back(v);
};
for (std::size_t j = 0; j < nx; ++j)
for (std::size_t i = 0; i <= j; ++i)
if (cov[i][j] != 0)
add(i, j, cov[i][j]);
for (std::size_t i = 0; i < nx; ++i) {
add(i, nx, 1.0); // Σ xᵢ = 1
add(i, nx + 1, mu[i]); // μᵀ x = 0.08
}
add(nx, nx, -1 / rho);
add(nx + 1, nx + 1, -1 / rho);
std::vector<I> cp(n + 1), ri(ti.size()), work(n);
std::vector<double> vx(ti.size());
sp::csc_view<double, I> kkt{0, 0, cp, ri, vx};
ok &= sp::from_triplets(n, n, std::span<const I>(ti), std::span<const I>(tj), std::span<const double>(tv), kkt, std::span<I>(work)).is_ok();
// Once: the order, the permuted matrix (and where each entry went), the analysis
std::vector<I> perm(n), amd_work(sp::amd_workspace_size(n, kkt.nnz()));
ok &= sp::amd(kkt.as_const(), std::span<I>(perm), std::span<I>(amd_work)).is_ok();
std::vector<I> pcp(n + 1), pri(kkt.nnz()), map(kkt.nnz()), pwork(2 * n);
std::vector<double> pvx(kkt.nnz());
sp::csc_view<double, I> k{0, 0, pcp, pri, pvx};
ok &= sp::symmetric_permute_upper(kkt.as_const(), std::span<const I>(perm), k, std::span<I>(pwork), std::span<I>(map)).is_ok();
std::vector<I> parent(n), counts(n), lp(n + 1), iwork(3 * n);
const auto symbolic = sp::ldl_symbolic(k.as_const(), std::span<I>(parent), std::span<I>(counts), std::span<I>(lp), std::span<I>(iwork).first(n));
ok &= symbolic.is_ok();
std::vector<I> li(symbolic ? symbolic->nnz : 0);
std::vector<double> lx(li.size()), d(n), dinv(n), xwork(n);
sp::csc_view<double, I> l{n, n, lp, li, lx};
// The expected sign of each pivot, in the new numbering: + for a weight, - for a multiplier
std::vector<std::int8_t> signs(n);
for (std::size_t i = 0; i < n; ++i)
signs[i] = static_cast<std::size_t>(perm[i]) < nx ? 1 : -1;
// Each iteration: factor, solve in the new numbering, refine, map back
auto solve = [&](std::array<double, n>& solution, std::size_t& regularised, sp::ldl_refine_result<double>& refined) {
const auto r = sp::ldl_numeric(k.as_const(), *symbolic, l, d, dinv, std::span<I>(iwork), xwork, signs);
if (!r)
return false;
regularised = *r;
const std::array<double, n> rhs{0, 0, 0, 0, 1, 0.08};
std::array<double, n> prhs{}, px{}, residual{};
sp::permute(std::span<const I>(perm), std::span<const double>(rhs), std::span<double>(prhs));
px = prhs;
sp::ldl_solve(l.as_const(), std::span<const double>(dinv), std::span<double>(px));
refined = sp::ldl_refine(k.as_const(), l.as_const(), std::span<const double>(dinv), std::span<const double>(prhs), std::span<double>(px),
std::span<double>(residual), 5, 1e-14);
sp::inverse_permute(std::span<const I>(perm), std::span<const double>(px), std::span<double>(solution));
return true;
};
std::array<double, n> first{}, second{};
std::size_t reg1 = 0, reg2 = 0;
sp::ldl_refine_result<double> ref1{}, ref2{};
ok &= solve(first, reg1, ref1);
// A new ρ: change the two diagonal values in the original matrix, carry them through the map, refactor
rho = 1e10;
for (std::size_t j = nx; j < n; ++j)
vx[static_cast<std::size_t>(cp[j + 1]) - 1] = -1 / rho; // the diagonal is the last entry of its column
for (std::size_t e = 0; e < kkt.nnz(); ++e)
pvx[static_cast<std::size_t>(map[e])] = vx[e];
ok &= solve(second, reg2, ref2);

Implementations. The up-looking factorisation (Davis, Direct Methods for Sparse Linear Systems, SIAM 2006, §4.4 and §4.7; and Davis, Algorithm 849, 2005): row k of L is a sparse triangular solve with the first k rows, whose pattern is the reach of column k of A in the elimination tree, found by walking up the tree from each entry and marking. ldl_symbolic walks the same paths once to count the entries of each column of L, building the tree as it goes. etree is Liu's algorithm with path compression. Rows of L within each column come out ascending. Static regularisation (as OSQP and Clarabel do): with signs, a pivot d whose sign is not signs[k], or whose magnitude is below delta, becomes signs[k] · delta; ldl_refine against the unregularised matrix removes the perturbation from the solution.

Guarantees. constexpr, noexcept, no allocation, no recursion. ldl_symbolic is O(nnz(L) + n) time; ldl_numeric is O(Σ |L_{*j}|²) flops, the same as a dense-in-the-pattern factorisation; ldl_solve is O(nnz(L) + n). On failure the outputs written so far are unspecified; the inputs are not modified.

Errors. etree, ldl_symbolic: sparse_error (dimension_mismatch not square, invalid_index not valid, insufficient_capacity short spans or an nnz(L) that does not fit the index type). ldl_numeric: ldl_error::dimension_mismatch (a different order from the symbolic analysis), insufficient_capacity (short spans), zero_pivot (without a sign for that row, a pivot of exactly zero; with or without signs, a pivot that is not finite, from non-finite input).

Performance. benchmarks/sparse/ldl_benchmark.cpp (-O3, Apple clang 17, Xeon W-3245, a loaded machine, 2026-11-23; CPU time). The 100 x 100 grid Laplacian: in AMD order nnz(L) = 186,098, symbolic 1.4 ms, numeric 7.7 ms, solve 0.52 ms; in natural order nnz(L) = 990,099, numeric 52 ms, solve 3.6 ms. A random KKT system of 5,000 rows (3,000 variables, 2,000 local constraints): in AMD order nnz(L) = 24,118, symbolic 0.28 ms, numeric 0.60 ms, solve 0.09 ms; in natural order (the constraints last, so their block fills in) nnz(L) = 5.0 million, numeric 5.6 s. Not compared against another implementation.

Tests and demos. tests/sparse/ldl_test.cpp, demos/sparse/ldl_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <limits>, <span>, <type_traits>, sparse/csc.hpp, result.hpp.

Known issues. Entries below the diagonal of the input are ignored: pass the upper triangle. A structurally missing diagonal entry is a zero pivot unless a later update makes it non-zero. There is no pivoting: a matrix that is indefinite but not quasi-definite needs signs (and refinement) or a pivoting factorisation.

Status. Experimental, new in 0.21.0.
