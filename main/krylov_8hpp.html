Detailed Description

snicholls::linalg::conjugate_gradient and minres: Krylov solvers for A x = b over any linear operator (a CSC matrix, a symmetric upper triangle, a dense array, or a callable the GPU provides), on the caller's storage, all constexpr.

Overview. A convex solver's inner step is a linear system: the reduced KKT system of an interior-point method, P + σI + ρAᵀA in ADMM, a Newton system in L-BFGS-B. When the matrix is large, or is never formed (a product the GPU computes from factor loadings), a Krylov method solves it from matrix-vector products alone.

  • linear_operator<Op>: Op::value_type, op.rows(), op.cols() and op.apply(x, y), which writes y = A x. Adapters: csc_operator (sparse::spmv), symmetric_csc_operator (a symmetric matrix stored as its upper triangle, sparse::spmv_symmetric_upper), dense_operator (row-major), function_operator (any callable f(x, y)); make_csc_operator, make_symmetric_csc_operator, make_dense_operator, make_function_operator.
  • preconditioner<M, T>: m.apply(r, z), which writes z = M⁻¹ r for a symmetric positive definite M. identity_preconditioner, jacobi_preconditioner (from a diagonal; csc_diagonal extracts one).
  • conjugate_gradient(op, b, x, work, options, m): preconditioned CG (Hestenes and Stiefel) for symmetric positive definite A. minres(op, b, x, work, options, m): MINRES (Paige and Saunders, 1975) for symmetric A, definite or not (a KKT matrix, a saddle point).
  • conjugate_gradient_workspace(n), minres_workspace(n): the working storage, so the caller sizes it.

x is the warm start on entry and the solution on exit. Use CG when A is SPD (it is the cheaper of the two, one product and two dot products an iteration); MINRES when A is symmetric but indefinite. Neither is for a non-symmetric A (that is GMRES or BiCGStab, not here), nor for a small dense system (factorise it: linalg/fixed.hpp, linalg/backend.hpp).

// The n x n second-difference matrix tridiag(-1, 2, -1), assembled as CSC from triplets
struct poisson {
std::vector<std::int32_t> ti, tj, col_ptr, row_idx, work;
std::vector<double> tv, values;
sp::csc_view<double> a;
explicit poisson(std::size_t n) : col_ptr(n + 1), row_idx(3 * n), work(n), values(3 * n)
{
for (std::size_t i = 0; i < n; ++i)
for (std::size_t j = i > 0 ? i - 1 : 0; j <= i + 1 && j < n; ++j) {
ti.push_back(static_cast<std::int32_t>(i));
tj.push_back(static_cast<std::int32_t>(j));
tv.push_back(i == j ? 2.0 : -1.0);
}
a = {n, n, col_ptr, row_idx, values};
(void)sp::from_triplets(n, n, std::span<const std::int32_t>(ti), std::span<const std::int32_t>(tj), std::span<const double>(tv), a, std::span<std::int32_t>(work));
}
};
bool krylov_example()
{
constexpr std::size_t n = 100;
poisson p(n);
std::vector<double> b(n, 1.0), x(n, 0.0), work(la::conjugate_gradient_workspace(n));
// 1. CG through the CSC matrix: at most n iterations in exact arithmetic
const auto r = la::conjugate_gradient(la::make_csc_operator(p.a), b, x, work, {1e-10});
std::printf(" CG, CSC operator: %-9s %3zu iterations, residual %.2e\n", r.converged() ? "converged" : "failed", r.iterations, r.residual_norm);
// 2. The same product as a callable (a GPU kernel would sit here), warm-started from the answer: no iterations
const auto matrix_free = la::make_function_operator<double>(n, n, [](std::span<const double> v, std::span<double> y) {
for (std::size_t i = 0; i < v.size(); ++i)
y[i] = 2 * v[i] - (i > 0 ? v[i - 1] : 0.0) - (i + 1 < v.size() ? v[i + 1] : 0.0);
});
const auto warm = la::conjugate_gradient(matrix_free, b, x, work, {1e-8});
std::printf(" CG, matrix-free, warm: %-9s %3zu iterations\n", warm.converged() ? "converged" : "failed", warm.iterations);
// 3. Rows and columns scaled by 1 to 1e3: Jacobi (the diagonal) undoes most of the damage
std::vector<double> d(n);
for (std::size_t i = 0; i < n; ++i)
d[i] = std::pow(10.0, 3.0 * static_cast<double>((i * 37) % 100) / 99); // a scrambled 1 to 1e3
sp::scale(p.a, std::span<const double>(d), std::span<const double>(d));
std::vector<double> diag(n), x0(n, 0.0), x1(n, 0.0);
la::csc_diagonal(p.a, std::span<double>(diag));
const la::krylov_options<double> tight{1e-8, 0, 20 * n};
const auto plain = la::conjugate_gradient(la::make_csc_operator(p.a), b, x0, work, tight);
const auto jacobi = la::conjugate_gradient(la::make_csc_operator(p.a), b, x1, work, tight, la::jacobi_preconditioner<double>{diag});
std::printf(" scaled, unpreconditioned: %3zu iterations; Jacobi: %3zu\n", plain.iterations, jacobi.iterations);
// 4. A KKT system [P Aᵀ; A 0], symmetric indefinite, by MINRES over its upper triangle:
// P = diag(2, 2), A = [1 1]: upper triangle columns {2}, {2}, {1, 1, 0}
const std::array<std::int32_t, 4> kp{0, 1, 2, 4};
const std::array<std::int32_t, 4> ki{0, 1, 0, 1};
const std::array<double, 4> kv{2, 2, 1, 1};
const sp::csc_view<const double, const std::int32_t> kkt{3, 3, kp, ki, kv};
const std::array<double, 3> rhs{1, -1, 1}; // [-q; b]: minimise x₁² + x₂² - x₁ + x₂ subject to x₁ + x₂ = 1
std::array<double, 3> sol{};
std::array<double, la::minres_workspace(3)> mw{};
const auto m = la::minres(la::make_symmetric_csc_operator(kkt), rhs, sol, mw, {1e-12});
std::printf(" MINRES on the KKT system: x = (%.4f, %.4f), multiplier %.4f, %zu iterations\n", sol[0], sol[1], sol[2], m.iterations);
// 5. CG on an indefinite matrix stops with breakdown rather than diverging
const std::array<double, 4> indefinite{1, 0, 0, -1};
const std::array<double, 2> b2{1, 1};
std::array<double, 2> x2{};
std::array<double, 8> w2{};
const auto bad = la::conjugate_gradient(la::make_dense_operator(std::span<const double>(indefinite), 2, 2), b2, x2, w2);
std::printf(" CG on diag(1, -1): %s\n", bad.status == la::krylov_status::breakdown ? "breakdown" : "unexpected");
return r.converged() && r.iterations <= n && warm.converged() && warm.iterations == 0 && jacobi.converged() && jacobi.iterations * 2 < plain.iterations && m.converged() &&
std::abs(sol[0] - 1) < 1e-10 && std::abs(sol[1]) < 1e-10 && std::abs(sol[2] + 1) < 1e-10 && bad.status == la::krylov_status::breakdown;
}

Relationships. sparse/csc.hpp (the products the CSC adapters call), linalg/types.hpp (scalar), math/constexpr_math.hpp (sqrt), optim/scaling.hpp (equilibrate before solving), optim/lbfgs.hpp. Group: snicholls-core.

Implementations. CG: r = b - A x, z = M⁻¹ r, p = z; each iteration q = A p, α = rᵀz / pᵀq, x += α p, r -= α q, then the test on ‖r‖₂, z = M⁻¹ r, β = rᵀz_new / rᵀz_old, p = z + β p. The residual is the recurrence's, not recomputed. With identity_preconditioner, z is r (no copy, no call). MINRES: the Lanczos process with the M-inner product, the tridiagonal system's QR factor updated by one Givens rotation an iteration, and three search directions, rotated in place; the residual estimate φ̄ is ‖b - A x‖ in the M⁻¹-norm (‖·‖₂ without a preconditioner). Dot products accumulate in index order.

Guarantees. constexpr; noexcept when the operator's and the preconditioner's apply are and T's arithmetic is. No allocation, no recursion. Convergence: ‖r‖ ≤ max(relative_tolerance · ‖b‖, absolute_tolerance), in the norm stated above (CG: ‖·‖₂; MINRES: ‖·‖_{M⁻¹}, ‖b‖ too). b = 0 returns x = 0, converged, with no iterations. In exact arithmetic CG and MINRES finish in at most k iterations for A with k distinct eigenvalues (at most n). An iteration is one product with A; the initial residual's product is not counted. Complexity: per iteration one apply, one preconditioner apply and O(n) more.

Errors. Nothing throws unless the operator does. Every outcome is a krylov_status in the result: iteration_limit (not converged; x is the last iterate), breakdown (CG: pᵀAp ≤ 0 or rᵀM⁻¹r ≤ 0, so A or M is not positive definite; MINRES: rᵀM⁻¹r < 0, M is not; x is the last iterate), invalid_input (shapes that do not fit, or work too short; x untouched).

Performance. CG on the 2-D Laplacian of a 64 x 64 grid (n = 4096, 20 224 non-zeros), 200 iterations from zero, through csc_operator, against the same CG written by hand over the same CSC arrays in the same arithmetic order, after a bit-for-bit check (benchmarks/linalg/krylov_benchmark.cpp; Release, Apple clang 17, Xeon W-3245, 2026-11-23, a loaded machine): 10.5 ms of CPU a solve, by hand 10.7 ms (19.0 and 18.7 thousand iterations a second); the two are the same within the noise. Without a preconditioner z is r itself, so nothing is copied.

Tests and demos. tests/linalg/krylov_test.cpp, demos/linalg/krylov_demo.cpp.

Dependencies. <concepts>, <cstddef>, <cstdint>, <limits>, <span>, <type_traits>, <utility>, sparse/csc.hpp, linalg/types.hpp (which brings containers/md_span.hpp), math/constexpr_math.hpp.

Known issues. ‖·‖₂ is sqrt(xᵀx), without scaling, so it overflows for entries near sqrt(max()). In floating point CG loses orthogonality and may need more than n iterations; max_iterations = 0 allows 2n. The default relative tolerance, 1e-8, is out of reach in float: raise it.

Status. Experimental, new in 0.21.0.
