Detailed Description

snicholls::check_random_source: the conformance kit of the random_source_like contract.

Overview. Drives any source, in either form (a random_source_like value, a random_source_interface&, an any_random_source), through the contract and returns the failures as text, so any test framework can report them (an empty list is a pass). The checks: every length is filled exactly, the bytes past it untouched (0, 1, odd lengths, 256 and the lengths across it where getentropy must chunk, 1000); a zero-length fill with a null pointer succeeds; two fills differ; a fill is not all zero bytes. It does not test randomness quality: that is the operating system's, and statistical tests belong to the implementation's own suite.

For a source that should fail (an unavailable one), check_random_source_fails_closed checks that every length is refused with an error.

test_random_source source{99};
const std::vector<std::string> problems = check_random_source(source); // empty: it conforms
for (const std::string& p : problems)
std::printf(" %s\n", p.c_str());
unavailable_random_source down;
const auto closed = check_random_source_fails_closed(down); // empty: it fails closed

Known issues. "Two fills differ" can fail by chance for a true source with probability 2^-256; the kit draws 32 bytes each time.
