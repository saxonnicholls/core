Detailed Description

containers::md_array<T, E...> and md_span: multi-dimensional storage and views, row-major, zero-overhead indexing.

Overview. A 3-, 4- or 5-dimensional table (scenario x tenor x strike, currency x book x day) is one contiguous block indexed by a row-major offset. With the extents in the type, md_array<T, E...> holds the block in place and its strides are constants, so a(i, j, k) compiles to the arithmetic a hand-written a[(i * J + j) * K + k] does; with the extents known only at run time, md_span<T, Rank> is a view over any contiguous storage. for_each_index visits every index in row-major order, unrolled at compile time for an md_array through constexpr_nest.

// 3 scenarios x 4 tenors x 5 strikes, one block, strides known to the compiler.
snicholls::containers::md_array<double, 3, 4, 5> pnl{};
snicholls::containers::md_array<double, 3, 4, 5>::for_each_index([&](auto s, auto t, auto k) {
pnl(s(), t(), k()) = 10.0 * static_cast<double>(s) - static_cast<double>(t) + 0.5 * static_cast<double>(k);
});

Relationships. constexpr_for.hpp's constexpr_nest; C++23's std::mdspan, which this is a small part of. Group: snicholls-core.

Guarantees. constexpr; md_array is sizeof(T) * E0 * E1 * ... and trivially copyable when T is; indexing is unchecked (at checks); md_span is a pointer and Rank extents and strides.

Errors. at throws std::out_of_range.

Performance. benchmarks/containers/md_array_benchmark.cpp: a 16 x 16 x 16 x 16 grid summed in order, Release, Apple clang 17, Xeon W-3245, 2026-11-07: 65.3 us through a(i, j, k, l), 65.0 us through the offsets written by hand.

Tests and demos. tests/containers/md_array_test.cpp, demos/containers/md_array_demo.cpp.

Dependencies. <array>, <cstddef>, <span>, <stdexcept>, <utility>, constexpr_for.hpp.

Known issues. Row-major only; no slicing (a sub-view of fewer dimensions) yet.

Status. New in 0.5.0.
