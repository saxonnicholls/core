Detailed Description

An E.164 telephone number: a country calling code and the national significant number, at most 15 digits.

Overview

The vocabulary type for a phone number used as an identity (a login, an SMS destination, a directory key): one canonical value per number, so two spellings of the same number compare equal and hash alike. It checks the structure E.164 defines - a "+", an assigned country calling code, no trunk prefix, at most 15 digits - and nothing that depends on the country's own numbering plan. Use libphonenumber where a number must be valid for its region (lengths, mobile or fixed line, carrier); use this where the canonical E.164 form is the contract.

Relationships
  • snicholls::parse_phone_number (text in, snicholls::result), snicholls::to_chars / snicholls::to_text (canonical text out), operator""_e164 (a literal checked at compile time).
  • The country calling codes: detail/e164_country_codes.hpp, generated by scripts/generate_e164_country_codes.py.
  • The same shape as snicholls::uuid: a structural value with allocation-free text.
  • Group: snicholls-core.
Implementations and variants

None: a single implementation.

Guarantees and contracts
  • sizeof 8, alignof 8, trivially copyable, standard layout, structural; every member function is constexpr and noexcept except print.
  • Invariant
    empty(), or: country_code() is assigned in E.164, 2 <= national_number_length(), digit_count() <= 15. Only packed breaks it, by assignment; it is public because a structural type's members must be.
  • Ordering is that of the canonical text; hashing is O(1).
Errors

None: parse_phone_number returns its errors as values (snicholls::phone_errc).

Examples
int main()
{
using namespace snicholls::literals;
using snicholls::phone_errc;
using snicholls::phone_number;
std::puts("Parse: one number, many spellings, one value");
constexpr phone_number mobile = "+61412345678"_e164; // checked at compile time
for (const char* text : {"+61 412 345 678", "+61-412-345-678", "(+61) 412345678", "00 61 412 345 678",
"+61.412.345.678", "+61/412/345/678"}) {
const auto r = snicholls::parse_phone_number(text);
check(r.is_ok() && *r == mobile, text);
}
std::puts("Refused, with the reason as a value (no exceptions)");
struct refusal
{
const char* text;
phone_errc why;
};
for (const refusal& r : {refusal{"", phone_errc::empty},
refusal{"0412 345 678", phone_errc::missing_country_code},
refusal{"+1-800-FLOWERS", phone_errc::invalid_character},
refusal{"(+61 412 345 678", phone_errc::unbalanced_parentheses},
refusal{"+999 1234 5678", phone_errc::unknown_country_code},
refusal{"+44 (0)20 7946 0000", phone_errc::trunk_prefix},
refusal{"+61 4", phone_errc::too_short},
refusal{"+61 412 345 678 901 234", phone_errc::too_long}}) {
const auto p = snicholls::parse_phone_number(r.text);
check(!p.is_ok() && p.err() == r.why, (std::string("refuses \"") + r.text + "\"").c_str());
}
std::puts("Parts and text");
constexpr phone_number rome = "+39 06 6988 4444"_e164; // the leading 0 is part of an Italian number
std::cout << " " << snicholls::to_text(rome).view() << ": country code " << rome.country_code() << ", national "
<< rome.national_number().view() << '\n';
check(rome.country_code() == 39 && rome.country_code_length() == 2 && rome.national_number().view() == "0669884444" &&
rome.national_number_length() == 10 && rome.digit_count() == 12 && rome.digit(2) == '0',
"country_code, national_number, digit_count, digit");
std::array<char, snicholls::phone_number_max_text_size> buf{};
const auto [end, ec] = snicholls::to_chars(buf.data(), buf.data() + buf.size(), rome);
check(ec == std::errc{} && std::string_view(buf.data(), static_cast<std::size_t>(end - buf.data())) == "+390669884444",
"to_chars into a buffer");
check(snicholls::to_chars(buf.data(), buf.data() + 4, rome).ec == std::errc::value_too_large,
"to_chars: buffer too small");
check(snicholls::to_string(rome) == "+390669884444" && std::string(snicholls::to_text(rome).c_str()).size() == 13 &&
snicholls::to_text(rome).size() == 13 && std::string_view(snicholls::to_text(rome)) == "+390669884444",
"to_text / to_string agree");
std::cout << " printed: ";
mobile.print(std::cout);
std::cout << '\n';
check(phone_number{}.empty() && !mobile.empty() && snicholls::to_text(phone_number{}).size() == 0,
"the empty number");
check(snicholls::is_e164_country_code(61) && snicholls::is_e164_country_code(800) &&
!snicholls::is_e164_country_code(999),
"is_e164_country_code");
std::puts("Ordering and hashing: the order of the canonical text");
const std::set<phone_number> sorted{mobile, "+16502530000"_e164, "+442079460000"_e164};
check(*sorted.begin() == "+16502530000"_e164 && *sorted.rbegin() == mobile, "sorts as text");
const std::unordered_set<phone_number> directory{mobile, rome};
check(directory.count(*snicholls::parse_phone_number("0061 412-345-678")) == 1, "found by another spelling");
check(std::hash<phone_number>{}(mobile) == snicholls::hash_value(mobile) &&
snicholls::hash_value(mobile) != snicholls::hash_value(rome),
"std::hash");
std::printf("%s\n", failures == 0 ? "phone_number_demo: all checks passed" : "phone_number_demo: FAILED");
return failures == 0 ? 0 : 1;
}
Performance

Release, macOS, Intel Xeon W-3245, Apple clang 17, 2026-11-23, median of 9, 4,096 numbers in five written forms, on a loaded machine: parse_phone_number 44.6 ns a number against 43.2 ns for the same scan written by hand into a digit array; to_chars 18.0 ns against 2.8 ns for copying stored digit characters (the price of 8 bytes in place of 17). benchmarks/phone_number_benchmark.cpp; not yet in BENCHMARKS.md.

Known issues and gotchas
  • Region-specific validity is out of scope: the lengths each country allows, mobile against fixed line, and which ranges are in service are not checked. "+61 12" parses; libphonenumber would call it invalid.
  • A leading 0 after the country code is refused only where 0 is that country's trunk prefix ("+44 (0)20 ...", written with the trunk 0, is refused with phone_errc::trunk_prefix, not repaired); where the 0 belongs to the number (Italy's "+39 06 ...") it is kept. Other trunk prefixes (1 in the North American plan, 8 in Russia) are digits of the number as far as E.164 is concerned and are kept as written.
  • Only 00 is taken as the international prefix (the ITU-T E.164 recommendation); 011 and the other national choices of prefix are read as a missing country code.
  • Codes the ITU holds as spare, reserved or assigned to trials without a numbering plan are unknown here, since the table is libphonenumber's.
  • Extensions ("ext. 12"), vanity letters ("1-800-FLOWERS") and "tel:" URIs are refused as invalid characters.
