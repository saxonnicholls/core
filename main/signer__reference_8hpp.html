Detailed Description

snicholls::memory_signer: the standard-library reference signer, which is memory_key_store.

Overview. A signer signs with the keys a key store keeps, so the reference of both capabilities is one class, memory_key_store (interfaces/key_store_reference.hpp): HS256 keys in memory, for tests only. This header names it as the signer's reference, so each capability has its <capability>_reference.hpp.

memory_signer s = memory_signer::deterministic();
const auto key = s.create({signature_algorithm::hs256, "siwe"});
const std::array<std::byte, 2> payload{std::byte{'h'}, std::byte{'i'}};
const auto sig = s.sign({key->key_id.view(), payload, payload_kind::message});
