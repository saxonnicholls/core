Detailed Description

snicholls::memory_onramp_provider: the standard-library reference onramp_provider, a venue in memory with prices, balances, fills, withdrawals and facts.

Overview. A venue a test controls: set_price fixes the price of an asset in a quote currency (an exact rate), deposit funds a balance, set_fee_bps charges a fee on the quote side, set_withdrawal_fee a network fee. buy fills at once at the set price (never above max_price); withdraw checks the chain, the address and the balance, then broadcasts; the test calls confirm when it should land. All amounts are exact. Rounding favours the venue, as a real one does: a spend buys toward_zero of the asset, a receive costs ceiling of the quote currency. statement pages one fact per buy and per withdrawal, in the venue's own assets <code>:MEM at the same scale. fail_next(code, response) makes the next quote, buy or withdraw fail as though the venue had answered response.

auto venue = make_venue();
venue.set_withdrawal_fee(*parse_money(usdc, "0.5"));
static_cast<void>(venue.buy({"c-1", usdc, aud, *parse_money(aud, "153"), std::nullopt}));
const auto w = venue.withdraw({"w-1", *parse_money(usdc, "99.5"), 8453, "0x52908400098527886E0F7030069857D2E4169EE7", ""});
const auto landed = venue.confirm(w->withdrawal_id.view());

Relationships. Models onramp_provider (concepts/onramp_provider.hpp); passes interfaces/onramp_provider_conformance.hpp in every form. Group: snicholls-core.

Implementations / variants. One account ("trading"); no partial fills.

Guarantees. Not thread-safe. Ids and transaction hashes are deterministic (mem_ord_1, mem_wd_2, the hash a SHA-256 of the withdrawal id). Errors follow the redaction rule.

Errors. As the contract, and whatever fail_next armed.

Performance. Not benchmarked: a test double.

Tests and demos. tests/interfaces/onramp_provider_reference_test.cpp, demos/interfaces/onramp_provider_reference_demo.cpp.

Dependencies. <algorithm>, <chrono>, <cstddef>, <cstdint>, <functional>, <map>, <optional>, <string>, <string_view>, <utility>, <vector>, hash/sha2.hpp, interfaces/onramp_provider.hpp.

Known issues. One account; no partial fills.

Status. New in 0.23.0.
