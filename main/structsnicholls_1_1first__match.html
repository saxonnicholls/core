Detailed Description

template<typename... Fs>
struct snicholls::first_match< Fs >

An ordered set of callables: a call goes to the first one, in the order written, that accepts the arguments.

The compile-time replacement for an if constexpr / else if constexpr chain over a type. Each callable's parameter list is its condition, usually a concept-constrained auto parameter ([](std::integral auto n) {...}), and a plain [](const auto&) {...} last is the else. "Accepts" is std::is_invocable, implicit conversions included.

Template Parameters
FsThe callable types; each becomes a base. A function pointer is wrapped in snicholls::fn_ptr by the deduction guide.
