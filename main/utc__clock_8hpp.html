Detailed Description

snicholls::utc_clock, the one shape of a wall clock that core's reference implementations read, and snicholls::manual_utc_clock, the clock that moves only when told.

Overview. A component that stamps what it records (a provider's facts, a key's creation, a token's expiry, a UUID's timestamp) reads a wall clock, and a test must decide what that clock says. Core's reference implementations all take the clock the same way: a template parameter Clock modelling utc_clock (c.now() returns a utc<D> of any precision), owned by value and reachable through clock(), defaulted to manual_utc_clock. The owner stays copyable (nothing captures this), the clock costs no allocation and no indirect call, and a test moves time with x.clock().advance(d). A program's real clock is a type of its own with a now() that reads utc<D>::now(), or ts-moveables' clock sources; clock sources stay above core.

// A component that stamps what it records takes its clock as a type and owns it: still copyable, no allocation.
template <snicholls::utc_clock Clock = snicholls::manual_utc_clock>
class journal {
public:
explicit journal(Clock clock) : clock_(clock) {}
snicholls::utc_ms record() const { return clock_.now(); }
Clock& clock() noexcept { return clock_; } // a test moves a manual clock through this
private:
Clock clock_;
};
// A clock of the caller's own: anything whose now() is a utc of any precision.
struct market_open {
[[nodiscard]] constexpr snicholls::utc_s now() const noexcept { return snicholls::utc_s::from_unix_seconds(1'800'000'000); }
};
static_assert(snicholls::utc_clock<market_open>);

Group: snicholls-core.

Implementations / variants. manual_utc_clock, in milliseconds. Any type with now() returning a utc<D>.

Guarantees. manual_utc_clock is constexpr, noexcept, trivially copyable and an aggregate ({start}); it never moves backwards (advance ignores a negative step).
