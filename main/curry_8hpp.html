Detailed Description

snicholls::fn::curry, uncurry, partial and partial_right: a function of many arguments as a chain of functions of fewer, all constexpr.

Overview. A curried function takes its arguments one at a time, or several at a time, and calls the original once it has them all:

constexpr auto volume = [](double price, int lots, int lot_size) { return price * lots * lot_size; };
// One argument at a time, several at a time, or all at once: the same call.
static_assert(fn::curry(volume)(2.0)(3)(100) == 600.0);
static_assert(fn::curry(volume)(2.0, 3)(100) == 600.0);
// A generic lambda has no arity of its own: say it.
static_assert(fn::curry<2>([](auto a, auto b) { return a * b; })(6)(7) == 42);
here what it returns
curry(f) f, curried over its own arity (one signature only)
curry<N>(f) f, curried over N arguments (a generic lambda)
uncurry(g) (a, b, c) -> g(a)(b)(c): a hand-curried chain flattened
partial(f, a, b) (rest...) -> f(a, b, rest...)
partial_right(f, y, z) (rest...) -> f(rest..., y, z)

A partly applied curried function is an ordinary value: store it, pass it, compose it (fn::pipe(scale(fx), add(spread))), call it in a static_assert. Use curry when the pieces of a calculation are built in one place and finished in another (a rate fixed at start of day, the price per tick); use partial when the bound arguments are known together and the rest come later; use a lambda when neither is true.

The arity of curry(f) is read with snicholls::callable_traits, so f needs exactly one signature: a function, a function pointer, a pointer to member function (the object counts as the first argument), or a class with one non-template operator(). A generic lambda or an overload set has no arity of its own and curry(f) refuses it with a message; say how many with curry<N>(f).

Relationships. functional/combinators.hpp (the closures, compose, pipe); functional/bind.hpp (placeholders, for arguments in any order); snicholls::callable_traits (the arity); snicholls::invoke_with (arguments that exist only at run time). Group: snicholls-core.

Implementations / variants. curry(f) and curry<N>(f) return the same closure; the first only computes N. Each partial application returns a new closure holding f and the arguments so far; the original is unchanged.

Guarantees. constexpr. Arguments are stored by value (decayed), copied from an lvalue closure and moved from an rvalue one, so a partial application never dangles; pass std::ref(x) to bind by reference. The final call is noexcept exactly when f's call with the stored and the given arguments is; a partial application is noexcept when copying the parts is. A closure is trivially copyable when f and the stored arguments are. A curried function accepts at most the remaining number of arguments; more is not invocable (std::is_invocable_v is false).

Errors. curry(f) of a callable without one signature fails to compile with "snicholls::fn::curry: a generic or overloaded callable has no arity of its own; give it: curry<N>(f)" (compile-fail test fn_curry_generic_lambda). Calling with arguments f cannot take is a compile error at the final call.

Examples.

// Morning: fix the parameters of the day. Each is a curried function waiting for a price.
constexpr double eur_usd = 1.0850;
const auto to_usd = fn::curry(convert)(eur_usd);
const auto client_markup = fn::curry(widen)(25.0); // 25 bp
const auto within_limits = fn::curry(clamp)(1.00, 200.00);
// The pipeline: convert, mark up, clamp. One function, built from pieces, trivially copyable.
const auto quote = fn::pipe(to_usd, client_markup, within_limits);
// Per tick: one call. The same as the hand-written lambda, instruction for instruction.
const auto by_hand = [](double p) { return clamp(1.00, 200.00, widen(25.0, convert(1.0850, p))); };

Performance. The curried price-adjustment pipeline of benchmarks/functional/combinators_benchmark.cpp against the hand-written lambda over the same 4096 prices, fairness-checked: medians 4347 ns and 4326 ns, equal within noise (macOS x86-64 Xeon W-3245, Apple Clang 17, Release, 2026-11-26, 5 repetitions). At -O2 both compile to the same instructions (Apple Clang 17 and Clang 23, arm64 and x86-64).

Tests and demos. tests/functional/curry_test.cpp, tests/compile_fail/fn_curry_generic_lambda.cpp, demos/functional/curry_demo.cpp.

Dependencies. <cstddef>, <functional>, <type_traits>, <utility>, snicholls/core/functional/combinators.hpp and snicholls/core/meta/callable_traits.hpp.

Known issues and gotchas.

  • A stored argument is passed to f as an lvalue when the closure is an lvalue: an f taking T&& can only be finished through an rvalue closure (std::move(c)(x)), as with std::bind.
  • A parameter T& binds the stored copy, not the caller's object, unless the caller passed std::ref.
  • Default arguments do not count: curry(f) waits for every declared parameter.

Status. Experimental, new in 0.27.0.
