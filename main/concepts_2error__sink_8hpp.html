Detailed Description

snicholls::error_sink_like: anything that receives a structured error report at a level.

Overview. Where logged errors go. A sink receives one snicholls::error_report at an snicholls::error_level through write(level, report). This is the concept half of a pair; the pure virtual half is snicholls::error_sink (interfaces/error_sink.hpp), the hook that result::log_err calls. A sink chosen at compile time (a test probe, a sink for one program) models the concept and needs no virtual call; one chosen at run time derives from the interface or is wrapped in snicholls::error_sink_model.

struct counting_sink { // no base class: a sink for one program, chosen at compile time
int errors = 0;
void write(error_level, const error_report&) { ++errors; }
};
static_assert(error_sink_like<counting_sink>);
counting_sink sink;
sink.write(error_level::error, make_error_report(traced<load_error>(load_error::disk_full)));
// result::log_err takes the interface's log_error: put the sink behind it with error_sink_model
// (interfaces/error_sink.hpp)

Relationships. interfaces/error_sink.hpp (the virtual twin, text_error_sink, the adapter error_sink_model), traced.hpp (error_report, error_level, make_error_report), result.hpp (log_err). Group: snicholls-core.

Implementations. snicholls::error_sink and everything derived from it (text_error_sink, a super-log adapter in the consuming library); any type with the member.

Guarantees. A concept: no code, no cost. It names error_level and error_report by declaration only, so it costs no include; a caller that writes a report includes traced.hpp.
