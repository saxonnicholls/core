Detailed Description

template<math::math_number T, std::size_t HeadDim, std::size_t Gt, std::size_t Gh, std::size_t Gw>
requires (HeadDim % 2 == 0 && Gt > 0 && Gh > 0 && Gw > 0 && HeadDim / 2 >= (Gt > 1 ? 3 : 2))
struct snicholls::ml::axial_rope_table< T, HeadDim, Gt, Gh, Gw >

Axial RoPE over a grid of tokens: a rope_source by token index (raster order).

The head's HeadDim / 2 channel pairs are shared among the axes, (HeadDim / 2) / axes each in order (frame, row, column with three axes, Gt > 1; row, column with two), pair i of an axis rotating by coordinate · rope_frequency(i, 2 · share, base); pairs left over are not rotated (cosine 1, sine 0).

Template Parameters

HeadDimThe channels of a head, even.
GtThe frame groups (1 for an image).
