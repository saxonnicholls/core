Detailed Description

snicholls::check_asset and snicholls::check_currency: the conformance kit of the asset capability.

Overview. Drives any asset_like (or currency_like) implementation, a type, a value or an object behind the interface, through the contract and says which check failed:

  • the code is a valid asset code and the scale is at most max_scale;
  • both are the same on every call;
  • for a currency: the name is not empty, and the numeric code is between 1 and 999.

No test framework is included; a test asserts that the result is empty.

const auto eth = check_asset(native::ETH{});
const auto aud = check_currency(currency::AUD{});
const currency_model<currency::JPY> jpy;
const auto virtual_form = check_currency(static_cast<const currency_interface&>(jpy));
