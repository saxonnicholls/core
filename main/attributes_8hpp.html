Detailed Description

attribute_set, attrs and attributes_of: compile-time attributes declared beside a type, any number, keyed by type.

Overview. A currency's colour, a P&L's format, an index's tooltip should be written once, beside the type, and every printer (acout, a pivot table, imgui, a React front end) should read the same values. A type declares its attributes with a constexpr function attributes in its own namespace, found by argument-dependent lookup; it returns an attribute_set built with attrs(...), one value per attribute type, as many as wanted. An attribute is any literal type: core's display attributes (display.hpp) or the caller's own (a font, a column width). An enumeration gives each enumerator its own set with per_enumerator, a table the compiler builds once and checks covers every enumerator.

enum class greek : std::uint8_t { delta, gamma, vega, vanna, volga, theta, rho };
struct column_width { // an attribute of the caller's own: any literal type
int characters;
};
// One set per greek, in enumerator order; leaving one out is a compile error.
constexpr auto attributes(greek g)
{
using namespace snicholls;
return per_enumerator(g, [] { return std::array{
attrs(colours::blue, label{"delta"}, tooltip{"dV/dS: P&L per unit move in the underlying"}, column_width{8}),
attrs(colours::cyan, label{"gamma"}, tooltip{"d2V/dS2: how delta changes as the underlying moves"}, column_width{8}),
attrs(colours::magenta, label{"vega"}, tooltip{"dV/dsigma: P&L per volatility point"}, column_width{8}),
attrs(colours::orange, label{"vanna"}, tooltip{"d2V/dS dsigma: delta's change with volatility"}, column_width{8}),
attrs(colours::yellow, label{"volga"}, tooltip{"d2V/dsigma2: vega's change with volatility"}, column_width{8}),
attrs(colours::grey, label{"theta"}, tooltip{"dV/dt: P&L from one day passing"}, column_width{8}),
attrs(rgb(0x953800), label{"rho"}, tooltip{"dV/dr: P&L per basis point of rates"}, column_width{8}),
}; });
}
// Green and red mean up and down, so no greek is green or red.
struct pnl { // P&L is green when up and red when down, wherever it prints
double value;
};
constexpr auto attributes(const pnl&) { return snicholls::attrs(snicholls::sign_colours{}, snicholls::number_format{"{:+.0f}"}); }
// Everything is known to the compiler.
static_assert(snicholls::attributes_of(greek::vanna).get<snicholls::tooltip>().text.starts_with("d2V/dS dsigma"));
static_assert(snicholls::attribute_or(greek::rho, snicholls::colours::red) == snicholls::rgb(0x953800));
static_assert(snicholls::attribute_or(3.0, column_width{12}).characters == 12); // a double has none

Relationships. display.hpp (colour, sign colours, label, number format, tooltip, JSON export), acout.hpp (prints a value with its display attributes), stats/pivot.hpp (keys and cells), meta/enums.hpp. Group: snicholls-core.

Guarantees. Everything is constexpr; a set is its attributes and nothing else: an aggregate, trivially copyable when they are, empty when there are none. For a value known at compile time the lookup folds away; for an enumerator known at run time it is one table load. A type without attributes has the empty set, so asking costs nothing and changes nothing.

Errors. Two attributes of one type in a set, or a per_enumerator table that does not cover every enumerator, are compile errors with a message.

Performance. benchmarks/meta/attributes_benchmark.cpp: the colours of 1,048,576 greeks known at run time, Release, Apple clang 17, Xeon W-3245, 2026-11-08: 674 us through attributes_of, against 806 us for the same table written by hand (a colour and a label per greek, guarded) and 281 us for a bare colour table with no guard.

Tests and demos. tests/meta/attributes_test.cpp, demos/meta/attributes_demo.cpp.

Dependencies. <array>, <concepts>, <cstddef>, <type_traits>, <utility>, meta/enums.hpp.

Known issues. attributes must be declared in the type's namespace (or as a friend), before the point where it is printed. snicholls itself declares nothing called attributes, so the name is the caller's.

Status. New in 0.5.0.
