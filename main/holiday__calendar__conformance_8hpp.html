Detailed Description

snicholls::check_holiday_calendar: the conformance kit of the holiday_calendar capability.

Overview. Drives any holiday_calendar, a type or an object behind holiday_calendar_interface, over a window of days and says which check failed:

  • the answer for a day is the same on every call;
  • every day of the window has a business day within finance::max_business_day_search days on both sides, so no adjustment rule of finance/business_day.hpp fails on it.

No test framework is included; a test asserts that the result is empty.

constexpr sys_days from = sys_days{2026y / January / 1d};
const auto new_year = [](sys_days d) { return d == sys_days{2026y / January / 1d}; };
const auto good = snicholls::check_holiday_calendar(snicholls::finance::weekends_and_holidays{new_year}, from, 365);
const auto never = snicholls::check_holiday_calendar(snicholls::finance::weekends_and_holidays{[](sys_days) { return true; }}, from, 7);
