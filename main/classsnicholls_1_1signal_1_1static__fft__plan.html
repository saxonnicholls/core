Detailed Description

template<math::math_number T, std::size_t N>
class snicholls::signal::static_fft_plan< T, N >

A plan for a length known at compile time, every table computed by the compiler.

The tables are std::arrays filled by a consteval constructor, so inline constexpr static_fft_plan<float, 512> plan{}; costs nothing at run time. plan() is an fft_plan over them, for the free functions. For a power of two the plan also holds the bit-reversal permutation and transforms in place with no work buffer.
