Detailed Description

template<class To, class From>
struct snicholls::error_conversion< To, From >

Converts a propagated error of type From into the enclosing function's error type To (SNICHOLLS_TRY).

The primary template constructs To from From. snicholls/core/traced.hpp specialises it so that a traced error gains a "propagated" frame (the expression text and the SNICHOLLS_TRY location), and a plain error entering a function that returns a traced one is wrapped with that location.
