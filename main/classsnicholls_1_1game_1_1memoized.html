Detailed Description

template<game V>
class snicholls::game::memoized< V >

A game that evaluates each coalition at most once and remembers it: for a backtest, or a pricer.

Use it with the sampling estimators and owen, which visit only some coalitions, some of them repeatedly. The exact methods tabulate anyway and gain nothing from it. Not thread-safe.
