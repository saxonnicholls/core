Detailed Description

snicholls::run_https_client_conformance: the conformance kit of the https_client contract.

Overview. Drives any https_client, in either form, through the contract of concepts/https_client.hpp and reports which check failed (interfaces/capability_conformance.hpp). The probe is a default-constructible type with

  • auto& client(): the implementation (a client, an https_client_interface&, an https_client_ref);
  • std::string url(std::string_view path_and_query): an https:// URL the probe's server answers;
  • std::string unreachable_url(): an https:// URL nothing answers;
  • void answer(https_response r): what the server answers next;
  • https_observed_request seen(): what the server last received, as it arrived;
  • void provider_fails(capability_errc code, std::string_view response): the next send fails with code, as though the TLS layer had answered response.

The checks: a GET returns status, headers and body, an error status is a response, not an error, a POST carries its body, idempotency key and authorization, only https URLs and clean headers are sent, an unreachable host is unavailable, the credential never reaches an error, a provider failure never leaks its response.

const capability_conformance_report report = run_https_client_conformance<probe>();

Relationships. concepts/https_client.hpp, interfaces/https_client.hpp, interfaces/capability_conformance.hpp. Group: snicholls-core.

Implementations / variants. One kit for every form. A TLS client's probe runs a local server.

Guarantees. As interfaces/capability_conformance.hpp: no exception escapes a check.

Errors. Failures are data.

Performance. Not benchmarked: a test kit.

Tests and demos. tests/interfaces/https_client_conformance_test.cpp, demos/interfaces/https_client_conformance_demo.cpp.

Dependencies. <string>, <string_view>, <type_traits>, <utility>, <vector>, concepts/https_client.hpp, interfaces/capability_conformance.hpp.

Known issues. Timeouts are not exercised: a kit that waits would slow every test run.

Status. New in 0.27.0.
