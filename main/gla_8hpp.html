Detailed Description

snicholls::ml gated linear attention (GLA): the recurrent form, the chunked form, the backward pass, and one token at a time for decoding.

Overview. Gated linear attention (Yang, Wang, Shen, Panda and Kim, 2023, section 4.1 eq. 3) is linear attention whose state decays by a data-dependent gate per key channel, S_t = Diag(α_t) S_{t-1} + k_tᵀ v_t, o_t = q_t S_t. Here the gate is given by its logarithm, gk = log α ≤ 0 (as flash-linear-attention's gk; the paper's α = σ(x W_α¹ W_α² + b)^{1/16} is gk = log_sigmoid(...) / 16, section 4.4, the layer's business), and the queries are scaled by 1 / sqrt(N) (mixer_scale_v). Per head h of P value channels, in key group g = h / (H / G): 

S_t[n][p] = S_{t-1}[n][p] · exp(gk_t[n]) + v_t[p] · k_t[n],     o_t[p] = Σ_n S_t[n][p] · (q_t[n] · scale)

which is llama.cpp's GGML_OP_GATED_LINEAR_ATTN (commit 39039aa, ggml_compute_forward_gla_f32, the same products in the same order; tested against a transcription), with the gate passed as its logarithm.

The chunked form is the paper's (section 4.2, eq. 4, in log space): within a chunk with cumulative gates G_j[n] = Σ_{i≤j} gk_i[n], o_j = scale · (Σ_n q_j[n] e^{G_j[n]} S_prev[n] + Σ_{i≤j} (Σ_n q_j[n] k_i[n] e^{G_j[n] - G_i[n]}) v_i), and the state passed on is e^{G_last} ⊙ S_prev + Σ_i (e^{G_last - G_i} ⊙ k_i) v_iᵀ. Every exponent is of a difference that is not positive, so nothing overflows; the paper's secondary chunking, which exists to run the quadratic part on tensor cores, is a device's form of the same sums.

  • gla_forward<C>(backend, in, o, sequences, states, checkpoints) and gla_forward_chunked<C>(..., work).
  • gla_backward<C>(backend, in, dout, grads, sequences, checkpoints, dstates, work).
  • gla_step<C>(in, o, state): decoding, with gla_state_size(C) values.
// One head, 2 key channels, 2 value channels, chunks of 2
constexpr ml::transformer_config C = [] {
auto c = ml::tiny_mamba2;
c.mixer = ml::mixer_kind::gla;
c.mixer_heads = c.mixer_groups = 1;
c.mixer_state = c.mixer_head_dim = 2;
c.conv_width = 0;
c.mixer_chunk = 2;
return c;
}();
// Token 0 writes the value (1, 0) under the key e0; every token reads with the query e0. Key channel 0's gate is
// log 0.5 from token 1: the memory halves each step
constexpr std::size_t n = 4;
const std::array<double, n * 2> q{1, 0, 1, 0, 1, 0, 1, 0}, k{1, 0, 0, 0, 0, 0, 0, 0}, v{1, 0, 0, 0, 0, 0, 0, 0};
const double half = std::log(0.5);
const std::array<double, n * 2> gk{0, 0, half, 0, half, 0, half, 0};
const ml::gla_inputs<double> in{q, k, v, gk};
std::array<double, n * 2> o{}, o_chunked{};
std::array<double, ml::gla_state_size(C)> s{}, s_chunked{};
std::array<double, ml::gla_chunk_work(C)> work{};
ml::gla_forward<C>(backend, in, std::span<double>(o), 1, std::span<double>(s));
ml::gla_forward_chunked<C>(backend, in, std::span<double>(o_chunked), 1, std::span<double>(s_chunked), {}, std::span<double>(work));
// Decoding a fifth token from the state: it recalls 1/16 of the value, scaled by 1/sqrt(2)
const std::array<double, 2> q5{1, 0}, k5{0, 0}, v5{0, 0}, g5{half, 0};
std::array<double, 2> o5{};
ml::gla_step<C>(ml::gla_inputs<double>{q5, k5, v5, g5}, std::span<double>(o5), std::span<double>(s));
// Training: how the last recall depends on channel 0's gate at token 2
std::array<double, n * 2> dout{0, 0, 0, 0, 0, 0, 1, 0}, dq{}, dk{}, dv{}, dg{};
std::array<double, ml::recurrence_checkpoints(n, C.mixer_chunk) * ml::gla_state_size(C)> checkpoints{};
std::array<double, ml::gla_state_size(C)> s0{}, dstate{};
ml::gla_forward<C>(backend, in, std::span<double>(o), 1, std::span<double>(s0), std::span<double>(checkpoints));
std::array<double, ml::gla_backward_work<C, double>()> bwork{};
ml::gla_backward<C>(backend, in, std::span<const double>(dout), ml::gla_gradients<double>{dq, dk, dv, dg}, 1,
std::span<const double>(checkpoints), std::span<double>(dstate), std::span<double>(bwork));

Relationships. ml/recurrence.hpp, ml/rwkv.hpp (RWKV-6 is this recurrence read before the update, with a bonus), ml/delta_rule.hpp, ml/transformer_config.hpp (N is mixer_state, the key channels). Group: snicholls-core.

Implementations. The recurrent and chunked forms; one backward pass for both.

Guarantees. constexpr, no allocation (the chunked form's cumulative gates are in work), sums in a stated order (the recurrent output over n ascending, as ggml's). The chunked form is the recurrent within rounding (tested); the step is the recurrent forward to the bit. Each row's input gradients are written.

Errors. Preconditions, asserted: q and k rows · G · N, v and o rows · H · P, gk rows · H · N.

Performance. benchmarks/ml/gla_benchmark.cpp, 256 tokens of 8 heads of 64 by 64 (Release, AppleClang 17, Intel Xeon W-3245, macOS, 2026-11-19): the recurrent form 4.18 ms, the loop by hand 4.04 ms (checked to the bit); the chunked form 76.2 ms, a reference for a device's kernel. BENCHMARKS.md has the current numbers.

Tests and demos. tests/ml/gla_test.cpp, demos/ml/gla_demo.cpp.

Dependencies. <array>, <cassert>, <cstddef>, <span>, <type_traits>, math/constexpr_math.hpp, ml/recurrence.hpp, ml/transformer_config.hpp.

Known issues. No layer yet (mixer_kind::gla is the op's shape): the projections, low-rank gate and output gate of the paper's section 4.4 are not here.

Status. Experimental, new in 0.17.0.
