Detailed Description

snicholls::run_uuid_generator_conformance: the conformance kit of the uuid_generator contract.

Overview. Drives any uuid_generator, in either form, through the contract of concepts/uuid_generator.hpp and reports which check failed (interfaces/capability_conformance.hpp). The probe is a default-constructible type with

  • auto& generator(): the implementation (a generator, a uuid_generator_interface&, a uuid_generator_ref);
  • std::int64_t clock_ms(): the Unix millisecond its clock reads now;
  • void clock_steps_back(): the clock goes back (a second, say), as a system clock may;
  • void randomness_fails(): the next draws of its random source fail.

A fresh probe is made for every check. The checks: v4 is version 4 and distinct, v7 is version 7 at the clock's millisecond, v7 strictly increases within a millisecond, v7 never goes back with the clock, a failed random source is unavailable.

const capability_conformance_report report = run_uuid_generator_conformance<probe>();

Relationships. concepts/uuid_generator.hpp, interfaces/uuid_generator.hpp, interfaces/capability_conformance.hpp; run on basic_uuid_generator in every form by tests/interfaces/uuid_generator_test.cpp. Group: snicholls-core.

Implementations / variants. One kit for every form.

Guarantees. As interfaces/capability_conformance.hpp: no exception escapes a check.

Errors. Failures are data.

Performance. Not benchmarked: a test kit (it makes about 10,000 identifiers).

Tests and demos. tests/interfaces/uuid_generator_conformance_test.cpp (the kit catches broken generators), demos/interfaces/uuid_generator_conformance_demo.cpp.

Dependencies. <algorithm>, <cstdint>, <type_traits>, <utility>, <vector>, concepts/uuid_generator.hpp, interfaces/capability_conformance.hpp.

Known issues. Randomness is not tested for quality, only for distinctness.

Status. New in 0.27.0.
