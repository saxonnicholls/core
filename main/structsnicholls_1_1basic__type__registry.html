inlinestatic

Match name, deserialise the bound type from serialized, and invoke handler(object).

The fold short-circuits at the first match - no switch, no variant, no base class.

Parameters
nameThe run-time type name.
serializedThe payload, passed to the deserialiser unchanged.
handlerCalled once with the deserialised object; usually generic or an overloaded set.
deserializeMaps (std::type_identity<T>, std::string_view) to a T.
Returns
true iff a registered type matched.
Exceptions
Whateverdeserialize or handler throws.
