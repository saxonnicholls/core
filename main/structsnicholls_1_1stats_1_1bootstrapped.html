Detailed Description

template<typename Acc, std::size_t B = 200>
struct snicholls::stats::bootstrapped< Acc, B >

An accumulator with its own online Poisson bootstrap: B replicate accumulators, each row added to each a Poisson(1) number of times, so a statistic and its uncertainty come out of the same single pass.

Merging merges replicate by replicate, which the Poisson bootstrap allows. A pivot reseeds every cell's copy when the cell is first used, so cells draw independently.

Template Parameters
AccThe accumulator bootstrapped (mean<double>, variance<double>, sum<double>, ...), whose value() is a number.
BThe number of replicates.
