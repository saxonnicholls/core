Detailed Description

snicholls::run_payment_provider_conformance: the conformance kit of the payment_provider contract.

Overview. Drives any payment_provider, in either form, through the contract of concepts/payment_provider.hpp and reports which check failed (interfaces/capability_conformance.hpp). The probe is a default-constructible type with

  • auto& provider(): the implementation (a provider, a payment_provider_interface&, a payment_provider_ref);
  • money amount(): a positive amount in a supported currency; asset unsupported_currency(): one it does not hold;
  • void payer_pays(const collection& c): the payer completes c (a card, or a bank transfer by its reference);
  • owned_delivery deliver(const webhook_event& e): e as the provider would sign and send it, received now; owned_delivery deliver_late(const webhook_event& e): the same, received outside the provider's time window;
  • void provider_fails(capability_errc code, std::string_view response): the next collect fails with code, as though the provider had answered response;

and, optionally, webhook_event webhook_sample() (the event the webhook check round-trips, for a provider whose events cannot carry the kit's default) and std::size_t add_other_lines() (puts lines that are not payments on the statement and returns how many).

The checks: capabilities name a method and a currency, a request without a key or with a non-positive amount is invalid, an unsupported currency is unsupported, collect is idempotent, a card collection succeeds once the payer pays, a bank transfer gives details and a reference and succeeds on the credit, a refund never exceeds what remains, an unknown payment is not found, a webhook verifies and carries its event, a webhook fails closed, an event resolves to authoritative facts that balance (a test delivery to none), a statement pages through every line once, a provider failure never leaks its response.

const capability_conformance_report report = run_payment_provider_conformance<probe>();

Relationships. concepts/payment_provider.hpp, interfaces/payment_provider.hpp, interfaces/capability_conformance.hpp. Group: snicholls-core.

Implementations / variants. One kit for every form; checks that need a method the provider lacks pass without running it.

Guarantees. As interfaces/capability_conformance.hpp: no exception escapes a check.

Errors. Failures are data.

Performance. Not benchmarked: a test kit.

Tests and demos. tests/interfaces/payment_provider_conformance_test.cpp, demos/interfaces/payment_provider_conformance_demo.cpp.

Dependencies. <algorithm>, <cstddef>, <string>, <string_view>, <type_traits>, <utility>, <vector>, concepts/payment_provider.hpp, interfaces/capability_conformance.hpp.

Known issues. None.
