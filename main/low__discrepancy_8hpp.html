Detailed Description

Sobol and Halton sequences: points that fill the unit cube evenly, for faster-converging Monte Carlo.

Overview. Monte Carlo with random points has error proportional to 1 / sqrt(N). Points chosen to fill the cube evenly (a low-discrepancy sequence) bring that close to 1 / N for smooth integrands of modest effective dimension: the same accuracy from far fewer points, which is the speed-up for option pricing, risk integrals and any expectation over a few factors.

// E[max(0, average of 4 uniforms - 0.5)], estimated from 2^12 points.
const auto payoff = [](const std::array<double, 4>& x) { return std::max(0.0, (x[0] + x[1] + x[2] + x[3]) / 4 - 0.5); };
constexpr int n = 1 << 12, copies = 8;
// Eight randomly shifted Sobol copies: each is balanced, together they give an error bar.
stats::wyrand g(7);
double sum = 0, sum2 = 0;
for (int c = 0; c < copies; ++c) {
stats::sobol<4> points(g);
double estimate = 0;
for (int i = 0; i < n; ++i)
estimate += payoff(points.next());
estimate /= n;
sum += estimate;
sum2 += estimate * estimate;
}
const double qmc = sum / copies;
const double qmc_error = std::sqrt((sum2 / copies - qmc * qmc) / (copies - 1));
  • sobol<D>: Joe and Kuo's construction (new-joe-kuo-6.21201), up to 1024 dimensions, 32 bits, in Gray-code order; the first 2^m points of each dimension put exactly one point in each interval of width 2^-m. Prefer N = 2^m points. Built with a generator, it applies a random digital shift: each shifted copy is still balanced and is uniformly distributed, so a few independent copies give an unbiased estimate with an error bar (randomised quasi-Monte Carlo).
  • halton<D>: radical inverses in the first D primes; simple and fine in a few dimensions, correlated across dimensions above about ten, where Sobol is the better choice.

Both are constexpr: a table of points can be built at compile time.

Relationships. stats/random.hpp for the shift's randomness; stats/bootstrap.hpp. Group: snicholls-core.

Guarantees. constexpr, noexcept, no allocation; a sobol<D> holds 2D 32-bit words and an index. The direction numbers are computed once per D at compile time.

Errors. None: D above 1024 is a compile error; more than 2^32 Sobol points is a precondition violation (asserted).

Performance. next() is one XOR per dimension; not benchmarked separately.

Tests and demos. tests/stats/low_discrepancy_test.cpp, demos/stats/low_discrepancy_demo.cpp.

Dependencies. <array>, <bit>, <cassert>, <cstddef>, <cstdint>, <utility>, detail/sobol_directions.hpp (generated, 73 KB), stats/random.hpp.

Known issues. Unscrambled Sobol starts at the origin; skip it (skip(1)) where a zero breaks the integrand (an inverse normal), or use the shifted form. Resampling a dataset with quasi-random indices does little: a bootstrap's dimension is the dataset's size; see stats/bootstrap.hpp.

Status. New in 0.5.0.
