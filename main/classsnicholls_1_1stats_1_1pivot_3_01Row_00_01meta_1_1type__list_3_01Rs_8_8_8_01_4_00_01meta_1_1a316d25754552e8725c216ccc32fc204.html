◆ print()

template<typename Row, typename... Rs, typename... Cs, typename... Vs, typename... As>
void snicholls::stats::pivot< Row, meta::type_list< Rs... >, meta::type_list< Cs... >, measure< Vs, As >... >::print ( std::ostream & os) const
inline

Print measure 0 as a grid: a line per combination of row keys, a column per combination of column keys.

Keys print as acout prints them, so an enumeration with display attributes shows its label in its colour; cells take the attributes of measure 0's getter, so a P&L getter with sign_colours makes them green or red. Colour is written when os is an acout message that wants it (acout{} << table;), and into a plain stream only under colour_mode::always.

Parameters
osThe stream.
