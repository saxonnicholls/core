Detailed Description

Display attributes: colour, sign_colours (P&L green and red), label, number_format, tooltip; and their JSON export.

Overview. Colour is how a trader reads a screen that changes every second, so a currency, a greek or a P&L must look the same in the terminal, in imgui and in the browser. These are the attributes every printer understands, declared once with meta/attributes.hpp:

  • colour (from colour.hpp): the value's colour.
  • sign_colours: for a number, green when positive, red when negative, grey at zero or within a dead zone; wins over colour.
  • threshold_colours: for a number, a colour per band of ascending cut points (amber from 5 s, red from 15 s); wins over both.
  • label: the text to show instead of the value (an enumerator's display name).
  • number_format: a std::format specification for a number ("{:+.2f}"), checked by the compiler.
  • units ("bps", "USD", "s"), written after a number; scale ({1e6, "m"}), dividing it first.
  • minor_units: a currency's decimal places, for whatever formats an amount in it.
  • tooltip: the text for a mouse-over, a string literal fixed at compile time; the terminal ignores it.

acout prints a value in its colour, with its label or format; stats::pivot does the same for its keys and cells. write_json and write_enum_json render the same attributes as JSON for imgui and React, from a small program run at build time, so the C++ declaration is the only place a colour or a tooltip is written. A caller's own attribute joins the JSON by specialising attribute_json.

enum class currency : std::uint8_t { usd, eur, jpy };
constexpr auto attributes(currency c)
{
using namespace snicholls;
return per_enumerator(c, [] { return std::array{attrs(colours::cyan, label{"USD"}, tooltip{"US dollar, 2 decimals"}, minor_units{2}),
attrs(colours::blue, label{"EUR"}, tooltip{"Euro, 2 decimals"}, minor_units{2}),
attrs(colours::magenta, label{"JPY"}, tooltip{"Japanese yen, no decimals"}, minor_units{0})}; });
}
struct pnl {
double value;
};
constexpr auto attributes(const pnl&) { return snicholls::attrs(snicholls::sign_colours{}, snicholls::number_format{"{:+.2f}"}); }

Relationships. meta/attributes.hpp, colour.hpp, acout.hpp, stats/pivot.hpp. Group: snicholls-core.

Guarantees. The attributes are literal types, constexpr throughout; choosing a colour by sign is one comparison. NaN has no sign colour. rgba gives imgui's four floats from a colour, constexpr.

Errors. None: the JSON writer sets the stream's state on a failed write, as any operator<< does.

Performance. Not benchmarked: printing; the lookup it rests on is benchmarked in meta/attributes.hpp.

Tests and demos. tests/display_test.cpp, demos/display_demo.cpp.

Dependencies. <array>, <bit>, <charconv>, <cmath>, <cstddef>, <cstdint>, <initializer_list>, <concepts>, <optional>, <ostream>, <string_view>, <type_traits>, colour.hpp, meta/attributes.hpp, meta/enums.hpp.

Known issues. std::format has no thousands separator except through a locale (L), so {:,} is refused.

Status. New in 0.5.0.
