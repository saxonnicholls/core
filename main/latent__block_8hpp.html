Detailed Description

snicholls::ml transformer blocks whose attention is multi-head latent attention: x += mla(norm(x)); x += mlp(norm(x)), for decoding with a latent cache and, for training, over a batch of sequences with its backward pass.

Overview. ml/transformer_block.hpp's pre-norm block with ml/latent_attention.hpp in place of the standard attention, configured at compile time by the same transformer_config (its MLA fields, and the sinks, sparse selection, window and YaRN scale they carry): the overloads of block_forward, block_forward_sequence and block_backward taking latent_block_weights are chosen by the weights' type, so a model's code calls the same names for either attention.

  • block_forward<C>(w, x, pos, cache, layer, rope_src): one token, in place, through the absorbed attention and a latent_kv_cache_view.
  • block_forward_sequence<C>(backend, w, xs, rope_src, act, sequences) and block_backward<C>(backend, w, rope_src, act, dxs, grads, sequences): the batched training passes, every step a backend call (TRAINING.md T9), as the standard block's.

A DeepSeek-V3 block puts a mixture of experts where this block has its dense MLP (ml/moe.hpp's layer): that block is ml/composed_block.hpp's latent_moe_block_weights, whose skeleton composes either attention with either MLP (with latent attention and a dense MLP it is this block to the bit).

constexpr auto C = ml::tiny_mla;
constexpr std::size_t d = C.d_model, f = C.d_ff, h = C.n_heads, dqk = C.head_dim, dr = C.qk_rope_dim, dv = C.v_head_dim;
constexpr std::size_t dc = C.kv_lora_rank, dq = C.q_lora_rank, kvw = C.qk_nope_dim() + dv, n = 6;

down = filled(d * f, 0.8f);

{}, {}, {{q_down, dq, d}, {}, {q_up, h * dqk, dq}, {kv_down, dc + dr, d}, {}, {kv_up, h * kvw, dc}, {o, d, h * dv}, {}},
{}, {}, {{up, f, d}, {gate, f, d}, {down, d, f}}};

y(n * h * dv), lse(n * h);
const ml::latent_block_activations<float> act{x0, h1, x1, h2, {cq_raw, cq, q, ckv_raw, ckv, kr, kv, y, lse, {}}, mup, mgate, mhidden};
const auto input = filled(n * d, 1.0f);
auto xs = input;
ml::block_forward_sequence<C>(snicholls::linalg::reference, w, std::span<float>(xs), rope, act);

g_up(up.size()), g_gate(gate.size()), g_down(down.size()), g_scratch(2 * n * f), scratch(n * d);

w_cq(cq.size()), w_cq_raw(cq.size());

mg.up = g_up;
mg.gate = g_gate;
mg.down = g_down;
mg.scratch = g_scratch;
const ml::latent_block_gradients<float> grads{
{}, {}, {}, {}, {g_q_down, {}, g_q_up, g_kv_down, {}, g_kv_up, g_o, {}, w_y, w_q, w_kv, w_kr, w_ckv, w_ckv_raw, w_cq, w_cq_raw}, mg, scratch};
auto dxs = filled(n * d, 2.0f); // the gradient in the block's output, replaced by the gradient in its input
ml::block_backward<C>(snicholls::linalg::reference, w, rope, act, std::span<float>(dxs), grads);
// Decoding: the same block one token at a time, its attention absorbed, its cache 10 numbers a token
ml::latent_kv_cache<C, float, 1, 16> cache;
float worst = 0.0f;
for (std::size_t t = 0; t < n; ++t) {
std::vector<float> x(input.begin() + std::ptrdiff_t(t * d), input.begin() + std::ptrdiff_t((t + 1) * d));
ml::block_forward<C>(w, x, t, cache.view(), 0, rope);
for (std::size_t i = 0; i < d; ++i)
worst = std::fmax(worst, std::fabs(x[i] - xs[t * d + i]));

Relationships. ml/latent_attention.hpp, ml/transformer_block.hpp (block_norm, block_norm_rows and their backward passes), ml/mlp.hpp, ml/composed_block.hpp (the block with a mixture of experts), ml/multi_token_prediction.hpp (a user). Group: snicholls-core.

Implementations. One, configured at compile time.

Guarantees. constexpr, no allocation in decoding, the cost of the attention plus the MLP. The batched passes are the standard block's with the latent attention's passes in place of attention_forward_sequence and attention_backward.

Errors. As ml/latent_attention.hpp and ml/mlp.hpp; the norm weights empty or of d_model.

Performance. Not benchmarked on its own: the latent attention (benchmarked) plus the standard block's MLP and norms.

Tests and demos. tests/ml/latent_block_test.cpp, demos/ml/latent_block_demo.cpp.

Dependencies. <array>, <cassert>, <concepts>, <cstddef>, <span>, <type_traits>, linalg/backend.hpp, ml/latent_attention.hpp, ml/mlp.hpp, ml/transformer_block.hpp.

Known issues. None beyond the latent attention's.

Status. Experimental, new in 0.16.0.
