Detailed Description

template<typename S>
requires key_value_store<std::remove_cvref_t<S>>
class snicholls::key_value_store_adapter< S >

Any model of key_value_store behind key_value_store_interface: owned (S) or referred to (S&).

No exception of the model crosses it (see the file's guarantees).
