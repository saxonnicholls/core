Detailed Description

snicholls::pipeline stages - compile-time composable observer chains.

snicholls::pipeline stages - compile-time composable observer chains. Std only.

auto chain = filter([](const quote& q) { return q.bid > 0; })
| transform([](const quote& q) { return mid_of(q); })
| tap([&](double m) { last = m; })
| sink; // any callable
chain(q); // all inlined: no allocation, no virtual call
snicholls::pipeline::tap
tap_spec< std::decay_t< F > > tap(F &&f)
The tap.
Definition stages.hpp:278

A stage spec (filter, transform, tap, batch<T>) describes a step; spec | spec composes specs, and spec | callable binds the chain to its final sink, giving a plain callable struct whose members are the specs' functions and the sink. Every call is a direct, inlinable call (the zero-cost form; benchmarked against a hand-written loop). For run-time plug-and-play, connect any chain to a run-time emitter or observer in the consuming library.
