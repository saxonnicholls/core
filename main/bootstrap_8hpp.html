Detailed Description

The bootstrap, fast: resampling by indices, by multinomial or Poisson counts, balanced, or in blocks for time series.

Overview. A bootstrap draws B resamples of n observations with replacement and recomputes a statistic on each. The usual implementation (std::mt19937_64, std::uniform_int_distribution, a gathered copy of each resample) spends its time drawing indices and copying data. Here:

  • indices come from wyrand and Lemire's unbiased draw, two indices per 64-bit draw;
  • a statistic that is a weighted sum (a mean, a variance, a Sharpe ratio, any moment) need not see a resample at all, only how many times each observation was drawn: for_each_resample_counts gives those multinomial counts, and bootstrap_moments turns them into weighted moments in one sequential pass the compiler vectorises;
  • the Poisson bootstrap (for_each_poisson_resample) draws each count independently as Poisson(1), two per 64-bit draw: about 1.4 times the cost of multinomial counts on one core, but independent, so it suits streaming data, an n not known in advance, and workers that must not coordinate; its resamples vary slightly in size, which for moments is immaterial;
  • the balanced bootstrap uses every observation exactly B times in total, which removes the first-order simulation error in the bootstrap mean;
  • returns are autocorrelated, so for_each_stationary_resample (Politis and Romano) and for_each_block_resample keep runs of consecutive observations together.
// The Sharpe ratio is a function of the mean and the variance: bootstrap it from resampling counts,
// with no resample ever gathered.
const auto sharpe = [](const stats::weighted_moments& m) { return m.mean / m.standard_deviation() * std::sqrt(252.0); };
stats::wyrand g(2026);
const auto distribution = stats::bootstrap_moments(returns, 10000, g, sharpe);
const auto [low, high] = distribution.percentile_interval(0.95);
// Autocorrelated returns: resample in blocks of about 10 days instead of one at a time.
std::vector<double> block_sharpes;
stats::for_each_stationary_resample(returns.size(), 10.0, 2000, g, [&](std::span<const std::uint32_t> days) {
std::vector<std::uint32_t> counts(returns.size());
for (const std::uint32_t d : days)
++counts[d];
block_sharpes.push_back(sharpe(stats::moments_of(returns, counts)));
});

A statistic that is not a weighted sum (a median, a maximum drawdown) uses bootstrap, which gathers each resample into one reused buffer. The draws are specified to the bit, so a seed reproduces a bootstrap on every platform.

When the same n is bootstrapped many times (every strategy over the same window), draw the resamples once into a resample_table and reuse it: reading an index is about twice as fast as drawing one, and every series then sees the same resamples (common random numbers). Built at run time it is as fast as a table built at compile time, without megabytes in the binary. Quasi-random indices do not help much, because a bootstrap's dimension is n.

Relationships. stats/random.hpp; stats/low_discrepancy.hpp for Monte Carlo integration. Group: snicholls-core.

Guarantees. The for_each_* functions allocate once per call (the index or count buffer) and call f once per resample with a view valid for that call only. Results are in resample order. n is below 2^32. Not thread-safe per generator; give each thread its own (wyrand::stream).

Errors. None of their own; n of zero and a mean block length below 1 are precondition violations (asserted). std::bad_alloc.

Performance. benchmarks/stats/bootstrap_benchmark.cpp: the bootstrap distribution of the mean of 1,024 observations, 2,000 resamples, against std::mt19937_64 with a gathered copy, after a fairness check. Release, Apple clang 17, Xeon W-3245, 2026-11-07: 10.4 ms for the standard way; 3.7 ms by for_each_resample (2.8 times faster; 4.4 ms for the same draws written by hand); 3.7 ms by multinomial counts; 5.4 ms by Poisson counts; 2.1 ms reusing a resample_table (4.9 times faster). All of these are single-threaded.

Tests and demos. tests/stats/bootstrap_test.cpp (BCa against SciPy, block lengths against arch), demos/stats/bootstrap_demo.cpp.

Dependencies. <algorithm>, <cassert>, <cmath>, <cstddef>, <cstdint>, <numeric>, <ranges>, <span>, <utility>, <vector>, math/constexpr_math.hpp, stats/random.hpp.

Known issues. Poisson counts above 12 are capped (probability below 1e-10). The jackknife for BCa recomputes the statistic n times; for a statistic of moments it could be done in one pass, and is not yet.

Status. New in 0.5.0.
