Detailed Description

Wolfram's Partition of a list into sublists, at compile time, and every partition of a set.

Overview. Partition[list, n, d] cuts a list into sublists of length n with offset d: d == n gives consecutive chunks, d == 1 every window. The array is known at compile time, so the result is an array of arrays, and it is constexpr.

Wolfram here
Partition[list, n] partition<n>(list)
Partition[list, n, d] partition<n, d>(list)
Partition[list, n, d, {1, 1}, x] partition_padded<n, d>(list, x)
Partition[list, n, d, {1, 1}] partition_cyclic<n, d>(list)

For type lists, meta::partition_n_t<L, n, d>.

A partition of a set is something else: a grouping of its elements into blocks. for_each_set_partition<N> visits all bell_v<N> of them as restricted growth strings, which is how to search the groupings of factors for game::owen.

// Bars of two, and every window of three: Partition[list, 2] and Partition[list, 3, 1].
constexpr std::array prices{100, 101, 99, 102, 104, 103};
constexpr auto bars = snicholls::partition<2>(prices);
constexpr auto windows = snicholls::partition<3, 1>(prices);
static_assert(bars.size() == 3 && windows.size() == 4 && windows[3] == std::array{102, 104, 103});
// Every way to group four factors (15, the Bell number), as the masks game::owen takes.
std::size_t groupings = 0;
snicholls::for_each_set_partition<4>([&](const std::array<std::size_t, 4>& block, std::size_t blocks) {
const std::array<std::uint64_t, 4> groups = snicholls::blocks_as_masks(block, blocks);
groupings += groups[0] != 0 ? 1 : 0;
});

Relationships. game/owen.hpp; meta/type_list.hpp for partition_n_t; combinatorics/permutations.hpp. Group: snicholls-core.

Guarantees. constexpr, allocation-free. An element type need only be copyable. A sublist that would run past the end is dropped by partition, padded by partition_padded, wrapped by partition_cyclic. Set partitions come in lexicographic order of their restricted growth strings.

Errors. Compile errors with a message for n == 0, d == 0, and a Bell number that does not fit 64 bits (above 25 elements).

Performance. Copies, nothing else.

Tests and demos. tests/combinatorics/partition_test.cpp, demos/combinatorics/partition_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <type_traits>, <utility>.

Known issues. Wolfram's other overhang specifications ({kL, kR} other than {1, 1}) are not provided.

Status. New in 0.5.0.
