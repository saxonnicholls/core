Detailed Description

snicholls::ml the codebooks of ggml's IQ quantisation family: the lattice grids of IQ1_S/IQ1_M, IQ2_XXS, IQ2_XS, IQ2_S, IQ3_XXS and IQ3_S, the even-parity sign table and the IQ4_NL values, every table built by the compiler from the grids' compact index lists.

Overview. An IQ format stores a group of 8 (or 4) weights as the index of a point of a fixed grid, a codebook of magnitudes. Each grid is a short list of points of a lattice, chosen by ggml's authors; a point's coordinate is one of 3 (IQ1, IQ2) or 8 (IQ3) levels. The points are stored here once, compactly, as ggml's quantiser stores them (iq2xxs_grid_index and friends: 2 or 3 bits per coordinate, ascending), and consteval functions expand them into the tables the decoders read, byte for byte ggml-common.h's:

Table Points Coordinates Levels (byte values) ggml name
iq2xxs_grid 256 8 8, 25, 43 iq2xxs_grid
iq2xs_grid 512 8 8, 25, 43 iq2xs_grid
iq2s_grid 1024 8 8, 25, 43 iq2s_grid
iq1s_grid 2048 8 -1, 0, 1 iq1s_grid
iq3xxs_grid 256 4 4, 12, ..., 52, 62 iq3xxs_grid
iq3s_grid 512 4 1, 3, ..., 15 iq3s_grid
iq2_signs 128 7 sign bits and their parity as the 8th ksigns_iq2xs
iq4nl_values 16 the non-linear 4-bit values kvalues_iq4nl

Byte k of a point (bits 8k to 8k + 7 of the integer) is coordinate k, as ggml's tables lay them out on a little-endian machine. The quantiser's view of the same grid, 2 · level + 1, is iq_grid_coordinate, and iq_grid_find is ggml's kmap (the grid index of a point, or -1), a binary search over the sorted indices.

// Point 1 of IQ2_XXS's grid: index 2 is level 2 in coordinate 0, so its bytes are 43, 8, 8, ...
static_assert(ml::iq2xxs_grid_index[1] == 2 && ml::iq2xxs_grid[1] == 0x080808080808082bULL);
// The quantiser's view of the same point, 2 · level + 1: 5, 1, 1, ...
constexpr int c0 = ml::iq_grid_coordinate(ml::iq2xxs_grid_index, 2, 1, 0);
// ggml's kmap: a packed point's grid index, or -1 off the grid
constexpr int on = ml::iq_grid_find(ml::iq3xxs_grid_index, ml::iq3xxs_grid_index[100]);
constexpr int off = ml::iq_grid_find(ml::iq3xxs_grid_index, 1);
// 7 sign bits and their parity: entry 1 (one minus) gains an eighth minus sign
constexpr std::uint8_t signs = ml::iq2_signs[1];

Relationships. ml/quant_iq.hpp (the IQ blocks, their quantisers, decoders and dot products) reads these tables. Group: snicholls-core.

Implementations. One. The index lists are data (ggml-quants.c's kgrid_*); every other table is computed.

Guarantees. Every table is constexpr, built at compile time (consteval), and its FNV-1a hash equals that of ggml-common.h's table (static_asserted in the test against tests/fixtures/ml/quant_iq_fixture.txt). iq_grid_find is noexcept, O(log n). The index lists are ascending (static_asserted here).

Errors. None.

Performance. Not benchmarked: tables. Building them costs the compiler about 20,000 evaluation steps.

Tests and demos. tests/ml/quant_iq_grids_test.cpp, demos/ml/quant_iq_grids_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>. About 31 KB of index lists.

Known issues. None.

Status. Experimental, new in 0.17.0.
