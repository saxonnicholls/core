Detailed Description

What snicholls::invoke_with reads arguments from: a count, and argument i as a T or a refusal.

size() is the number of arguments. get<T>(i), for every object type T a callable may ask for, returns either const T* (a pointer into the source, null to refuse) or std::optional<T> (a value, empty to refuse). snicholls::any_source is the std::any one; a JSON source, a command-line source and the like are written the same way.
