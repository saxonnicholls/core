Detailed Description

snicholls::colour: one display colour, as RGB for user interfaces and an ANSI code for terminals.

Overview. One value carries both forms a display needs: an RGB colour for user interfaces (CSS hex, ImGui) and an ANSI terminal colour. To print in colour, use it with acout.hpp, which decides whether the target should see the escape codes at all; the functions here only render text and never ask.

snicholls::hex(snicholls::colours::green).view() -> "#2da44e"
snicholls::ansi_start(snicholls::colours::green).view() -> "\x1b[32m" (the 16-colour code when one is set)
snicholls::ansi_start(snicholls::rgb(0x123456)).view() -> "\x1b[38;2;18;52;86m" (24-bit otherwise)

};

show("red", snicholls::colours::red);
show("green", snicholls::colours::green);
show("yellow", snicholls::colours::yellow);
show("orange", snicholls::colours::orange);
show("blue", snicholls::colours::blue);
show("magenta", snicholls::colours::magenta);
show("cyan", snicholls::colours::cyan);
show("grey", snicholls::colours::grey);
std::cout << "== any RGB colour (24-bit terminal sequence)\n";
show("teal", snicholls::rgb(0x008080));
failures += snicholls::hex(snicholls::rgb(0x008080)).view() == "#008080" ? 0 : 1;
failures += snicholls::ansi_start(snicholls::rgb(0x008080)).view() == "\x1b[38;2;0;128;128m" ? 0 : 1;
failures += snicholls::ansi_start(snicholls::colours::red).view() == "\x1b[31m" ? 0 : 1;
snicholls::colour_text<4> t;
t.append("abcdef");
t.append('g');
t.append_decimal(1);
failures += t.view() == "abcd" && std::string_view(t) == "abcd" ? 0 : 1; // bounded, never overflows
std::cout << (failures ? "FAILED\n" : "all checks passed\n");
return failures ? 1 : 0;
}

Relationships. acout.hpp prints with it (styled, colours::red in a message); display.hpp attaches it to types as an attribute. Group: snicholls-core.

Guarantees. Everything is constexpr, noexcept and allocation-free, and a colour is a trivially copyable pair. colour_text is bounded: appending past its capacity stops.

Errors. None.

Performance. Not benchmarked here; acout.hpp benchmarks coloured messages.

Tests and demos. tests/colour_test.cpp, demos/colour_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <string_view>.

Known issues. Foreground colours only: no background, bold or underline. A terminal without 24-bit support shows rgb(...) colours as its nearest guess, or not at all; the named palette uses the 16-colour codes for that reason.

Status. Stable.
