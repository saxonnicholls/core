Detailed Description

snicholls::ml::block_forward_sequence and block_backward for a block whose MLP is a mixture of experts: x += attention(norm(x)); x += moe(norm(x)), batched through a backend.

Overview. The pre-norm block of ml/transformer_block.hpp with its MLP replaced by moe_forward (ml/moe.hpp), for a configuration with experts > 0: the same norms, the same attention over a batch of sequences, the same residual adds, every step a call on the backend (TRAINING.md T9, T10). The weights, activations and gradients are the dense block's with an MoE part (moe_block_weights, moe_block_activations, moe_block_gradients); the forward pass returns the MoE's auxiliary losses, which the backward pass includes in its gradients.

constexpr std::size_t seqs = 2, n = 6, rows = seqs * n, d = C.d_model, q = C.q_size(), kv = C.kv_size();
static const ml::rope_table<float, n, C.head_dim> rope(ml::rope_base_v<C, float>);
// The parameters: two RMS-norm weights, the attention's four matrices, the mixture of experts
std::vector<float> norm1 = noise(d, 1, 0.1, 1.0), norm2 = noise(d, 2, 0.1, 1.0), wq = noise(q * d, 3, 0.4), wk = noise(kv * d, 4, 0.4),
wv = noise(kv * d, 5, 0.4), wo = noise(d * q, 6, 0.4), moe = noise(ml::moe_parameter_count(C), 7, 0.3);
const ml::moe_block_weights<float> w{norm1, {}, {{wq, q, d}, {wk, kv, d}, {wv, kv, d}, {wo, d, q}}, norm2, {},
ml::moe_weights_in<C>(std::span<const float>(moe))};
// The activations and gradients, the MoE's laid out by its own size functions
std::vector<float> x0(rows * d), h1 = x0, x1 = x0, h2 = x0, aq(rows * q), ak(rows * kv), av = ak, ay = aq, lse(rows * C.n_heads),
mv(ml::moe_activation_values(C, rows)), mw(ml::moe_gradient_work(C, rows)), gm(moe.size()), gq(wq.size()), gk(wk.size()),
gv(wv.size()), go(wo.size()), gn1(d), gn2(d), dq(rows * q), dk(rows * kv), dv = dk, dy = dq, scratch(rows * d);
std::vector<u32> mi(ml::moe_activation_indices(C, rows));
const ml::moe_block_activations<float> act{x0, h1, x1, h2, {aq, ak, av, {}, {}, ay, lse},
ml::moe_activations_in<C>(std::span<float>(mv), std::span<u32>(mi), rows)};
const ml::moe_block_gradients<float> grads{gn1, {}, gn2, {}, {dq, dk, dv, gq, gk, gv, go, {}, {}, {}, {}, {}, {}, dy},
ml::moe_gradients_in<C>(std::span<float>(gm), std::span<float>(mw), rows), scratch};
const auto input = noise(rows * d, 8, 1.0), target = noise(rows * d, 9, 1.0);
auto step = [&] {
std::vector<float> xs = input;
const auto aux = ml::block_forward_sequence<C>(backend, w, xs, rope, act, seqs);
float loss = aux.balance + aux.z;
std::vector<float> dxs(xs.size());
for (std::size_t i = 0; i < xs.size(); ++i) {
loss += 0.5f * (xs[i] - target[i]) * (xs[i] - target[i]) / rows;
dxs[i] = (xs[i] - target[i]) / rows;
}
for (auto* g : {&gm, &gq, &gk, &gv, &go, &gn1, &gn2})
std::fill(g->begin(), g->end(), 0.0f);
ml::block_backward<C>(backend, w, rope, act, dxs, grads, seqs);
for (auto [p, g] : {std::pair{&moe, &gm}, std::pair{&wq, &gq}, std::pair{&wk, &gk}, std::pair{&wv, &gv}, std::pair{&wo, &go},
std::pair{&norm1, &gn1}, std::pair{&norm2, &gn2}})
for (std::size_t i = 0; i < p->size(); ++i)
(*p)[i] -= 0.2f * (*g)[i];
return loss;
};

Relationships. ml/moe.hpp (the MLP), ml/transformer_block.hpp (the dense block, whose norm steps these reuse), ml/attention_layer.hpp, ml/composed_block.hpp (the same steps with either attention; DeepSeek-V3's block of latent attention and a mixture of experts). Group: snicholls-core.

Implementations. One: the batched path, products through a linalg backend. Decoding one token is ml/composed_block.hpp's block_forward with these parts (mlp_forward's overload for moe_weights).

Guarantees. As the batched dense block's: constexpr, no allocation, each step in a fixed order, so the bits do not depend on scheduling. The forward pass's output is the dense block's steps with moe_forward in place of mlp_forward_sequence, to the bit (tested by composing them by hand).

Errors. Preconditions, asserted, as the dense block's and moe_forward's. A dense configuration is a compile error here.

Performance. Not benchmarked as a whole: its parts are (ml/transformer_block.hpp, ml/moe.hpp).

Tests and demos. tests/ml/moe_block_test.cpp, demos/ml/moe_block_demo.cpp.

Dependencies. <cassert>, <cstddef>, <span>, <type_traits>, linalg/backend.hpp, ml/attention_layer.hpp, ml/moe.hpp, ml/transformer_block.hpp.

Known issues. None known.

Status. Experimental, new in 0.16.0.
