Detailed Description

Lazy evaluation, constexpr: lazy (a thunk evaluated at most once) and infinite streams with iterate, repeat, cycle, unfold, map, filter, zip_with, scanl, drop, drop_while, take and take_while, finished into std::arrays at compile time.

Overview. Haskell's lists are lazy: take 5 (filter even (iterate (*3) 1)) describes an infinite list and computes five elements of it. Here an infinite list is a fn::stream: a state and a step state -> {value, next state}, a value type that describes the list without computing it. The stream operations, in namespace snicholls::fn::stream, return new streams; take<N> and take_while<N> compute, into a std::array or a containers::inplace_vector:

// The Fibonacci numbers, infinite, then the first eight above 10 that are even.
constexpr auto fib = st::unfold(std::pair{0L, 1L}, [](std::pair<long, long> s) {
return std::pair{s.first, std::pair{s.second, s.first + s.second}};
});
constexpr auto even_big = st::filter([](long x) { return x % 2 == 0; }, st::drop_while([](long x) { return x <= 10; }, fib));
static_assert(st::take<3>(even_big) == std::array{34L, 144L, 610L});
// A compounding balance: scanl over an infinite stream of monthly rates, the first year taken.
constexpr auto balances = st::scanl([](double b, double r) { return b * (1 + r); }, 1000.0, st::repeat(0.01));
constexpr auto year = st::take<13>(balances);
static_assert(year[12] > 1126.8 && year[12] < 1126.9);

lazy(f) is a thunk: f is called the first time the value is wanted, and the value kept.

Haskell here
iterate f x stream::iterate(f, x)
repeat x, cycle xs stream::repeat(x), stream::cycle(xs)
unfoldr (infinite) stream::unfold(seed, step)
map, filter, zipWith, zip, scanl stream::map, filter, zip_with, zip, scanl
drop n, dropWhile p stream::drop(n, s), stream::drop_while(p, s)
take n, takeWhile p stream::take<N>(s), stream::take_while<N>(p, s) (at most N)
head, tail, xs !! n stream::head(s), stream::tail(s), stream::nth(s, n)

Relationships. fn::unfold (functional/fold.hpp, which take calls), functional/list.hpp (the same operations on finite arrays), containers::inplace_vector, std::views (lazy views of run-time ranges). Group: snicholls-core.

Implementations / variants. A stream is one class template; each operation wraps the step of the stream it is given. drop and drop_while advance the state when called.

Guarantees. constexpr, allocation-free. A stream is a value; taking from it does not change it. Trivially copyable when its state and step are. take<N> calls the step exactly N times. lazy evaluates f at most once per object (copies share nothing).

Errors. None. filter, drop_while and take_while on a stream with no element that passes (or none that fails) do not terminate, as in Haskell; at compile time the compiler's step limit stops them.

Examples.

// A thunk: the expensive calibration runs the first time it is needed, and once.
int calibrations = 0;
const fn::lazy vol{[&] { ++calibrations; return 0.2; }};
const double a = vol.force(), b = vol.force();

Performance. A take of a mapped, filtered stream is the loop that computes it. benchmarks/functional/lazy_benchmark.cpp, take<256> of a filtered, mapped iterate against the hand-written loop, fairness-checked: medians 509 ns and 530 ns, equal within noise (macOS x86-64 Xeon W-3245, Apple Clang 17, Release, 2026-11-26, 5 repetitions).

Tests and demos. tests/functional/lazy_test.cpp, demos/functional/lazy_demo.cpp.

Dependencies. <array>, <cstddef>, <functional>, <optional>, <type_traits>, <utility>, functional/fold.hpp and containers/inplace_vector.hpp.

Known issues and gotchas. A lazy keeps its value in a mutable member, so a constexpr lazy variable cannot be forced at compile time (its value cannot change after it is created); create and force it inside one constant evaluation, or use a plain constexpr value.

Status. Experimental, new in 0.27.0.
