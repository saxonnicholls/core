Detailed Description

snicholls::tracking::set_metric_solver with ospa and gospa: distances between a set of truths and a set of estimates that charge for localisation error, missed targets and false tracks.

Overview. A multi-target tracker is scored by comparing, at each time, the set of true positions with the set of estimated ones, sets of possibly different sizes. With a cut-off c (an error that counts as a miss) and an order p:

  • OSPA (Schuhmacher, Vo and Vo 2008): for m ≤ n points, ((1/n) (min_π Σ min(d, c)^p + c^p (n - m)))^(1/p), between 0 and c, normalised per target.
  • GOSPA (Rahmathullah, García-Fernández and Svensson 2017): (min_π Σ min(d, c)^p + (c^p / α) |n - m|)^(1/p). With α = 2 (the default) it splits into localisation error, missed targets and false tracks, which gospa reports separately.

Both solve an optimal assignment (combinatorics/assignment.hpp) over the points. set_metric_solver<T, D, MaxTruths, MaxEstimates> holds the cost matrix and the solver's arrays, sized at compile time; construct it once (on the heap if large).

// Three targets; the tracker has two of them, slightly off, one missed, and one false track
const std::array<pt, 3> truths{pt{{0, 0}}, pt{{20, 0}}, pt{{40, 0}}};
const std::array<pt, 3> estimates{pt{{19, 0}}, pt{{0, 2}}, pt{{70, 10}}};
const double c = 10, p = 2; // an error over 10 counts as a miss; order 2
tr::set_metric_solver<double, 2, 8, 8> solver; // sized at compile time: up to 8 points each side
const auto ospa = solver.ospa(truths, estimates, c, p).unwrap();
const auto gospa = solver.gospa(truths, estimates, c, p).unwrap(); // α = 2

Relationships. combinatorics/assignment.hpp, linalg/fixed.hpp. Stone Soup's OSPAMetric and GOSPAMetric; the generators that run them over a whole scenario live in the framework above core. Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation. Both are metrics (zero only for equal sets, symmetric, triangle inequality). Complexity is one assignment, O(m² n).

Errors. metric_error::too_large: more points than the solver holds. metric_error::invalid_parameters: c ≤ 0, p < 1, or α outside (0, 2].

Performance. Not benchmarked: the assignment dominates (see its benchmark).

Tests and demos. tests/tracking/metrics_test.cpp, demos/tracking/metrics_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <span>, combinatorics/assignment.hpp, linalg/fixed.hpp, math/constexpr_math.hpp, result.hpp.

Known issues. Distances are Euclidean on the given vectors; map states to positions first.

Status. Experimental, new in 0.19.0.
