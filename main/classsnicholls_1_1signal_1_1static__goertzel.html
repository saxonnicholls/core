Detailed Description

template<math::math_number T, double Frequency, double SampleRate, std::size_t N, auto Window = rectangular{}>
class snicholls::signal::static_goertzel< T, Frequency, SampleRate, N, Window >

A Goertzel detector whose frequency, sample rate, block length and window are template parameters: every constant computed by the compiler, the object the state alone.

Template Parameters
TA math::math_number.
FrequencyThe frequency, in the units of SampleRate.
SampleRateThe sample rate, positive.
NThe block length, at least 1.
WindowA window value of signal/window.hpp (rectangular{}, the default, applies none).
