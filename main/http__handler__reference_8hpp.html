Detailed Description

snicholls::route_table: the standard-library reference http_handler, a router from a method and an exact path to handlers.

Overview. A handler of handlers: add registers one per method and exact path; handle answers with it, 404 for an unknown path, 405 with an Allow header for a known path and another method, HEAD as GET without the body, and 500 with the fixed body internal error when a handler throws, so nothing of the exception (its message may carry user data or a secret) reaches the response. It is what a product's tests call routes through. add_pattern (0.27.0, from crtp's http_server_interface::route) registers a pattern whose :name segments capture into the request's path_params (match_route); exact paths win, then patterns in registration order.

route_table t;
static_cast<void>(t.add(http_method::get, "/orders", [](const http_request&) { return respond(200, "[]", "application/json"); }));
static_cast<void>(t.add(http_method::post, "/boom", [](const http_request&) -> http_response { throw std::runtime_error("secret detail"); }));
http_request r;
r.method = http_method::put;
r.path = "/orders";
const http_response not_allowed = t.handle(r); // 405, Allow: GET

Relationships. Models http_handler (concepts/http_handler.hpp); passes interfaces/http_handler_conformance.hpp in every form. Group: snicholls-core.

Implementations / variants. Exact paths only; path parameters and middleware belong to the routers above core.

Guarantees. handle never throws except std::bad_alloc; it is const over the table, so one table may serve many threads once built if its handlers are thread-safe. add is not thread-safe. Lookup is O(log routes).

Errors. add returns capability_errc::conflict for a route already registered and invalid_argument for a path not starting with / or an empty handler.

Performance. benchmarks/interfaces/http_handler_benchmark.cpp.

Tests and demos. tests/interfaces/http_handler_reference_test.cpp, demos/interfaces/http_handler_reference_demo.cpp.

Dependencies. <cstddef>, <functional>, <map>, <new>, <string>, <utility>, <vector>, capability_error.hpp, interfaces/http_handler.hpp.

Known issues. Exact paths only.

Status. New in 0.23.0; add_pattern in 0.27.0.
