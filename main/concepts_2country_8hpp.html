Detailed Description

snicholls::country_like: an ISO 3166-1 country as a concept.

Overview. A country answers:

  • name();
  • alpha2() and alpha3(), its ISO 3166-1 codes, and numeric();
  • currencies(), the ISO 4217 codes in use, as a span of string views;
  • calling_code(), its E.164 country calling code, 0 where none is assigned.

The concept is written over object expressions, so the compile-time types of country.hpp (snicholls::country::AU) and any object behind the virtual twin country_interface (interfaces/country.hpp) model it, as would a caller's own record of a country.

template <snicholls::country_like C>
constexpr bool uses(const C& c, std::string_view currency)
{
for (const auto code : c.currencies())
if (code == currency)
return true;
return false;
}
static_assert(uses(snicholls::country::PA{}, "USD") && !uses(snicholls::country::AU{}, "USD"));
