Detailed Description

snicholls::signal IIR filters: biquads with the Audio EQ Cookbook's coefficients, Butterworth design as second-order sections (low-, high-, band-pass, band-stop), sosfilt, and frequency responses, all constexpr.

Overview. A biquad<T> is one second-order section H(z) = (b0 + b1 z^-1 + b2 z^-2) / (1 + a1 z^-1 + a2 z^-2) (normalised so a0 = 1; a first-order section has b2 = a2 = 0). A filter is a cascade of sections, applied by sosfilt (scipy.signal.sosfilt: each section in transposed direct form II, state from the caller, zero for a filter at rest) and evaluated by sos_response at any frequency.

  • rbj_biquad(kind, f0, fs, q, gain_db): Robert Bristow-Johnson's Audio EQ Cookbook (low-pass, high-pass, band-pass with 0 dB peak, notch, all-pass, peaking, low shelf, high shelf; q as the cookbook's Q, the shelves' slope given through Q as well).
  • butterworth(order, band, w1, w2, sections): the digital Butterworth filter of scipy.signal.butter(order, Wn, btype, output='sos'), edges as fractions of Nyquist, prewarped and mapped by the bilinear transform. The analog prototype's poles e^(i pi (2k + order + 1) / 2 order) are placed in closed form, paired with their conjugates, and each pair becomes one section (band forms: each prototype pole gives two). The cascade's response is scipy's to rounding; the split of the gain among the sections differs (here each low- and high-pass section has unit gain at DC or Nyquist, each band-stop section unit gain at DC).
  • make_butterworth<T, Order>(band, w1, w2): the sections as a std::array, a compile-time table when constexpr.
// A sixth-order Butterworth low-pass at 0.1 of Nyquist: three sections, computed by the compiler.
constexpr auto lowpass = s::make_butterworth<double, 6, s::iir_band::lowpass>(0.1);
static_assert(lowpass.size() == 3);
// Filter a stream in blocks of 64: the state carries from block to block, as scipy's sosfilt with zi.
std::array<s::biquad_state<double>, 3> state{};
std::vector<double> x(1024), y(1024);
for (std::size_t i = 0; i < x.size(); ++i)
x[i] = m::sin(2 * m::pi * 0.01 * static_cast<double>(i)) + 0.5 * m::sin(2 * m::pi * 0.3 * static_cast<double>(i));
for (std::size_t b = 0; b < x.size(); b += 64)
s::sosfilt<double>(lowpass, state, std::span<const double>(x).subspan(b, 64), std::span<double>(y).subspan(b, 64));
// Remove mains hum: a notch at 50 Hz at 48 kHz, Q 30.
const auto notch = s::rbj_biquad(s::biquad_kind::notch, 50.0, 48000.0, 30.0);

Relationships. signal/complex.hpp; signal/fir.hpp for linear-phase filters. Group: snicholls-core.

Implementations. The cookbook's eight biquads; Butterworth only among the classical designs (Chebyshev and elliptic are not provided).

Guarantees. constexpr, no allocation; biquad and biquad_state are trivially copyable. sosfilt costs five multiplications and four additions per section per sample and may filter in place. Sections: (order + 1) / 2 for low- and high-pass, order for the band forms.

Errors. Preconditions, asserted: 0 < f0 < fs / 2; 0 < w1 (< w2) < 1; order >= 1; the sections' span has butterworth_sections(order, band) elements and the state one per section.

Performance. Not benchmarked: a section is the arithmetic written out.

Tests and demos. tests/signal/iir_test.cpp (the cookbook's responses at their defining frequencies, Butterworth magnitudes against the closed form 1 / (1 + (Omega / Omega_c)^(2 order)) at sample frequencies and scipy 1.13.1's sosfreqz and sosfilt, compile-time design), demos/signal/iir_demo.cpp.

Dependencies. <array>, <cassert>, <cstddef>, <span>, <type_traits>, signal/complex.hpp.

Known issues. High orders with narrow bands lose precision in float (poles near the unit circle); design in double and round the coefficients if float is needed.

Status. Experimental, new in 0.17.0.
