Detailed Description

snicholls::ml sampling the next token: argmax, sampling from probabilities or from logits at a temperature, top_k and top-k sampling with a fixed-size buffer, and nucleus (top-p) sampling with the caller's scratch.

Overview. The last step of generation, as llm.c's sample_mult and nanochat's sample_next_token do it. Every sampler takes its randomness as one uniform draw u in [0, 1) from the caller (stats::uniform_real(g) with a stats::wyrand), so the same seed gives the same text on every machine, and a batch of sequences can each have their own stream.

  • argmax(row): the index of the largest value, the first on ties (greedy decoding, temperature 0).
  • sample(probabilities, u): the inverse of the cumulative distribution at u.
  • sample_logits(logits, temperature, u): softmax at a temperature and the inverse CDF, in two passes with no row of probabilities stored. A temperature of 0 is argmax.
  • top_k<K>(row): the K largest values and their indices, largest first, in a std::array: O(n · K), no allocation, K known to the compiler.
  • sample_top_k<K>(logits, temperature, u): sampling among the K largest logits (nanochat's top_k).
  • sample_top_p(logits, temperature, p, u, scratch): sampling among the smallest set of most probable tokens whose probability reaches p (Holtzman et al.), sorting the caller's scratch of indices.
// One row of logits over a vocabulary of eight tokens
const std::array<float, 8> logits{1.0f, 4.0f, 2.5f, -1.0f, 3.5f, 0.0f, 2.0f, -2.0f};
st::wyrand g(2026); // one stream per sequence: the same seed gives the same text everywhere
const auto u = [&] { return static_cast<float>(st::uniform_real(g)); };
const std::size_t greedy = ml::argmax(logits); // temperature 0
const std::size_t warm = ml::sample_logits(logits, 0.8f, u()); // the model's distribution, sharpened
const std::size_t top3 = ml::sample_top_k<3>(logits, 1.0f, u()); // among tokens 1, 4 and 2 only
std::array<std::size_t, 8> scratch{};
const std::size_t nucleus = ml::sample_top_p(logits, 1.0f, 0.9f, u(), scratch);
const auto best = ml::top_k<3>(logits); // the candidates, largest first

Relationships. ml/softmax.hpp (the same stable exponentials), stats/random.hpp (the draw), ml/row.hpp. Group: snicholls-core.

Implementations. One each.

Guarantees. constexpr, no allocation. Deterministic: the same row and draw give the same index. Complexity: linear for argmax, sample, sample_logits; O(n · K) for top_k; O(n log n) for sample_top_p.

Errors. Preconditions, asserted: the row is not empty; u is in [0, 1); the temperature is not negative; p is in (0, 1]; scratch has the row's size. Rounding never makes a sampler return an index past the row: if u falls beyond the last cumulative sum, the last index with a nonzero probability is returned.

Performance. Not benchmarked: one or two passes over the row, dominated by the exponentials.

Tests and demos. tests/ml/sampling_test.cpp, demos/ml/sampling_demo.cpp.

Dependencies. <algorithm>, <array>, <cassert>, <cstddef>, <limits>, <span>, snicholls/core/math/constexpr_math.hpp, ml/row.hpp.

Known issues. NaN logits are not ordered; a row with one compares as if it were absent from the maximum.

Status. Experimental, new in 0.7.0.
