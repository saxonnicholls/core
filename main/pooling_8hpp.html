Detailed Description

snicholls::ml pooling for embeddings and rerankers: one row per sequence from its token rows by mean, first (CLS) or last token, with backward, and the classification head of a reranker (RANK).

Overview. An embedding model or a reranker ends where a language model would compute logits: the final hidden rows of each sequence become one row (llm_graph_context::build_pooling, src/llama-graph.cpp, llama.cpp 39039aa):

pooling_kind Row of sequence s llama.cpp
none every token's row, unchanged LLAMA_POOLING_TYPE_NONE
mean the mean of its rows (mean_pool_rows, ml/probe.hpp) MEAN: sentence-transformers, nomic-embed
cls its first row CLS: BERT, BGE
last its last row LAST: Qwen3-Embedding, e5-mistral
rank the CLS (or mean) row through rank_head RANK: BGE-reranker, Jina, Qwen3-Reranker
  • Sequences are packed end to end, as a llama.cpp batch holds them: starts gives each sequence's first row and the end of the last (starts.size() == sequences + 1).
  • pool_rows(kind, rows, width, starts, out) and pool_rows_backward(kind, dout, width, starts, drows).
  • rank_head(w, pooled, scratch, scores): RoBERTa's classification head as llama.cpp builds it: cls (a dense layer, its bias and an activation, tanh by default, then an optional layer norm), then cls_out (the score projection) and a softmax over the scores for Qwen3's reranker; either layer may be absent (rows == 0), as in Jina's single-layer head.
// Two sequences packed end to end, as a batch holds them: rows 0 to 2 and row 3, two values a row
const std::array<float, 8> rows{1, 2, 3, 4, 5, 6, 10, 20};
const std::array<std::size_t, 3> starts{0, 3, 4};
std::array<float, 4> mean{}, cls{}, last{};
ml::pool_rows<float>(ml::pooling_kind::mean, rows, 2, starts, mean); // sentence-transformers
ml::pool_rows<float>(ml::pooling_kind::cls, rows, 2, starts, cls); // BERT, BGE
ml::pool_rows<float>(ml::pooling_kind::last, rows, 2, starts, last); // Qwen3-Embedding
std::array<float, 8> none{}, drows{};
ml::pool_rows<float>(ml::pooling_kind::none, rows, 2, starts, none);
ml::pool_rows_backward<float>(ml::pooling_kind::mean, std::array<float, 4>{3, 3, 1, 1}, 2, starts, drows);
// A reranker: the first token's row through a dense layer, tanh, and a one-score projection
const std::array<float, 4> dense{1, 0, 0, 1};
const std::array<float, 2> project{2, -1};
const ml::rank_head_weights<float, float> head{.cls = {dense, 2, 2}, .out = {project, 1, 2}};
std::array<float, 2> scratch{};
std::array<float, 1> score{};
ml::rank_head(head, std::span<const float>(cls).first(2), scratch, score);

Relationships. ml/probe.hpp (mean_pool_rows, reused), ml/linear.hpp (the head's layers), ml/norm.hpp, ml/softmax.hpp, ml/activations.hpp; ml/reward_model.hpp (a reward head over the last token). Group: snicholls-core.

Implementations. One each.

Guarantees. constexpr, no allocation; linear in the rows. The mean sums in order and divides once (mean_pool_rows's order). An empty sequence pools to zeros.

Errors. Preconditions, asserted: starts non-decreasing from 0 to the rows; out sequences · width (rows' size for none); the head's layers fit each other; a nonempty sequence for cls and last.

Performance. Not benchmarked: one pass over the rows; the head is two matrix-vector products.

Tests and demos. tests/ml/pooling_test.cpp, demos/ml/pooling_demo.cpp.

Dependencies. <algorithm>, <cassert>, <cstddef>, <span>, <type_traits>, ml/activations.hpp, ml/linear.hpp, ml/norm.hpp, ml/probe.hpp, ml/softmax.hpp.

Known issues. ggml takes the mean as a matrix product with 1/n weights (build_inp_mean), so each term is scaled before the sum: the last bits can differ from core's sum-then-divide. A reranker whose model pools by mean before its head (pooling_type_cls) uses pool_rows(mean, ...) and then rank_head.

Status. Experimental, new in 0.17.0.
