Detailed Description

template<typename F>
requires (!std::is_same_v<F, std::remove_cvref_t<F>>)
struct snicholls::callable_traits< F >

A cv-qualified or reference type: the traits of the unqualified type.

A class with exactly one non-template operator() (a lambda, a function object, a std::function): the operator()'s traits, but called as an object, not through a member pointer.
