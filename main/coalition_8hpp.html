Detailed Description

Coalitions as bit strings, their enumeration, and games: functions from 2^N to a value.

Overview. A coalition of players 0 .. n-1 is a std::uint64_t with bit i set when player i is in it, so the 2^n coalitions are the integers 0 .. 2^n - 1 and a game, a value for every coalition, is a function or a table of 2^n entries. This header enumerates coalitions in the orders attribution needs, all constexpr:

order function use
every coalition, ascending for_each_coalition filling a table
one player changes per step for_each_coalition_gray revaluing incrementally
every coalition of size k for_each_coalition_of_size one layer of the hypercube
every subset / superset of S for_each_subset_of / ..._superset_of Mobius transforms, local checks
// Three factors: rates, credit, equity. A coalition is a bit string, so the eight are 0 .. 7.
constexpr game::coalition rates_and_equity = game::singleton(0) | game::singleton(2);
static_assert(game::coalition_size(rates_and_equity) == 2 && !game::contains(rates_and_equity, 1));
// A game maps 2^N to a value; this one is known at compile time, so its table is too.
constexpr auto pnl = [](game::coalition s) { return 1.0 * game::contains(s, 0) + 2.0 * game::contains(s, 1) + 0.5 * game::coalition_size(s); };
constexpr auto table = game::make_table<3>(pnl);
static_assert(table[0b111] == 1.0 + 2.0 + 1.5);
// Gray-code order changes one factor per step: revalue by moving one input at a time.
std::string path;
game::for_each_coalition_gray(3, [&path](game::coalition s, std::size_t) { path += std::to_string(s) + ' '; });

A game is anything callable with a coalition that returns a game_value: a lambda, a backtest wrapper, table_game over a precomputed table, memoized over an expensive function. make_table builds the table at compile time when the game is constexpr.

Relationships. game/shapley.hpp, game/harsanyi.hpp, game/owen.hpp and game/properties.hpp take these games; combinatorics/permutations.hpp for orderings of players. Group: snicholls-core.

Guarantees. Everything but memoized is constexpr and allocation-free except where it returns a std::vector. Enumerations visit each coalition exactly once. n is at most 63 for enumeration and at most max_table_players for a table.

Errors. None: the limits are preconditions, checked by assert and, where n is a template argument, by static_assert.

Performance. Each step is a few integer instructions; the cost is the game's.

Tests and demos. tests/game/coalition_test.cpp, demos/game/coalition_demo.cpp.

Dependencies. <array>, <bit>, <cassert>, <concepts>, <cstddef>, <cstdint>, <functional>, <span>, <type_traits>, <unordered_map>, <utility>, <vector>.

Known issues. memoized caches in a hash map and is not thread-safe.

Status. New in 0.5.0, experimental.
