Detailed Description

snicholls::ml attention for one query: attend over a block of keys and values in one pass, its backward pass, attention_accumulator, the partial that merges across workers, and attention_window for causal and sliding-window masks.

Overview. Scaled dot-product attention, out = softmax(scale · q·K) · V, for one query of one head: the inner loop of llm.c's attention_forward and of nanochat's attention. It is computed in one pass over the keys with a running softmax (flash attention's recurrence), so there is no row of scores to store and the keys can be split into blocks, each attended to by a different worker, a thread or a GPU block, and the partials merged.

  • attend(q, keys, values, out, scale): the keys and values are n rows of q.size() channels, laid end to end in one row each (a slice of a KV cache). Writes out and returns logsumexp of the scores, which the backward pass needs. With no keys, out is zero and the result -infinity.
  • attend_backward(q, keys, values, out, dout, lse, scale, dq, dkeys, dvalues): writes dq, adds into dkeys and dvalues (which sum over queries), recomputing each score from lse as flash attention does.
  • attention_accumulator<T, D>: a fixed-size partial, the running softmax plus the weighted sum of the values. add a score and a value, merge another worker's, result into the output. Trivially copyable; merge is commutative and associative up to rounding.
  • attention_window(pos, window): the keys a query at pos may see, causal and optionally limited to the last window positions (nanochat's sliding window). Pass that slice of the keys and values to attend.

Multi-head and grouped-query attention are loops over heads: each query head attends to the key and value head it shares. Rotate queries and keys with ml/rope.hpp first.

// A head of 4 channels and a cache of 6 positions, keys and values end to end
constexpr std::size_t d = 4, n = 6;
const std::array<float, d> q{1.0f, 0.5f, -0.5f, 0.0f};
std::array<float, n * d> keys{}, values{};
for (std::size_t j = 0; j < n; ++j)
for (std::size_t i = 0; i < d; ++i) {
keys[j * d + i] = std::sin(static_cast<float>(j * d + i));
values[j * d + i] = static_cast<float>(j); // value j is all j: the output is the mean position attended
}
const float scale = 1.0f / std::sqrt(static_cast<float>(d));
// One pass: no row of scores is stored
std::array<float, d> out{};
const float lse = ml::attend(q, keys, values, out, scale);
// Two workers take half the cache each and merge: the same output
ml::attention_accumulator<float, d> a, b;
for (std::size_t j = 0; j < n; ++j) {
float s = 0.0f;
for (std::size_t i = 0; i < d; ++i)
s += q[i] * keys[j * d + i];
(j < n / 2 ? a : b).add(scale * s, std::span<const float>(values).subspan(j * d, d));
}
a.merge(b);
std::array<float, d> merged{};
a.result(merged);
// A sliding window of 2 at position 5: only keys 4 and 5
const ml::key_range w = ml::attention_window(5, 2);
std::array<float, d> windowed{};
ml::attend(q, std::span<const float>(keys).subspan(w.first * d, w.size() * d),
std::span<const float>(values).subspan(w.first * d, w.size() * d), windowed, scale);

Relationships. Extends online_softmax (ml/softmax.hpp) with the values; ml/rope.hpp; ml/row.hpp. Group: snicholls-core.

Implementations. One.

Guarantees. constexpr, no allocation. attend reads each key and value once: O(n · D). The result equals softmax of the scores times the values up to rounding, and a sum of merged partials equals one pass up to rounding.

Errors. Preconditions, asserted: keys and values have the same size, a multiple of q.size(); out, dq and dout have q's size; dkeys and dvalues have keys' size. A score of -infinity (a masked key) has weight zero.

Performance. Against the same recurrence written by hand (benchmarks/ml/attention_benchmark.cpp), one query of 64 float channels: level at 256 keys, within 5% at 4,096, about 10.5 million keys per second (Xeon W-3245, Release, Apple clang 17, 2026-11-11, one thread).

Tests and demos. tests/ml/attention_test.cpp, demos/ml/attention_demo.cpp.

Dependencies. <algorithm>, <array>, <cassert>, <concepts>, <cstddef>, <limits>, <span>, snicholls/core/math/constexpr_math.hpp, ml/row.hpp, ml/softmax.hpp.

Known issues. Sums accumulate in T, as llm.c's do in float.

Status. Experimental, new in 0.7.0.

The backward pass of attend: writes dq, adds into dkeys and dvalues.

With p_j = e^(scale · q·k_j - lse) and D = dout·out: dv_j += p_j · dout, ds_j = p_j · (dout·v_j - D), dq = scale · sum ds_j · k_j, dk_j += scale · ds_j · q.
