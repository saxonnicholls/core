Detailed Description

snicholls::tracking::constant_velocity, singer, constant_turn, combined and the other motion models: how a state moves over a time step, and how uncertain the move is.

Overview. A transition model maps a state over dt seconds and says how much process noise the step adds. Every model here satisfies transition_model:

  • static constexpr std::size_t dim, and value_type;
  • apply(x, dt): the predicted state;
  • jacobian(x, dt): ∂apply/∂x (the matrix F(dt) itself for a linear model);
  • covariance(dt): the process noise Q(dt).

A linear_transition also has matrix(dt). Models compose with combined<Ms...>, a block-diagonal type, so a 2-D constant-velocity target is combined<constant_velocity<double>, constant_velocity<double>>, state (x, ẋ, y, ẏ), with no run-time cost for the composition.

Model State Noise
constant_nth_derivative<T, N>{q} a value and its first N derivatives white N-th derivative, closed form
random_walk, constant_velocity, constant_acceleration N = 0, 1, 2
nth_derivative_decay<T, N>{q, k} the N-th derivative decays at rate k integrated by Gauss-Legendre
ornstein_uhlenbeck (N = 1), singer (N = 2)
singer_approximate<T>{q, k} Singer's matrix, constant acceleration's noise closed form
known_turn_rate<T>{q₁, q₂, ω} (x, ẋ, y, ẏ) turning at a known rate per axis, as constant velocity
constant_turn<T>{q_x, q_y, q_ω} (x, ẋ, y, ẏ, ω), nonlinear analytic Jacobian
combined<Ms...> the models side by side block diagonal

Formulas, state order and noise are Stone Soup's (models/transition/linear.py, nonlinear.py), so the matrices compare with it element for element. The process noise uses |dt|, so a negative step (retrodiction) has the same noise as the positive one.

// A ship in the plane, state (x, vx, y, vy): constant velocity on each axis, the composition free at run time
const auto ship = tr::combine(tr::constant_velocity<double>{0.05}, tr::constant_velocity<double>{0.05});
const la::fixed_vector<double, 4> now{{0, 5, 0, 2}}; // at the origin, 5 m/s east, 2 m/s north
const auto in_ten = ship.apply(now, 10); // (50, 5, 20, 2)
const auto f = ship.matrix(10); // block diagonal [[1, 10], [0, 1]]
const auto q = ship.covariance(10); // q dt^3 / 3 = 16.7 m^2 of position variance per axis
std::printf(" ship after 10 s: (%.1f, %.1f), position sd %.2f m\n", in_ten[0], in_ten[2], std::sqrt(q(0, 0)));
// A manoeuvring target with its turn rate in the state, (x, vx, y, vy, w): nonlinear, so it has a Jacobian
const tr::constant_turn<double> turning{0.05, 0.05, 1e-4};
const la::fixed_vector<double, 5> banking{{0, 10, 0, 0, std::numbers::pi / 20}}; // 9 degrees a second
const auto after_turn = turning.apply(banking, 20); // half a circle: heading west
const auto jt = turning.jacobian(banking, 20);
std::printf(" turning target after 20 s: (%.2f, %.2f), velocity (%.2f, %.2f)\n", after_turn[0], after_turn[2], after_turn[1], after_turn[3]);

Relationships. linalg/fixed.hpp, math/constexpr_math.hpp; tracking/kalman.hpp and tracking/unscented.hpp predict with them. Group: snicholls-core.

Implementations. constant_nth_derivative: Fᵢⱼ = dt^(j-i) / (j-i)!, Qᵢⱼ = q |dt|^(2N+1-i-j) / ((N-i)! (N-j)! (2N+1-i-j)). nth_derivative_decay: Stone Soup's closed-form F, and Q = q ∫₀^|dt| F(τ) e_N e_Nᵀ F(τ)ᵀ dτ by 16-point Gauss-Legendre on as many panels as k |dt| needs (at least one, at most 64). The nodes are computed at compile time. constant_turn and known_turn_rate switch to series when |ω dt| < 0.5, where sin(ω dt) / ω and the Jacobian's turn-rate column would cancel; twelve terms are exact to rounding there.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation, no recursion. Every model but combined is an aggregate of its parameters, trivially copyable; combined holds its models in a std::tuple. covariance(dt) is symmetric positive semi-definite.

Errors. None: parameters are the caller's to choose (a decay rate k > 0).

Performance. Not benchmarked on their own. Form matrix(dt) and covariance(dt) once for many targets stepped over the same dt, and use predict(prior, F, Q) (tracking/kalman.hpp, whose benchmark does so).

Tests and demos. tests/tracking/transition_test.cpp, demos/tracking/transition_demo.cpp.

Dependencies. <array>, <concepts>, <cstddef>, <tuple>, <type_traits>, <utility>, linalg/fixed.hpp, math/constexpr_math.hpp.

Known issues. Stone Soup integrates nth_derivative_decay's noise with QUADPACK; the two agree to about 1e-12 relative.

Status. Experimental, new in 0.19.0.
