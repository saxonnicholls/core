Detailed Description

snicholls::error_sink, the virtual twin of snicholls::error_sink_like; text_error_sink; the adapter error_sink_model.

Overview. The run-time form of a log sink: result::log_err(sink) and error_sink::log_error build an error_report and hand it to write once. text_error_sink writes text to a stream; error_sink_model<S> puts any error_sink_like type behind the interface. Included by traced.hpp, so existing code that includes only traced.hpp sees the same names.

std::ostringstream log;
std::vector<std::unique_ptr<error_sink>> sinks; // chosen at run time
sinks.push_back(std::make_unique<text_error_sink>(log, error_level::warning));
sinks.push_back(std::make_unique<error_sink_model<last_level_sink>>());
for (auto& sink : sinks)
sink->log_error(error_level::error, traced<load_error>(load_error::disk_full));

Relationships. concepts/error_sink.hpp (the concept), traced.hpp, result.hpp. Group: snicholls-core.

Implementations. text_error_sink here; error_sink_model<S> over any concept-modelling type; a super-log adapter in the consuming library.

Guarantees. See each class. log_error never throws.

Errors. None escape log_error; write may throw.

Performance. Not benchmarked (error path only).

Tests and demos. tests/interfaces/error_sink_test.cpp, demos/interfaces/error_sink_demo.cpp; the conformance suite tests/support/snicholls/core/conformance/error_sink.hpp.

Dependencies. traced.hpp, <mutex>, <ostream>, <string>.

Known issues. None.

Status. Experimental, pre-1.0. Moved out of traced.hpp in 0.23.0.
