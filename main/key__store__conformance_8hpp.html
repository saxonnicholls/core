Detailed Description

snicholls::run_key_store_conformance: the conformance kit of the key_store contract.

Overview. Drives any key_store, in either form, through the contract of concepts/key_store.hpp and reports which check failed (interfaces/capability_conformance.hpp). The probe is a default-constructible type with

  • auto& store(): the implementation (a store, a key_store_interface&, a key_store_ref);
  • key_spec supported(): a spec the store can create;
  • std::optional<key_spec> unsupported(): a spec it cannot, or std::nullopt when it holds every algorithm;
  • void provider_fails(capability_errc code, std::string_view response): the next create fails with code, as though the KMS had answered response.

The checks: create makes version one active, rotate retires the previous version and list shows both, a retired key cannot rotate, destroy removes every version and the id is never reused, an unknown id is not found everywhere, an algorithm it cannot hold is unsupported, a label too long is invalid, a provider failure never leaks its response.

const capability_conformance_report report = run_key_store_conformance<probe>();

Relationships. concepts/key_store.hpp, interfaces/key_store.hpp, interfaces/capability_conformance.hpp. Group: snicholls-core.

Implementations / variants. One kit for every form.

Guarantees. As interfaces/capability_conformance.hpp: no exception escapes a check.

Errors. Failures are data.
