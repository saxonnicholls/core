std::pair< double, double > snicholls::stats::bootstrap_distribution::bca_interval ( double confidence,
std::span< const double > jackknife ) const
inlinenodiscard

The BCa interval (Efron 1987): percentiles corrected for the bootstrap distribution's bias and skew.

More accurate than the percentile interval for a skewed statistic (a variance, a Sharpe ratio, a maximum drawdown). The bias correction comes from the share of replicates below the estimate, the acceleration from the jackknife (stats::jackknife). The same formulas as SciPy's bootstrap(method="BCa").

Parameters
confidencec, for example 0.95.
jackknifeThe statistic on the data with each observation left out in turn.
Returns
The interval; NaN ends if every replicate is on one side of the estimate.
