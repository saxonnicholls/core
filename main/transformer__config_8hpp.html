Detailed Description

snicholls::ml::transformer_config: the architecture of a transformer layer as one compile-time value, from which every size is a constant.

Overview. Transformers differ in a handful of choices: the widths, how many key-value heads the query heads share, the normalisation, the MLP's activation, the positional encoding, a sliding window, a soft cap on the scores, biases. transformer_config holds them as one structural aggregate, passed as a template parameter to attention_forward, mlp_forward and block_forward, so every size is a constant: scratch is fixed-size, loops are bounded, nothing is allocated, and one layer of code serves GPT-2, Llama and nanochat. Multi-head, grouped-query and multi-query attention are one code path with n_kv_heads equal to n_heads, a divisor of it, or 1.

// Grouped-query attention: 8 query heads share 2 key-value heads; RMS norm, SwiGLU, RoPE, a sliding window of 512
constexpr ml::transformer_config mine{.d_model = 512, .n_heads = 8, .n_kv_heads = 2, .head_dim = 64, .d_ff = 1536,
.norm = ml::norm_kind::rms, .norm_eps = 1e-6, .mlp = ml::mlp_kind::swiglu,
.rope = ml::rope_kind::half, .rope_base = 10000, .window = 512};
static_assert(ml::valid(mine)); // every template taking a configuration checks this too
// Read a floating-point member through its reader, which evaluates it at compile time
constexpr float eps = ml::norm_eps_v<mine, float>;

Latent attention, multi-token prediction and long context (TRAINING.md T11), one group of fields after the others, every default leaving a model as it was: multi-head latent attention's ranks and widths (q_lora_rank, kv_lora_rank, qk_rope_dim, v_head_dim; ml/latent_attention.hpp), RoPE's rescaling for a long context (rope_scaling, rope_factor, rope_original_context, YaRN's β, α and temperature coefficient; ml/rope.hpp), learnable attention sinks, a sparse selection of sparse_top_k keys, and multi-token prediction's depth and weight (ml/multi_token_prediction.hpp). valid_long_context checks them; deepseek_v3 and tiny_mla set them.

// Multi-head latent attention with YaRN to 4x a trained 2048, a sink per head and one multi-token prediction module
// (TRAINING.md T12): every other model leaves these fields at their defaults
constexpr ml::transformer_config latent{.d_model = 512, .n_heads = 8, .n_kv_heads = 8, .head_dim = 96, .d_ff = 1536,
.norm = ml::norm_kind::rms, .norm_eps = 1e-6, .mlp = ml::mlp_kind::swiglu,
.rope = ml::rope_kind::interleaved, .rope_base = 10000, .q_lora_rank = 192,
.kv_lora_rank = 128, .qk_rope_dim = 32, .v_head_dim = 64,
.rope_scaling = ml::rope_scaling_kind::yarn_index_ramp, .rope_factor = 4,
.rope_original_context = 2048, .attention_sinks = true, .mtp_depth = 1,
.mtp_loss_weight = 0.3};
static_assert(ml::valid(latent) && ml::valid_long_context(latent) && latent.latent() && latent.qk_nope_dim() == 64);
constexpr auto scaling = ml::rope_scaling_v<latent, double>; // for rope_table(base, scaling)
constexpr double temperature = ml::yarn_attention_factor_v<latent, double>;

Gated MLPs (INFERENCE.md I12). mlp is one of the plain activations (GELU, tanh GELU, ReLU², quick GELU) or a gated linear unit (gated(mlp): SwiGLU, ReGLU, the three GEGLUs, gpt-oss's clamped SwiGLU and SwiGLU with a clamp; ml/glu.hpp). The clamped ones read glu_alpha and glu_limit, one group after the others whose defaults (gpt-oss's 1.702 and 7) change no other kind.

// gpt-oss's MLP: a clamped SwiGLU, with the constants read at compile time
constexpr ml::transformer_config oss{.d_model = 2880, .n_heads = 64, .n_kv_heads = 8, .head_dim = 64, .d_ff = 2880,
.mlp = ml::mlp_kind::swiglu_oai, .rope = ml::rope_kind::half, .rope_base = 150000};
static_assert(ml::valid(oss) && ml::gated(oss.mlp) && !ml::gated(ml::mlp_kind::gelu_quick));
constexpr float alpha = ml::glu_alpha_v<oss, float>, limit = ml::glu_limit_v<oss, float>;

Linear-time sequence mixers (TRAINING.md T15), one group of fields after the others, every default leaving a model as it was: the mixer a layer uses in place of attention (mixer: Mamba-2 or the gated delta rule as layers; gated linear attention and RWKV as ops), its heads, channels, groups, convolution and chunk, and the hybrid stack's pattern (hybrid_period, hybrid_attention_offset, read by layer_is_attention). valid_mixer checks them; mixer_state_size is a sequence's state; tiny_mamba2 and tiny_gated_deltanet set them.

// Qwen3-Next's hybrid stack in miniature: gated delta rule layers, one attention layer in every four
constexpr ml::transformer_config hybrid = ml::tiny_gated_deltanet;
static_assert(ml::valid_mixer(hybrid));
std::size_t attention_layers = 0;
for (std::size_t layer = 0; layer < 12; ++layer)
attention_layers += ml::layer_is_attention(hybrid, layer) ? 1 : 0;
const std::size_t state = ml::mixer_state_size(hybrid); // per sequence and mixer layer, whatever the length

Relationships. ml/linear.hpp, ml/mlp.hpp, ml/kv_cache.hpp, ml/attention_layer.hpp, ml/transformer_block.hpp; the plan is INFERENCE.md. Group: snicholls-core.

Mixture of experts. With experts > 0 the MLP is a mixture of experts (ml/moe.hpp, TRAINING.md T10): top_k of experts routed experts of expert_d_ff per token, scored as scoring says, shared_experts dense experts every token passes through, the balance settings, and DeepSeek-V3's node-limited routing (expert_groups, group_top_k: a token's experts come from its best group_top_k of expert_groups groups; 0 and 0, the defaults, route over every expert). With experts == 0 (the default) every expert field is 0 and nothing changes for a dense model.

// A mixture of experts in DeepSeek-V3's style: 16 fine-grained experts of 256, each token to 4, one shared expert,
// sigmoid scoring scaled by 2.5, the selection bias stepped by 0.001 (ml/moe.hpp)
constexpr ml::transformer_config experts = [] {
auto c = mine;
c.d_ff = 256;
c.experts = 16;
c.top_k = 4;
c.shared_experts = 1;
c.expert_d_ff = 256;
c.scoring = ml::moe_scoring::sigmoid;
c.route_scale = 2.5;
c.bias_update_rate = 0.001;
return c;
}();
static_assert(ml::valid(experts) && experts.moe() && !mine.moe());

Attention masks. mask chooses the keys a query sees (attention_keys, ml/attention.hpp): causal (the default, with window), bidirectional (a ViT; the encoders and predictors of a joint embedding predictive architecture, TRAINING.md T11) or block_causal with mask_block tokens per block.

Implementations. One. The presets (gpt2_small, gpt2_medium, gpt2_large, llama3_8b, nanochat_d20, olmoe_1b_7b, vit_base, deepseek_v3) are the shapes of those models; tiny_moe is a small mixture of experts and tiny_mla a small latent attention for tests.

Guarantees. constexpr, trivially copyable, structural (usable as a template argument). valid(c) checks the invariants below; every class and function templated on a configuration rejects an invalid one at compile time.

Errors. None at run time. A configuration whose n_heads is not a multiple of n_kv_heads, with an odd head_dim under RoPE, or with a zero width is a compile error (static_assert with a snicholls::ml:: message).

Performance. Not applicable: a value read by the compiler.

Tests and demos. tests/ml/transformer_config_test.cpp, demos/ml/transformer_config_demo.cpp.

Dependencies. <cstddef>, snicholls/core/math/constexpr_math.hpp, snicholls/core/ml/attention.hpp (attention_mask), snicholls/core/ml/rope.hpp (rope_layout, rope_scaling).

Known issues. Clang (Apple clang 17, Clang 18) miscompiles a run-time read of a double member of a class-type template argument: it loads garbage (C.norm_eps reads as 6e-314), while the same read in a constant expression is right, and GCC is right in both. Read the floating-point members through norm_eps_v, rope_base_v, attention_softcap_v, the mixture of experts' route_scale_v, bias_update_rate_v, balance_loss_weight_v and z_loss_weight_v, rope_factor_v, mtp_loss_weight_v, rope_scaling_v and yarn_attention_factor_v, and glu_alpha_v and glu_limit_v, which evaluate them at compile time, never as C.norm_eps in code that runs; every header here does. Wrapping the value in a class (its bits as an integer) is worse: Clang 18 crashes.

Status. Experimental, new in 0.8.0; the mixture-of-experts fields, mask, mask_block, vit_base, the fields of TRAINING.md T12, deepseek_v3 and tiny_mla new in 0.16.0; the gated kinds after swiglu, gated, glu_alpha, glu_limit and their readers, the mixer fields, valid_mixer, mixer_state_size, layer_is_attention, mixer_scale_v, tiny_mamba2 and tiny_gated_deltanet new in 0.17.0.
