Detailed Description

snicholls::signal::complex<T>, a trivially copyable complex number for the transforms, usable in constant evaluation, and twiddle<T>(k, n), the root of unity e^(-2 pi i k / n) to the last bit the type allows.

Overview. The transforms of signal/ need a complex number that works in a static_assert, is plain data on a GPU or an FPGA, and costs nothing at run time. std::complex is constexpr in C++20 only in part (no abs, no polar), its multiplication recovers from infinities with calls that are not constexpr in every standard library, and it cannot be specialised for a number type of the caller's. complex<T> is two Ts, re and im, with the field operations, conj, norm (|z|^2), abs, arg, polar and expi, all constexpr, in the argument's type (float, double, long double or a math::math_number of the caller's).

twiddle<T>(k, n) is e^(-2 pi i k / n). It reduces k / n to the first octant with integer arithmetic before any trigonometry, so the quarter turns are exact (twiddle(n / 4, n) is -i exactly) and every value is the correctly reduced sine and cosine of an angle below pi / 4, computed in math_limits<T>::compute_type (double for float) and rounded once.

using cd = s::complex<double>;
constexpr cd a{3, 4}, b{1, -2};
static_assert(a * b == cd{11, -2} && a + b == cd{4, 2} && s::conj(a) == cd{3, -4} && s::norm(a) == 25.0);
constexpr double r = s::abs(a); // 5, at compile time
constexpr cd q = a / b; // (3 + 4i) / (1 - 2i) = -1 + 2i
constexpr cd root = s::sqrt(cd{-9, 0}); // 3i
constexpr cd turn = s::twiddle<double>(1, 4); // e^(-2 pi i / 4) = -i, exactly
constexpr cd eighth = s::twiddle<double>(1, 8); // (1 - i) / sqrt 2
const cd p = s::polar(2.0, m::pi / 3) * s::expi(-m::pi / 3); // 2, the angles cancel

Relationships. Every header of signal/: signal/fft.hpp builds its tables with twiddle. The functions are math/constexpr_math.hpp's. Group: snicholls-core.

Implementations. One. There is deliberately no conversion to std::complex, so this header does not pull in <complex>: the two layouts are the same (an array of two T, real part first), as cuFFT's cufftComplex and C's _Complex are, so data can be exchanged by copying.

Guarantees. Trivially copyable, standard layout, sizeof(complex<T>) == 2 * sizeof(T), structural (usable as a non-type template parameter). Every function is constexpr and noexcept. Multiplication is the textbook formula, without C's recovery of infinities: an infinite operand may give NaN where Annex G gives an infinity.

Errors. None. Division by zero gives infinities or NaN, as the type's own division does.

Performance. Not benchmarked on its own; signal/fft.hpp's benchmark runs on it. Each operation is the arithmetic written out, inlined.

Tests and demos. tests/signal/complex_test.cpp, demos/signal/complex_demo.cpp.

Dependencies. <cstddef>, <type_traits>, snicholls/core/math/constexpr_math.hpp.

Known issues. abs is sqrt(re^2 + im^2) without rescaling, so it overflows when a part exceeds the square root of the type's largest value (about 1e154 for a double).

Status. Experimental, new in 0.17.0.
