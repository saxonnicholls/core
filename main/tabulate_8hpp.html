Detailed Description

snicholls::fn::tabulate<N>(f): a function of an index, memoised at compile time into a table lookup.

Overview. tabulate<N>(f) calls f(0) ... f(N - 1) once, when it is built (by the compiler, for a constexpr variable), and returns a function that looks the answer up:

// A discount factor per day for a year at 5%, computed by the compiler. At run time: one load.
constexpr auto discount = fn::tabulate<366>([](std::size_t day) {
double d = 1.0;
for (std::size_t i = 0; i < day; ++i) d /= 1.0 + 0.05 / 365;
return d;
});
static_assert(discount(0) == 1.0);

It is memoisation that can be constexpr: the domain is known and small, the values are computed before the program runs, and the hot path is one indexed load. Use it for a pure function of a small index that is called often: binomial coefficients, a discount factor per day, a lookup by enumerator. The table itself, as a std::array, is snicholls::table<N>(f) (snicholls/core/iterate.hpp), which this calls.

Run-time memoisation is deliberately absent. A cache filled as calls arrive needs mutable state and, for an unbounded domain, allocation; both are outside core's rules (compile time first, no hidden state, allocation-free hot paths). Where that is wanted it belongs to the caller, or to a library above core, wrapped around a pure function from here.

Relationships. snicholls::table (the array), snicholls::constexpr_map and containers/static_map (tables keyed by something other than an index), functional/combinators.hpp. Group: snicholls-core.

Implementations / variants. One.

Guarantees. constexpr: building and calling. The closure holds the std::array of the N values and nothing else, so it is trivially copyable when the values are. A call returns the value by value, noexcept when copying it is. Building is noexcept when f and the moves are.

Precondition
The index is less than N (checked with assert; at compile time an out-of-range index does not compile).

Errors. None; see the precondition.

Examples.

// A row of Pascal's triangle, for a binomial tree of 30 steps.
constexpr auto choose_30 = fn::tabulate<31>([](std::size_t k) {
std::uint64_t r = 1;
for (std::size_t i = 1; i <= k; ++i) r = r * (30 - k + i) / i;
return r;
});
static_assert(choose_30(15) == 155'117'520);

Performance. One indexed load per call; not benchmarked.

Tests and demos. tests/functional/tabulate_test.cpp, demos/functional/tabulate_demo.cpp.

Dependencies. <array>, <cassert>, <cstddef>, <type_traits>, <utility>, snicholls/core/iterate.hpp and snicholls/core/functional/combinators.hpp.

Known issues and gotchas. A large N costs compile time (each value is evaluated by the compiler) and the table's size in the binary; keep tables to what the hot path needs.

Status. Experimental, new in 0.27.0.
