Detailed Description

snicholls::chain_interface: the virtual twin of chain_like, and the adapters between them.

Overview. For code that chooses a chain at run time, a wallet's list of networks or a config file, without templates. chain_model<T> adapts any chain_like type. The interface models chain_like:

  • native_asset() returns the value snicholls::asset;
  • chain_id() returns std::optional<std::uint64_t>, empty for a chain with no EIP-155 identifier.
std::vector<std::unique_ptr<chain_interface>> networks;
networks.push_back(std::make_unique<chain_model<chain::ethereum>>());
networks.push_back(std::make_unique<chain_model<chain::solana>>());
