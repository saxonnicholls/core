Detailed Description

snicholls::phone_number: a normalised E.164 telephone number.

snicholls::phone_number - an ITU-T E.164 number: a country calling code of 1 to 3 digits and the national significant number after it, at most 15 digits in all, held in one 64-bit word.

auto r = snicholls::parse_phone_number("+61 412 345 678"); // result<phone_number, phone_errc>, no exceptions
snicholls::parse_phone_number("00 61 412-345-678"); // the same number: 00 is the international prefix
snicholls::parse_phone_number("0412 345 678"); // err(phone_errc::missing_country_code): no region guessed
snicholls::to_text(*r).view(); // "+61412345678", no allocation
r->country_code(); r->national_number().view(); // 61, "412345678"
using namespace snicholls::literals; constexpr auto n = "+61412345678"_e164; // checked at compile time

Semantics:

  • An aggregate holding one std::uint64_t: sizeof 8, trivially copyable, standard layout, structural (usable as a template argument). Value-initialised is the empty number, which no parse produces.
  • Every non-empty value has a country calling code assigned in E.164 (detail/e164_country_codes.hpp, generated from libphonenumber's metadata) and at least 2, at most 15 - (code length) digits after it.
  • == and <=> are constexpr and order the canonical text as strings ("+1..." < "+44..." < "+61..."); std::hash is constexpr and noexcept (not portable, like every std::hash).
  • Text is the canonical "+" and digits form (E.164 in its E.123 written form without spaces). Input accepts the written forms people use: spaces, hyphens, dots, slashes and one level of parentheses between the digits, and the international prefix 00 in place of "+".
