Detailed Description

The std-only in-memory key-value store. Models key_value_store, kv_health and kv_backup.

See the file documentation for its guarantees and its controls as a test fake.

◆ inject_failure()

void snicholls::reference_key_value_store::inject_failure ( kv_errc error,
std::size_t after = 0 )
inlinenoexcept

Makes the write after writes from now fail with error, and the call containing it change nothing.

Every put, insert, erase, erase_range and checkpoint is one write; a batch counts each of its writes. inject_failure(e) fails the next write call; inject_failure(e, 2) fails a batch at its third write. One-shot: it is spent by the failure. A later call replaces it.

Parameters
errorthe error to fail with.
afterhow many writes succeed first.
