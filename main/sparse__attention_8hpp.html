Detailed Description

snicholls::ml::attend_selected and its backward pass, attention over the keys an index list selects; and DeepSeek Sparse Attention's lightning indexer: its scores, their backward pass, the top-k selection and the indexer's KL loss.

Overview. Sparse attention lets each query read k of its n visible keys, so a long context costs n · k instead of n². DeepSeek Sparse Attention (DeepSeek-V3.2-Exp, 2025, section 2.1) chooses them with a lightning indexer, a few cheap heads whose scores are 

I_{t,s} = Σ_j w_{t,j} · ReLU(q_{t,j} · k_s)       (eq. 1)

(q_{t,j} and w_{t,j} from the query token, k_s one shared key per token), takes the top k (2048 in the report) and attends to those keys only (eq. 2), in MLA's MQA mode. The pieces, each a primitive:

  • indexer_scores(q, weights, keys, scores): eq. 1 for one query over n keys; indexer_scores_backward gives the gradients in the indexer's query, weights and keys.
  • select_top_k(scores, indices): the indices.size() best keys (ties to the earlier key), written in position order; returns how many (fewer when there are fewer keys).
  • attend_selected(q, keys, values, indices, out, scale, sink): attention over the selected rows of keys and values, folded in the order given, with an optional sink (ml/attention_sink.hpp); with every key selected in order it is attend to the bit. attend_selected_backward adds into the selected rows' gradients only.
  • indexer_kl_loss(target, scores, dscores): the indexer's training loss for one query, KL(p ‖ softmax(I)) (eqs. 3 and 4), and its gradient in the scores. The target p is the main attention's weights summed over the heads and normalised to sum to 1, over every visible key in the dense warm-up and over the selected ones in the sparse stage; the indexer's input is detached, so this loss trains the indexer alone and the language-model loss the rest.

The indexer's projections (its queries from MLA's query latent, its key from the token through a layer norm, its weights from the token), its RoPE, the Hadamard rotation and the FP8 storage are the model's, above these primitives; as are its 64 heads of 128 (the released configuration's).

Native Sparse Attention (Yuan et al., 2025) has three branches, gated per query by a sigmoid: attention to compressed blocks (an MLP over blocks of l keys at stride d), to the top n selected blocks of l' keys chosen by the compressed branch's scores, and to a sliding window. Its selected branch is attend_selected over the chosen blocks' positions, its window attention_window; the block compression, the block scoring and the gates are deferred (TRAINING.md T12).

// Twelve keys of 4 channels; the indexer has 2 heads of 3 channels and one key of 3 per position
constexpr std::size_t n = 12, d = 4, ih = 2, id = 3, k = 4;
std::array<float, n * d> keys{}, values{};
std::array<float, n * id> index_keys{};
for (std::size_t j = 0; j < n; ++j) {
for (std::size_t i = 0; i < d; ++i) {
keys[j * d + i] = std::sin(0.7f * static_cast<float>(j * d + i));
values[j * d + i] = static_cast<float>(j);
}
for (std::size_t i = 0; i < id; ++i)
index_keys[j * id + i] = std::cos(0.9f * static_cast<float>(j + 2 * i));
}
const std::array<float, d> q{0.5f, -0.5f, 1.0f, 0.25f};
const std::array<float, ih * id> index_q{1.0f, 0.5f, -0.5f, 0.2f, 0.8f, 0.4f};
const std::array<float, ih> index_w{0.7f, 0.3f};
// I_s = Σ_j w_j ReLU(q_j · k_s); keep the best k, in position order
std::array<float, n> scores{};
ml::indexer_scores(index_q, index_w, index_keys, scores);
std::array<std::uint32_t, k> chosen{};
const std::size_t count = ml::select_top_k(scores, std::span<std::uint32_t>(chosen));
// Attention over the chosen keys only
std::array<float, d> out{};
const float scale = 0.5f;
const float lse = ml::attend_selected(q, keys, values, std::span<const std::uint32_t>(chosen).first(count), out, scale);
// Its backward pass reaches the chosen rows only
const std::array<float, d> dout{1.0f, 0.0f, 0.0f, 0.0f};
std::array<float, d> dq{};
std::array<float, n * d> dkeys{}, dvalues{};
ml::attend_selected_backward(q, keys, values, std::span<const std::uint32_t>(chosen).first(count), out, dout, lse, scale, none, dq,
dkeys, dvalues);
// The indexer learns from the main attention's weights over every key (dense warm-up), by KL divergence
std::array<float, n> target{}, dscores{};
std::array<float, d> full{};
const float full_lse = ml::attend(q, keys, values, full, scale);
for (std::size_t j = 0; j < n; ++j) {
float s = 0.0f;
for (std::size_t i = 0; i < d; ++i)
s += q[i] * keys[j * d + i];
target[j] = std::exp(scale * s - full_lse);
}
const float kl = ml::indexer_kl_loss(target, scores, dscores);
std::array<float, ih * id> dindex_q{};
std::array<float, ih> dindex_w{};
std::array<float, n * id> dindex_keys{};
ml::indexer_scores_backward(index_q, index_w, index_keys, dscores, dindex_q, dindex_w, dindex_keys);

Relationships. ml/attention_sink.hpp (the recurrence), ml/attention.hpp, ml/latent_attention.hpp (which takes each token's selection), transformer_config::sparse_top_k. Group: snicholls-core.

Implementations. One.

Guarantees. constexpr, no allocation. attend_selected O(k · (Dk + Dv)); indexer_scores O(n · H · D); select_top_k O(n log k) with a heap in the output, then a sort of the k chosen. Deterministic: ties go to the earlier key.

Errors. Preconditions, asserted: every index below the number of keys; the rows whole; the gradients sized as their inputs; select_top_k and indexer_kl_loss have as many scores as targets.

Performance. Not benchmarked on its own: attend's loop over k keys, and the indexer's dot products.

Tests and demos. tests/ml/sparse_attention_test.cpp, demos/ml/sparse_attention_demo.cpp.

Dependencies. <algorithm>, <cassert>, <concepts>, <cstddef>, <cstdint>, <limits>, <span>, <type_traits>, ml/attention.hpp, ml/attention_sink.hpp, ml/row.hpp.

Known issues. The report's indexer runs in FP8 with a Hadamard rotation; this reference runs in T.

Status. Experimental, new in 0.16.0.
