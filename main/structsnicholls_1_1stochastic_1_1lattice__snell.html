Detailed Description

template<std::size_t Steps, std::size_t Branches, typename T = double>
struct snicholls::stochastic::lattice_snell< Steps, Branches, T >

The Snell envelope of a recombining lattice: the value, the first steps' values and the early-exercise boundary.

Template Parameters
StepsThe number of steps; the horizon.
BranchesThe stencil's width: 2 for a binomial lattice, 3 for a trinomial one.
TThe number type.
