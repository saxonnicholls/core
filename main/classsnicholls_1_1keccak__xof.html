Detailed Description

template<std::size_t Rate>
class snicholls::keccak_xof< Rate >

A Keccak extendable-output function: the class behind shake128 and shake256.

update absorbs; the first squeeze pads, and every squeeze continues the same output stream, so squeeze(10 bytes) then squeeze(22 bytes) writes what one squeeze(32 bytes) would.

Template Parameters
RateThe rate in bytes: 168 for SHAKE128, 136 for SHAKE256.
