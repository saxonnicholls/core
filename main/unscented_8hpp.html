Detailed Description

snicholls::tracking::make_sigma_points, make_cubature_points, point_transform and the unscented and cubature Kalman steps: propagating a Gaussian through a nonlinear function by deterministic samples.

Overview. Linearising a strongly nonlinear sensor (a bearing at short range, a camera) loses accuracy. The unscented transform instead pushes 2n + 1 sigma points through the function and refits a Gaussian to them; the cubature rule does the same with 2n equally weighted points. Neither needs a Jacobian.

  • make_sigma_points(g, params): the scaled sigma points of Julier and Uhlmann, x ± √(n + λ) Lᵢ, with λ = α² (n + κ) - n, mean weights λ / (n + λ) and 1 / (2(n + λ)), and covariance weight λ / (n + λ) + 1 - α² + β at the centre. unscented_parameters defaults to Stone Soup's: α = 0.5, β = 2, κ = 3 - n.
  • make_cubature_points(g, α): x ± √(α n) Lᵢ (Arasaratnam and Haykin), equal weights.
  • point_transform<Kinds>(points, f, noise): the mean (circular in angle components), covariance (plus the additive noise) and cross-covariance of f over the points.
  • unscented_predict(prior, model, dt), unscented_predict_measurement(prediction, sensor), and the cubature forms; the update is tracking::update<S::kinds>(prediction, z, mp) from tracking/kalman.hpp.
// A radar at the origin, 0.5 degree and 2 m of noise; a target crossing west to east 300 m north of it, so the
// bearing sweeps from about 150 to 30 degrees
const tr::bearing_range<double, 4, xy> radar{{{0.5 * deg * 0.5 * deg, 0, 0, 4}}};
const auto model = tr::combine(cv{0.05}, cv{0.05});
tr::gaussian<double, 4> ukf{{{-500, 0, 300, 0}}, la::fixed_matrix<double, 4, 4>::identity() * 400}, ckf = ukf;
double ukf_error = 0, ckf_error = 0;
for (int k = 1; k <= steps; ++k) {
const state truth{{-500 + 12.0 * k, 12, 300, 0}};
const auto clean = radar.measure(truth);
const la::fixed_vector<double, 2> z{{ge::wrap_pi(clean[0] + 0.5 * deg * normal(g)), clean[1] + 2 * normal(g)}};
// Unscented: sigma points through the motion and through the radar, then the Kalman update
const auto up = tr::unscented_predict(ukf, model, 1.0);
const auto ump = tr::unscented_predict_measurement(*up, radar);
ukf = tr::update<decltype(radar)::kinds>(*up, z, *ump)->posterior; // the bearing innovation wraps
// Cubature: 2n equally weighted points, the same steps
const auto cp = tr::cubature_predict(ckf, model, 1.0);
const auto cmp = tr::cubature_predict_measurement(*cp, radar);
ckf = tr::update<decltype(radar)::kinds>(*cp, z, *cmp)->posterior;
if (k > 20) {
ukf_error += std::hypot(ukf.mean[0] - truth[0], ukf.mean[2] - truth[2]);
ckf_error += std::hypot(ckf.mean[0] - truth[0], ckf.mean[2] - truth[2]);
}
}
ukf_error /= steps - 20;
ckf_error /= steps - 20;
std::printf(" mean position error: UKF %.2f m, CKF %.2f m; UKF velocity (%.2f, %.2f)\n", ukf_error, ckf_error, ukf.mean[1], ukf.mean[3]);

Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types and a noexcept function, no allocation: points live in std::arrays of compile-time size. Exact for linear functions, where it reproduces the Kalman filter.

Errors. linalg::error::not_positive_definite when the input covariance has no Cholesky factor.

Performance. Not benchmarked: 2n + 1 evaluations of the function and one Cholesky.

Tests and demos. tests/tracking/unscented_test.cpp, demos/tracking/unscented_demo.cpp.

Dependencies. <array>, <cstddef>, <optional>, linalg/fixed.hpp, geometry/angle.hpp, tracking/gaussian.hpp, tracking/kalman.hpp, result.hpp.

Known issues. With the default κ = 3 - n and n > 3 the centre mean weight is negative, so the predicted covariance can lose definiteness for a strongly nonlinear function; the remedy is the caller's: raise α, or use cubature points, whose weights are all positive.

Status. Experimental, new in 0.19.0.
