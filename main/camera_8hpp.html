Detailed Description

snicholls::geometry::pinhole, project, pixel_ray, ray_plane and plane_fix: a camera's pixel as a point on a plane, with its covariance.

Overview. A camera alone measures a direction, not a range. When the target is known to lie on a plane (a water surface, a road, a floor), the pixel's ray meets the plane in one point, so one camera gives a 3-D fix. With camera centre C, orientation R (camera to world) and intrinsics K, a pixel u has the world ray d = R K⁻¹ ũ. The plane n·x = h meets it at 

x = C + t d,   t = (h - n·C) / (n·d).

The fix's uncertainty follows from the pixel's: plane_fix propagates a pixel covariance (and, optionally, a variance of the plane's height, for a target that rides above it) through the exact Jacobian of x(u, h). The error is long along the ray and short across it, growing like r σ / tan γ at grazing angle γ.

  • pinhole<T>: focal lengths and principal point, in pixels; matrix() is K.
  • project(K, R, C, x): the pixel of a world point, or camera_error::behind_camera.
  • pixel_ray(K, R, u): the world direction of a pixel (not normalised).
  • ray_plane(C, d, n, h): the intersection, or camera_error::parallel_to_plane / behind_camera.
  • plane_fix(K, R, C, u, Σ_u, n, h, σ_h²): the point, its 3 x 3 covariance, its range and grazing angle.
  • grazing_angle(d, n): the angle between a ray and the plane.

Camera axes are the computer-vision convention: x right, y down, z forward along the optical axis. A camera orientation error σ_θ (radians) enters as pixel noise f σ_θ.

// A 1280 x 720 camera, 10 m up, its optical axis 20° below the horizon, looking along world y (north)
constexpr geo::pinhole<double> k{1000, 1000, 640, 360};
const m33 level{{1, 0, 0, 0, 0, 1, 0, -1, 0}}; // camera x east, y down, z north
const m33 r = geo::rotation_x(-20 * pi / 180) * level; // tilt the axis down
const v3 c{{0, 0, 10}};
const v3 up{{0, 0, 1}}; // the water: z = 0
// A swimmer detected at pixel (700, 420), to 2 pixels; the camera's pointing known to 1 mrad (1 pixel)
const v2 u{{700, 420}};
const m22 pixel_cov = m22::identity() * (2.0 * 2.0 + 1.0 * 1.0);
const auto fix = geo::plane_fix(k, r, c, u, pixel_cov, up, 0.0);
if (!fix)
return 1;
// The error ellipse: long along the line of sight, short across it
const auto e = la::symmetric_eigen(la::block<0, 0, 2, 2>(fix->covariance));

Relationships. linalg/fixed.hpp, result.hpp; geometry/coordinates.hpp for building R; geometry/geodetic.hpp for the world frame; the fix's covariance is a measurement covariance for tracking/kalman.hpp. Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation. The covariance is symmetric and positive semi-definite (rank 2, or 3 with a height variance).

Errors. camera_error::behind_camera: the point (or the intersection) is behind the camera. camera_error::parallel_to_plane: the ray does not meet the plane (|n·d| at or below 1e-12 |n| |d|).

Performance. Not benchmarked: a few 3 x 3 products.

Tests and demos. tests/geometry/camera_test.cpp, demos/geometry/camera_demo.cpp.

Dependencies. <cstdint>, linalg/fixed.hpp, math/constexpr_math.hpp, result.hpp.

Known issues. No lens distortion: undistort pixels first.

Status. Experimental, new in 0.19.0.
