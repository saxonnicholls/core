Detailed Description

template<transformer_config C, math::math_number T = float, std::size_t MaxPages = 64>
class snicholls::ml::paged_kv_cache_view< C, T, MaxPages >

A paged KV cache over the caller's pool: fixed pages of page_size positions, a sequence's pages named by its page table, so sequences that share a prefix can share its pages.

The pool is [page][layer][kv_head][slot][head_dim]; logical page i of the sequence is physical page table[i], so position p is in page table[p / page_size], slot p % page_size. Which pages are free, shared or evicted is the caller's (the serving layer above core); this view only reads and writes them.

Template Parameters
CThe configuration.
TThe number type.
MaxPagesThe most pages one visible range may span: visible returns kv_runs<T, MaxPages>.
