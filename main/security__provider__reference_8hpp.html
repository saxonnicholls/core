Detailed Description

snicholls::memory_security_provider: the standard-library reference security_provider; a broker and registry in memory, with trades that settle later, any fact booked by hand, signed webhooks, statements and holdings.

Overview. It plays the provider's side for a product's tests, without a network:

  • execute(order, quantity, consideration, fees) fills an order now: a buy (positive quantity) or sell fact, due to settle two calendar days later (dates.settles_on, estimated: business days are the ledger's);
  • settle(order) settles it now (a settle fact with the trade's quantity), and fail_settlement(order) reports a fail (settle_failed);
  • book(fact) records any other fact (a dividend, a split, a repo) after validate, filling in the source, the account, an id and known_at where they are empty.

Webhooks are signed as memory_payment_provider signs them (a Memory-Signature header, HMAC-SHA256 over <t>.<body>, a 300-second window); signed_webhook makes a delivery for a test. resolve returns the facts an event names, by fact_id or by the order in payment_id, from the records, never from the body. statement pages through every fact in order. holdings(as_of) folds the facts by the contract's rule: the traded position counts every fact but settle and settle_failed traded on or before the day, the settled position every settle and every other fact with settled_at on or before it, both instruments of a two-instrument fact. fail_next(code, response) makes the next resolve, statement or holdings fail as though the provider had answered response.

memory_security_provider broker{secret<std::string>{"whsec_demo_only"}, manual_utc_clock{utc_s::from_unix_seconds(1'800'000'000)}};
const auto buy = broker.execute("ord-1", money::from_units(bhp, 100), -*parse_money(aud, "4512.50"),
*parse_money(aud, "9.95")); // T: a buy, due T+2
const std::chrono::sys_days trade_day = broker.clock().now().days();
broker.clock().advance(std::chrono::days{2}); // the provider's own clock, moved by hand
const auto settled = broker.settle("ord-1"); // T+2: settled

Relationships. Models security_provider (concepts/security_provider.hpp); passes interfaces/security_provider_conformance.hpp in every form; shares its webhook scheme with interfaces/payment_provider_reference.hpp. Group: snicholls-core.

Implementations / variants. One. basic_memory_security_provider<Clock> reads any utc_clock (time/utc_clock.hpp), owned by value and reached through clock(); memory_security_provider is basic_memory_security_provider<manual_utc_clock>.

Guarantees. Not thread-safe. Ids are deterministic (mem_sf_1, ...). Quantities and cash are exact. Errors follow the redaction rule.

Errors. book returns validate's error, or conflict for a fact_id already booked with other content; execute returns invalid_argument for a zero quantity or an order id that is empty, too long or already filled; settle and fail_settlement return not_found for an unknown order and conflict for one already settled or failed; and whatever fail_next armed.

Performance. Not benchmarked: a test double.

Tests and demos. tests/interfaces/security_provider_reference_test.cpp, demos/interfaces/security_provider_reference_demo.cpp.

Dependencies. <chrono>, <cstdint>, <functional>, <map>, <optional>, <string>, <string_view>, <utility>, <vector>, detail/memory_webhook.hpp (HMAC-SHA256), interfaces/security_provider.hpp, secret.hpp, time/utc_clock.hpp.

Known issues. Settlement is T+2 calendar days; real settlement is in business days of the market's calendar.

Status. New in 0.27.0; the clock a utc_clock template parameter, owned, since 0.27.0 (it was a std::function<utc_s()>).
