Detailed Description

Explicit byte order: load_le, store_le, load_be, store_be, byteswap.

Overview. Read and write integers and floating-point values in a fixed byte order, whatever the machine's own. Every wire format and file format in the family needs this - the remote-compute frames, WebSocket lengths, the binary codecs - and each had been writing the shifts out by hand:

// A frame header: a big-endian u16 length (network order), then a
// little-endian u64 call id and a double, the way the remote-compute
// frames carry them. The same bytes on every machine.
unsigned char header[18];
snicholls::store_be(header, std::uint16_t{512});
snicholls::store_le(header + 2, std::uint64_t{42});
snicholls::store_le(header + 10, 101.25);
const auto length = snicholls::load_be<std::uint16_t>(header);
const auto call_id = snicholls::load_le<std::uint64_t>(header + 2);
const auto price = snicholls::load_le<double>(header + 10); // unaligned is fine

The functions are written as shifts, not as a memcpy plus a conditional swap, so the result never depends on the host and they work in constant expressions. Compilers recognise the pattern: on a little-endian machine load_le compiles to one load, and load_be to a load and a bswap.

Relationships. byteswap is C++23's std::byteswap, provided here because the family is C++20. std::endian tells you the host's order, which these functions make you never need to ask.

Guarantees. All constexpr and noexcept. T is an integral type other than bool, an enumeration (its underlying type's bytes), float or double (their IEEE bits). The pointer is to sizeof(T) readable or writable bytes of char, unsigned char, signed char or std::byte; it need not be aligned.

Errors. None. A pointer to fewer than sizeof(T) bytes is undefined behaviour, as for memcpy.

Performance. Not benchmarked in core. The shift form is the one compilers fold into a single load or store; check a disassembly before replacing it with memcpy.

Tests and demos. tests/endian_test.cpp, demos/endian_demo.cpp.

Dependencies. <array>, <bit>, <cstddef>, <cstdint>, <type_traits>.

Status. Experimental.
