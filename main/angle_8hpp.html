Detailed Description

snicholls::geometry::wrap_pi, wrap_elevation, angle_kind and angle-aware residuals and means: arithmetic on vectors some of whose components are angles.

Overview. A bearing of 179° and one of -179° are 2° apart, not 358°. Filters that subtract a predicted measurement from a measured one, or average sigma points, must know which components are angles and how each wraps. Here that is data known at compile time: an angle_kinds<N> array, one angle_kind per component (linear, bearing wrapping to [-π, π), elevation folding into [-π/2, π/2]), passed as a template argument. A component marked linear costs nothing; an angle costs one wrap.

  • wrap_pi(x) into [-π, π), wrap_two_pi(x) into [0, 2π), wrap_elevation(x) into [-π/2, π/2] (an elevation past the pole comes back down the other side), wrap(kind, x).
  • difference(kind, a, b): a - b, wrapped as kind says.
  • residual<Kinds>(a, b) and wrapped<Kinds>(x): the same per component of a fixed_vector.
  • circular_mean(angles, weights): atan2(Σ wᵢ sin aᵢ, Σ wᵢ cos aᵢ); weights may be negative (the unscented transform's centre weight can be).
  • weighted_mean<Kinds>(points, weights): the weighted mean of vectors, circular in the angle components.

The conventions are Stone Soup's (mod_bearing, mod_elevation, Angle.average), so results compare with it directly.

// A radar measures (bearing, elevation, range); the kinds are part of the measurement model's type
constexpr geo::angle_kinds<3> kinds{angle_kind::bearing, angle_kind::elevation, angle_kind::linear};
const auto measured = la::make_vector(geo::radians(179.0), geo::radians(10.0), 1500.0);
const auto predicted = la::make_vector(geo::radians(-179.0), geo::radians(12.0), 1480.0);
// -2° the short way round, not 358°
const auto nu = geo::residual<kinds>(measured, predicted);
// The unscented transform's mean of sigma points, with a negative centre weight
const std::array<la::fixed_vector<double, 3>, 3> sigma{la::make_vector(geo::radians(180.0), 0.1, 1000.0), la::make_vector(geo::radians(175.0), 0.1, 1010.0),
la::make_vector(geo::radians(-175.0), 0.1, 990.0)};
const std::array<double, 3> w{-1.0, 1.0, 1.0};
const auto mean = geo::weighted_mean<kinds>(sigma, w);

Relationships. linalg/fixed.hpp (fixed_vector), math/constexpr_math.hpp (floor, sin, cos, atan2). Used by tracking/measurement.hpp (each model's kinds), tracking/kalman.hpp and tracking/unscented.hpp (residuals and means). Group: snicholls-core.

Implementations. One floor per wrap: x - 2π ⌊(x + π) / 2π⌋, with the rounding case that lands on π folded back to -π.

Guarantees. constexpr, noexcept for float, double and long double, no allocation. wrap_pi returns a value in [-π, π) for every finite input; NaN and infinity give NaN, in every wrap.

Errors. None.

Performance. Not benchmarked: a floor and a few multiplications.

Tests and demos. tests/geometry/angle_test.cpp, demos/geometry/angle_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <limits>, <numbers>, <span>, linalg/fixed.hpp, math/constexpr_math.hpp.

Known issues. For |x| beyond about 1e9 the reduction loses the angle's low bits, as any argument reduction by a rounded 2π does.

Status. Experimental, new in 0.19.0.
