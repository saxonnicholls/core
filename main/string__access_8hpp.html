Detailed Description

Zero-copy, allocation-free access to strings and byte sequences.

Zero-copy, allocation-free uniform access to every code-unit sequence classified by <snicholls/core/reflect/string_traits.hpp>.

snicholls::to_string_view(s) text -> std::basic_string_view<code_unit_t<S>, char_traits_t<S>>
snicholls::as_bytes_view(s) bytes, or single-byte text (char, char8_t) -> std::span<const std::byte>
snicholls::length_of(s) any -> length in code units
snicholls::c_str_of(s) NUL-terminated text -> const code_unit_t<S>* (never null)

Cost: O(1) for every carrier except C*, which is one char_traits::length scan (O(n)) - visible in the type as length_kind::linear_time. Nothing allocates or throws (all noexcept); all are constexpr except as_bytes_view over non-std::byte units, which needs reinterpret_cast.

Null C* (char* p = nullptr): an empty string - to_string_view gives an empty view, length_of gives 0, c_str_of gives "", as_bytes_view an empty span. One branch, never UB (std::string_view(p) would be).

Character arrays are string literals: length N-1 (embedded NULs kept), and the last element must be NUL. Violating that is a compile error in constant evaluation and an assert at run time (debug builds).
