Detailed Description

template<math::math_number T>
class snicholls::signal::fft_plan< T >

A plan for complex transforms of one length, over tables in memory the caller owns.

Construct it over storage_size(n) elements (a std::array in constant evaluation, any span at run time); the constructor fills them. The plan refers to the storage, which must outlive it.
