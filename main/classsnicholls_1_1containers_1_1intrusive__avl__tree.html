Detailed Description

template<class T, class Traits>
requires avl_traits<Traits, T>
class snicholls::containers::intrusive_avl_tree< T, Traits >

An intrusive AVL tree: the caller owns the nodes, the tree only links them.

Overview

A balanced binary search tree over nodes that embed an avl_hook. It allocates nothing and never copies a node: insert links a node the caller owns, erase unlinks it. Linkage (Traits::hook) and ordering (Traits::less) are policies, so one implementation serves trees that differ only in direction - for example the bid tree (std::greater<>) and the ask tree (std::less<>) of a limit order book, and its buy-stop and sell-stop trees, which the reference implementations each duplicated by hand. front() is always the first node in the ordering, so with the right comparator it is the best price.

Use it when nodes already live in a pool or an arena and you need ordered access, O(log n) insert/erase and stable node addresses. Prefer std::map when the tree should own its values, and a sorted vector for small, rarely modified sets.

Relationships
  • Used by limit order books (price levels and stop levels).
  • Nodes usually come from snicholls::containers::object_pool.
  • Module: snicholls-core.
Implementations and variants

None: a single implementation. The hook and ordering are the variation points.

Guarantees and contracts
  • Thread safety: none internal; one writer, or many readers with no writer.
  • Exception safety: every operation is noexcept provided Traits::less does not throw.
  • Complexity: insert, erase, find, lower_bound: O(log n); front/back: O(1) (cached); next/prev: O(1) amortised; height <= 1.44 log2(n + 2).
  • Ownership and lifetime: nodes must outlive their membership; destroying the tree does not touch nodes (call clear() first if the hooks will be reused).
  • Invariants: BST order under Traits::less, parent links consistent, stored heights exact, every balance factor in [-1, 1]; validate() checks them all in O(n).
    Precondition
    A node is inserted into at most one tree per hook, and keys are not modified while linked.
    Errors
    None: insert of a duplicate key returns the existing node and false.
Examples
struct level
{
long price = 0;
snicholls::containers::avl_hook<level> by_price_up; // linkage for the ascending tree
snicholls::containers::avl_hook<level> by_price_down; // a second, independent linkage
};
using ascending = snicholls::containers::intrusive_avl_tree<
level, snicholls::containers::member_avl_traits<level, &level::by_price_up, &level::price, std::less<>>>;
using descending = snicholls::containers::intrusive_avl_tree<
level, snicholls::containers::member_avl_traits<level, &level::by_price_down, &level::price, std::greater<>>>;
Performance

Measured inside limit order books. In core, benchmarks/containers/intrusive_avl_tree_benchmark.cpp compares it like for like with std::set, after a fairness check; not yet measured in Release.

Tests and demos
  • Tests: tests/containers/intrusive_avl_tree_test.cpp (model-checked against std::set, validated after every operation, both orderings, multiple hooks).
  • Demo: demos/containers/intrusive_avl_tree_demo.cpp.
  • Benchmark: benchmarks/containers/intrusive_avl_tree_benchmark.cpp.
Dependencies

CMake target snicholls::core; standard library only.

Known issues and gotchas
  • Generic: it needs nothing but the standard library and the node type's hook.
