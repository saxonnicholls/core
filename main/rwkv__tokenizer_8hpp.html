Detailed Description

snicholls::ml::rwkv_encode: RWKV's "world" tokenizer, greedy longest match over a trie of byte strings, and rwkv_unescape, which reads its vocabulary's escaped pieces.

Overview. RWKV's tokenizer has no merges and no scores: from the start of the text, take the longest vocabulary entry that is a prefix, and repeat. Its vocabulary holds arbitrary bytes, which GGUF stores escaped (\n, \t, \r, \xNN, and a backslash before anything else taken literally); rwkv_unescape reads one back, once, when the vocabulary is loaded. Decoding is the concatenation of the pieces (bpe_decode in ml/bpe.hpp).

// Greedy longest match: "the" beats "th" beats "t"
constexpr ml::static_token_trie<5> vocab{std::array<std::string_view, 5>{"t", "th", "the", " ", "\n"}};
constexpr std::size_t count(std::string_view text)
{
std::array<std::uint32_t, 32> out{};
return ml::rwkv_encode(text, vocab.view(), 99, out).unwrap();
}
static_assert(count("the th t\n") == 6); // "the", " ", "th", " ", "t", "\n"

Relationships. ml/token_trie.hpp (the vocabulary over the unescaped pieces), ml/bpe.hpp (bpe_decode). Group: snicholls-core.

Implementations. One, llama.cpp's llm_tokenizer_rwkv_session, except that a byte no entry starts with is the unknown token and the walk moves on one byte (llama.cpp would loop: its vocabulary has every byte, so it never meets one).

Guarantees. constexpr, noexcept, no allocation. Complexity: O(n · L log V).

Errors. rwkv_error::output_too_small (fewer slots than tokens; text.size() always suffice), bad_escape (a truncated \x).

Performance. Not benchmarked separately: the work is token_trie::longest_prefix (benchmarks/ml/token_trie_benchmark.cpp).

Tests and demos. tests/ml/rwkv_tokenizer_test.cpp (greedy matches, the unknown byte, escapes, at compile time), demos/ml/rwkv_tokenizer_demo.cpp. No RWKV vocabulary ships with llama.cpp's test vectors, so there is no token-for-token fixture.

Dependencies. <cstddef>, <cstdint>, <span>, <string_view>, snicholls/core/result.hpp, ml/token_trie.hpp.

Known issues. None known.

Status. Experimental, new in 0.17.0.
