Detailed Description

template<std::size_t Slots, std::size_t ArenaBytes, std::size_t Values = 0>
class snicholls::containers::byte_map< Slots, ArenaBytes, Values >

A byte-string map that owns fixed-size storage, so it can be built by the compiler or live in static storage with no allocation.

Template Parameters
SlotsThe number of slots: a power of two; holds Slots / 2 keys.
ArenaBytesThe bytes for the keys.
ValuesThe size of the reverse table (values 0 .. Values - 1); 0 for none.
