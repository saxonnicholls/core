Detailed Description

snicholls::ml embeddings: a token's row of a table, GPT-2's token plus position, and the backward pass that adds a gradient into the token's row.

Overview. The first layer of a language model: token id becomes row id of a table of V rows of C channels, laid out row after row in one contiguous row (table[id · C + c]), as llm.c's wte and wpe and nanochat's nn.Embedding.

  • embedding_row(table, id, channels): the row, as a span: no copy.
  • embed(table, id, out): copies the row into out (C = out.size()).
  • embed_with_position(tokens, id, positions, pos, out): out = tokens[id] + positions[pos], GPT-2's learned position embedding (llm.c's encoder_forward). A model with RoPE has no position table: use embed.
  • embedding_backward(dout, id, dtable): adds dout into row id of the gradient table (llm.c's encoder_backward). Rows of the same token in a batch add up, so workers that share a table either own disjoint tokens or keep their own gradient tables and add them.
// A vocabulary of 4 tokens and a context of 3 positions, 2 channels each, row after row
constexpr std::size_t channels = 2;
const std::array<float, 4 * channels> wte{0.0f, 0.1f, 1.0f, 1.1f, 2.0f, 2.1f, 3.0f, 3.1f};
const std::array<float, 3 * channels> wpe{0.00f, 0.00f, 0.01f, 0.02f, 0.03f, 0.04f};
const std::array<std::size_t, 3> sequence{3, 1, 3};
std::array<std::array<float, channels>, 3> x{};
for (std::size_t pos = 0; pos < sequence.size(); ++pos)
ml::embed_with_position(wte, sequence[pos], wpe, pos, x[pos]);
// With RoPE there is no position table: the token's row alone, or a view of it
std::array<float, channels> token1{};
ml::embed(wte, 1, token1);
const auto view = ml::embedding_row(wte, 2, channels);
// Backward: each position's gradient adds into its token's row, so token 3 collects two
std::array<float, 4 * channels> dwte{};
const std::array<float, channels> dx{1.0f, -1.0f};
for (const std::size_t id : sequence)
ml::embedding_backward(dx, id, dwte);

Relationships. ml/row.hpp; ml/norm.hpp and ml/rope.hpp come next in the model. Group: snicholls-core.

Implementations. One each.

Guarantees. constexpr, no allocation, linear in C. embedding_row refers to the caller's table and lives as long as it does.

Errors. Preconditions, asserted: the row id (and pos) lies inside its table, and dout has C channels.

Performance. Not benchmarked: one row copied or added.

Tests and demos. tests/ml/embedding_test.cpp, demos/ml/embedding_demo.cpp.

Dependencies. <cassert>, <concepts>, <cstddef>, <span>, ml/row.hpp.

Known issues. None.

Status. Experimental, new in 0.7.0.
