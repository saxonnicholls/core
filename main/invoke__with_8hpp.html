Detailed Description

snicholls::invoke_with and invoke_any: call an overload set with arguments that exist only at run time.

Overview. snicholls::overloaded and snicholls::first_match choose the callable at compile time, from the static types of the arguments. invoke_with(set, source) is the slow option for arguments that exist only at run time: a command parsed from a line of text, a message off a socket, a JSON-RPC call. The source is any object that says how many arguments there are and hands out argument i as a requested type, or refuses (snicholls::argument_source). invoke_with tries the set's callables in the order written and calls the first whose parameter list the source can fill: the same count, and every parameter type supplied. The callable's result comes back converted to R (std::any by default; empty, or R{}, for void); otherwise an overload_mismatch says why nothing was called.

invoke_any(set, {args...}) is invoke_with over snicholls::any_source: a std::span<const std::any>, each std::any holding exactly the parameter's type (its std::remove_cvref_t; a std::any has no conversions, so an int parameter takes a std::any holding an int, never a long or a short):

// A handler set whose callables have concrete parameter lists, which invoke_any reads.
const auto volume = snicholls::overloaded{
[](int level) { return "volume " + std::to_string(level); },
[](int level, bool fade) { return "volume " + std::to_string(level) + (fade ? " with fade" : ""); },
[](const std::string& preset) { return "preset " + preset; },
};
// Arguments that exist only at run time: here written out, in practice read off a socket or
// handed over by a script. Each std::any holds exactly a parameter's type.
const std::vector<std::any> line{42};
auto r = snicholls::invoke_any(volume, line); // snicholls::result<std::any, snicholls::overload_mismatch>
if (r)
std::printf(" %s\n", std::any_cast<std::string>(r.unwrap()).c_str()); // volume 42
r = snicholls::invoke_any(volume, {7, true}); // the (int, bool) handler
std::printf(" %s\n", std::any_cast<std::string>(r.unwrap()).c_str());
r = snicholls::invoke_any(volume, {std::string{"loud"}}); // the (const std::string&) handler
std::printf(" %s\n", std::any_cast<std::string>(r.unwrap()).c_str());
// Every handler returns a std::string, so ask for that instead of a std::any.
const auto typed = snicholls::invoke_any<std::string>(volume, {3});
std::printf(" %s\n", typed.unwrap().c_str());
const auto three = snicholls::invoke_any(volume, {1, 2, 3}); // nothing takes three arguments
const auto wrong = snicholls::invoke_any(volume, {2.5}); // one argument, but no handler takes a double
std::printf(" {1, 2, 3}: %s\n", snicholls::error_text(three.unwrap_err()).c_str());
std::printf(" {2.5}: %s\n", snicholls::error_text(wrong.unwrap_err()).c_str());

A source of your own is a few lines: size(), and get<T>(i) returning either a pointer into the source (const T*, null to refuse) or a value (std::optional<T>, empty to refuse; moved into a by-value or && parameter). The demo's token_source fills parameters from the words of a command line:

// A source of the demo's own: the arguments are the words of a command line, converted on
// request. get<T>(i) returns std::optional<T>: a value when word i reads as a T, empty to refuse.
// Which conversion applies to which T is a first_match over a type tag, not an if constexpr chain.
// Each branch's constraint admits only what its body can take: std::from_chars takes no bool
// and no character type, and snicholls::integer excludes exactly those.
struct token_source {
std::vector<std::string_view> words;
[[nodiscard]] std::size_t size() const noexcept { return words.size(); }
template <typename T>
[[nodiscard]] std::optional<T> get(std::size_t i) const
{
const std::string_view word = words[i];
return snicholls::first_match{
[word](std::same_as<bool> auto*) -> std::optional<bool> {
if (word == "true" || word == "on") return true;
if (word == "false" || word == "off") return false;
return std::nullopt;
},
[word](snicholls::integer auto* tag) {
using number = std::remove_pointer_t<decltype(tag)>;
number value{};
const auto [end, error] = std::from_chars(word.data(), word.data() + word.size(), value);
return error == std::errc{} && end == word.data() + word.size() ? std::optional<number>{value} : std::nullopt;
},
[word](std::string*) { return std::optional<std::string>{std::string{word}}; },
[](auto* tag) { return std::optional<std::remove_pointer_t<decltype(tag)>>{}; }, // refused
}(static_cast<T*>(nullptr));
}
};

Every callable needs a parameter list the library can read, snicholls::callable_traits: exactly one non-template operator() (a non-generic lambda, a function object, a std::function), or a function pointer. A generic lambda has no single parameter list and is rejected at compile time with a message. The first argument can also be a single callable rather than a set, and a set inside a set is flattened.

Relationships. snicholls::overloaded and snicholls::first_match, whose callables it reads; snicholls::result, which carries the outcome; snicholls::any_source, the source behind invoke_any. A table of named sets is one std::map of std::functions away:

// Sets of different types behind one signature: a command table.
using outcome = snicholls::result<std::any, snicholls::overload_mismatch>;
std::map<std::string, std::function<outcome(std::span<const std::any>)>> commands;
commands["volume"] = [&volume](std::span<const std::any> args) { return snicholls::invoke_any(volume, args); };
commands["mute"] = [](std::span<const std::any> args) {
return snicholls::invoke_any([](bool on) { return std::string{on ? "muted" : "unmuted"}; }, args);
};
const std::vector<std::any> muted{true};
const auto m = commands.at("mute")(muted);
std::printf(" mute {true}: %s\n", std::any_cast<std::string>(m.unwrap()).c_str());

Group: snicholls-core.

Guarantees. The set and the source are not modified. From a pointer source, a parameter taken by value or by const& binds the source's object directly (no copy for const&) and one taken by && gets a copy; from a value source the value is moved into a by-value or && parameter. The candidates are tried in order and the first match is called, once; whatever it throws propagates and nothing else is tried. Not noexcept: converting the result to R can allocate, the source may allocate, and the callable may throw. Complexity: at most one get<T>(i) per parameter per candidate before the call (for any_source, one type_info comparison each).

Errors.

  • Returns snicholls::err(overload_mismatch::arity) when no callable takes source.size() arguments, and err(overload_mismatch::types) when one does but the source refuses one of its parameter types. snicholls::error_text spells both out, so unwrap() on a miss says which.
  • Compile-time, each with a snicholls::invoke_with: message: a callable whose parameter list cannot be read; a parameter that is a non-const lvalue reference (a source lends or gives, never shares); a callable not callable through the set's constness (a mutable lambda in a const set); a result that does not convert to R (for std::any, a non-copyable result); a get<T>(i) that returns neither a pointer nor an optional.
  • Exceptions
    std::bad_allocfrom R or the source, and whatever the chosen callable throws.
    Performance. benchmarks/invoke_with_benchmark.cpp runs the same 4,096 invoke_any calls three ways, after a fairness check that they agree: through invoke_any, through the same std::any_cast chain written by hand, and as the direct compile-time call through the overloaded. Release, Apple clang 17, Xeon W-3245 (a loaded machine, so indicative only), 2026-11-05: 27 ns per call through invoke_any, 22 ns by hand, 6 ns direct. The difference to the hand-written chain is the snicholls::result and the std::any moves on the way out.

Tests and demos. tests/invoke_with_test.cpp, demos/invoke_with_demo.cpp, and the compile-fail cases tests/compile_fail/invoke_with_generic_lambda.cpp and tests/compile_fail/invoke_with_mutable_reference.cpp.

Dependencies. <any>, <concepts>, <cstddef>, <initializer_list>, <span>, <type_traits>, <utility>, snicholls/core/meta/callable_traits.hpp, snicholls/core/overloaded.hpp, snicholls/core/meta/type_list.hpp and snicholls/core/result.hpp. Heavier than it looks: result.hpp brings <format> and <string>. The compile-time sets in overloaded.hpp do not include this header, so code that only visits a variant pays none of it.

Known issues.

  • any_source matches the dynamic type exactly, so build the arguments with the parameter types in mind: std::any{42} holds an int, std::any{"x"} holds a const char*, not a std::string.
  • Two callables with the same parameter types once references are stripped ((int) and (const int&)) both match; the first written is called.
  • An operator() with a ref-qualifier (&, &&) or volatile is not read.

Status. New in 0.5.0, experimental.
