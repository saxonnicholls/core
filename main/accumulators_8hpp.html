Detailed Description

Streaming accumulators: count, sum, min, max, mean, variance, covariance, exponentially weighted moments, histogram.

Overview. Live risk needs statistics that move with every tick without recomputing from history. Each accumulator here takes one observation in constant time (add), combines with another built from other observations (merge, so worker threads each build one and the results are merged), and reports (value). The variance is Welford's, merged by Chan, Golub and LeVeque's formula, so it does not lose precision the way a sum of squares does.

// Each tick updates the statistics in constant time: no history kept, nothing recomputed.
stats::variance<double> returns;
stats::covariance<double> against_index;
stats::ewma<double> risk{.alpha = 0.06}; // RiskMetrics' lambda of 0.94
stats::maximum<double> best;
for (std::size_t t = 0; t < portfolio.size(); ++t) {
returns.add(portfolio[t]);
against_index.add(index[t], portfolio[t]); // x the index, y the portfolio: beta is y on x
risk.add(portfolio[t]);
best.add(portfolio[t]);
}
// Two workers' accumulators merge into what one would have seen.
stats::variance<double> first_half, second_half;
for (std::size_t t = 0; t < 3; ++t)
first_half.add(portfolio[t]);
for (std::size_t t = 3; t < 6; ++t)
second_half.add(portfolio[t]);
first_half.merge(second_half);
accumulator value() merge
count observations exact
sum<T> their sum (compensated_sum<T>: Kahan) exact / Neumaier
minimum<T>, maximum<T> the extreme, std::nullopt if none exact
mean<T> the mean Chan
variance<T> the sample variance (mean(), standard_deviation() too) Chan
covariance<T> the sample covariance of pairs (correlation() too) Chan
ewma<T> exponentially weighted mean and variance not mergeable
histogram<T, Bins> counts in fixed bins, with under and overflow exact
collect<T> every value, for any statistic afterwards append
bootstrapped<Acc, B> Acc's value and B Poisson-bootstrap replicates of it per replicate

Every accumulator is a snicholls::stats::accumulator, which stats/pivot.hpp uses for its cells.

Relationships. stats/pivot.hpp; stats/bootstrap.hpp for the uncertainty of a statistic. Group: snicholls-core.

Guarantees. All but collect and bootstrapped's value() are constexpr, noexcept, allocation-free and trivially copyable. add is O(1); merging two accumulators gives what one accumulator would give on both sets of observations, exactly for count, minimum, maximum and histogram, and up to rounding for the moments.

Errors. None: an empty accumulator's mean and variance are NaN, its minimum is std::nullopt.

Performance. benchmarks/stats/accumulators_benchmark.cpp: 1,000,000 observations into variance and covariance, Release, Apple clang 17, Xeon W-3245, 2026-11-08: 6.39 ms, against 6.05 ms for the same updates written by hand. The inner loops compile to identical instructions; two identical hand-written copies measure 6.07 and 6.36 ms, so the difference is code placement, not cost.

Tests and demos. tests/stats/accumulators_test.cpp, demos/stats/accumulators_demo.cpp.

Dependencies. <array>, <cmath>, <concepts>, <cstddef>, <cstdint>, <limits>, <optional>, <span>, <vector>, stats/bootstrap.hpp, stats/random.hpp.

Known issues. ewma depends on the order of observations and cannot be merged. histogram's bins are fixed at construction.

Status. New in 0.5.0.
