Detailed Description

snicholls::ml ALiBi: each head's slope as ggml computes it, a compile-time table of slopes, the linear bias of a query and a key, and attention with that bias, forward and backward.

Overview. ALiBi (Press et al., 2022; BLOOM, MPT, Baichuan 13B, Falcon's early versions) has no positional rotation: each head adds -m_h · |i - j| to the score of query i against key j, with slopes m_h a geometric series over the heads. ggml computes them (ggml_compute_forward_soft_max_f32 and ggml_compute_forward_flash_attn_ext_f16_one_chunk, ggml/src/ggml-cpu/ops.cpp, llama.cpp 39039aa) as n = 2^floor(log2 H), m0 = 2^(-max_bias / n), m1 = 2^(-max_bias / 2 / n), and m_h = m0^(h + 1) for h < n, m1^(2(h - n) + 1) above, so a head count that is not a power of two takes the odd powers of the next series (the paper's rule); the cache's mask holds -|p_q - p_k| (llama_kv_cache::set_input_kq_mask with use_alibi), multiplied by the slope and added after the scale (and any soft cap).

  • alibi_slope<T>(h, heads, max_bias) and alibi_slopes<T, Heads>(max_bias), a std::array the compiler can build (max_bias 8 in every ALiBi model; 0 gives slopes of 1, ggml's "no ALiBi").
  • alibi_bias(slope, query_pos, key_pos): -slope · |query_pos - key_pos|.
  • attend_alibi(q, keys, values, out, scale, slope, query_pos, first_key_pos): attend over keys at consecutive positions from first_key_pos, with the bias added to each score; attend_alibi_backward its gradients (the bias is a constant of the inputs).
// Each head's slope, at compile time: a geometric series, 1/2 to 1/256 for eight heads
constexpr auto slopes = ml::alibi_slopes<float, 8>();
constexpr auto twelve = ml::alibi_slopes<float, 12>(); // not a power of two: the odd powers of the next series
// One query at position 3 against the keys at positions 0 to 3, every key the same, so only the bias tells them apart
const std::array<float, 2> q{1.0f, 0.0f};
const std::array<float, 8> keys{1, 0, 1, 0, 1, 0, 1, 0}, values{1, 0, 2, 0, 3, 0, 4, 0};
std::array<float, 2> out{};
const float lse = ml::attend_alibi(q, keys, values, out, 1.0f, slopes[0], 3, 0); // the steepest head: nearer keys weigh more
// The backward pass, for a gradient of 1 in the output's first channel
std::array<float, 2> dq{};
std::array<float, 8> dkeys{}, dvalues{};
ml::attend_alibi_backward(q, keys, values, out, std::array<float, 2>{1.0f, 0.0f}, lse, 1.0f, slopes[0], 3, 0, dq, dkeys, dvalues);

Relationships. ml/attention.hpp (attend and its recurrence; with a slope of 0 this is attend to the bit); ml/kv_cells.hpp (attend_cells takes a slope for keys at scattered positions). Group: snicholls-core.

Implementations. One each.

Guarantees. constexpr, no allocation, linear in the keys; the slopes are exact powers where max_bias / n is an integer exponent of 2. The recurrence and its order are attend's.

Errors. Preconditions, asserted: heads > 0, h < heads, max_bias >= 0; the rows' sizes as attend's.

Performance. Not benchmarked: one multiplication and one addition per score over attend, which is.

Tests and demos. tests/ml/alibi_test.cpp, demos/ml/alibi_demo.cpp.

Dependencies. <algorithm>, <array>, <cassert>, <concepts>, <cstddef>, <cstdint>, <limits>, <span>, ml/attention.hpp, ml/row.hpp, snicholls/core/math/constexpr_math.hpp.

Known issues. ggml computes the slopes in float with powf; core's math::pow agrees to the last place where both are exact (every head of an 8-, 16-, 32- or 64-head model at max_bias 8) and within an ulp otherwise. ggml stores the mask in float16 for flash attention: positions beyond 2048 apart are then rounded; core keeps the distance exact.

Status. Experimental, new in 0.17.0.
