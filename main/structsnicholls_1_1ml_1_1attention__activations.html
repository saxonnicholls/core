Detailed Description

template<math::math_number T>
struct snicholls::ml::attention_activations< T >

What attention_forward_sequence saves for attention_backward: views the caller owns.

For a batch of sequences sequences of n tokens (the batched passes' sequences), every field is the sequences' own laid end to end, sequence-major: q is sequences · n · q_size, and k is sequences blocks of n_kv_heads · n · head_dim, each block one sequence's keys head by head. So a batch's activations are its sequences' activations side by side, and a view of one sequence is a slice.
