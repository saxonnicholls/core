Detailed Description

snicholls::run_http_client_conformance: the conformance kit of the http_client contract.

Overview. Drives any http_client, in either form, through the contract of concepts/http_client.hpp and reports which check failed (interfaces/capability_conformance.hpp). The probe is a default-constructible type with

  • auto& client(): the implementation (a client, an http_client_interface&, an http_client_ref), talking to a server that answers GET /echo with 200 and the request's body and X-Echo header echoed back, and every unknown path with 404;
  • void transport_fails(capability_errc code, std::string_view response): the next send gets no response.

A fresh probe is made for every check. The checks: a request reaches the server and its response returns, an error status is a response, HEAD returns no body, a malformed request is refused, a transport failure leaks nothing.

const capability_conformance_report report = run_http_client_conformance<probe>();

Relationships. concepts/http_client.hpp, interfaces/http_client.hpp, interfaces/capability_conformance.hpp; run on loopback_http_client in every form by tests/interfaces/http_client_test.cpp. Group: snicholls-core.

Implementations / variants. One kit for every form.

Guarantees. As interfaces/capability_conformance.hpp: no exception escapes a check.

Errors. Failures are data.

Performance. Not benchmarked: a test kit.

Tests and demos. tests/interfaces/http_client_conformance_test.cpp (the kit catches broken clients), demos/interfaces/http_client_conformance_demo.cpp.

Dependencies. <string>, <string_view>, <type_traits>, <utility>, concepts/http_client.hpp, interfaces/capability_conformance.hpp.

Known issues. None.
