Detailed Description

Where errors are logged: receives a structured snicholls::error_report at a level.

Overview

The log hook of snicholls::result: r.log_err(sink) / r.log_err(sink, level) call log_error, which builds the report and calls write once. Implement write to send it anywhere; the core stays free of logging libraries.

Relationships
  • snicholls::result::log_err, snicholls::error_report, snicholls::traced.
  • Module: snicholls-core.
Implementations and variants

Guarantees and contracts
  • log_error never throws: an exception from building the report or from write is swallowed (logging is best effort; the result is returned unchanged either way). write may throw.
  • Thread safety is the implementation's: both shipped sinks may be called from any thread.
Errors

None escape log_error.

Examples
// Log once, at the top, through any snicholls::error_sink (for example a super-log adapter).
std::ostringstream log;
snicholls::text_error_sink sink(log);
auto logged = load_positions("ACC2", "gone.csv").log_err(sink, snicholls::error_level::warning);
