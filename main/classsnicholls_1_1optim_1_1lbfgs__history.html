Detailed Description

template<linalg::scalar T, std::size_t M, std::size_t N = std::dynamic_extent>
class snicholls::optim::lbfgs_history< T, M, N >

The last M curvature pairs (s, y) of L-BFGS, in a ring buffer: over the caller's storage when N is std::dynamic_extent, inside when N is the dimension.

Template Parameters
TThe value type.
MThe most pairs kept, at least 1.
NThe dimension if fixed at compile time, else std::dynamic_extent.
