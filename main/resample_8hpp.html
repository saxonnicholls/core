Detailed Description

snicholls::signal polyphase resampling by a rational factor up / down, as scipy.signal.resample_poly, with the windowed-sinc kernel built at compile time when the factor is known.

Overview. resample_poly(x, up, down, h, y) gives ceil(n up / down) samples at up / down times the rate: conceptually x with up - 1 zeros after each sample, low-pass filtered by h, every down-th sample kept; in fact only the taps that meet a non-zero input are summed, (taps / up) multiply-adds per output (the polyphase form). The factor is reduced by its greatest common divisor first.

The kernel is scipy's: firwin(20 max(up, down) + 1, 1 / max(up, down), window=('kaiser', 5.0)) times up, the centre tap aligned with the first output, so the outputs equal scipy's (padtype='constant'). resample_kernel fills it in a span; polyphase_resampler<T, Up, Down> builds it in a consteval constructor, so the 44.1 kHz to 48 kHz kernel (Up = 160, Down = 147, 3,201 taps) is a table the compiler writes.

// CD to DAT: 160 / 147, a kernel of 3,201 taps written by the compiler.
static constexpr s::polyphase_resampler<float, 160, 147> cd_to_dat{};
std::vector<float> cd(44100), dat(cd_to_dat.output_size(cd.size())); // one second each
for (std::size_t i = 0; i < cd.size(); ++i)
cd[i] = static_cast<float>(m::sin(2 * m::pi * 440.0 * static_cast<double>(i) / 44100.0));
cd_to_dat.process(cd, dat);
// 48 kHz to 16 kHz for a speech model: the factor 1 / 3 known only at run time.
const std::size_t up = 16000, down = 48000;
std::vector<double> h(s::resample_kernel_size(up, down)), speech(4800), out(s::resample_size(speech.size(), up, down));
s::resample_kernel(up, down, std::span<double>(h));
for (std::size_t i = 0; i < speech.size(); ++i)
speech[i] = m::sin(2 * m::pi * 300.0 * static_cast<double>(i) / 48000.0) + 0.5 * m::sin(2 * m::pi * 12000.0 * static_cast<double>(i) / 48000.0);
s::resample_poly<double>(speech, up, down, h, out); // the 12 kHz component is above the new Nyquist: removed

Relationships. signal/fir.hpp (fir_design), signal/window.hpp (kaiser). Group: snicholls-core.

Implementations. The direct polyphase sum; one call over a whole signal (no streaming state).

Guarantees. constexpr, no allocation. Complexity: O(n up / down x taps / up). A sinusoid well inside both bands is reproduced at the new rate within the kernel's ripple (about 1e-3 with Kaiser 5; tested).

Errors. Preconditions, asserted: up, down >= 1; h has resample_kernel_size(up, down) taps; y has resample_size(x.size(), up, down) samples.

Performance. Not benchmarked; a direct sum of taps / up terms per output.

Tests and demos. tests/signal/resample_test.cpp (scipy 1.13.1's outputs, sinusoids, the identity, compile-time kernels), demos/signal/resample_demo.cpp.

Dependencies. <array>, <cassert>, <cstddef>, <numeric>, <span>, <type_traits>, signal/fir.hpp.

Known issues. scipy's other padding types (mean, line, ...) are not provided: the signal is zero outside.

Status. Experimental, new in 0.17.0.
