Detailed Description

snicholls::basic_uuid_generator: the standard-library reference uuid_generator, over the caller's random source and clock.

Overview. Makes version 4 and version 7 UUIDs from a random source Random (for real use a random_source_like source, concepts/random_source.hpp, whose real implementation is ts-moveables' operating-system source; for tests a seeded one, or a callable returning std::uint64_t such as stats::wyrand, or std::optional<std::uint64_t> when it can fail) and a clock Clock (anything whose now() has unix_millis(): every utc_clock, such as manual_utc_clock, time/utc_clock.hpp). Version 7 is monotonic by RFC 9562 section 6.2, method 1: a 12-bit counter in rand_a, started from a random value below 2048 at each new millisecond and incremented within one; when it would overflow, or when the clock steps back, the timestamp moves one millisecond past the last one used instead. reference_uuid_generator is the deterministic one tests use.

basic_uuid_generator ids{test_random_source{7}, manual_utc_clock{utc_ms::from_unix_millis(1'800'000'000'000)}};
const uuid a = *ids.v7();
const uuid b = *ids.v7(); // same millisecond: the counter orders them
ids.clock().advance(std::chrono::milliseconds{5});
const uuid c = *ids.v7();
const uuid r = *ids.v4();

Relationships. Models uuid_generator (concepts/uuid_generator.hpp); passes interfaces/uuid_generator_conformance.hpp directly and through interfaces/uuid_generator.hpp. stats/random.hpp (wyrand), time/utc.hpp. Group: snicholls-core.

Implementations / variants. basic_uuid_generator<Random, Clock>; reference_uuid_generator = basic_uuid_generator<stats::wyrand, manual_utc_clock>, made by make_reference_uuid_generator(seed, start).

Guarantees. Not thread-safe (one per thread). No allocation; noexcept when the source and the clock are. A failed draw changes nothing.

Errors. unavailable when the random source fails; invalid_argument when the clock is before 1970 or past v7's 48-bit range.

Performance. Not benchmarked.

Tests and demos. tests/interfaces/uuid_generator_reference_test.cpp, demos/interfaces/uuid_generator_reference_demo.cpp.

Dependencies. <array>, <chrono>, <concepts>, <cstddef>, <cstdint>, <optional>, <system_error>, <type_traits>, <utility>, interfaces/uuid_generator.hpp, stats/random.hpp, time/utc.hpp, time/utc_clock.hpp.

Known issues. Predictable by design when the source is wyrand: a test double, never an identifier source in production.

Status. New in 0.27.0.
