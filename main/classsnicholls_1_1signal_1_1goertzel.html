Detailed Description

template<math::math_number T>
class snicholls::signal::goertzel< T >

A Goertzel detector for a frequency chosen at run time: the coefficients and the state.

The constructor is constexpr, so constexpr goertzel<float> d(697.0, 8000.0, 205); has its coefficient computed by the compiler; copy it to push samples.
