Detailed Description

snicholls::rate and snicholls::convert: exact conversion between assets, with a named rounding mode and the exact residual.

Overview. A rate is the price of one whole unit of one asset in whole units of another, as an exact ratio of two uint256s:

  • rate::parse(ETH, USD, "3000.123456789012345678") holds 3000123456789012345678 / 10^18 exactly, so a rate is never limited to 18 digits;
  • rate::make(from, to, numerator, denominator) gives any ratio;
  • inverse() swaps the two.

convert(amount, rate, mode) computes the target amount in minor units, amount * numerator * 10^to.scale / (denominator * 10^from.scale). The product is formed in 512 bits and divided once, so nothing is lost before the named rounding mode is applied. It returns:

  • converted, the rounded target amount;
  • residual, the exact signed fraction of one target minor unit between the true value and converted.

A ledger posts converted, and either keeps the residual exactly or posts it to a rounding account at a finer scale with residual.at_scale(target, extra_digits).

const asset eth = asset_v<native::ETH>, usd = asset_v<currency::USD>;
const rate r = *rate::parse(eth, usd, "3000.123456789012345678"); // 22 digits, exact
const auto c = convert(*parse_money(eth, "1.5"), r, rounding::half_even);
const auto finer = c->residual.at_scale(usd, 18); // to post to a rounding account

Implementations. One.

Guarantees. constexpr, noexcept, allocation-free. converted + residual is the exact value: the property tests check it for every mode.

Errors. money_errc:

  • asset_mismatch: the amount is not of the rate's source asset;
  • overflow: the scaled numerator or denominator, or the result, exceeds 256 bits;
  • malformed: a zero denominator, or malformed rate text.

Performance. benchmarks/money/rate_benchmark.cpp: convert against the same multiply, divide and round written by hand, after a fairness check.

Tests and demos. tests/money/rate_test.cpp, with fixtures for every rounding mode from Python's decimal (scripts/generate_money_fixtures.py); demos/money/rate_demo.cpp.

Dependencies. <cstdint>, <string_view>, detail/mul_div.hpp, money/money.hpp.
