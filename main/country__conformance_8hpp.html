Detailed Description

snicholls::check_country: the conformance kit of the country capability.

Overview. Drives any country_like implementation, a type or an object behind country_interface, through the contract and says which check failed:

  • the name is not empty and does not change;
  • alpha2() is two capitals, alpha3() three, numeric() 1 to 999;
  • a code ISO 3166-1 assigns agrees with ISO: the alpha-3 and numeric of its alpha-2 (a user-assigned code, such as XK, is checked for form only);
  • every currency is three capitals;
  • calling_code() is at most 999.

No test framework is included.

const auto type_form = check_country(country::JP{});
const country_model<country::JP> model;
const auto virtual_form = check_country(static_cast<const country_interface&>(model));
const auto stale = check_country(stale_record{}); // "country: alpha3() or numeric() disagrees with ISO 3166-1"
