Detailed Description

SHA-1 (FIPS 180-4), usable at compile time; for the protocols that still name it, never for security.

Overview. SHA-1 with the incremental interface of every hash in core (update, then finish) and a one-shot hash, returning a 20-byte digest<20>. SHA-1 is broken for collision resistance (a chosen-prefix collision costs a few tens of thousands of GPU-days, and identical-prefix collisions are public): never use it for a signature, a certificate, an integrity check against an adversary or a password. It is here because protocols fix it: RFC 9562's name-based (version 5) UUIDs (uuid.hpp uses it), the WebSocket handshake (RFC 6455), Git's object names, RFC 6070's PBKDF2-HMAC-SHA1 and TOTP / HOTP (RFC 6238 / 4226), where HMAC-SHA1 remains sound because HMAC does not rely on collision resistance.

// RFC 6455 4.2.2: the server answers the client's key with SHA-1(key + GUID). The protocol fixes SHA-1; nothing
// here relies on collision resistance. (The answer is sent base64-encoded, by base-encode-decode.)
snicholls::digest<20> websocket_accept(const std::string& client_key)
{
snicholls::sha1 h;
h.update(client_key).update("258EAFA5-E914-47DA-95CA-C5AB0DC85B11");
return h.finish();
}

Relationships. md_hash and digest<N> (hash/digest.hpp); sha256 (hash/sha2.hpp) for anything new; hmac<sha1> (hash/hmac.hpp). Group: snicholls-core.

Guarantees. Every member is constexpr and noexcept; no allocation; a hasher is a trivially copyable value. Complexity: one 80-round compression per 64-byte block.

Errors. None.

Examples. Above; demos/hash/sha1_demo.cpp.

Performance. benchmarks/hash/sha1_benchmark.cpp, against a hand-written loop and OpenSSL (when installed), after a fairness check. Release, Apple clang 17, Xeon W-3245 (a shared machine), 2026-11-20, 16 KiB / 64-byte messages: core 346 / 168 MB/s, the hand loop 249 / 137, OpenSSL 1,130 / 138 (its SIMD message schedule).

Tests and demos. tests/hash/sha1_test.cpp (FIPS 180-4 examples, NIST's byte-oriented short-message and Monte Carlo vectors, Python's hashlib on random lengths, every split), demos/hash/sha1_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, hash/digest.hpp.

Known issues. See the warning above: SHA-1 is kept for compatibility only. No collision-detection variant (Git's sha1dc) is provided.

Status. New in 0.17.0 (it was internal, detail/sha1.hpp, behind uuid). Experimental.
