Detailed Description

Properties of a game: supermodular (convex), submodular, monotone, superadditive, additive, and the core.

Overview. Whether an attribution is stable depends on the game's shape.

  • Supermodular, or convex: v(S + T) + v(S & T) >= v(S) + v(T); each player's lift grows as others join, so features are complements. A long-gamma option portfolio's payoff in its factor moves is one. For a supermodular game the Shapley value lies in the core (Shapley 1971): no group of features is credited less than it earns on its own, so the attribution is one nobody can argue down.
  • Submodular: the reverse; features are substitutes, as risk factors in a diversified book are.
  • Monotone: adding a feature never lowers the value.
  • Superadditive: two disjoint groups together earn at least what they earn apart.
  • Additive: no interaction at all; every attribution method agrees, and Shapley is the lift.

Each check returns the first counterexample, so a failing property says where it fails.

// Three signals whose value grows with each other: the payoff is convex in them.
const auto convex = [](game::coalition s) { const double k = static_cast<double>(game::coalition_size(s)); return k * k; };
// Three risk factors that diversify: risk grows less than additively.
const auto diversified = [](game::coalition s) { return std::sqrt(static_cast<double>(game::coalition_size(s))); };
const bool complements = game::is_supermodular<3>(convex);
const bool substitutes = game::is_submodular<3>(diversified);
const auto attribution = game::shapley<3>(convex);
const bool stable = game::in_core<3>(convex, attribution.values, 1e-12); // Shapley 1971
const auto where = game::find_supermodularity_violation<3>(diversified);

Relationships. game/shapley.hpp, game/harsanyi.hpp (additive means no dividend of two or more players). Group: snicholls-core.

Guarantees. constexpr; each tabulates the game once. Supermodularity, submodularity and additivity are checked on the n(n-1)/2 2^(n-2) second differences, which suffices; superadditivity on all 3^n pairs of disjoint coalitions.

Errors. None.

Performance. Not benchmarked: O(n^2 2^n), and O(3^n) for superadditivity.

Tests and demos. tests/game/properties_test.cpp, demos/game/properties_demo.cpp.

Dependencies. <concepts>, <cstddef>, <optional>, <span>, <vector>, game/coalition.hpp, game/shapley.hpp.

Known issues. The tolerance is absolute; scale it to the game.

Status. New in 0.5.0, experimental.
