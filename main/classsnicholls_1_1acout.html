Detailed Description

A message assembled off to the side and written to its target in one call when it is emitted or destroyed.

acout{} << "x = " << x << '\n'; or acout{}.println("x = {}", x); to std::cout; acout{std::cerr}, acout{stream}, acout{file} for another target. See the file description for the guarantees.
