Detailed Description

template<class T, std::size_t W = std::dynamic_extent>
class snicholls::fn::rust::slice_view< T, W >

Consecutive sub-slices of a contiguous range, each a std::span<T, W>: what slice::windows, slice::chunks and slice::chunks_exact return.

Template Parameters
TThe element type (const when the range is).
WThe span's extent: a compile-time width, or std::dynamic_extent.
