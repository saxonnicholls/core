Detailed Description

English month and weekday names, declared once as presentation attributes of month_of_year and day_of_week.

Overview. "November" and "Mon" are presentation, so they are attributes of a type (CLAUDE.md, "Presentation is a compile-time attribute of the type"), not string tables at call sites. month_of_year (January = 1) and day_of_week (Monday = 1, as ISO 8601 and std::chrono::weekday::iso_encoding() number them) declare, per enumerator, a label (the English name) and an abbreviation (the three-letter form). Every printer reads them: acout, print_to, stats::pivot, and write_enum_json for imgui and React. For std::chrono's own types, month_name, month_abbreviation, weekday_name and weekday_abbreviation read the same attributes.

constexpr year_month_day d = 2026y / November / 23d;
static_assert(snicholls::month_name(d.month()) == "November");
static_assert(snicholls::weekday_abbreviation(weekday{sys_days{d}}) == "Mon");
// the names are attributes of the enumerations, so every printer reads the same ones
static_assert(snicholls::attributes_of(snicholls::month_of_year::may).get<snicholls::label>().text == "May");
static_assert(snicholls::attributes_of(snicholls::day_of_week::sunday).get<snicholls::abbreviation>().text == "Sun");

Relationships. meta/attributes.hpp (per_enumerator, attributes_of), display.hpp (label, attribute_json), time/week_date.hpp, time/utc_format.hpp. Group: snicholls-core.

Implementations. One.

Guarantees. constexpr, noexcept; a name is one table load. The views are of string literals: valid for the whole program.

Errors. None. A std::chrono::month or weekday that is not ok() has the empty name.

Performance. One table load; not benchmarked.

Tests and demos. tests/time/names_test.cpp, demos/time/names_demo.cpp.

Dependencies. <array>, <chrono>, <cstdint>, <ostream>, <string_view>, display.hpp (which brings <ostream> for the JSON export), meta/attributes.hpp.

Known issues. The enumerations and their attributes are declared in snicholls::calendar and brought into snicholls by using-declarations, so snicholls itself still declares nothing called attributes (meta/attributes.hpp). English only: other languages are the caller's attributes, or CLDR data in a library above core.

Status. New in 0.23.0.
