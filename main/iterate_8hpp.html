Detailed Description

Wolfram's iteration primitives, constexpr: table, nest, nest_list, nest_while, fixed_point, fold_list.

Overview.

Wolfram here
Table[f[i], {i, 0, n - 1}] table<n>(f)
Nest[f, x, n] nest(f, x, n)
NestList[f, x, n] nest_list<n>(f, x): n + 1 values
NestWhile[f, x, test] nest_while(f, x, test, limit)
FixedPoint[f, x] fixed_point(f, x, limit)
FoldList[f, x, list] fold_list(f, x, list): n + 1 values

Each is constexpr: a table of iterates (a recurrence, a schedule of rates, Newton's steps) can be built by the compiler. For types, meta::nest_list_t and meta::fold_list_t. Accumulate, Differences and Range are C++20's constexpr std::partial_sum, std::adjacent_difference and std::iota.

// NestList: a balance compounding at 5% a year for five years.
constexpr auto balances = snicholls::nest_list<5>([](double b) { return b * 1.05; }, 1000.0);
// FoldList: the running P&L of a week's trades.
constexpr auto running = snicholls::fold_list([](double total, double pnl) { return total + pnl; }, 0.0,
std::array{120.0, -40.0, 15.0, 60.0, -5.0});
// FixedPoint: the yield y with 100 = 105 / (1 + y), by iterating y = 105 / 100 - 1 to a fixed point.
constexpr auto yield = snicholls::fixed_point([](double y) { return 0.5 * y + 0.5 * (105.0 / 100.0 - 1.0); }, 0.0, 200);
static_assert(yield.converged);

Relationships. meta/type_list.hpp; thread_apply.hpp; combinatorics/subsets.hpp. Group: snicholls-core.

Guarantees. constexpr, allocation-free; noexcept when f is. nest_while and fixed_point stop at limit steps whatever happens.

Errors. None of their own: fixed_point reports, through iterations, whether it converged.

Performance. The calls to f.

Tests and demos. tests/iterate_test.cpp, demos/iterate_demo.cpp.

Dependencies. <array>, <cstddef>, <functional>, <type_traits>, <utility>.

Known issues. fixed_point compares with ==; for floating point, pass a same test with a tolerance.

Status. New in 0.5.0.
