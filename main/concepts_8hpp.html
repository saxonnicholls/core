Detailed Description

The small concepts the family keeps re-declaring: streamable, printable, enumeration, integer, map_like and friends.

Overview. A first_match chain, a to_text function or a serialiser asks the same questions of a type over and over: can it be streamed, is it an enumeration, is it a number rather than a bool or a char, is it a map. The standard library answers some (std::integral, std::floating_point, std::ranges::range) and not others, and std::integral says yes to bool and to every character type, which is rarely what a branch means. These concepts are the answers, declared once:

// Each branch states its condition with a concept; the order of the list is the chain.
std::string text(const auto& value);
const auto text_chain = snicholls::first_match{
[](std::string_view s) { return std::string{s}; },
[](std::same_as<bool> auto b) { return std::string{b ? "true" : "false"}; },
[](snicholls::character auto c) { return std::string(1, static_cast<char>(c)); },
[](snicholls::number auto n) { return std::to_string(n); },
[](snicholls::enumeration auto e) { return std::to_string(static_cast<std::underlying_type_t<decltype(e)>>(e)); },
[](const snicholls::map_like auto& m) {
std::string out{"{"};
for (const auto& [key, value] : m)
out += (out.size() > 1 ? ", " : "") + text(key) + ": " + text(value);
return out + "}";
},
[](const std::ranges::input_range auto& r) {
std::string out{"["};
for (const auto& element : r)
out += (out.size() > 1 ? ", " : "") + text(element);
return out + "]";
},
[](const snicholls::streamable auto& x) { std::ostringstream os; os << x; return os.str(); },
[](const auto&) { return std::string{"?"}; },
};
std::string text(const auto& value) { return text_chain(value); }

always_false_v<T> is the dependent false for a static_assert in a template branch that must fail only when it is instantiated.

Relationships. snicholls::first_match is where constrained lambdas meet; the string concepts (string_like, byte_sequence ...) live in reflect/string_traits.hpp and tuple_like in reflect/struct_tuple.hpp, and are not repeated here. Group: snicholls-core.

Guarantees. Compile time only; nothing here has a run-time footprint. Every concept strips const, volatile and references before asking, so const int& is an integer.

Errors. None.

Performance. Not applicable.

Tests and demos. tests/meta/concepts_test.cpp, demos/meta/concepts_demo.cpp.

Dependencies. <concepts>, <iosfwd>, <ranges>, <type_traits>.

Known issues. streamable only requires that os << t is an expression; a stream operator that returns something other than the stream still counts. map_like and set_like are duck-typed on key_type and mapped_type, which every standard associative container has and a std::vector<std::pair<K, V>> does not.

Status. New in 0.5.0.
