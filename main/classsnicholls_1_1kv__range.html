Detailed Description

The keys a scan or a range erase covers: a lower bound, an optional exclusive upper bound, a prefix.

Views its bounds (keep them alive while the range is used); allocates nothing, so a prefix range has no computed upper bound: a backend that needs one computes it. Built by all(), from(), between() and prefixed(); after(key) continues a range after a key already seen, which is how a scan is chunked.

Invariant
lower() starts with prefix() or sorts after it, so an ascending walk from lower() stops at the first key that beyond() reports.
