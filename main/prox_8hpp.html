Detailed Description

snicholls::optim: proximal operators prox_{λf}(v) = argmin_x λ f(x) + ½‖x − v‖² in place, Moreau envelopes, and the prox of a conjugate by Moreau's identity.

Overview. Proximal gradient (ISTA, FISTA), ADMM and the primal-dual methods take a step by the prox of each nonsmooth term. These are the common ones, each in place on a std::span (the input v becomes prox_{λf}(v)), with λ > 0:

| f | Function | prox_{λf}(v) | |—|—|—| | ‖x‖₁ | prox_l1 | soft threshold sign(v) max(|v| − λ, 0) | | ‖x‖₂ | prox_l2 | block soft threshold max(1 − λ/‖v‖, 0) v | | Σ_g ‖x_g‖₂, consecutive groups | prox_group_l2 | prox_l2 per group | | ‖x‖∞ | prox_linf | v − P_{‖·‖₁ ≤ λ}(v) (Moreau), i.e. clamp(v, −τ, τ) | | Σ huber(xᵢ, M) (CVXPY: x² for |x| ≤ M, 2M|x| − M² beyond) | prox_huber | v/(1 + 2λ) or v − 2λM sign(v) | | ‖x‖₂² | prox_squared_l2 | v / (1 + 2λ) | | indicator of [l, u], of x ≥ 0 | prox_box, prox_nonnegative | the projection | | ‖x‖₁ + (μ/2)‖x‖₂² | prox_elastic_net | soft(v, λ) / (1 + λμ) | | Σ xᵢ log xᵢ | prox_negative_entropy | λ W₀(e^{v/λ − 1} / λ) | | −Σ log xᵢ | prox_log_barrier | (v + √(v² + 4λ)) / 2 | | Σ ½dᵢxᵢ² + cᵢxᵢ, dᵢ ≥ 0 | prox_quadratic | (v − λc) / (1 + λd) |

moreau_envelope_* gives M_{λf}(v) = min_x f(x) + ‖x − v‖²/(2λ) where its closed form is cheap (ℓ1, ℓ2, squared ℓ2, Huber, a box, the orthant). prox_conjugate(prox_f, v, λ, workspace) gives prox_{λf*}(v) = v − λ prox_{f/λ}(v/λ) from any prox of f.

// ISTA: x ← prox_{t μ‖·‖₁}(x − t ∇½‖Ax − b‖²), with the step t below 1 / ‖AᵀA‖ (here ‖AᵀA‖ < 5)
std::array<double, n> lasso_ista(int iterations)
{
std::array<double, n> x{};
const double t = 0.2;
for (int k = 0; k < iterations; ++k) {
const auto g = gradient(x);
for (std::size_t j = 0; j < n; ++j)
x[j] -= t * g[j];
op::prox_l1(std::span<double>(x), t * mu);
}
return x;
}
// KKT for the LASSO: -∇ᵢ = μ sign(xᵢ) where xᵢ ≠ 0, |∇ᵢ| ≤ μ where xᵢ = 0
double kkt_violation(const std::array<double, n>& x)
{
const auto g = gradient(x);
double worst = 0;
for (std::size_t j = 0; j < n; ++j) {
const double v = x[j] != 0 ? std::abs(g[j] + mu * (x[j] > 0 ? 1 : -1)) : std::max(0.0, std::abs(g[j]) - mu);
worst = std::max(worst, v);
}
return worst;
}

Relationships. optim/cones.hpp (the projections, which are the prox of indicators; the ℓ1-ball projection behind prox_linf). Group: snicholls-core.

Implementations. Closed forms. The ℓ∞ prox finds the ℓ1-ball threshold by Condat's algorithm with a workspace, or Michelot's without. The negative-entropy prox computes W₀(e^a) directly as the root of w + log w = a by Halley's iteration (from a − log a above 1, e^a / (1 + e^a) below), so no e^a is formed and v/λ up to the type's range works; below e^a < ε it returns e^a. The log barrier's root avoids cancellation for negative v.

Guarantees. Every function is constexpr and noexcept for the standard floating-point types; no allocation (prox_conjugate and the Condat form of prox_linf take the caller's workspace); O(n), and the ℓ∞ prox expected O(n). prox_conjugate is noexcept when the given prox is.

Errors. optim::error::dimension_mismatch when group sizes do not add up, or bounds or coefficients differ in length from v; workspace_too_small. Nothing throws. λ ≤ 0 is a precondition violation, not checked.

Performance. Not benchmarked.

Tests and demos. tests/optim/prox_test.cpp, demos/optim/prox_demo.cpp (a LASSO by ISTA, with its KKT conditions checked).

Dependencies. <cstddef>, <limits>, <span>, <type_traits>, <utility>, optim/cones.hpp, math/constexpr_math.hpp, result.hpp.

Known issues. The negative-entropy prox evaluates W₀(eᵃ) in log form (Wright's ω), so it never overflows; math::lambert_w0 (math/special.hpp) is the general function. The negative-entropy prox underflows towards 0 (a subnormal, then 0) for v/λ below about −700 in double, where the exact answer is below the least normal number.

Status. Experimental, new in 0.21.0.
