Detailed Description

snicholls::metric::mahalanobis and the Gaussian measures hellinger, squared_hellinger and kl_divergence as plug-in metrics.

Overview. Distances that account for uncertainty, packaged as metrics so that any search structure or set metric can use them:

  • mahalanobis<T, N>: √((a - b)ᵀ S⁻¹ (a - b)) for a fixed covariance S, made by make_mahalanobis(S), which factorises S once. It holds L = cholesky(S) and is the Euclidean distance after whitening by L⁻¹: a metric, with the squared distance as its reduced form. Gating detections against one track's innovation covariance is a radius search with it.
  • hellinger, squared_hellinger, kl_divergence: between two tracking::gaussians, the functions of tracking/gaussian.hpp as metric values. hellinger is a metric; the other two are not (kl_divergence is not even symmetric). A covariance without a Cholesky factor gives NaN, which never compares below a bound.
// A track predicted at the origin, uncertain along x (σ = 10) and sure along y (σ = 1)
const v2 predicted{{0, 0}};
const auto gate = me::make_mahalanobis(m2{{100, 0, 0, 1}}).unwrap(); // factorised once
// Gating is a radius search: compare reduced (squared) distances against the contracted radius, no square roots
const std::array<v2, 3> detections{v2{{15, 0}}, v2{{0, 4}}, v2{{-20, 1}}};
const double radius = 3; // three sigma
std::size_t inside = 0;
for (const auto& d : detections)
inside += gate.reduced(predicted, d) <= gate.contract(radius) ? 1 : 0;
// Two estimates of one target, compared as distributions
const tr::gaussian<double, 2> a{v2{{0, 0}}, m2{{1, 0, 0, 1}}}, b{v2{{1, 0}}, m2{{2, 0, 0, 1}}};
const double h = me::hellinger{}(a, b), h2 = me::squared_hellinger{}(a, b);
const double kl_ab = me::kl_divergence{}(a, b), kl_ba = me::kl_divergence{}(b, a);

Relationships. metric/concepts.hpp, tracking/gaussian.hpp (the functions), linalg/fixed.hpp (cholesky, lower_solve), result.hpp. Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation. mahalanobis is trivially copyable (it holds an N x N factor).

Errors. make_mahalanobis returns linalg::error::not_positive_definite for a covariance without a Cholesky factor. The Gaussian measures return NaN in that case.

Performance. Not benchmarked: mahalanobis is a triangular solve per pair, O(N²).

Tests and demos. tests/metric/statistical_test.cpp, demos/metric/statistical_demo.cpp.

Dependencies. <cstddef>, <limits>, linalg/fixed.hpp, math/constexpr_math.hpp, metric/concepts.hpp, result.hpp, tracking/gaussian.hpp.

Known issues. None known.

Status. Experimental, new in 0.20.0.
