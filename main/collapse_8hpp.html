Detailed Description

snicholls::ml collapse safeguards for joint-embedding training: embedding_moments (mergeable per-dimension standard deviation, covariance and effective rank), VICReg's variance and covariance terms, and LeJEPA's SIGReg (sketched Epps-Pulley), each with its gradient.

Overview. A joint-embedding objective has a trivial minimum: an encoder that maps every input to one point predicts itself perfectly. JEPAs avoid it with an EMA target and a narrow predictor (ml/jepa.hpp), and watch for it with diagnostics; other methods add a regulariser that makes collapse expensive. This header has both (TRAINING.md T11).

Diagnostics. embedding_moments<T> accumulates rows of embeddings (add, add_rows) into a count, a mean and the co-moment (Welford's update), over views the caller owns: the full width x width co-moment, or only its diagonal for the variances alone. Two accumulators merge (Chan, Golub and LeVeque's update), so workers and batches combine. From it: variance and standard_deviation per dimension (unbiased, n - 1), whose collapse to 0 is the first sign of trouble (V-JEPA's pstd); covariance; and effective_rank (Roy and Vetterli, 2007: exp(-Σ p_k log p_k) with p_k = σ_k / Σ σ, σ_k = sqrt(λ_k) from the covariance's eigenvalues, the singular values of the centred embeddings up to a factor; RankMe, Garrido et al. 2023, takes the singular values of the embeddings uncentred), 1 for a collapse to a line and width for isotropic embeddings.

VICReg (Bardes, Ponce and LeCun, 2022; read from its code 2026-11-19): over a batch X of n rows of d, centred X̃ = X - mean,

  • vicreg_variance_rows: v = (1/d) Σ_j max(0, γ - sqrt(Var(x_j) + ε)), Var unbiased, γ = 1, ε = 1e-4;
  • vicreg_covariance_rows: c = (1/d) Σ_{i≠j} C_ij², C = X̃ᵀ X̃ / (n - 1); each with its gradient added, times a weight (VICReg's coefficients: 25 on the invariance and variance terms, 1 on the covariance, for a loss over two branches each).

SIGReg (Balestriero and LeCun, 2025, "LeJEPA: Provable and Scalable Self-Supervised Learning Without the Heuristics", and its code, read 2026-11-19): embeddings should be distributed as an isotropic Gaussian, and SIGReg tests that along M random unit directions a (sigreg_directions, redrawn every step from (seed, step), the same on every worker) with the Epps-Pulley statistic of the 1-D projections z_n = a·x_n: EP = N ∫ |φ̂(t) - e^(-t²/2)|² e^(-t²/2) dt, φ̂(t) = (1/N) Σ_n e^(i t z_n), integrated by the trapezoid rule on [-t_max, t_max] through the integrand's symmetry, K knots on [0, t_max] (sigreg_quadrature, 17 knots and t_max = 3 by default, the code's), and averaged over the directions. The empirical characteristic function is a mean, so the statistic splits into sums that merge across workers (an all-reduce): sigreg_moments_rows adds each row's cos(t_k z_n) and sin(t_k z_n) into sums, sigreg_value reads the statistic from the merged sums and the global count, and sigreg_backward_rows adds its gradient, ∂EP/∂z_n = Σ_k 2 w_k t_k (s̄_k cos(t_k z_n) - (c̄_k - φ_k) sin(t_k z_n)) taken along each direction. LeJEPA's loss is (1 - λ) · prediction + λ · SIGReg, λ = 0.05, its prediction term the squared distance of each view's embedding to the mean of the global views' (jepa_loss_rows with jepa_loss::l2).

// Two workers accumulate half the rows each and merge; then the spread per dimension and the effective rank
std::vector<double> mean_a(d), m_a(d * d), mean_b(d), m_b(d * d), sd(d), var(d), cov(d * d), work(2 * d * d + d);
ml::embedding_moments<double> a{mean_a, m_a}, b{mean_b, m_b};
a.add_rows(std::span<const double>(healthy).first(n / 2 * d));
for (std::size_t r = n / 2; r < n; ++r)
b.add(std::span<const double>(healthy).subspan(r * d, d));
a.merge(b);
a.standard_deviation(sd);
a.variance(var);
a.covariance(cov);
const double rank = *a.effective_rank(backend, std::span<double>(work));
// SIGReg: 32 directions for this step, the statistic per direction averaged; two workers' sums add
const ml::sigreg_quadrature<double> quad{};
std::vector<double> directions(32 * d), sums(32 * 17 * 2), other(sums.size());
ml::sigreg_directions<double>(2026, 0, d, directions);
ml::sigreg_moments_rows(backend, std::span<const double>(healthy).first(n / 2 * d), d, std::span<const double>(directions), quad,
std::span<double>(sums));
ml::sigreg_moments_rows(backend, std::span<const double>(healthy).subspan(n / 2 * d), d, std::span<const double>(directions), quad,
std::span<double>(other));
for (std::size_t i = 0; i < sums.size(); ++i)
sums[i] += other[i]; // the all-reduce
const double healthy_sigreg = ml::sigreg_value(std::span<const double>(sums), n, quad);
std::vector<double> dx(n * d);
ml::sigreg_backward_rows(backend, std::span<const double>(healthy), d, std::span<const double>(directions), quad, std::span<const double>(sums), n,
std::span<double>(dx));

Relationships. ml/jepa.hpp, linalg/backend.hpp (symmetric_eigen for the effective rank), stats/normal.hpp (normal_inverse_cdf for the directions), ml/diloco.hpp (ordered_sum, the merge of sums across workers). Group: snicholls-core.

Implementations. One each, on the host for any backend; a device library overloads the _rows functions.

Guarantees. constexpr, no allocation (the caller's spans). Sums run in row order, then channel order, as written. merge of two halves equals one pass up to rounding.

Errors. Preconditions, asserted: the sizes of the spans; at least two rows for a variance. effective_rank returns the backend's linalg::error if the eigensolver fails.

Performance. vicreg_covariance_rows and sigreg_moments_rows against the loops by hand (benchmarks/ml/collapse_benchmark.cpp), 256 embeddings of 128 floats, SIGReg over 64 directions and 17 knots: the covariance term with its gradient within 10% (4.9 ms), the SIGReg sums level (3.6 ms, its cosines and sines) (Xeon W-3245, Release, Apple clang 17, 2026-11-19, one thread, a machine at load average 60 to 80: differences within about 15% are noise). The covariance term is O(n d²); SIGReg O(n d M + n M K).

Tests and demos. tests/ml/collapse_test.cpp, demos/ml/collapse_demo.cpp.

Dependencies. <cassert>, <cstddef>, <cstdint>, <span>, <type_traits>, linalg/backend.hpp, snicholls/core/math/constexpr_math.hpp, snicholls/core/result.hpp, stats/normal.hpp, stats/random.hpp.

Known issues. The LeJEPA paper's text gives the weight as e^(-t²/σ²) with σ = 1; its code uses e^(-t²/2), as here. Its code multiplies by the world size as well as the local count; count here is the global count.

Status. Experimental, new in 0.16.0.
