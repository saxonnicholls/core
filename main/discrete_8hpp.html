Detailed Description

snicholls::tracking::hmm_predict, hmm_update and hmm_predict_measurement: the Bayes filter of a hidden Markov model, for a target's class or mode.

Overview. Some of a target's state is a category, not a number: a swimmer above the surface, at it, or not visible; a manoeuvre mode; an object class. Its distribution is a probability vector p over K hidden categories, propagated by a column-stochastic transition matrix and corrected by an emission matrix:

  • hmm_predict(p, A): normalise(A p), A[i][j] the probability of moving from j to i.
  • hmm_predict_measurement(p, E): normalise(E p), the predicted distribution of the L observable categories, E[l][k] the probability of observing l in hidden category k.
  • hmm_update(p, z, E): normalise((Eᵀ z) ⊙ p), for an observation z that is one-hot or itself a distribution (a classifier's soft output).
  • hmm_likelihood(p, z, E): zᵀ E p, the observation's marginal likelihood, for association.
  • normalise_columns(A): columns summed to 1, as Stone Soup normalises its matrices.

Conventions are Stone Soup's (MarkovianTransitionModel, MarkovianMeasurementModel, HMMPredictor, HMMUpdater).

// Hidden: surfaced, at the surface, submerged. Columns are "from", rows "to"; counts, normalised per column
const m33 transition = tr::normalise_columns(m33{{8, 1, 0,
2, 7, 2,
0, 2, 8}});
// Observed: seen, not seen. A submerged swimmer is never seen
const m23 emission{{0.9, 0.5, 0.0,
0.1, 0.5, 1.0}};
const std::array<v2, 4> observations{v2{{1, 0}}, v2{{0, 1}}, v2{{0, 1}}, v2{{0.7, 0.3}}}; // the last a classifier's soft output
v3 belief{{1.0 / 3, 1.0 / 3, 1.0 / 3}};
double log_evidence = 0;
std::array<v3, 4> history{};
std::size_t step = 0;
for (const v2& z : observations) {
const auto predicted = tr::hmm_predict(belief, transition).unwrap();
const auto expect = tr::hmm_predict_measurement(predicted, emission).unwrap(); // P(seen) before looking
log_evidence += std::log(tr::hmm_likelihood(predicted, z, emission));
belief = tr::hmm_update(predicted, z, emission).unwrap();
history[step++] = belief;
std::printf(" P(seen) predicted %.3f; observed (%.1f, %.1f): belief %.4f %.4f %.4f\n", expect[0], z[0], z[1], belief[0], belief[1], belief[2]);
}

Relationships. linalg/fixed.hpp, result.hpp. Combined with a gaussian kinematic state in the framework above core. Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation. Results are non-negative and sum to 1.

Errors. hmm_error::zero_probability when the result would be all zero: the observation is impossible under every hidden category the prior allows.

Performance. Not benchmarked: a K x K or L x K product.

Tests and demos. tests/tracking/discrete_test.cpp, demos/tracking/discrete_demo.cpp.

Dependencies. <cstddef>, <cstdint>, linalg/fixed.hpp, result.hpp.

Known issues. None known.
