Detailed Description

snicholls::optim::backtracking_armijo and strong_wolfe: line searches along a descent direction, over callables and the caller's storage, all constexpr.

Overview. A descent method picks a direction d at x and then a step α along it. With φ(α) = f(x + α d) and φ'(0) = ∇f(x)ᵀd < 0:

  • backtracking_armijo(f, x, d, f(x), φ'(0), trial, options) tries α = initial_step, ρ α, ρ² α, … until the sufficient-decrease (Armijo) condition φ(α) ≤ φ(0) + c₁ α φ'(0) holds. It needs values only. Use it for Newton-type directions whose unit step is usually right, and for projected and proximal methods.
  • strong_wolfe(fg, x, d, f(x), φ'(0), trial, trial_gradient, options) finds α with sufficient decrease and the strong curvature condition |φ'(α)| ≤ c₂ |φ'(0)|, by bracketing and zoom (Nocedal and Wright, Numerical Optimization, 2nd ed., algorithms 3.5 and 3.6). The trial steps inside the bracket come from the cubic that interpolates φ and φ' at both ends (their equation 3.59), else the quadratic through φ(lo), φ'(lo) and φ(hi), else bisection, and are kept at least a tenth of the bracket from either end. Quasi-Newton methods need it: the curvature condition makes sᵀy > 0, so the BFGS update stays positive definite (optim/lbfgs.hpp).

f(x) is a callable T(std::span<const T>); fg(x, g) is T(std::span<const T>, std::span<T>), returning f(x) and writing ∇f(x) into g. trial (and trial_gradient) are n values of the caller's: on return they hold x + α d (and ∇f there) for the returned α, so the caller moves to it without evaluating again.

// Rosenbrock's function with its gradient
double rosenbrock(cspan x, std::span<double> g)
{
const double a = x[1] - x[0] * x[0], b = 1 - x[0];
g[0] = -400 * x[0] * a - 2 * b;
g[1] = 200 * a;
return 100 * a * a + b * b;
}
bool line_search_example()
{
const std::array<double, 2> x{-1.2, 1};
std::array<double, 2> g{}, d{}, trial{}, trial_g{};
const double f = rosenbrock(x, g);
d = {-g[0], -g[1]}; // steepest descent
const double slope = g[0] * d[0] + g[1] * d[1]; // φ'(0) < 0
// Armijo: values only; the unit step overshoots badly and is halved until f falls enough
const auto values_only = [](cspan v) {
std::array<double, 2> unused{};
return rosenbrock(v, unused);
};
const auto a = op::backtracking_armijo(values_only, x, d, f, slope, trial);
std::printf(" Armijo: step %.3e, f %.4f -> %.4f, %zu evaluations\n", a.step, f, a.value, a.evaluations);
// Strong Wolfe: also |φ'(α)| ≤ 0.9 |φ'(0)|, found by bracketing and cubic interpolation; the trial storage
// holds the new point and its gradient, ready for the next iteration
const auto w = op::strong_wolfe(rosenbrock, x, d, f, slope, trial, trial_g);
std::printf(" strong Wolfe: step %.3e, f %.4f -> %.4f, φ' %.3e -> %.3e, %zu evaluations\n", w.step, f, w.value, slope, w.derivative, w.evaluations);
// A first step far too short is expanded (doubling) until the minimum along the line is bracketed
const auto fg = [](cspan v, std::span<double> grad) {
grad[0] = 2 * (v[0] - 100);
return (v[0] - 100) * (v[0] - 100);
};
const std::array<double, 1> x1{0}, d1{1};
std::array<double, 1> t1{}, tg1{};
const auto e = op::strong_wolfe(fg, x1, d1, 1e4, -200.0, t1, tg1, {1e-3, 1e-4, 0.1, 2, 1e10, 40});
std::printf(" expanded: step %.4f from 1e-3, %zu evaluations\n", e.step, e.evaluations);
// Uphill: nothing is evaluated
const auto up = op::strong_wolfe(fg, x1, d1, 1e4, 200.0, t1, tg1);
// Unbounded below: the search stops at max_step and says so
const auto unbounded = op::strong_wolfe([](cspan v, std::span<double> grad) { grad[0] = -1; return -v[0]; }, x1, d1, 0.0, -1.0, t1, tg1, {1, 1e-4, 0.9, 10, 1e8, 40});
std::printf(" uphill: %s; unbounded: %s at step %.0e\n", up.status == op::line_search_status::not_descent_direction ? "not a descent direction" : "?",
unbounded.status == op::line_search_status::step_at_maximum ? "step_at_maximum" : "?", unbounded.step);
return a.satisfied() && a.value <= f + 1e-4 * a.step * slope && w.satisfied() && w.value <= f + 1e-4 * w.step * slope && std::abs(w.derivative) <= 0.9 * std::abs(slope) &&
e.satisfied() && std::abs(e.step - 100) < 10 && up.evaluations == 0 && unbounded.status == op::line_search_status::step_at_maximum;
}

Relationships. optim/lbfgs.hpp (its line search), linalg/types.hpp (scalar), math/constexpr_math.hpp (sqrt). Group: snicholls-core.

Implementations. Armijo: plain contraction by shrink. Strong Wolfe: the bracketing phase expands the step by expansion up to max_step; the zoom keeps the invariants of algorithm 3.6 (lo satisfies sufficient decrease and has the lowest φ seen, φ'(lo) (hi - lo) < 0). A value that is not a number fails the sufficient-decrease test, so a step into a region where f is undefined is shortened rather than taken.

Guarantees. constexpr; noexcept when the callable is and T's arithmetic is. No allocation, no recursion. At most max_evaluations evaluations, plus one when a failed strong-Wolfe search re-evaluates its best point so that trial holds it. On line_search_status::satisfied the returned step meets the documented conditions with the documented constants.

Errors. Nothing throws unless the callable does. The outcome is a line_search_status: not_descent_direction (φ'(0) ≥ 0, or not a number: nothing is evaluated, the step is 0 and trial is untouched), evaluation_limit, step_at_maximum (strong Wolfe: max_step satisfies sufficient decrease and φ is still falling: the function may be unbounded below), interval_collapsed (strong Wolfe: the bracket shrank to rounding). After a failure the step is the best one found with sufficient decrease (0 if none).

Performance. Not benchmarked: the cost is the callable's evaluations, which the result counts.

Tests and demos. tests/optim/line_search_test.cpp, demos/optim/line_search_demo.cpp.

Dependencies. <cstddef>, <cstdint>, <span>, <type_traits>, linalg/types.hpp, math/constexpr_math.hpp.

Known issues. c₁ < c₂ < 1 is the caller's to ensure (the defaults are 1e-4 and 0.9, for quasi-Newton methods; use c₂ = 0.1 for nonlinear conjugate gradients). The searches do not check that trial is n long.

Status. Experimental, new in 0.21.0.
