Detailed Description

snicholls::ml rotary position embedding: the frequencies, a table of cosines and sines the compiler can build, and the rotation of a head, forward and inverse.

Overview. RoPE (Su et al., 2021), as LLaMA, GPT-NeoX and nanochat use it: each pair of channels of a query or key head is rotated by the angle pos · base^(-2i/d), so that the dot product of a query and a key depends on their distance only.

  • rope_frequency<T>(i, d, base): base^(-2i/d), the angular frequency of pair i of a head of d channels.
  • rope_angles(pos, cos, sin, base): one position's row of d/2 cosines and sines.
  • rope_table<T, Positions, HeadDim>: every position's rows, built by a constexpr constructor: in a constexpr variable for a table the compiler holds (a fixed context on an FPGA, a float table a GPU kernel reads), or at start-up for a long context, which would exceed the compiler's evaluation limits.
  • rope(x, cos, sin, layout) rotates a head by +θ; rope_inverse by -θ. The rotation is orthogonal, so the backward pass of rope is rope_inverse applied to the gradient, and the other way round.
  • rope_source<R>: anything with cos_at(pos) and sin_at(pos), such as rope_table; no_rope stands in where a model has no RoPE (ml/attention_layer.hpp, ml/self_attention.hpp).
  • Long context: rope_scaling<T> rescales the frequencies (rope_scaled_frequency) for a context s times the trained one: position interpolation (linear, every frequency over s; Chen et al., 2023), ntk (the base raised to base · s^(d/(d-2)); YaRN section 3.1), and YaRN's NTK-by-parts (Peng et al., 2023, eqs. 10 to 13): pairs that turn fewer than α times over the trained context are interpolated, more than β times kept, a ramp yarn_ramp between. yarn is the paper's ramp, linear in the rotations r; yarn_index_ramp is its published code's, which DeepSeek-V3 also uses: linear in the pair index between the correction dimensions (yarn_correction_dim) rounded down and up. yarn_attention_factor(s) = 0.1 ln s + 1 is YaRN's temperature, applied squared to the scores: as the table's amplitude (queries and keys each scaled) or in a softmax scale. rope_angles(pos, cos, sin, base, scaling) and rope_table(base, scaling) build the scaled rows, in the table's type and at compile time in a constexpr variable. Every method is plain RoPE at a factor of 1.
  • rope_layout::half pairs channel i with i + d/2 (GPT-NeoX, Hugging Face LLaMA, nanochat); rope_layout::interleaved pairs 2i with 2i + 1 (Meta's LLaMA, GPT-J).
// A context of 16 positions and heads of 8 channels: the compiler builds the whole table, in float as a kernel reads it
constexpr ml::rope_table<float, 16, 8> table{};
static_assert(table.cos[0][0] == 1.0f && table.sin[0][0] == 0.0f); // position 0 does not rotate
float score(std::array<float, 8> q, std::size_t pq, std::array<float, 8> k, std::size_t pk, ml::rope_layout layout)
{
ml::rope(q, table.cos_at(pq), table.sin_at(pq), layout);
ml::rope(k, table.cos_at(pk), table.sin_at(pk), layout);
float s = 0.0f;
for (std::size_t i = 0; i < 8; ++i)
s += q[i] * k[i];
return s;
}
// Reaching 40 times past a trained context of 4096: the five rescalings of a head of 64 rotary channels, pair by pair
const auto method = [](ml::rope_scaling_kind kind) { return ml::rope_scaling<double>{kind, 40.0, 4096, 32.0, 1.0, 1.0}; };
const double plain = ml::rope_frequency<double>(31, 64), fast = ml::rope_frequency<double>(0, 64);
const double linear = ml::rope_scaled_frequency(31, 64, 10000.0, method(ml::rope_scaling_kind::linear)); // θ / 40
const double ntk = ml::rope_scaled_frequency(16, 64, 10000.0, method(ml::rope_scaling_kind::ntk)); // a larger base:
const double mid = ml::rope_frequency<double>(16, 64); // between the two
const double yarn = ml::rope_scaled_frequency(31, 64, 10000.0, method(ml::rope_scaling_kind::yarn)); // slow pairs: θ / 40
const double yarn_fast = ml::rope_scaled_frequency(0, 64, 10000.0, method(ml::rope_scaling_kind::yarn_index_ramp)); // fast: θ
const double none = ml::rope_scaled_frequency(31, 64, 10000.0, method(ml::rope_scaling_kind::none));
const double ramp = ml::yarn_ramp(16.5, 1.0, 32.0), lo = ml::yarn_correction_dim(32.0, 64, 10000.0, 4096);
// YaRN's temperature: DeepSeek-V3 multiplies its softmax scale by its square; a table can carry it as an amplitude
const double t = ml::yarn_attention_factor(40.0);
std::array<double, 2> yc{}, ys{};
ml::rope_angles(0, yc, ys, 10000.0, ml::rope_scaling<double>{ml::rope_scaling_kind::yarn_index_ramp, 40.0, 4096, 32.0, 1.0, t});
constexpr ml::rope_table<float, 4, 8> long_table{10000.0f, ml::rope_scaling<float>{ml::rope_scaling_kind::ntk, 4.0f}};

Relationships. ml/attention.hpp takes the rotated queries and keys; ml/row.hpp (the rows). Group: snicholls-core.

Implementations. One.

Guarantees. constexpr, no allocation, linear in the head. rope_table is trivially copyable. A rotation keeps a pair's length up to rounding.

Errors. Preconditions, asserted: the head has an even number of channels, and cos and sin have half as many. Position 0 is the identity.

Performance. Not benchmarked: four multiplications and two additions per pair, against a table read.

Tests and demos. tests/ml/rope_test.cpp, demos/ml/rope_demo.cpp.

Dependencies. <array>, <cassert>, <concepts>, <cstddef>, <span>, snicholls/core/math/constexpr_math.hpp, ml/row.hpp.

Known issues. nanochat's apply_rotary_emb rotates by -θ (y1 = x1 cos + x2 sin): its forward pass is rope_inverse here. Either direction is a valid RoPE as long as queries and keys agree. LLaMA 3's own long-context rescaling (a ramp over wavelengths with its own constants) is not built in. YaRN's paper and its code differ in the ramp's shape between the bounds (both are offered); gpt-oss computes the paper's form. A table with an amplitude other than 1 is not orthogonal: rope_inverse is still rope's backward pass (the transpose), but no longer its inverse.

Status. Experimental, new in 0.7.0; the rescalings new in 0.16.0.

YaRN's attention temperature as a factor on the scores' square root: sqrt(1/t) = 0.1 · mscale · ln s + 1, 1 for s <= 1 (YaRN, definition 2; DeepSeek-V3, section 4.3, with mscale 1).
