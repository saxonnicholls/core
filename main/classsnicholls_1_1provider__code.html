Detailed Description

The provider's own short code for a failure: at most 32 characters of A-Z a-z 0-9 _ - . :.

Made from a literal checked by the compiler (provider_code{"card_declined"}) or at run time by make, which refuses text that is too long or has any other character, so free text, JSON or a response body cannot pass for a code.
