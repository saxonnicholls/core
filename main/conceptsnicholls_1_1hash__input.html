Detailed Description

What a hash accepts: a sequence of one-byte code units under core's string rules, or a digest<N>.

std::string, std::string_view, a string literal (length N - 1), const char*, char8_t text, std::span<const std::byte>, std::vector<std::uint8_t>, std::array<std::byte, N>, a digest<N>. Not wider text, whose bytes depend on the host's byte order.
