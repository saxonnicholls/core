Detailed Description

Maybe and Either helpers over std::optional and snicholls::result: lift, sequence / traverse (Traversable), fold_m, zip_with_m, replicate_m, for_m, when_m / unless_m, the eliminators maybe and either, and value_or, from_maybe, map_maybe, cat_maybes. All constexpr.

Overview. The type classes (fmap, ap, mbind, kleisli, alt) are in functional/typeclasses.hpp; these are the helpers built on them for the two carriers of a value that may be missing (std::optional, Maybe) or may have failed (snicholls::result, Either):

here std::optional<T> snicholls::result<V, E> Haskell
lift(f)(m1, m2, ...) f(*m1, *m2, ...) if all hold a value f(values...), or the first error liftA2, liftA3, ...
sequence(xs), sequence_a(xs) optional<tuple> / optional<array> result<tuple, E> / result<array, E> sequenceA, sequence
traverse(f, xs), map_m, for_m(xs, f) sequence(map f xs) the same traverse, mapM, forM
fold_m(f, z, xs) a fold that stops at the first empty step at the first error foldM
zip_with_m(f, a, b) sequence(zip_with(f, a, b)) the same zipWithM
replicate_m<N>(m) N copies of m, sequenced the same replicateM
when_m(b, m), unless_m(b, m) m or pure(std::monostate{}) the same when, unless (Control.Monad)
maybe(d, f, m), either(f, g, r) m ? f(*m) : d r ? g(value) : f(error) maybe, either
value_or(m, x), from_maybe(x, m) m.value_or(x) m.unwrap_or(x) fromMaybe
map_maybe(f, xs), cat_maybes(xs) the values of the engaged results - mapMaybe, catMaybes
constexpr auto spread = [](double bid, double ask) { return ask - bid; };
// lift: a function of plain values, used on values that may be missing...
constexpr std::optional<double> bid = 1.0850, ask = 1.0852, none{};
static_assert(fn::lift(spread)(bid, ask).has_value());
static_assert(!fn::lift(spread)(bid, none).has_value());
// ...or may have failed: the first error is kept.
static_assert(fn::lift(spread)(price(ok(1.0)), price(err(feed_error::stale))).unwrap_err_unchecked() ==
feed_error::stale);

Use these when a calculation is a chain of steps that may each fail; use SNICHOLLS_TRY when the chain is a function body with early returns.

Relationships. functional/typeclasses.hpp, functional/instances.hpp, functional/list.hpp (zip_with, replicate), snicholls::result, std::optional. Group: snicholls-core.

Implementations / variants. One overload per carrier, constrained with snicholls::specialisation_of; the carriers do not overlap.

Guarantees. constexpr. noexcept exactly when f and the copies or moves of values and errors are. The carrier's value category is kept. lift(f) evaluates f only when every argument holds a value; traverse calls f on every element, then sequences; fold_m stops at the first failure.

Errors. None of their own: an empty optional or an error result propagates. Results combined by lift, sequence or traverse need one error type, and the first error, left to right, is kept.

Examples.

// sequence: a tuple of results turned inside out. traverse: map, then sequence.
constexpr auto book = std::tuple{checked(1.0, 1.2), checked(2.0, 2.2)};
static_assert(fn::sequence(book).is_ok());
constexpr auto mids = fn::traverse([](auto quote) { return checked(quote.first, quote.second); },
std::tuple{std::pair{1.0, 1.2}, std::pair{2.2, 2.0}});
static_assert(mids.unwrap_err_unchecked() == feed_error::crossed);

Performance. A branch on has_value() / is_ok() and the call; not benchmarked.

Tests and demos. tests/functional/monad_test.cpp, tests/functional/monad_traversable_test.cpp, demos/functional/monad_demo.cpp, demos/functional/monad_railway_demo.cpp (railway error handling).

Dependencies. <array>, <cstddef>, <functional>, <optional>, <tuple>, <type_traits>, <utility>, <variant>, snicholls/core/result.hpp (heavier than it looks: <string_view> and <stdexcept>), functional/instances.hpp and functional/list.hpp.

Known issues and gotchas.

  • result<void, E> is not lifted or sequenced: there is no value to pass on. Use its own and_then.
  • sequence / traverse of a std::tuple or std::pair give a std::tuple inside; of a std::array, an array. fold_m is for Maybe and Either; for State, chain mbind.

Status. Experimental, new in 0.27.0.
