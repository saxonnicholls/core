Detailed Description

template<typename Policy>
class snicholls::md_hash< Policy >

A Merkle-Damgard hash over a policy: the class behind sha1, every SHA-2 and ripemd160.

Use it through its aliases. update(input) absorbs any hash_input and returns the hasher, so calls chain; finish() pads, compresses the last block and returns the digest; hash(input) is both at once.
