Detailed Description

Resamples drawn once and kept: reused across many series and statistics, they cost a read instead of a draw.

Reading a table of indices is about twice as fast as drawing them (BENCHMARKS.md), and every series bootstrapped through one table sees the same resamples: common random numbers, so the difference between two strategies is estimated with less noise than from independent resamples. It holds n x resamples 32-bit indices: 8 MB for 1,024 observations and 2,000 resamples. Built at run time, it is as fast as one built at compile time and costs the binary nothing.
