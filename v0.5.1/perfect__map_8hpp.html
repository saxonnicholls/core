Detailed Description

containers::perfect_map: a map built by the compiler with a perfect hash: two hashes, one slot, one compare.

Overview. For a table known when the program is written, a perfect hash places every key in its own slot, so a lookup never probes. Hash-and-displace: hash keys into buckets; for each bucket, largest first, find a displacement that sends all its keys to free slots; keep one displacement per bucket. A lookup is slot = h(key, displacement[h(key, 0) % buckets]) % slots and one key comparison. The constructor is consteval: the search always runs in the compiler, never at run time.

// The perfect hash is found by the compiler; at run time a lookup is two hashes and one compare.
constexpr snicholls::containers::perfect_map<std::string_view, double, 4> tick_size{
std::array<std::pair<std::string_view, double>, 4>{{{"ES", 0.25}, {"NQ", 0.25}, {"CL", 0.01}, {"GC", 0.1}}}};
const double* cl = tick_size.find("CL"sv);

Relationships. containers/static_map.hpp (binary search, ordered iteration), constexpr_map.hpp (linear, two-way); hash/wyhash.hpp. Group: snicholls-core.

Guarantees. find is O(1): two hashes and one comparison, no branches on collisions. Keys are integers, enumerations or anything convertible to std::string_view. Clang's default constant-evaluation budget holds 1,024 text keys and 1,600 integer keys (GCC 13 more); -fconstexpr-steps= raises it.

Errors. A duplicate key is a compile error.

Performance. benchmarks/containers/perfect_map_benchmark.cpp: 32,768 lookups of 512 four-letter codes, Release, Apple clang 17, Xeon W-3245, 2026-11-08: 211 us, against 685 us for std::unordered_map, 2.81 ms for static_map and 2.90 ms for a binary search written by hand.

Tests and demos. tests/containers/perfect_map_test.cpp, demos/containers/perfect_map_demo.cpp.

Dependencies. <algorithm>, <array>, <bit>, <concepts>, <cstddef>, <cstdint>, <stdexcept>, <string_view>, <type_traits>, <utility>, hash/wyhash.hpp.

Known issues. Space is about 1.5 slots per key, plus a 32-bit displacement per two keys.

Status. New in 0.5.0.
