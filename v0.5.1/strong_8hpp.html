Detailed Description

strong<T, Tag>: a value with its own type, so prices, quantities and notionals cannot be mixed.

Overview. using price = strong<double, struct price_tag>; gives a type that holds a double and is nothing else: it compares and adds with another price, scales by a plain number, and refuses a quantity or a bare double where a price is expected. It costs nothing: the same size and the same code as the double.

using price = snicholls::strong<double, struct price_tag>;
using quantity = snicholls::strong<double, struct quantity_tag>;
using notional = snicholls::strong<double, struct notional_tag>;
// The one place a price meets a quantity: stated, not guessed.
constexpr notional operator*(price p, quantity q) { return notional(p.value * q.value); }

Multiplying two different quantities (price times quantity is a notional) is the caller's to state, with a function: core does not guess units.

Relationships. meta/assignable.hpp; acout.hpp prints one (its print member); a std::hash is provided. Group: snicholls-core.

Guarantees. constexpr and noexcept when T's operations are; sizeof(strong<T, Tag>) == sizeof(T); trivially copyable when T is; construction is explicit.

Errors. None.

Performance. The same as T's.

Tests and demos. tests/strong_test.cpp, demos/strong_demo.cpp.

Dependencies. <compare>, <cstddef>, <functional>, <ostream>, <utility>.

Known issues. No units algebra: a product of two strong types is a function the caller writes.

Status. New in 0.5.0.
