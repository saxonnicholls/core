Detailed Description

Explain f(to) - f(from) by the inputs that moved: a game whose players are the moves.

Overview. A book is worth f(market). Overnight the market moved from from to to, each risk factor a little, and the book's value changed. change_game is the game in which a coalition of factors has moved and the rest have not; its Shapley attribution splits the change exactly, with no residual and no Taylor approximation, and shares every cross effect (spot and volatility together) fairly between the factors that cause it. attribute_change is that in one call.

// A book worth f(spot, vol, rate): long a quantity of spot, long volatility, short rates, with a cross effect.
const auto book = [](const std::array<double, 3>& m) { return 100 * m[0] + 5000 * m[1] * m[0] / 100 - 2000 * m[2]; };
const std::array<double, 3> yesterday{100.0, 0.20, 0.050};
const std::array<double, 3> today{102.0, 0.22, 0.051};
// 2^3 revaluations, every cross effect shared fairly, nothing left over.
const auto why = game::attribute_change<3>(book, yesterday, today);

The cost is 2^n revaluations of f. For n up to about 12 factors and a fast pricer that is real time; above it, group the factors (owen) or sample (shapley_sampled). finance/attribution.hpp gives the closed form for a second-order Taylor model, which costs O(n^2).

Relationships. game/shapley.hpp, game/owen.hpp; game/tabular.hpp is the same with many background points; finance/attribution.hpp. Group: snicholls-core.

Guarantees. constexpr. A point is any copyable random-access container of inputs (std::array, std::vector, a struct with operator[]); the game copies from for each evaluation and refers to f, from and to, which must outlive it.

Errors. None of its own; from and to must be the same size (asserted).

Performance. The revaluations; nothing else to speak of.

Tests and demos. tests/game/change_test.cpp, demos/game/change_demo.cpp.

Dependencies. <bit>, <cassert>, <cstddef>, <functional>, <ranges>, <type_traits>, <utility>, game/coalition.hpp, game/shapley.hpp.

Known issues. None known.

Status. New in 0.5.0, experimental.
