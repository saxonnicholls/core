Detailed Description

Martingale tools: the Doob decomposition, the martingale transform, quadratic variation, Markov chains, and tests of the martingale hypothesis.

Overview. A price is a martingale when no information available now predicts its next move. The tools here work on sampled paths, in discrete time:

  • doob_decomposition: any adapted path is X_t = X_0 + M_t + A_t, a martingale M and a predictable part A (the compensator), given the conditional expectations a model supplies. A is the drift a strategy can harvest; M is the noise it cannot. For a supermartingale, A decreases: Doob and Meyer.
  • martingale_transform: (H . X)_t = sum H_k (X_k - X_{k-1}), the P&L of holding H_k, chosen at k - 1. Against a martingale it is a martingale: no strategy beats a fair game.
  • quadratic_variation: [X]_t = sum (X_k - X_{k-1})^2.
  • markov_chain: finite states and a transition matrix, the setting of stochastic/snell.hpp.
  • variance_ratio_test (Lo and MacKinlay, heteroskedasticity-robust) and ljung_box: is a series of prices a martingale, or do its increments carry memory?
// The model's forecast of each next value; the Doob decomposition splits the path into what it
// predicted (the compensator: the reversion a strategy can harvest) and what it could not.
std::vector<double> forecast;
for (std::size_t t = 0; t + 1 < spread.size(); ++t)
forecast.push_back(0.8 * spread[t]);
const st::doob_parts parts = st::doob_decomposition(spread, forecast);
// Fade the spread: hold minus its last value. The P&L is the martingale transform.
std::vector<double> holding{0.0};
for (std::size_t t = 0; t + 1 < spread.size(); ++t)
holding.push_back(-spread[t]);
const std::vector<double> pnl = st::martingale_transform(holding, spread);
// Is the spread a martingale? Its increments have memory, so no.
std::vector<double> moves;
for (std::size_t t = 1; t < spread.size(); ++t)
moves.push_back(spread[t] - spread[t - 1]);
const st::test_result memory = st::ljung_box(moves, 5);

Relationships. stochastic/snell.hpp for optimal stopping; stats/bootstrap.hpp for the stationary bootstrap when the increments are dependent. Group: snicholls-core.

Guarantees. Each function is one pass, O(n); the decomposition, transform and quadratic variation are constexpr, usable inside a constant evaluation (variance_ratio_test: O(n q)). The variance ratio's z statistic and p-value match Python arch's VarianceRatio with its defaults (overlapping, debiased, robust).

Errors. None: sizes that do not match are precondition violations (asserted).

Performance. Not benchmarked.

Tests and demos. tests/stochastic/martingale_test.cpp, demos/stochastic/martingale_demo.cpp.

Dependencies. <cassert>, <cmath>, <cstddef>, <span>, <vector>, math/constexpr_math.hpp.

Known issues. Continuous time is the caller's to discretise.

Status. New in 0.5.0, experimental.
