Detailed Description

Compile-time permutations of positions and values: index_permutations, permutations, for_each_permutation.

Overview. Every ordering of N positions, or of R positions chosen from N, as a table computed at compile time, in lexicographic order of position. For permutations of types, use snicholls::meta::permutations_t.

// The table, built at compile time: the first row is the identity, the last is reversed.
constexpr auto orders = snicholls::index_permutations<3>();
static_assert(orders.size() == 6 && orders[5] == std::array<std::size_t, 3>{2, 1, 0});
// The same for values, and for 2 chosen from 3.
constexpr auto legs = snicholls::permutations(std::array{'A', 'B', 'C'});
constexpr auto pairs = snicholls::permutations<2>(std::array{'A', 'B', 'C'});
static_assert(legs[1] == std::array{'A', 'C', 'B'} && pairs[5] == std::array{'C', 'B'});
// Where a table would not fit: one row at a time, storing none.
std::size_t rows = 0;
snicholls::for_each_permutation<9>([&rows](const std::array<std::size_t, 9>&) { ++rows; });

Use for_each_permutation where a table would be too large: it visits the rows one at a time and stores none. Use std::next_permutation for a run-time sequence of unknown length.

Relationships. meta/type_list.hpp builds meta::permutations_t on the same walk; constexpr_for.hpp for other value loops. Group: snicholls-core.

Guarantees. Everything is constexpr and allocation-free. Rows are in lexicographic order of position, so the first is the identity. Asking for more positions than exist (R > N) gives no rows; R == 0 gives one empty row. These functions permute positions: equal values in permutations still give separate rows, so its row count is always permutation_count_v<N, R>. Complexity is proportional to the rows visited.

Errors. A count too large for std::size_t (above 20! on a 64-bit platform) is a compile error with a message, not a wrapped number.

Performance. Not benchmarked: the tables are built at compile time. for_each_permutation at run time costs a recursive call per position per row.

Tests and demos. tests/combinatorics/permutations_test.cpp, demos/combinatorics/permutations_demo.cpp.

Dependencies. <array>, <cstddef>, <limits>, <optional>, <type_traits>, <utility>.

Known issues. A compiler's constant-evaluation budget limits a table's size: see the figures in tests/combinatorics/permutations_test.cpp. Clang's default allows index_permutations<8> and MSVC's budget is smaller and is not measured here; raise it with -fconstexpr-steps or /constexpr:steps, or use for_each_permutation at run time, which has no such limit.

Status. New in 0.5.0.
