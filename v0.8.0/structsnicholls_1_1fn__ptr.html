Detailed Description

template<typename P>
struct snicholls::fn_ptr< P >

A function pointer as a callable class, so that it can be an element of an overload set.

overloaded{&f, g} and first_match{&f, g} wrap a pointer in this through their deduction guides; it is rarely named directly. The call has the pointer's exact signature, so it takes part in overload resolution exactly as the function would, and snicholls::invoke_any can read its parameter types. Defined for R(*)(Args...) and R(*)(Args...) noexcept; a C-variadic pointer is rejected with a message (wrap it in a lambda).
