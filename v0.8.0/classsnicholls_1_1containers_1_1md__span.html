Detailed Description

template<typename T, std::size_t Rank, typename Layout = layout_right>
class snicholls::containers::md_span< T, Rank, Layout >

A view of storage as a Rank-dimensional array whose extents are known at run time; std::mdspan in miniature.

Template Parameters
TThe element type (const for a read-only view).
RankThe number of dimensions.
Layoutlayout_right (row-major, the default), layout_left (column-major) or layout_stride.
