Detailed Description

snicholls::ml the gated delta rule (Gated DeltaNet, Qwen3-Next's and Kimi Linear's linear attention): the recurrent form, the chunked form through the WY / UT representation and a triangular solve, the backward pass, and one token at a time for decoding.

Overview. The delta rule writes into a linear attention's state only what the state does not already predict: S_t = S_{t-1}(I - β_t k_t k_tᵀ) + β_t v_t k_tᵀ (DeltaNet; Yang et al., 2024, arXiv 2406.06484, section 3.1), and Gated DeltaNet decays the state first, S_t = S_{t-1}(α_t (I - β_t k_t k_tᵀ)) + β_t v_t k_tᵀ (Yang, Kautz and Hatamizadeh, 2024, arXiv 2412.06464, eq. 10), o_t = S_t q_t. Here, per head h of P value channels in key group g (the state laid out N key rows of P), with the gate as its logarithm g_t = log α_t (one per head, Qwen3-Next's -exp(A_log) · softplus(a + dt_bias), or one per key channel, Kimi Delta Attention's) and the queries scaled by 1 / sqrt(N): 

S ← e^{g_t} S;   δ[p] = (v_t[p] - Σ_n S[n][p] k_t[n]) · β_t;   S[n][p] += k_t[n] δ[p];   o_t[p] = (Σ_n S[n][p] q_t[n]) · scale

which is llama.cpp's GGML_OP_GATED_DELTA_NET (commit 39039aa, ggml_compute_forward_gated_delta_net_one_chunk, with its per-channel gate for Kimi; tested against a transcription), the state transposed.

The chunked form is the WY representation with the UT transform (2406.06484 eqs. 8-11; with the gates, 2412.06464 section 3.3). Within a chunk of L tokens from the state S_0, with cumulative gates G_j = Σ_{i≤j} g_i (per channel), the recurrence unrolls to δ_j + β_j Σ_{i<j} A_{ji} δ_i = β_j (v_j - S_0ᵀ (e^{G_j} ⊙ k_j)) with A_{ji} = Σ_n k_j[n] k_i[n] e^{G_j[n] - G_i[n]}: a unit lower-triangular system (I + strictLower(diag(β) A)) [U | W] = diag(β) [V | e^{G} ⊙ K], solved with the backend's linalg::triangular_solve (the paper's T = (I + ...)⁻¹ diag(β), never formed), so Δ = U - W S_0. Then o_j = scale · ((e^{G_j} ⊙ q_j)ᵀ S_0 + Σ_{i≤j} (Σ_n q_j[n] k_i[n] e^{G_j[n] - G_i[n]}) Δ_i) and the state passed on is e^{G_last} ⊙ S_0 + Σ_i (e^{G_last - G_i} ⊙ k_i) Δ_iᵀ. Every exponent is of a difference that is not positive. It is the recurrence within rounding (tested in float and double).

// One head, 2 key channels, 2 value channels, chunks of 4
constexpr ml::transformer_config C = [] {
auto c = ml::tiny_gated_deltanet;
c.mixer_heads = c.mixer_groups = 1;
c.mixer_state = c.mixer_head_dim = 2;
c.hybrid_period = c.hybrid_attention_offset = 0;
return c;
}();
constexpr std::size_t n = 4, S = ml::delta_rule_state_size(C);
// Keys: (3, 4) normalised to (0.6, 0.8) at tokens 0 and 1; token 1 stores a new value under the same key with β = 1
std::array<double, n * 2> k{3, 4, 3, 4, 0, 0, 0, 0};
ml::l2_normalise_rows(backend, std::span<const double>(k), std::span<double>(k), 2, 1e-12);
const std::array<double, n * 2> q{0.6, 0.8, 0.6, 0.8, 0.6, 0.8, 0.6, 0.8}, v{1, 0, 0, 1, 0, 0, 0, 0};
const std::array<double, n> g{0, 0, 0, std::log(0.5)}, beta{1, 1, 0, 0}; // token 3 halves the memory
const ml::delta_rule_inputs<double> in{q, k, v, g, beta};
std::array<double, n * 2> o{}, o_chunked{};
std::array<double, S> s{}, s_chunked{};
std::array<double, ml::delta_rule_chunk_work(C)> work{};
ml::delta_rule_forward<C>(backend, in, std::span<double>(o), 1, std::span<double>(s));
ml::delta_rule_forward_chunked<C>(backend, in, std::span<double>(o_chunked), 1, std::span<double>(s_chunked), {}, std::span<double>(work));
// Decoding the next token (β = 0: read only)
const std::array<double, 2> q5{0.6, 0.8}, zero{0, 0};
const std::array<double, 1> g5{0}, b5{0};
std::array<double, 2> o5{};
ml::delta_rule_step<C>(ml::delta_rule_inputs<double>{q5, zero, zero, g5, b5}, std::span<double>(o5), std::span<double>(s));
// Training: the gradient of the last output's second channel in β at token 1
std::array<double, n * 2> dout{0, 0, 0, 0, 0, 0, 0, 1}, dq{}, dk{}, dv{};
std::array<double, n> dg{}, dbeta{};
std::array<double, ml::recurrence_checkpoints(n, C.mixer_chunk) * S> checkpoints{};
std::array<double, S> s0{}, dstate{};
ml::delta_rule_forward_chunked<C>(backend, in, std::span<double>(o_chunked), 1, std::span<double>(s0), std::span<double>(checkpoints),
std::span<double>(work));
std::array<double, ml::delta_rule_backward_work<C, double>()> bwork{};

std::span<const double>(checkpoints), std::span<double>(dstate), std::span<double>(bwork));

Relationships. ml/recurrence.hpp, ml/gla.hpp (the same chunking without the solve), ml/rwkv.hpp (RWKV-7 generalises the rule), ml/mixer_layer.hpp (Qwen3-Next's layer), linalg/backend.hpp (triangular_solve). Group: snicholls-core.

Implementations. The recurrent and chunked forms; one backward pass for both. Gates per head or per key channel, told apart by g's size.

Guarantees. constexpr (on a constexpr backend, as core's reference), no allocation, sums in a stated order (ggml's: the state's product with k and with q over n ascending). Decoding gives the recurrent forward's bits at every position (tested). Each row's input gradients are written.

Errors. Preconditions, asserted: q and k rows · G · N, v and o rows · H · P, g rows · H or rows · H · N, beta rows · H; work delta_rule_chunk_work(C). The unit lower-triangular solve cannot fail.

Performance. benchmarks/ml/delta_rule_benchmark.cpp, 256 tokens of 8 value heads of 64 sharing 4 key heads (Release, AppleClang 17, Intel Xeon W-3245, macOS, 2026-11-19): the recurrent form 4.27 ms, the loop by hand 4.20 ms (checked to the bit); the chunked WY form 109 ms, a reference for a device's kernel. BENCHMARKS.md has the current numbers.

Tests and demos. tests/ml/delta_rule_test.cpp, demos/ml/delta_rule_demo.cpp.

Dependencies. <array>, <cassert>, <cstddef>, <span>, <type_traits>, linalg/backend.hpp, math/constexpr_math.hpp, ml/recurrence.hpp, ml/transformer_config.hpp.

Known issues. The keys should be normalised (the rule is stable for β ‖k‖² ≤ 2); the layer does it.

Status. Experimental, new in 0.17.0.
