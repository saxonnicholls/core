Detailed Description

template<std::size_t Rate, std::uint8_t Pad, std::size_t DigestSize>
class snicholls::keccak_sponge< Rate, Pad, DigestSize >

A fixed-length Keccak sponge hash: the class behind sha3_224 ... sha3_512 and keccak256.

Template Parameters
RateThe rate in bytes (200 minus twice the digest size, for these).
PadThe domain padding byte: 0x06 for SHA-3, 0x01 for Keccak.
DigestSizeThe digest size in bytes.
