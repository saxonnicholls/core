Detailed Description

snicholls::asset_interface and snicholls::currency_interface: the virtual twins of asset_like and currency_like, and the adapters between them.

Overview. For code that chooses an asset at run time from many types, without templates: a list of every currency, a plug-in. asset_model<T> and currency_model<T> adapt any type modelling the concept; the interfaces model the concepts, so either form goes wherever the other is expected. to_asset(x) turns either into the value snicholls::asset.

std::vector<std::unique_ptr<asset_interface>> held;
held.push_back(std::make_unique<asset_model<native::ETH>>());
held.push_back(std::make_unique<asset_model<asset>>(*make_asset("USDC:56", 18)));
held.push_back(std::make_unique<currency_model<currency::AUD>>());

Relationships. concepts/asset.hpp, interfaces/named.hpp, interfaces/asset_conformance.hpp, money/asset.hpp. Group: snicholls-core.

Implementations. asset_model<T>, currency_model<T>.

Guarantees. Every member is noexcept; the adapters are usable in constant expressions when T is.

Errors. to_asset returns std::nullopt for an implementation whose code or scale is not a valid asset.

Performance. One virtual call per member; not benchmarked.

Tests and demos. tests/interfaces/asset_test.cpp, demos/interfaces/asset_demo.cpp.

Dependencies. <cstdint>, <optional>, <string_view>, concepts/asset.hpp, interfaces/named.hpp, money/asset.hpp.

Known issues. None.
