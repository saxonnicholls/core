Detailed Description

snicholls::chain_like and snicholls::evm_chain_like: a blockchain as a concept.

Overview. A chain answers:

  • name();
  • kind(), its family: EVM, Bitcoin, Solana, TRON;
  • native_asset(), an asset_like value of what its fees are paid in.

An EVM chain also answers chain_id(), its EIP-155 identifier. Chains change rarely and a recompile is cheap, so they are compile-time types (snicholls::chain::ethereum, chain::base, chain/chains.hpp). The concepts are written over object expressions, so the types, and any object behind the virtual twin chain_interface (interfaces/chain.hpp), model them.

static_assert(evm_chain_like<chain::base>);
static_assert(chain_like<chain::bitcoin> && !evm_chain_like<chain::bitcoin>);
