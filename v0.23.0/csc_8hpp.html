Detailed Description

snicholls::sparse::csc_view and csc_matrix: compressed sparse column matrices over the caller's storage, with assembly from triplets, products, transposes, scaling, norms and symmetric permutation, all constexpr.

Overview. Optimisation problems are large and sparse: a portfolio QP's constraint matrix has a few non-zeros per column, a KKT system a few per row. Compressed sparse column (CSC) storage keeps, for an m x n matrix with nnz stored entries, three arrays: col_ptr (n + 1 offsets), row_idx (nnz row indices, ascending within each column) and values (nnz numbers). It is the layout of SuiteSparse, OSQP, QDLDL, SCS and Clarabel.

  • csc_view<T, I>: dimensions plus three spans; T and I may be const for a read-only view. It owns nothing.
  • csc_matrix<T, Rows, Cols, MaxNnz, I>: the three arrays inside, sized at compile time, for problems whose structure is fixed when the program is written (and for building one in a constant expression); view().
  • Assembly: from_triplets (any order, duplicates summed), is_valid.
  • Products: spmv (y ← αAx + βy), spmv_transpose (y ← αAᵀx + βy), spmv_symmetric_upper (for a symmetric matrix stored as its upper triangle, the form of KKT matrices).
  • Structure: transpose, symmetric_permute_upper (P A Pᵀ of an upper-triangle symmetric matrix, for a fill-reducing ordering), to_dense.
  • Scaling and norms: scale (A ← diag(r) A diag(c)), column_inf_norms, row_inf_norms, symmetric_upper_inf_norms (equilibration needs them).

Indices are std::int32_t by default (as QDLDL's c_int); pass std::int64_t for more than 2³¹ entries. Working storage, where a function needs any, is a span the caller passes, so nothing allocates.

// A 3 x 4 constraint matrix from triplets in any order; the two (0, 1) entries are summed to 2
// [ 1 2 . . ]
// [ . . 3 . ]
// [ 4 . . 5 ]
const std::array<I, 6> ti{2, 0, 1, 0, 2, 0}, tj{3, 1, 2, 0, 0, 1};
const std::array<double, 6> tv{5, 1.5, 3, 1, 4, 0.5};
sp::csc_matrix<double, 3, 4, 6> a{};
auto av = a.view();
std::array<I, 4> work{};
const auto stored = sp::from_triplets(3, 4, std::span<const I>(ti), std::span<const I>(tj), std::span<const double>(tv), av, std::span<I>(work));
// stored == 5 entries, is_valid(a.view())
// y = A x and z = Aᵀ y
const std::array<double, 4> x{1, 1, 1, 1};
std::array<double, 3> y{};
std::array<double, 4> z{};
sp::spmv(std::as_const(a).view(), std::span<const double>(x), std::span<double>(y)); // (3, 3, 9)
sp::spmv_transpose(std::as_const(a).view(), std::span<const double>(y), std::span<double>(z)); // (39, 6, 9, 45)
// Aᵀ as a matrix of its own
sp::csc_matrix<double, 4, 3, 6> t{};
auto tview = t.view();
std::array<I, 3> twork{};
const bool transposed = sp::transpose(std::as_const(a).view(), tview, std::span<I>(twork)).is_ok();
// One step of Ruiz equilibration: divide every row and column by the square root of its largest magnitude
std::array<double, 3> rn{};
std::array<double, 4> cn{};
sp::row_inf_norms(std::as_const(a).view(), std::span<double>(rn)); // (2, 3, 5)
sp::column_inf_norms(std::as_const(a).view(), std::span<double>(cn)); // (4, 2, 3, 5)
std::array<double, 3> r{};
std::array<double, 4> c{};
for (std::size_t i = 0; i < 3; ++i)
r[i] = 1 / std::sqrt(rn[i]);
for (std::size_t j = 0; j < 4; ++j)
c[j] = 1 / std::sqrt(cn[j]);
sp::scale(a.view(), std::span<const double>(r), std::span<const double>(c));
// A symmetric 3 x 3 matrix as its upper triangle, its product, and P S Pᵀ for the order (2, 0, 1)
// [ 4 1 . ]
// [ 1 3 2 ]
// [ . 2 5 ]
const sp::csc_matrix<double, 3, 3, 5> s{{0, 1, 3, 5}, {0, 0, 1, 1, 2}, {4, 1, 3, 2, 5}};
const std::array<double, 3> u{1, 2, 3};
std::array<double, 3> su{};
sp::spmv_symmetric_upper(s.view(), std::span<const double>(u), std::span<double>(su)); // (6, 13, 19)
const std::array<I, 3> perm{2, 0, 1};
sp::csc_matrix<double, 3, 3, 5> ps{};
auto psv = ps.view();
std::array<I, 6> pwork{};
const bool permuted = sp::symmetric_permute_upper(s.view(), std::span<const I>(perm), psv, std::span<I>(pwork)).is_ok();
std::array<double, 9> dense{};
sp::to_dense(std::as_const(ps).view(), std::span<double>(dense)); // upper triangle of [5 . 2; . 4 1; 2 1 3]

Relationships. sparse/ordering.hpp (AMD), sparse/ldl.hpp (the factorisation), linalg/krylov.hpp (iterative solvers over these products), optim/scaling.hpp (equilibration), linalg/ (dense). Group: snicholls-core.

Guarantees. constexpr, noexcept for arithmetic T and integer I, no allocation, no recursion. Every function that writes a matrix writes row indices ascending within each column, without duplicates. Products are O(nnz); from_triplets, transpose and symmetric_permute_upper are O(nnz + n).

Errors. sparse_error::insufficient_capacity: an output's spans are too short. sparse_error::invalid_index: a triplet's or permutation's index is out of range. sparse_error::dimension_mismatch: shapes that do not fit.

Performance. Not yet benchmarked.

Tests and demos. tests/sparse/csc_test.cpp, demos/sparse/csc_demo.cpp.

Dependencies. <array>, <concepts>, <cstddef>, <cstdint>, <span>, result.hpp.

Known issues. Values of explicitly stored zeros are kept (a structural non-zero may be numerically zero); pattern-reusing factorisations rely on it.

Status. Experimental, new in 0.21.0.
