Detailed Description

snicholls::metric::levenshtein<MaxLength>: the edit distance between two sequences, allocation-free.

Overview. The minimum number of single-element insertions, deletions and substitutions that turn one sequence into another: names that differ by a typo, call signs, token sequences. levenshtein<MaxLength>{}(a, b) works on any two points whose elements compare with ==: std::string_views, std::arrays, std::spans, std::vectors of characters, integers or categories, mixed. Its one row of working storage is an std::array of MaxLength + 1 counts, so it never allocates. A sequence longer than MaxLength gives the largest std::size_t rather than a wrong answer.

// The closest known call sign to one received with a typo; the working row is sized at compile time
constexpr me::levenshtein<16> edit{};
const std::array known{"SPEEDBIRD"sv, "SHAMROCK"sv, "SPEEDWAY"sv, "SPRINGBOK"sv};
const std::string_view received = "SPEEDBRID";
std::size_t best = 0;
for (std::size_t i = 1; i < known.size(); ++i)
if (edit(received, known[i]) < edit(received, known[best]))
best = i;
// Any two sequences whose elements compare: token ids in a vector against a span, characters against an array
const std::vector<int> sentence{7, 3, 9, 9, 2};
const std::array<int, 4> other{7, 9, 9, 4};
const std::size_t tokens = edit(sentence, std::span<const int>(other));
const std::size_t mixed = edit("kitten"sv, std::array<char, 7>{'s', 'i', 't', 't', 'i', 'n', 'g'});

Relationships. metric/concepts.hpp, metric/binary.hpp (mismatches: substitutions only, equal lengths). Group: snicholls-core.

Implementations. The Wagner-Fischer recurrence over one row, the shorter sequence along it: O(m n) time, O(min(m, n)) space.

Guarantees. constexpr, noexcept when the element reads and comparisons are, no allocation. A metric: zero only for equal sequences, symmetric, and obeying the triangle inequality.

Errors. None; the largest std::size_t for a sequence beyond MaxLength (both longer is fine as long as the shorter fits).

Performance. Not benchmarked.

Tests and demos. tests/metric/string_test.cpp, demos/metric/string_demo.cpp.

Dependencies. <array>, <cstddef>, <limits>, metric/concepts.hpp.

Known issues. Elements are compared as code units: two encodings of one character differ.

Status. Experimental, new in 0.20.0.
