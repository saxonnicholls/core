Detailed Description

snicholls::ml Mamba-2's selective state space (SSD): the recurrent scan, the chunked form (quadratic within a chunk, the state passed between chunks), the backward pass, and one token at a time for decoding.

Overview. Mamba-2 (Dao and Gu, 2024, "Transformers are SSMs", section 2.4 and eqs. 2a-2b) restricts the state transition of a selective SSM to a scalar per head and time, h_t = a_t h_{t-1} + B_t x_t, y_t = C_tᵀ h_t, with a_t = exp(Δ_t A) (Mamba's discretisation, section 2.1 remark 1). Per head h of P channels, in group g = h / (H / G) whose B and C it shares (section 7.2, grouped-value attention), with the state S of N rows of P (state-space duality's keys by values): 

S_t[n][p] = exp(dt_t A) · S_{t-1}[n][p] + B_t[n] · (x_t[p] · dt_t),     y_t[p] = Σ_n C_t[n] · S_t[n][p]

which is llama.cpp's GGML_OP_SSM_SCAN for a scalar A (commit 39039aa, ggml_compute_forward_ssm_scan_f32, the same products in the same order; tested against a transcription of it), except that dt arrives here already positive (the layer applies softplus(dt + dt_bias), which ggml does inside the op) and the state is laid out [n][p] rather than [p][n].

The chunked form is the paper's SSD algorithm (section 6, its listing ssd): within a chunk of L tokens with cumulative log-decays a_j = Σ_{i≤j} dt_i A, y_j = Σ_{i≤j} (C_j · B_i) exp(a_j - a_i) dt_i x_i + exp(a_j) C_jᵀ S_prev (the diagonal block and the left factor), and the state passed on is exp(a_last) S_prev + Σ_i exp(a_last - a_i) dt_i B_i x_iᵀ (the right and centre factors). It gives the recurrence's result within rounding: relative L · ε in the exponents' sums (tested in float and double).

  • ssd_forward<C>(backend, in, y, sequences, states, checkpoints): the scan, recurrence_forward over ssd_step's arithmetic.
  • ssd_forward_chunked<C>(backend, in, y, sequences, states, checkpoints): the chunked form, the same checkpoints.
  • ssd_backward<C>(backend, in, dy, grads, sequences, checkpoints, dstates, work): backpropagation through time from either forward pass's checkpoints (ml/recurrence.hpp).
  • ssd_step<C>(in, y, state): one token for decoding, with the fixed-size state ssd_state_size(C).
// tiny_mamba2: 2 heads of 4 channels sharing one group of 4 state channels, chunks of 4
constexpr ml::transformer_config C = ml::tiny_mamba2;
constexpr std::size_t n = 10, H = C.mixer_heads, P = C.mixer_head_dim, N = C.mixer_state;
std::array<double, n * H * P> x{};
std::array<double, n * H> dt{};
std::array<double, n * N> b{}, c{};
const std::array<double, H> a{-0.5, -2.0}; // A: the second head forgets faster
for (std::size_t t = 0; t < n; ++t) {
for (std::size_t i = 0; i < H * P; ++i)
x[t * H * P + i] = std::sin(0.3 * static_cast<double>(t + i));
for (std::size_t h = 0; h < H; ++h)
dt[t * H + h] = 0.1 + 0.05 * static_cast<double>(h + t % 3);
for (std::size_t i = 0; i < N; ++i) {
b[t * N + i] = std::cos(0.2 * static_cast<double>(t * N + i));
c[t * N + i] = std::sin(0.7 * static_cast<double>(t + i));
}
}
const ml::ssd_inputs<double> in{x, dt, a, b, c};
// The scan and the chunked form (training's), each from a zero state, each saving the state at every chunk's start
constexpr std::size_t S = ml::ssd_state_size(C), chunks = ml::recurrence_checkpoints(n, C.mixer_chunk);
std::array<double, n * H * P> y_scan{}, y_chunked{};
std::array<double, S> state_scan{}, state_chunked{};
std::array<double, chunks * S> checkpoints{};
ml::ssd_forward<C>(backend, in, std::span<double>(y_scan), 1, std::span<double>(state_scan));
ml::ssd_forward_chunked<C>(backend, in, std::span<double>(y_chunked), 1, std::span<double>(state_chunked), std::span<double>(checkpoints));
// Decoding: one token at a time, the same S numbers whatever the length
std::array<double, S> state{};
std::array<double, H * P> y_t{};
for (std::size_t t = 0; t < n; ++t)
ml::ssd_step<C>(ml::ssd_inputs<double>{std::span<const double>(x).subspan(t * H * P, H * P), std::span<const double>(dt).subspan(t * H, H), a,
std::span<const double>(b).subspan(t * N, N), std::span<const double>(c).subspan(t * N, N)},
std::span<double>(y_t), std::span<double>(state));
// Training: the gradient of Σ y in every input, from the chunked form's checkpoints
std::array<double, n * H * P> dy{}, dx{};
dy.fill(1.0);
std::array<double, n * H> ddt{};
std::array<double, H> da{};
std::array<double, n * N> db{}, dc{};
std::array<double, S> dstate{};
std::array<double, ml::ssd_backward_work<C, double>()> work{};
ml::ssd_backward<C>(backend, in, std::span<const double>(dy), ml::ssd_gradients<double>{dx, ddt, da, db, dc}, 1,
std::span<const double>(checkpoints), std::span<double>(dstate), std::span<double>(work));

Relationships. ml/recurrence.hpp (the driver), ml/mixer_layer.hpp (the Mamba-2 layer: projections, the short convolution, softplus, the D skip, the gate and the grouped norm), ml/transformer_config.hpp (H is mixer_heads, P mixer_head_dim, N mixer_state, G mixer_groups, L mixer_chunk). Group: snicholls-core.

Implementations. The scan and the chunked form; one backward pass for both.

Guarantees. constexpr, no allocation (the chunk's cumulative decays are a fixed-size array of L), every sum in a stated order: the scan's y over n ascending, the chunked form's diagonal block over i ascending then the inter-chunk term. Decoding with ssd_step gives ssd_forward's bits at every position (tested). The gradients in the inputs of each row are written; grads.a is added into.

Errors. Preconditions, asserted, as ml/recurrence.hpp's and the views' sizes (rows · H · P for x and y, rows · H for dt, H for a, rows · G · N for b and c).

Performance. benchmarks/ml/ssd_benchmark.cpp, 256 tokens of 8 heads of 64 by 64 (Release, AppleClang 17, Intel Xeon W-3245, macOS, 2026-11-19): the scan 1.96 ms, the loop by hand 1.96 ms (the same arithmetic in the same order, checked to the bit); the chunked form 56.7 ms, a reference written for clarity (every decay an exp of its own), whose worth is its parallel shape on a device. BENCHMARKS.md has the current numbers.

Tests and demos. tests/ml/ssd_test.cpp, demos/ml/ssd_demo.cpp.

Dependencies. <array>, <cassert>, <cstddef>, <span>, <type_traits>, math/constexpr_math.hpp, ml/recurrence.hpp, ml/transformer_config.hpp.

Known issues. The chunked form here is the reference, a token's row at a time: a device runs it as batched products over chunks (and its backward pass chunked) and checks against this.

Status. Experimental, new in 0.17.0.
