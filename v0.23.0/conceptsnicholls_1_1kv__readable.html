Detailed Description

The read operations: read, contains, scan, sequence, on a const store, returning result.

  • s.read(key, fn) -> result<bool, kv_errc>: calls fn(value) and answers true, or false without calling.
  • s.contains(key) -> result<bool, kv_errc>.
  • s.scan(range, fn) -> result<std::size_t, kv_errc>: fn(key, value) in ascending key order until it answers false; the count of entries passed to fn, the one that stopped it included.
  • s.sequence() -> result<std::uint64_t, kv_errc>: see the file's guarantees.
