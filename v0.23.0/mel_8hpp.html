Detailed Description

snicholls::signal audio front ends: the mel scales (HTK and Slaney), mel filterbanks as librosa and torchaudio build them, mel spectrograms, log compression (decibels, Whisper's), OpenAI Whisper's log-mel spectrogram, MFCCs, and the backward passes.

Overview.

  • hz_to_mel / mel_to_hz with mel_scale::htk (2595 log10(1 + f / 700)) or mel_scale::slaney (linear below 1 kHz at 3 mels per 200 Hz, logarithmic above at 27 mels per factor of 6.4: librosa's default and the Auditory Toolbox's).
  • mel_filterbank(options, out): the n_mels x (n_fft / 2 + 1) triangular filters of librosa.filters.mel, with the same arithmetic (linspace in mels, rfftfreq, the ramps, and Slaney's area normalisation 2 / (f_{m+2}
    • f_m)
    ), so float filters match librosa's float32 ones within one unit in the last place. torchaudio's melscale_fbanks is the transpose of the same matrix for an even sample rate (with mel_scale::htk and mel_norm::none, its defaults). make_mel_filterbank<T, Mels, NFft>(...) returns a std::array, a compile-time table when it is constexpr.
  • mel_spectrogram(filters, power, out) applies the filters to each frame of a power spectrogram (frame-major); mel_backward is its transpose.
  • log_compress(in, out, c): y = scale (multiplier log10(max(x, floor)) floored at (max - range) + offset), the maximum taken over the whole array. decibels(top_db) is librosa's power_to_db (10 log10, amin 1e-10, top_db 80); whisper_compression is Whisper's (log10, clamp 1e-10, floor at max - 8, (x + 4) / 4). log_compress_backward is its gradient.
  • whisper_log_mel: OpenAI Whisper's log_mel_spectrogram (whisper/audio.py): padding zeros appended, a centred, reflect-padded STFT with a periodic Hann window of 400 points and a hop of 160, the last frame dropped, |X|^2, the mel filters of librosa.filters.mel(sr=16000, n_fft=400, n_mels=80 or 128) (Slaney scale and normalisation), and whisper_compression. The output is mel-major, n_mels x frames, as Whisper's tensor; a 30-second chunk (480,000 samples) gives 3,000 frames. whisper_log_mel_backward is its gradient with respect to the audio, each frame's spectrum recomputed rather than stored.
  • mfcc: librosa's MFCCs, the orthonormal DCT-II of each frame of a log-mel spectrogram (decibels), its first n_mfcc coefficients.
// The scales: 1 kHz is 15 Slaney mels and about 1000 HTK mels.
static_assert(m::near(s::hz_to_mel(1000.0), 15.0, 1e-13) && m::near(s::hz_to_mel(1000.0, s::mel_scale::htk), 1000.0, 0.02));
// librosa.filters.mel(sr=16000, n_fft=512, n_mels=40), computed by the compiler.
constexpr auto filters = s::make_mel_filterbank<double, 40, 512>(16000.0);
// A power spectrogram (here 2 frames of 257 bins of white noise, power 1) to mel bands, decibels and MFCCs.
const std::vector<double> power(2 * 257, 1.0);
std::vector<double> mel(2 * 40), db(2 * 40), coefficients(2 * 13);
s::mel_spectrogram<double>(filters, 40, power, mel);
s::log_compress<double>(mel, db, s::decibels<double>()); // librosa's power_to_db, top_db 80
std::vector<cd> st(s::fft_plan<double>::storage_size(40));
const s::fft_plan<double> dct_plan(40, st);
std::vector<cd> work(s::dct_work_size(dct_plan));
s::mfcc(dct_plan, std::span<const double>(db), std::span<double>(coefficients), 13, std::span<cd>(work));
// Whisper's front end on a tenth of a second of a 1 kHz tone: 80 mels x 10 frames, mel-major as Whisper's tensor.
std::vector<float> audio(1600);
for (std::size_t i = 0; i < audio.size(); ++i)
audio[i] = static_cast<float>(0.5 * m::sin(2 * m::pi * 1000.0 * static_cast<double>(i) / 16000.0));
static constexpr auto window = s::whisper_window<float>(); // torch.hann_window(400)
static constexpr auto mel80 = s::whisper_mel_filters<float, 80>(); // whisper's mel_filters.npz, by the compiler
std::vector<s::complex<float>> rst(s::rfft_plan<float>::storage_size(s::whisper_n_fft));
const s::rfft_plan<float> plan(s::whisper_n_fft, rst);
std::vector<s::complex<float>> wwork(s::whisper_work_size(plan));
const std::size_t frames = s::whisper_frames(audio.size()); // 10
std::vector<float> log_mel(80 * frames);
s::whisper_log_mel(plan, std::span<const float>(window), std::span<const float>(mel80), 80, std::span<const float>(audio), 0,
std::span<float>(log_mel), std::span<s::complex<float>>(wwork));

Relationships. signal/stft.hpp (spectrograms), signal/window.hpp (the Hann window), signal/dct.hpp (MFCCs). Group: snicholls-core.

Implementations. One each; Whisper's front end is fixed by Whisper's constants.

Guarantees. constexpr; no allocation (work buffers from the caller: whisper_work_size(plan) complex elements). Filterbanks are computed in compute_t<T> (double for float, as librosa computes in float64) and rounded as librosa rounds. Complexity: a filterbank is n_mels x bins; a mel spectrogram frames x n_mels x bins.

Errors. Preconditions, asserted: sizes agree; f_min < f_max <= sample_rate / 2 is not checked (librosa warns of empty filters; so do the values). The audio given to whisper_log_mel must be longer than 200 samples after padding (reflection, as PyTorch requires).

Performance. Not benchmarked separately; the STFT dominates.

Tests and demos. tests/signal/mel_test.cpp: the scales, the filterbanks of Whisper's 80 and 128 mels and an HTK bank against librosa 0.11.0's (fixtures in tests/fixtures/signal/), Whisper's log-mel against an independent float64 implementation of whisper/audio.py in numpy 2.0.2, MFCCs against librosa's, a filterbank and a log-mel at compile time, every backward pass by central differences. demos/signal/mel_demo.cpp.

Dependencies. <array>, <cassert>, <cstddef>, <span>, <type_traits>, signal/dct.hpp, signal/stft.hpp, signal/window.hpp.

Known issues. PyTorch splits the gradient of max(y, max(y) - range) evenly at a tie and so does log_compress_backward for the global maximum; at an exact tie between a value and the floor the value takes it all. Whisper's own STFT runs in float32 in PyTorch's FFT; whisper_log_mel<float> agrees with it to rounding, not to the bit.

Status. Experimental, new in 0.17.0.
