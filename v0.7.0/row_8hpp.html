Detailed Description

snicholls::ml::row and mutable_row: what the ml functions accept as a row of numbers, and the spans they work on.

Overview. A row is any contiguous, sized range of a math::math_number: std::vector<float>, std::array<double, N>, std::span<const float>, a C array, a row of an md_span. The ml functions take rows as they are, so a caller never writes std::span<const float>(v) to call them; inside, each works on the std::span that as_row or as_mutable_row gives, which costs nothing.

// A function over rows takes any contiguous range of numbers and works on a span inside.
template <snicholls::ml::row R>
constexpr auto total(const R& r)
{
snicholls::ml::row_value_t<R> s{};
for (const auto x : snicholls::ml::as_row(r))
s += x;
return s;
}
template <snicholls::ml::mutable_row R>
constexpr void scale(R&& r, snicholls::ml::row_value_t<R> by)
{
for (auto& x : snicholls::ml::as_mutable_row(r))
x *= by;
}
