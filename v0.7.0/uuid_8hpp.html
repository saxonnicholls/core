Detailed Description

snicholls::uuid: an RFC 9562 UUID value.

snicholls::uuid - an RFC 9562 UUID: exactly 16 bytes in network (big-endian) order, nothing else.

snicholls::uuid id = make_uuid(); // v7: a generator needs OS randomness and lives in the consumer
snicholls::to_text(id).view(); // "0190a5c4-7e1b-7c3a-9f12-3b4c5d6e7f80", no allocation
snicholls::to_string(id); std::cout << id; // the same text, allocating / streaming
snicholls::parse_uuid("0190A5C4-7E1B-7C3A-9F12-3B4C5D6E7F80"); // std::optional<uuid> (hex is case-insensitive)
snicholls::parse_uuid("{0190a5c4-...}", snicholls::uuid_parse_options::lenient()); // braces, urn:uuid:, 32 hex digits
using namespace snicholls::literals; constexpr auto ns = "6ba7b810-9dad-11d1-80b4-00c04fd430c8"_uuid;
id.version(); id.variant(); id.timestamp(); id.is_nil(); snicholls::uuid::max();
snicholls::make_uuid_v5(snicholls::uuid_namespace::dns, "www.example.com"); // name-based, deterministic, constexpr

Semantics:

  • An aggregate holding std::array<std::uint8_t, 16>: sizeof 16, alignof 1 (adds no padding to an object), trivially copyable, standard layout, structural (usable as a template argument). Value-initialised = nil.
  • Every 128-bit value is a valid snicholls::uuid (nil, max, any version or variant); generators and composers set the version and variant bits, the value type never checks them.
  • == and <=> are constexpr and compare the bytes in order (strong_ordering): the RFC 9562 sort order, so v7 UUIDs sort by creation time. std::hash<snicholls::uuid> is constexpr and noexcept (not portable, like every std::hash).
  • Text is the canonical 8-4-4-4-12 form, lowercase on output. Input hex is case-insensitive (RFC 9562 §4); braces, the urn:uuid: prefix and the 32-digit form are accepted only when asked for (uuid_parse_options). Text I/O is to_chars / from_chars style: no allocation, no locale, no exceptions, constexpr.
