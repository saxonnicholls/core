Detailed Description

snicholls::member_count_v<S>: the member count of a plain aggregate struct.

Member count of a plain aggregate struct, detected at compile time (no N at call sites).

Technique (as Boost.PFR): find the largest N for which S{x0, ..., xN-1} is valid, where each x converts to any member type. Binary search, so cost is logarithmic in SNICHOLLS_MAX_STRUCT_MEMBERS.

Supported members: values of any type, including move-only (unique_ptr), const, std::optional, std::any, std::variant, nested aggregates and std::array. Not supported: reference members (rejected with a clear error), C-array members (miscounted via brace elision - use std::array), bit-fields (cannot be bound by reference), and aggregates with base classes or unions.
