Detailed Description

snicholls::ml normalisation: layer_norm and rms_norm over one row, forward and backward, with or without learned parameters.

Overview. The per-token normalisations of a transformer. Each works on one row of C channels; a batch is a loop over rows, which a caller spreads across threads (each row is independent).

  • layer_norm(x, weight, bias, out, eps): out = (x - mean) · rstd · weight + bias, with rstd = 1 / sqrt(var + eps) and the biased variance, as GPT-2 and PyTorch compute it. The mean is subtracted before squaring (two passes), so a row with a large mean keeps its variance's digits. Returns the mean and rstd, which the backward pass needs.
  • rms_norm(x, weight, out, eps): out = x · rstd · weight, rstd = 1 / sqrt(mean(x²) + eps) (LLaMA, nanochat). Returns rstd.
  • Empty weight and bias mean none: nanochat's RMSNorm has no parameters.
  • The backward passes write dx and add into dweight and dbias, which sum over the rows of a batch.
// One token of four channels through LayerNorm with a learned weight and bias (GPT-2).
const std::array<float, 4> x{1.0f, 2.0f, 4.0f, 9.0f};
const std::array<float, 4> weight{1.0f, 0.5f, 2.0f, 1.0f}, bias{0.0f, 0.1f, 0.0f, -0.1f};
std::array<float, 4> y{};
const ml::norm_stats<float> stats = ml::layer_norm(x, weight, bias, y);
// The backward pass: dx is written, dweight and dbias add up over the rows of a batch.
const std::array<float, 4> dy{0.1f, -0.2f, 0.3f, 0.0f};
std::array<float, 4> dx{}, dweight{}, dbias{};
ml::layer_norm_backward(dy, x, weight, stats, dx, dweight, dbias);
// A batch of three rows through RMSNorm with no parameters (nanochat), in place.
std::vector<float> batch{3.0f, 4.0f, -6.0f, 8.0f, 0.5f, 0.5f};
std::vector<float> rstd;
for (std::size_t r = 0; r < 3; ++r) {
const std::span<float> row(batch.data() + 2 * r, 2);
rstd.push_back(ml::rms_norm(row, std::span<const float>{}, row));
}
// And RMSNorm's backward pass, for one row with a weight.
const std::array<float, 2> v{3.0f, 4.0f}, g{1.0f, 1.0f}, scale{2.0f, 1.0f};
std::array<float, 2> out{}, dv{}, dscale{};
const float r = ml::rms_norm(v, scale, out);
ml::rms_norm_backward(g, v, scale, r, dv, dscale);

Relationships. ml/row.hpp (the rows), ml/activations.hpp. Group: snicholls-core.

Implementations. One each.

Guarantees. constexpr, no allocation, linear in the row. out and dx may be the input row. norm_stats is trivially copyable.

Errors. Preconditions, asserted: every row has x's size, or (weight, bias, dweight, dbias) is empty. An empty x is a no-op that returns rstd 1/sqrt(eps).

Performance. Benchmarked against the same loops written by hand (benchmarks/ml/norm_benchmark.cpp).

Tests and demos. tests/ml/norm_test.cpp, demos/ml/norm_demo.cpp.

Dependencies. <cassert>, <concepts>, <cstddef>, <limits>, <span>, <type_traits>, snicholls/core/math/constexpr_math.hpp, ml/row.hpp.

Known issues. Sums accumulate in the row's type, as llm.c does in float.

Status. Experimental, new in 0.6.0.

The backward pass of layer_norm: writes dx, adds into dweight and dbias.

With n = (x - mean) · rstd and g = weight · dout: dx = rstd · (g - mean(g) - n · mean(g · n)), dweight += dout · n, dbias += dout.
