Detailed Description

snicholls::ml training arithmetic: the AdamW step, learning-rate schedules, clipping by the global norm, Muon's Newton-Schulz polynomial, and the FLOPs and utilisation of a transformer.

Overview. The per-element and per-step arithmetic of training, as llm.c and nanochat do it. Each is a pure function or an elementwise loop over the caller's rows, so a tensor is updated in shards by as many workers as it has, and a step is the same wherever it runs.

  • adamw_step(params, grads, m, v, step, config): one AdamW update (Loshchilov and Hutter), with bias correction and decoupled weight decay, exactly llm.c's adamw_update. step counts from 1.
  • warmup_cosine(step, warmup, total, max_lr, min_lr): linear warm-up then cosine decay (llm.c, GPT-2).
  • warmup_warmdown(step, total, warmup, warmdown, final_fraction): the multiplier of nanochat: linear warm-up, a constant, then linear decay to final_fraction (the "trapezoid" schedule).
  • squared_norm(row) and clip_coefficient(norm, max_norm): clipping by the global norm, as PyTorch's clip_grad_norm_. Each worker sums the squares of its shard, the sums add (the merge), and every gradient is multiplied by the coefficient.
  • muon_newton_schulz<T> and newton_schulz_polynomial(x): the quintic Muon iterates on each singular value (Jordan et al., nanochat's optimiser), a x + b x³ + c x⁵ with (a, b, c) = (3.4445, -4.7750, 2.0315). The matrix iteration, X ← a X + (b A + c A²) X with A = X Xᵀ, belongs with the matrices, above core.
  • transformer_flops_per_token(...) and model_flops_utilisation(...): 6N + 12·L·H·Q·T (PaLM's appendix, llm.c, nanochat) and the fraction of the hardware's peak a run achieves.
// Fit y = 2x - 1 from four points: two parameters, their gradients, and AdamW's two moments
const std::array<float, 4> xs{0.0f, 1.0f, 2.0f, 3.0f}, ys{-1.0f, 1.0f, 3.0f, 5.0f};
std::array<float, 2> w{0.0f, 0.0f}, grad{}, m{}, v{};
constexpr std::uint64_t steps = 3000, warmup = 100;
for (std::uint64_t t = 0; t < steps; ++t) {
grad = {};
for (std::size_t i = 0; i < 4; ++i) {
const float e = w[0] * xs[i] + w[1] - ys[i];
grad[0] += 0.5f * e * xs[i];
grad[1] += 0.5f * e;
}
// Clip by the global norm (one shard here; shards' squared norms add), then step at the scheduled rate
const float clip = ml::clip_coefficient(std::sqrt(ml::squared_norm(grad)), 1.0f);
for (float& g : grad)
g *= clip;
const float lr = ml::warmup_cosine<float>(t, warmup, steps, 0.05f, 0.0f);
ml::adamw_step(w, grad, m, v, t + 1, {.learning_rate = lr, .beta2 = 0.95f});
}

Relationships. ml/minifloat.hpp (to_minifloat_stochastic, for bfloat16 master weights), ml/row.hpp. Group: snicholls-core.

Implementations. One each.

Guarantees. constexpr, no allocation, linear in the rows. adamw_config is trivially copyable.

Errors. Preconditions, asserted: the rows of adamw_step have one size; step is at least 1; warmup and warmdown fit in total. clip_coefficient is 1 at or below max_norm, and 1 for a NaN norm: a NaN gradient is the caller's to catch.

Performance. adamw_step against llm.c's loop written by hand (benchmarks/ml/optim_benchmark.cpp), 1M float parameters: level, 860 million parameters per second (Xeon W-3245, Release, Apple clang 17, 2026-11-11, one thread). The schedules and the polynomial are a few operations each and not benchmarked.

Tests and demos. tests/ml/optim_test.cpp, demos/ml/optim_demo.cpp.

Dependencies. <cassert>, <concepts>, <cstddef>, <cstdint>, <numbers>, snicholls/core/math/constexpr_math.hpp, ml/row.hpp.

Known issues. The moments accumulate in the row's type, as llm.c's do in float.

Status. Experimental, new in 0.7.0.

One AdamW step over a row of parameters: updates params, m and v in place.

m = β1 m + (1 - β1) g, v = β2 v + (1 - β2) g², then p -= lr · (m / (1 - β1^t) / (sqrt(v / (1 - β2^t)) + eps) + wd · p).

Parameters

mThe first moments, zero before the first step.

Iterated steps times from a singular value in (0, 1] (the matrix is first divided by its norm), it lands near 1, roughly in [0.7, 1.2]: Muon's approximate orthogonalisation, traded for speed against exactness.
