inlineconstexprnoexcept

The unnormalised inverse real transform of the half spectrum in(k), k <= n / 2, each sample handed to out(j, x_j): the building block of irfft.

Only the real parts of bin 0 and (for even n) bin n / 2 are read. The result is n times numpy's irfft.

Template Parameters
InA callable complex<T>(std::size_t).
OutA callable void(std::size_t, T).
