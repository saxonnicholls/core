Detailed Description

The pushdown stacks of a grammar over the text accepted so far, and the token mask that follows from them.

Each stack is a list of element indices whose top is a terminal; an empty stack means the text so far is a complete sentence. The matcher holds a grammar_view: the grammar must outlive it.
