Detailed Description

snicholls::run_role_store_conformance: the conformance kit of the role_store contract.

Overview. Drives any role_store, in either form, through the contract of concepts/role_store.hpp and reports which check failed (interfaces/capability_conformance.hpp). The probe is a default-constructible type, empty when made, with

  • auto& store(): the implementation (a store, a role_store_interface&, a role_store_ref);
  • void provider_fails(capability_errc code, std::string_view response): the next call fails with code, as though the database behind it had answered response.

The checks: a grant is active in its tenant only, an expired grant is inactive, a regrant replaces the grant and appends an event, revoking what is not there is not found and appends nothing, history records the actor, the reason and the confirmation in order, a provider failure never leaks its response.

const capability_conformance_report report = run_role_store_conformance<probe>();

Relationships. concepts/role_store.hpp, interfaces/role_store.hpp, interfaces/capability_conformance.hpp. Group: snicholls-core.

Implementations / variants. One kit for every form.

Guarantees. As interfaces/capability_conformance.hpp: no exception escapes a check.

Errors. Failures are data.

Performance. Not benchmarked: a test kit.

Tests and demos. tests/interfaces/role_store_conformance_test.cpp, demos/interfaces/role_store_conformance_demo.cpp.
