Detailed Description

ISO 4217: every currency as a type (snicholls::currency::AUD) and as a constexpr table, from the lists SIX publishes, with the countries using it, and CLDR's cash rounding and symbol.

Overview. ISO 4217 codes are immutable, so they are compiled in. Each code is a type in snicholls::currency, named by the code itself (AUD, EUR, XAU). Capitals are kept deliberately, so that the name is the code (lowercase would make TRY, the Turkish lira, the keyword try). Each type has static constexpr member functions:

  • code(), name() and numeric();
  • scale(), the ISO minor units, where ISO gives them;
  • withdrawn(), for a historic code;
  • countries(), for a current code: the ISO 3166-1 alpha-2 codes of the countries using it, from SIX's list one (the entities of list one that are not countries, such as EUROPEAN UNION, are left out), sorted;
  • cash_scale() and cash_rounding(), where Unicode CLDR gives a cash rule: a cash amount is a multiple of cash_rounding() x 10^-cash_scale() (CHF 5 x 10^-2 = 0.05, DKK 0.50, SEK whole kronor).

The display symbol is presentation, so it is not a member: each type declares attributes() (found by ADL, meta/attributes.hpp) with a label holding CLDR's root-locale symbol ("A$", "€", "JP¥", "US$"; the code where CLDR gives none) and, where ISO gives a scale, minor_units. Every printer that reads attributes shows it: attribute_or(currency::AUD{}, label{""}).text is "A$".

static_assert(currency::CHF::cash_scale() == 2 && currency::CHF::cash_rounding() == 5); // cash: 0.05
static_assert(currency::CHF::countries()[1] == "LI"); // CH and LI
constexpr std::string_view symbol = attribute_or(currency::AUD{}, label{""}).text; // "A$", by ADL

A type with a scale models currency_like and asset_like, so asset_v<currency::AUD> and money_of<currency::AUD> work. The same data is a sorted table for codes that arrive at run time: find_iso4217("AUD"), find_iso4217(36), iso4217_asset("AUD"). The literal "AUD"_iso4217 is checked by the compiler.

The table is generated by scripts/generate_iso4217.py from SIX's list one (current currencies and funds) and list three (historic denominations), committed unmodified under scripts/data/iso4217/. The publication date of list one is iso4217_published. A historic code (ANG, withdrawn 2025-03) still resolves, so old books do. The countries come through the curated scripts/data/iso4217/entities.tsv, which maps each entity of list one to its alpha-2; cash rules and symbols from the subset of CLDR under scripts/data/cldr/ (release iso4217_cldr_version, the Unicode licence). The table's rows carry the same: countries, symbol, cash_scale (-1 where CLDR gives no cash rule) and cash_rounding.

constexpr asset aud = "AUD"_iso4217; // a compile error for an unknown code
static_assert(currency::AUD::numeric() == 36);
const iso4217_entry* jpy = find_iso4217("JPY"); // a code that arrives at run time
const iso4217_entry* by_number = find_iso4217(std::uint16_t{978});

Relationships. money/asset.hpp, concepts/asset.hpp, money/money.hpp, money/native.hpp (chain assets, which are not ISO), country.hpp (whose currencies() are the inverse of countries(), funds left out), display.hpp (label, minor_units). Group: snicholls-core.

Implementations. One generated type per code, and the generated table.

Guarantees.

  • constexpr, noexcept, no allocation.
  • The table is sorted by alphabetic code. A code in both lists keeps list one's entry.
  • A code withdrawn more than once keeps its latest withdrawal.

Errors.

  • find_iso4217 returns nullptr for an unknown code.
  • iso4217_asset returns std::nullopt for an unknown code, or one with no ISO scale.
  • "XXX"_iso4217 for such a code is a compile error.

Performance. Binary search over the generated rows, at compile time where the code is a constant. Not benchmarked.

Tests and demos. tests/money/iso4217_test.cpp (checked against SIX's XML through Python's xml.etree, the CTest generated.iso4217_up_to_date; the countries against pycountry and the cash rules and symbols against babel through tests/fixtures/money/currencies.tsv, the CTest generated.country_fixtures_up_to_date), demos/money/iso4217_demo.cpp.

Dependencies. <cstddef>, <cstdint>, <optional>, <span>, <string_view>, money/asset.hpp, detail/iso4217_table.hpp (about 300 types and rows: heavier than it looks, so include it only where needed), which includes display.hpp and so <ostream>.

Known issues.

  • ISO gives no minor units to the precious metals (XAU, XAG, XPT, XPD), the SDR (XDR) and the funds. Those types need with_scale<currency::XAU, 18>.
  • SIX's historic list has no minor units, so historic codes need with_scale too.
  • --latest on the generator reports a newer SIX list; regenerate when SIX publishes one.
  • CLDR's digits differ from ISO's for a few codes (AFN, IQD); scale() is always ISO's, and CLDR only decides the cash rule. Root-locale symbols are deliberately unambiguous ("US$", "JP¥"), not a locale's ("$", "¥").

Status. New in 0.22.0; countries, cash rules and symbols new in 0.23.0.
