Detailed Description

snicholls::tracking::reduce_to_single, merge_pair, runnalls_cost and reduce_mixture: Gaussian mixtures kept small enough to carry forward.

Overview. Multi-hypothesis filters (PDA's components, GM-PHD, multiple models) multiply mixture components every step. These keep the mixture bounded:

  • weighted_gaussian<T, N>: a weight and a Gaussian.
  • reduce_to_single(components): the moment-matched single Gaussian (Stone Soup's gm_reduce_single).
  • merge_pair(a, b): two components as one, moments preserved, weight min(w_a + w_b, 1) as Stone Soup caps it.
  • runnalls_cost(a, b): the upper bound on the KL divergence a merge adds, [(w_a + w_b) log det P_ab - w_a log det P_a - w_b log det P_b] / 2, for choosing what to merge.
  • reduce_mixture(components, options): in place, Stone Soup's GaussianMixtureReducer: prune components below a weight (their weight shared among the rest), merge (the heaviest component absorbs every one within a squared Mahalanobis distance of it, measured with that component's covariance, repeatedly), and truncate to the heaviest max_components. Returns the new size.
// Hypotheses about two targets: three near (0, 0), two near (10, 0), one negligible far away; weights sum to 1
std::array<component, 6> mixture{at(0.30, 0, 0), at(0.15, 0.5, 0.2), at(0.05, -0.4, 0.3),
at(0.30, 10, 0), at(0.1999999995, 10.6, -0.3), at(1e-9 / 2, 50, 50)};
const auto single = tr::reduce_to_single<double, 2>(mixture); // one Gaussian for display or a gate
// How much information one merge would lose (Runnalls' bound on the KL divergence it adds)
const auto near_cost = tr::runnalls_cost(mixture[0], mixture[1]);
const auto far_cost = tr::runnalls_cost(mixture[0], mixture[3]);
const auto merged = tr::merge_pair(mixture[0], mixture[1]);
// Prune below 1e-9, merge within a squared Mahalanobis distance of 16, keep at most 4 (Stone Soup's defaults
// but the cap)
const std::size_t kept = tr::reduce_mixture<double, 2>(mixture, {1e-9, 16, 4});

Relationships. tracking/gaussian.hpp, tracking/association.hpp (PDA's mixture). Stone Soup's gm_reduce_single and GaussianMixtureReducer. Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation, no recursion. Merging preserves the mixture's weighted mean and covariance. Complexity O(n²) for reduce_mixture.

Errors. reduce_to_single of no components, or of zero total weight, returns a zero Gaussian. runnalls_cost returns linalg::error::not_positive_definite for a covariance without a Cholesky factor. In reduce_mixture a component whose covariance has none is never merged into another.

Performance. Not benchmarked.

Tests and demos. tests/tracking/mixture_test.cpp, demos/tracking/mixture_demo.cpp.

Dependencies. <cstddef>, <limits>, <span>, linalg/fixed.hpp, result.hpp, tracking/gaussian.hpp.

Known issues. Stone Soup's optional k-d-tree coarse gate is not applied; every pair is tested, which gives the same result.

Status. Experimental, new in 0.19.0.
