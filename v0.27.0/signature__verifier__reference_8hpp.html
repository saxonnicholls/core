Detailed Description

snicholls::memory_signature_verifier: the standard-library reference signature_verifier, HS256 under a memory_key_store's keys, for tests only.

Overview. Borrows a memory_key_store (interfaces/key_store_reference.hpp), which must outlive it, and checks HS256 tags with core's hmac<sha256> and constant_time_equal for every version the store still holds: retired versions verify, as rotation requires. Every asymmetric algorithm (EdDSA, ES256, ES256K, RS256) is unsupported: those need constant-time elliptic-curve and RSA code, which is crypto's (servers' crypto_signature_verifier). fail_next(code, response) makes the next verify fail as though the store had answered response. Never configure it in production: a production JWT policy refuses HS256 before it reaches a verifier.

memory_signer keys = memory_signer::deterministic(); // HS256 keys, for tests only
const std::string kid{keys.create({signature_algorithm::hs256, "jwt"})->key_id.view()};
const std::array<std::byte, 2> message{std::byte{'h'}, std::byte{'i'}};
const auto old_tag = keys.sign({kid, message, payload_kind::message});
static_cast<void>(keys.rotate(kid)); // version 2 signs; version 1 still verifies
memory_signature_verifier verifier{keys};
const auto still_good = verifier.verify({signature_algorithm::hs256, kid, 1, {}, message, old_tag->bytes});

Relationships. Models signature_verifier (concepts/signature_verifier.hpp); passes its kit in every form; verifies what memory_signer (interfaces/signer_reference.hpp) signs. Group: snicholls-core.

Implementations / variants. One.

Guarantees. verify is const and reads the store; it is as thread-safe as the store, which is not, while a failure is armed. Errors carry fixed messages only.

Errors. unsupported (not HS256), invalid_argument (no version), not_found (no such key or version), signature_invalid, and whatever fail_next armed.

Performance. One hmac<sha256> and a constant-time compare (benchmarks/interfaces/key_store_reference_benchmark.cpp measures the same MAC).

Tests and demos. tests/interfaces/signature_verifier_reference_test.cpp, demos/interfaces/signature_verifier_reference_demo.cpp.

Dependencies. <optional>, <string_view>, <vector>, interfaces/key_store_reference.hpp, interfaces/signature_verifier.hpp.

Known issues. HS256 only, by design.

Status. New in 0.27.0.
