Detailed Description

snicholls::manual_loop_clock: the standard-library reference loop clock; time moves only when told.

Overview. What a test drives a loop's timers with: the clock starts at a given instant and moves only on advance(d) or advance_to(t), never backwards, and wakes the loop (the installed waker) each time it moves. block_for always answers 0, because only the program moves this clock. Never moved, it is a fixed clock. ts-moveables' manual_clock is the same with an atomic, for a test thread driving a loop on another thread; this one is single-threaded, and C++17-clean.

manual_loop_clock clock{loop_time_point{10s}};
int woken = 0;
clock.set_waker([&woken] { ++woken; });
clock.advance(5s);
clock.advance(-1s); // ignored: time does not go back
clock.advance_to(loop_time_point{1s}); // earlier: stays, but still wakes

Relationships. Models loop_clock_like (concepts/loop_clock.hpp); passes interfaces/loop_clock_conformance.hpp directly and through interfaces/loop_clock.hpp. Group: snicholls-core.

Implementations / variants. One.

Guarantees. Not thread-safe. now, block_for and advance of a clock with no waker are noexcept; a waker that throws propagates out of advance.

Errors. None.

Performance. Not benchmarked: a test double.

Tests and demos. tests/interfaces/loop_clock_reference_test.cpp, demos/interfaces/loop_clock_reference_demo.cpp.

Dependencies. <chrono>, <functional>, <utility>, concepts/loop_clock.hpp.
