Detailed Description

snicholls::sql_connection_interface: the pure virtual twin of sql_connection, and the adapters both ways.

Overview. When the engine is chosen at run time (configuration names SQLite or PostgreSQL), code holds a sql_connection_interface& (crtp's sql_connection); its dialect() is a const sql_dialect_interface&. Its pure virtual functions are the operations of the concept sql_connection (concepts/sql_connection.hpp, where the contract is documented), so the interface models the concept and sql_execute, sql_query and sql_transaction take it. sql_connection_adapter<C> puts any model behind the interface, owning it (C) or referring to it (C&), with its dialect behind sql_dialect_interface; sql_connection_ref is a copyable, non-owning handle on the interface that models the concept.

std::unique_ptr<sql_connection_interface> db = std::make_unique<sql_connection_adapter<memory_sql_connection>>(memory_sql_connection{});
sql_connection_ref c{*db}; // copyable, models the concept
const sql_table t{"t", {{"k", sql_type::int64, false}}, {0}, false};
const auto created = sql_execute(c, *sql_create_table(c.dialect(), t));
const auto inserted = sql_execute(c, *sql_insert(c.dialect(), t), {std::int64_t{1}});

Relationships. concepts/sql_connection.hpp, interfaces/sql_dialect.hpp, interfaces/sql_connection_reference.hpp, interfaces/sql_connection_conformance.hpp. Group: snicholls-core.

Implementations / variants. sql_connection_adapter<C> over any model; crtp's engines may derive from the interface directly.

Guarantees. The adapters add one virtual call per operation. An adapter refers to its own model's dialect, so it is neither copied nor moved.

Errors. As the contract.

Performance. One virtual call; not benchmarked.

Tests and demos. tests/interfaces/sql_connection_test.cpp (the kit through every form), demos/interfaces/sql_connection_demo.cpp.

Dependencies. <cstddef>, <span>, <string_view>, <type_traits>, <utility>, concepts/sql_connection.hpp, interfaces/sql_dialect.hpp.

Known issues. None.

Status. New in 0.27.0. Experimental until two real implementations pass the kit.
