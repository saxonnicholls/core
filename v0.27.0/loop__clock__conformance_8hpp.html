Detailed Description

snicholls::check_loop_clock: the conformance kit of the loop clock contract, C++17-clean.

Overview. Drives any clock with loop_clock_like's members (a clock, a loop_clock_interface&, an any_loop_clock) through the contract of concepts/loop_clock.hpp and returns the failures as strings (ts-moveables' kit style): empty is a pass. The checks: now never goes backwards (a thousand reads), a due deadline does not block (block_for of a past instant and of now is 0), a wait is never below -1, set_waker takes a callable and an empty one. check_loop_clock_moves(clock, step) adds the checks of a clock that moves on command: step() moves it forward and must call the waker once, after which now() is later.

manual_loop_clock clock;
const auto any_clock = check_loop_clock(clock); // every clock
const auto manual = check_loop_clock_moves(clock, [&] { clock.advance(1ms); }); // one that moves on command

Relationships. concepts/loop_clock.hpp, interfaces/loop_clock.hpp; run on manual_loop_clock in every form by tests/interfaces/loop_clock_test.cpp. Group: snicholls-core.

Implementations / variants. check_loop_clock for every clock; check_loop_clock_moves for manual ones.

Guarantees. The kit leaves no waker installed.

Errors. Failures are data.

Performance. Not benchmarked: a test kit.

Tests and demos. tests/interfaces/loop_clock_conformance_test.cpp (the kit catches broken clocks), demos/interfaces/loop_clock_conformance_demo.cpp.

Dependencies. <chrono>, <functional>, <string>, <vector>, concepts/loop_clock.hpp.

Known issues. "Never backwards" is sampled, not proven.
