Detailed Description

The compare-and-swap capability, virtual form: kv_cas_interface, its adapter, and the kit check_kv_cas.

Overview. kv_cas_interface is kv_cas (concepts/kv_cas.hpp) behind a virtual function, for a store chosen at run time; it models the concept. kv_cas_adapter<S> puts any model behind it, owned (S) or referred to (S&), translating an exception into kv_errc as the store adapters do. check_kv_cas(store) is the capability's kit: it drives a store that is also kv_readable through the contract and names the first check that fails.

std::unique_ptr<kv_cas_interface> cas = std::make_unique<kv_cas_adapter<reference_key_value_store&>>(store);
const auto first = cas->compare_and_swap(b("version"), std::nullopt, b("1"));
const auto stale = cas->compare_and_swap(b("version"), b("0"), b("2")); // an optimistic update from an old read

Relationships. concepts/kv_cas.hpp, interfaces/key_value_store.hpp, reference_key_value_store (interfaces/key_value_store_reference.hpp). Group: snicholls-core.

Implementations / variants. kv_cas_adapter<S> over any model.

Guarantees. One virtual call; no exception crosses the adapter but std::bad_alloc.

Errors. As the model's; check_kv_cas returns the failed check's name.

Performance. One virtual call; not benchmarked.

Tests and demos. tests/interfaces/kv_cas_test.cpp (the kit through both forms), demos/interfaces/kv_cas_demo.cpp.

Dependencies. <array>, <cstddef>, <optional>, <string_view>, <type_traits>, <utility>, concepts/kv_cas.hpp, interfaces/key_value_store.hpp.

Known issues. The kit writes and erases the keys kit/cas/*.

Status. New in 0.27.0. Experimental.
