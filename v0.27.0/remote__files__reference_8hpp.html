Detailed Description

snicholls::memory_remote_files: the standard-library reference remote_files, a drop held in memory as name to bytes and a modification time.

Overview. What a collector's tests list and fetch from: it applies the contract exactly (name validation, sorted listing, streaming in chunks with the digest, move when switched on) over files the test puts, so no server, credential or file system is needed; core has no I/O. fail_next(code, response) makes the next operation that would be attempted fail as though the server had answered response, to test a collector's retry path; the error keeps the response's first word as the provider code when it is one (provider_error) and nothing else of it. A small chunk_size makes every fetch arrive in many chunks, as it would from a network.

memory_remote_files drop{true, 8}; // move supported, 8-byte chunks
const auto put = drop.put("outgoing/APST_20261126.csv", bytes, utc_s::from_unix_seconds(1'800'000'000));
std::size_t chunks = 0;
const auto digest = drop.fetch("outgoing/APST_20261126.csv", [&](std::span<const std::byte>) -> capability_result<void> {
++chunks;
return ok();
});
drop.fail_next(capability_errc::unavailable, "503 Service Unavailable"); // the next call fails once

Relationships. Models remote_files (concepts/remote_files.hpp); passes interfaces/remote_files_conformance.hpp directly and through interfaces/remote_files.hpp. Group: snicholls-core.

Implementations / variants. One; move can be switched off, to stand for a read-only drop.

Guarantees. Not thread-safe (one per test). Strong exception safety for put and move: a throwing allocation leaves the drop unchanged. Errors follow the redaction rule: fixed messages only, never a name.

Errors. As the contract, and whatever fail_next armed. put refuses an invalid name with invalid_argument and an existing one with conflict.

Performance. Not benchmarked: a test double.

Tests and demos. tests/interfaces/remote_files_reference_test.cpp, demos/interfaces/remote_files_reference_demo.cpp.

Dependencies. <algorithm>, <cstddef>, <functional>, <map>, <optional>, <span>, <string>, <string_view>, <utility>, <vector>, interfaces/remote_files.hpp.

Known issues. None.

Status. New in 0.27.0.
