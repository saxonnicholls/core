Detailed Description

template<typename T, std::size_t N, std::size_t MaxNnzL, typename I = std::int32_t>
struct snicholls::sparse::ldl_fixed< T, N, MaxNnzL, I >

Every array of an L D Lᵀ of fixed order and fixed nnz(L), inside one object: for a problem whose size is known when the program is written, and for a factorisation in a constant expression.

Template Parameters
TThe value type.
NThe order.
MaxNnzLThe most entries of L below the diagonal (ldl_nnz<N>(a) gives the exact need).
IThe index type.
