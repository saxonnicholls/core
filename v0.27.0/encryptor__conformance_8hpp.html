Detailed Description

snicholls::run_encryptor_conformance: the conformance kit of the encryptor contract.

Overview. Drives any encryptor, in either form, through the contract of concepts/encryptor.hpp and reports which check failed (interfaces/capability_conformance.hpp). The probe is a default-constructible type with

  • auto& encryptor(): the implementation (an encryptor, an encryptor_interface&, an encryptor_ref), holding two keys;
  • std::string_view key() and std::string_view other_key(): the ids of those keys;
  • void forget(std::string_view key_id): the implementation no longer holds that key.

A fresh probe is made for every check. The checks: what is sealed opens, every seal is fresh, a changed envelope does not open, other associated data does not open, an unknown key is not_found, a malformed envelope is invalid_argument, the key id is in the envelope, errors carry no secret.

const capability_conformance_report report = run_encryptor_conformance<probe>();

Relationships. concepts/encryptor.hpp, interfaces/encryptor.hpp, interfaces/capability_conformance.hpp; run on insecure_test_encryptor in every form by tests/interfaces/encryptor_test.cpp. Group: snicholls-core.

Implementations / variants. One kit for every form.

Guarantees. As interfaces/capability_conformance.hpp: no exception escapes a check.

Errors. Failures are data.

Performance. Not benchmarked: a test kit (a few hundred seals; each byte of one envelope is flipped).

Tests and demos. tests/interfaces/encryptor_conformance_test.cpp (the kit catches broken encryptors), demos/interfaces/encryptor_conformance_demo.cpp.

Dependencies. <cstddef>, <span>, <string>, <string_view>, <type_traits>, <utility>, <vector>, concepts/encryptor.hpp, interfaces/capability_conformance.hpp.

Known issues. The kit tests the contract, never the cipher's strength: the test double passes it.

Status. New in 0.27.0.
