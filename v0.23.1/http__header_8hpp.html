Detailed Description

snicholls::http_header, a header field (HTTP, a webhook's), and find_header, the case-insensitive lookup.

Overview. A header is a name and a value. find_header finds the first by name ignoring ASCII case, as RFC 9110 requires, with ascii_iequals (no locale). The HTTP handler contract (concepts/http_handler.hpp) carries headers on its requests and responses; the payment provider contract (concepts/payment_provider.hpp) reads a webhook's signature header with find_header. Core does no networking: these are the values, not a transport.

const std::vector<http_header> headers{{"Content-Type", "application/json"}, {"Stripe-Signature", "t=1,v1=ab"}};
const auto signature = find_header(headers, "stripe-signature"); // RFC 9110: names ignore case

Relationships. concepts/http_handler.hpp, concepts/payment_provider.hpp. Group: snicholls-core.

Implementations / variants. One.

Guarantees. ascii_iequals and find_header are constexpr, noexcept, allocation-free and locale-free; O(total length). http_header owns its strings: copying one may throw std::bad_alloc.

Errors. None; a missing header is std::nullopt.

Performance. Not benchmarked on its own; measured inside benchmarks/interfaces/http_handler_benchmark.cpp.

Tests and demos. tests/http_header_test.cpp, demos/http_header_demo.cpp.

Dependencies. <cstddef>, <optional>, <span>, <string>, <string_view>.

Known issues. Names are compared, not validated: a name with a space or a colon is found like any other.

Status. New in 0.23.0.
