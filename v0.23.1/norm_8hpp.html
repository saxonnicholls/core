Detailed Description

snicholls::ml normalisation: layer_norm and rms_norm over one row, group_norm over a sample's channel groups and l2_norm, forward and backward, with or without learned parameters.

Overview. The per-token normalisations of a transformer. Each works on one row of C channels; a batch is a loop over rows, which a caller spreads across threads (each row is independent).

  • layer_norm(x, weight, bias, out, eps): out = (x - mean) · rstd · weight + bias, with rstd = 1 / sqrt(var + eps) and the biased variance, as GPT-2 and PyTorch compute it. The mean is subtracted before squaring (two passes), so a row with a large mean keeps its variance's digits. Returns the mean and rstd, which the backward pass needs.
  • rms_norm(x, weight, out, eps): out = x · rstd · weight, rstd = 1 / sqrt(mean(x²) + eps) (LLaMA, nanochat). Returns rstd.
  • group_norm(x, C, G, weight, bias, out, eps): one sample laid out [channel][spatial] (a vision or audio encoder's feature map), each of G groups of channels normalised together and scaled per channel; groups split as ggml's group_norm splits them (group_channels: ceil(C / G) each, the last shorter). G = 1 is a LayerNorm over the sample, G = C an InstanceNorm.
  • l2_norm(x, out, eps): x / max(‖x‖, eps) (ggml's l2_norm), returning ‖x‖ for the backward pass.
  • Empty weight and bias mean none: nanochat's RMSNorm has no parameters.
  • The backward passes write dx and add into dweight and dbias, which sum over the rows of a batch.
// One token of four channels through LayerNorm with a learned weight and bias (GPT-2).
const std::array<float, 4> x{1.0f, 2.0f, 4.0f, 9.0f};
const std::array<float, 4> weight{1.0f, 0.5f, 2.0f, 1.0f}, bias{0.0f, 0.1f, 0.0f, -0.1f};
std::array<float, 4> y{};
const ml::norm_stats<float> stats = ml::layer_norm(x, weight, bias, y);
// The backward pass: dx is written, dweight and dbias add up over the rows of a batch.
const std::array<float, 4> dy{0.1f, -0.2f, 0.3f, 0.0f};
std::array<float, 4> dx{}, dweight{}, dbias{};
ml::layer_norm_backward(dy, x, weight, stats, dx, dweight, dbias);
// A batch of three rows through RMSNorm with no parameters (nanochat), in place.
std::vector<float> batch{3.0f, 4.0f, -6.0f, 8.0f, 0.5f, 0.5f};
std::vector<float> rstd;
for (std::size_t r = 0; r < 3; ++r) {
const std::span<float> row(batch.data() + 2 * r, 2);
rstd.push_back(ml::rms_norm(row, std::span<const float>{}, row));
}
// And RMSNorm's backward pass, for one row with a weight.
const std::array<float, 2> v{3.0f, 4.0f}, g{1.0f, 1.0f}, scale{2.0f, 1.0f};
std::array<float, 2> out{}, dv{}, dscale{};
const float r = ml::rms_norm(v, scale, out);
ml::rms_norm_backward(g, v, scale, r, dv, dscale);
// A feature map of 4 channels x 3 positions through GroupNorm with 2 groups (a vision encoder), and its backward pass
const std::array<float, 12> fmap{1, 2, 3, 2, 3, 4, 10, 20, 30, 20, 30, 40};
const std::array<float, 4> gamma{1.0f, 1.0f, 2.0f, 2.0f}, beta{0.0f, 0.0f, 0.5f, 0.5f};
std::array<float, 12> normed{}, dfmap{};
ml::group_norm(fmap, 4, 2, gamma, beta, normed);
std::array<float, 12> dnormed{};
dnormed[0] = 1.0f;
std::array<float, 4> dgamma{}, dbeta{};
ml::group_norm_backward(dnormed, fmap, 4, 2, gamma, dfmap, dgamma, dbeta);
// L2 normalisation of a key row (the linear attentions'), and its backward pass
const std::array<float, 2> key{3.0f, 4.0f};
std::array<float, 2> unit{}, dkey{};
const float length = ml::l2_norm(key, unit);
ml::l2_norm_backward(std::array<float, 2>{1.0f, 0.0f}, key, length, dkey);
const auto [first, last] = ml::group_channels(4, 2, 1); // the second group's channels: 2 and 3

Relationships. ml/row.hpp (the rows), ml/activations.hpp. Group: snicholls-core.

Implementations. One each.

Guarantees. constexpr, no allocation, linear in the row. out and dx may be the input row. norm_stats is trivially copyable.

Errors. Preconditions, asserted: every row has x's size, or (weight, bias, dweight, dbias) is empty. An empty x is a no-op that returns rstd 1/sqrt(eps).

Performance. Benchmarked against the same loops written by hand (benchmarks/ml/norm_benchmark.cpp); group_norm over 512 channels of 8 x 8 in 32 groups, 373 million values per second against 274 (Xeon W-3245, Release, Apple clang 17, 2026-11-19). l2_norm is not benchmarked: one sum and one scale per row.

Tests and demos. tests/ml/norm_test.cpp, demos/ml/norm_demo.cpp.

Dependencies. <cassert>, <concepts>, <cstddef>, <limits>, <span>, <type_traits>, snicholls/core/math/constexpr_math.hpp, ml/row.hpp.

Known issues. Sums accumulate in the row's type, as llm.c does in float; ggml's group_norm and l2_norm accumulate float rows in double (ggml_float, ggml/src/ggml-cpu/ops.cpp, llama.cpp 39039aa), so a long float group can differ from ggml's in the last places; pass double rows for its result.

Status. Experimental, new in 0.6.0; group_norm, group_channels and l2_norm new in 0.17.0.

The backward pass of group_norm: writes dx, adds into dweight and dbias; each group's mean and rstd are recomputed, as for the other norms (2 · C · S operations).

Per group, with n = (x - mean) · rstd and g = weight[c] · dout: dx = rstd · (g - mean(g) - n · mean(g · n)); dweight[c] += Σ_s dout · n, dbias[c] += Σ_s dout.
