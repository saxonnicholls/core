Detailed Description

snicholls::check_day_count: the conformance kit of the day_count_convention capability.

Overview. Drives any day_count_convention, a type or an object behind day_count_interface, through the contract every convention keeps, over every start and end in a window of days, and says which check failed:

  • the name is not empty;
  • a period of no days counts zero days and is zero years;
  • for a fixed start, the count and the fraction never fall as the end moves later;
  • the fraction is between 1/400 and 1/300 of a year per counted day, so a convention's denominator is a year's worth of days (360 to 366).

No test framework is included; a test asserts that the result is empty.

constexpr sys_days from = sys_days{2024y / February / 1d};
static_assert(!snicholls::check_day_count(snicholls::finance::thirty_360{}, from, 45)); // conforms
const auto broken = snicholls::check_day_count(per_week{}, from, 45); // names the failed check
