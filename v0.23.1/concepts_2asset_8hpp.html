Detailed Description

snicholls::asset_like and snicholls::currency_like: what an amount can be of, as concepts.

Overview. An asset answers code() (a short string) and scale() (the decimal places of its minor unit); a currency is an asset that is also has_name and has an ISO 4217 numeric() code. The concepts are written over object expressions, so they are modelled by compile-time types with static constexpr member functions (snicholls::currency::AUD, snicholls::native::ETH, a product's own token struct), by the value snicholls::asset, and by any object behind the virtual twins asset_interface and currency_interface (interfaces/asset.hpp).

static_assert(currency_like<currency::EUR>);
static_assert(asset_like<native::ETH> && !currency_like<native::ETH>);
static_assert(asset_like<asset>); // the value models it too
static_assert(!asset_like<currency::XAU>); // until a scale is chosen

Known issues. The ISO 4217 codes with no minor units (XAU, XAG, XPT, XPD, XDR, the funds) and the historic codes do not model asset_like until a scale is given with with_scale.
