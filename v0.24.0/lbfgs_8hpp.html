Detailed Description

snicholls::optim::lbfgs_minimize: limited-memory BFGS for smooth unconstrained minimisation, with its history of curvature pairs and the two-loop recursion, over the caller's storage, all constexpr.

Overview. L-BFGS (Nocedal, 1980; Liu and Nocedal, 1989) minimises a smooth f: ℝⁿ → ℝ from values and gradients alone. It keeps the last M pairs sₖ = xₖ₊₁ - xₖ, yₖ = ∇fₖ₊₁ - ∇fₖ and applies the BFGS inverse Hessian they define to the gradient in O(Mn), without forming an n x n matrix. It is the workhorse for calibration, maximum likelihood and smooth penalties when n is too large for Newton's method or the Hessian is unavailable. It is not for constrained problems (bounds need L-BFGS-B; general constraints a QP or interior-point solver), nor for non-smooth objectives.

  • lbfgs_history<T, M>: a ring buffer of up to M pairs over storage of the caller's (n · M values for the s vectors and n · M for the y vectors); lbfgs_history<T, M, N> keeps them inside, for a size fixed at compile time. push(s, y) adds a pair (dropping the oldest when full) unless sᵀy ≤ ε yᵀy, which would spoil positive definiteness.
  • two_loop(history, g, d): d = -H g, H the L-BFGS inverse Hessian with H₀ = γ I, γ = sᵀy / yᵀy of the newest pair (1 with no pairs), by the two-loop recursion (Nocedal and Wright, algorithm 7.4).
  • lbfgs_minimize<M>(fg, x, options, work): from x, repeat d = -H ∇f, a strong-Wolfe line search along d (optim/line_search.hpp), push(s, y), until ‖∇f‖∞ ≤ gradient_tolerance. work is lbfgs_workspace(n, M) values. The first step is min(1, 1 / ‖∇f‖₂) along -∇f; later steps start at 1.
// The extended Rosenbrock function: independent pairs, minimum 0 at all ones
double rosenbrock(cspan x, std::span<double> g)
{
double f = 0;
for (std::size_t i = 0; i + 1 < x.size(); i += 2) {
const double a = x[i + 1] - x[i] * x[i], b = 1 - x[i];
f += 100 * a * a + b * b;
g[i] = -400 * x[i] * a - 2 * b;
g[i + 1] = 200 * a;
}
return f;
}
bool lbfgs_example()
{
// 1. Ten variables, seven pairs of memory; the caller owns every byte
constexpr std::size_t n = 10, memory = 7;
std::vector<double> x(n), work(op::lbfgs_workspace(n, memory));
for (std::size_t i = 0; i < n; ++i)
x[i] = i % 2 == 0 ? -1.2 : 1.0;
const auto r = op::lbfgs_minimize<memory>(rosenbrock, std::span<double>(x), {1e-8}, work);
std::printf(" Rosenbrock, n = 10: %s after %zu iterations, %zu evaluations, f = %.2e, x0 = %.8f\n", r.converged() ? "converged" : "failed", r.iterations, r.evaluations,
r.value, x[0]);
// 2. Logistic regression by maximum likelihood: P(yᵢ = 1) = σ(w₀ + w₁ tᵢ), stopped when f stops moving
const std::array<double, 8> t{-3, -2, -1, -0.5, 0.5, 1, 2, 3}, y{0, 0, 1, 0, 1, 0, 1, 1};
const auto nll = [&](cspan w, std::span<double> g) {
double f = 0;
g[0] = g[1] = 0;
for (std::size_t i = 0; i < t.size(); ++i) {
const double z = w[0] + w[1] * t[i], p = 1 / (1 + std::exp(-z));
f += std::log(1 + std::exp(z)) - y[i] * z;
g[0] += p - y[i];
g[1] += (p - y[i]) * t[i];
}
return f;
};
std::array<double, 2> w{};
std::array<double, op::lbfgs_workspace(2, 4)> w_work{};
const auto fit = op::lbfgs_minimize<4>(nll, std::span<double>(w), {1e-12, 1e-14}, w_work);
std::printf(" logistic fit: w = (%.4f, %.4f), -log L = %.6f, %zu iterations\n", w[0], w[1], fit.value, fit.iterations);
// 3. The pieces: a fixed-dimension history and the two-loop recursion; H y = s for the newest pair
op::lbfgs_history<double, 3, 2> history;
const std::array<double, 2> s1{1, 0}, y1{4, 1}, s2{0.5, 1}, y2{3, 5};
history.push(s1, y1);
history.push(s2, y2);
std::array<double, 2> d{};
op::two_loop(history, y2, d); // d = -H y₂
std::printf(" two loop: -H y = (%.6f, %.6f), s = (%.6f, %.6f)\n", d[0], d[1], s2[0], s2[1]);
return r.converged() && std::abs(x[0] - 1) < 1e-7 && fit.converged() && fit.gradient_norm < 1e-6 && w[1] > 0 && std::abs(d[0] + s2[0]) < 1e-12 &&
std::abs(d[1] + s2[1]) < 1e-12;
}

Relationships. optim/line_search.hpp (strong_wolfe), linalg/types.hpp (scalar), linalg/krylov.hpp (CG, which L-BFGS matches on a quadratic with exact line searches). Group: snicholls-core.

Implementations. The history holds ρₖ = 1 / yₖᵀsₖ with each pair. When d is not a descent direction (∇fᵀd ≥ 0, possible only through rounding), the history is cleared and d = -∇f. When a line search fails without progress and the history is not empty, the history is cleared and the iteration retried once along -∇f; a failure with some decrease is accepted as a step.

Guarantees. constexpr; noexcept when fg is and T's arithmetic is. No allocation, no recursion. On return x is the best point reached (the last accepted iterate), and the result's value and gradient norm are at x. Per iteration O(Mn) besides the evaluations. The history's storage must outlive it.

Errors. Nothing throws unless fg does. The outcome is an lbfgs_status: gradient_converged, value_converged (|fₖ - fₖ₊₁| ≤ value_tolerance · max(|fₖ|, |fₖ₊₁|, 1), when that tolerance is positive), iteration_limit, line_search_failed (no decrease along -∇f: usually the gradient tolerance is below what rounding allows, or the gradient is wrong), invalid_input (work too short; x untouched).

Performance. Not benchmarked: the cost is the objective's evaluations, which the result counts.

Tests and demos. tests/optim/lbfgs_test.cpp, demos/optim/lbfgs_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <limits>, <span>, <type_traits>, linalg/types.hpp, math/constexpr_math.hpp, optim/line_search.hpp.

Known issues. M between 3 and 20 is usual; beyond that the O(Mn) work grows without much gain. The gradient tolerance is absolute: scale the objective, or the variables, so that 1e-6 means something.

Status. Experimental, new in 0.21.0.
