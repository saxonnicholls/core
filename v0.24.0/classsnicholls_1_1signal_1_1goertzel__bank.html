Detailed Description

template<math::math_number T, std::size_t K>
class snicholls::signal::goertzel_bank< T, K >

K Goertzel detectors over the same block, every state updated by each sample in one pass.

The constructor is constexpr: constexpr goertzel_bank<float, 8> dtmf(freqs, 8000.0, 205); is a table the compiler fills. The states are a structure of arrays, so the inner loop over the K frequencies vectorises.
