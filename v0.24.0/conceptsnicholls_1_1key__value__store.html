Detailed Description

The full contract: kv_writable plus s.snapshot() -> result<H, kv_errc>, a read-only consistent view.

H is a kv_readable value, or a pointer-like handle to one (std::unique_ptr<kv_reader_interface> in the virtual form). Its reads, sequence() included, see the state when it was taken, for as long as it lives.
