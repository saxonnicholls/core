Detailed Description

template<standard_int_type T = int, draw D = draw::core>
class snicholls::stats::uniform_int< T, D >

A uniform integer in [a, b], drawn by the algorithm D names: a drop-in for std::uniform_int_distribution<T> whose output does not depend on the standard library.

Template Parameters
TThe integer type, one of standard_int_type.
DWhose algorithm: draw::core (default), draw::libstdcxx or draw::libcxx.
