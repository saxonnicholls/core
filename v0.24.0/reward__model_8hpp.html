Detailed Description

snicholls::ml reward models: a scalar value head on hidden states, the Bradley-Terry pairwise loss on its rewards, and each sequence's last response position.

Overview. A reward model is a language model whose LM head is replaced by a value head, one linear output r = w · h + b on the hidden state of the last token of a response, trained on preference pairs to give the chosen response the higher reward (TRAINING.md T13). Its loss is Bradley-Terry's: the probability that y_w is preferred is σ(r_w - r_l), and the loss its negative logarithm, -log σ(r_w - r_l - m) (InstructGPT, Ouyang et al. 2022, eq. 1; Llama 2, Touvron et al. 2023, adds the margin m for pairs rated far apart). The same head on every position is PPO's value function (ml/rl.hpp).

  • bradley_terry{margin} with preference_loss(params, r_chosen, r_rejected): the loss of one pair, in the shape of ml/preference.hpp, so preference_loss_rows and preference_metrics serve reward models unchanged.
  • value_head(w, bias, h) and value_head_backward(w, h, dr, dh, dw, db): one hidden state.
  • value_head_rows(backend, w, bias, hs, values) and value_head_rows_backward(...): every row, on the backend.
  • last_response_positions(mask, positions): each sequence's last response position, the index list gather_rows(b, hs, positions, out, d, rows) (ml/gather.hpp) reads the hidden states at, and its backward scatter_add_rows takes the gradient back into the sequence's.
// Two sequences (chosen, rejected) of 3 positions with hidden states of 2; the response ends at different places
constexpr std::size_t d = 2, length = 3;
const std::array<double, 2 * length * d> hs{0.1, 0.0, 0.9, 0.2, 0.0, 0.0, /**/ 0.3, 0.1, 0.0, 0.8, 0.5, 0.5};
const std::array<std::uint8_t, 2 * length> mask{0, 1, 0, /**/ 0, 1, 1};
std::array<std::uint32_t, 2> last{};
ml::last_response_positions(mask, last); // positions 1 and 2
std::array<double, 2 * d> h_last{};
ml::gather_rows(backend, std::span<const double>(hs), last, std::span<double>(h_last), d, 2); // ml/gather.hpp
std::array<double, d> w{1.0, -1.0};
double bias = 0.0;
std::array<double, 2> rewards{};
ml::value_head_rows<double>(backend, w, bias, h_last, rewards);
const ml::pair_loss<double> p = ml::preference_loss(ml::bradley_terry{}, rewards[0], rewards[1]);

Relationships. ml/preference.hpp (pair_loss, preference_loss_rows, preference_metrics), ml/gather.hpp (gather_rows, scatter_add_rows), ml/transformer_block.hpp (the hidden states), ml/rl.hpp (the value loss). Group: snicholls-core.

Implementations. One each, on the host; the backend-first functions are the seam for a device (TRAINING.md T9).

Guarantees. constexpr, no allocation, noexcept for the standard floating-point types; linear in the hidden states. Gradients are added into (micro-batches accumulate); value_head_rows writes.

Errors. Preconditions, asserted: sizes agree; every row of a mask has a response token for last_response_positions.

Definitions. The Bradley-Terry loss -log σ(r_w - r_l) and the margin form: recalled from InstructGPT and Llama 2, not re-read; it is DPO's loss with the implicit reward replaced by the head's.

Performance. Not benchmarked: one dot product a row, negligible next to the model.

Tests and demos. tests/ml/reward_model_test.cpp, demos/ml/reward_model_demo.cpp.

Dependencies. <cassert>, <concepts>, <cstddef>, <cstdint>, <span>, <type_traits>, ml/activations.hpp, ml/preference.hpp, ml/row.hpp.

Known issues. A head with more than one output (a multi-objective reward) is linear's job.

Status. Experimental, new in 0.16.0.
