Detailed Description

snicholls::ml probes of frozen features: mean_pool_rows and the attentive probe (one learned query, one cross-attention, as V-JEPA's AttentivePooler), forward and backward.

Overview. A self-supervised encoder is judged by how well a small model on its frozen features does a task: a linear classifier on the mean of its token rows (a linear probe), or on an attentive pooling of them, which V-JEPA (Bardes et al., 2024) uses for every evaluation (TRAINING.md T11).

  • mean_pool_rows(b, rows, width, out, sequences, lengths): each sequence's mean row over its valid rows (all, or the first lengths[s]), summed in order and divided once. mean_pool_rows_backward spreads the gradient back evenly.
  • attentive_probe_forward(b, w, xs, act, out, heads, sequences, lengths): one learned query q0 attends over each sequence's rows, as V-JEPA's CrossAttentionBlock (read from its code 2026-11-19): h = layer_norm(x) (affine, norm1), q = Wq q0 + bq, K = h Wkᵀ + bk, V = h Wvᵀ + bv, each head y_h = softmax(q_h·K_h / sqrt(d_h)) V_h over the valid rows, and out = q0 + y: V-JEPA's CrossAttention has no output projection, and its block adds the attention to the query. The rest of V-JEPA's block, out = out + mlp(norm2(out)), and the classifier are block_norm / layer_norm, mlp_forward and linear (ml/mlp.hpp, ml/linear.hpp) on the pooled row.
  • attentive_probe_backward(...): every gradient (the query's, the projections', the biases', the norm's and, if asked, the features'), the softmax rebuilt from the saved log-sum-exps (TRAINING.md T2).
// Two sequences of three feature rows; the second has two real rows and one of padding
std::vector<float> features(seqs * n * d);
for (std::size_t i = 0; i < features.size(); ++i)
features[i] = std::sin(0.7f * float(i));
const std::array<std::size_t, 2> lengths{3, 2};
// The mean of each sequence's real rows
std::array<float, seqs * d> pooled{};
ml::mean_pool_rows(backend, std::span<const float>(features), d, std::span<float>(pooled), seqs, lengths);
// The attentive probe: a learned query attends over the rows (V-JEPA's pooler), out = query + attention
std::vector<float> query(d, 0.1f), wq(d * d), wk(d * d), wv(d * d);
for (std::size_t i = 0; i < d * d; ++i) {
wq[i] = 0.3f * std::cos(float(i));
wk[i] = 0.3f * std::sin(float(i) + 1);
wv[i] = i % (d + 1) == 0 ? 1.0f : 0.0f; // the identity
}
ml::attentive_probe_weights<float> w{query, {wq, d, d}, {wk, d, d}, {wv, d, d}};
std::vector<float> h(features.size()), k(features.size()), v(features.size()), q(d), y(seqs * d), lse(seqs * heads);
const ml::attentive_probe_activations<float> act{h, k, v, q, y, lse};
std::array<float, seqs * d> out{};
ml::attentive_probe_forward(backend, w, std::span<const float>(features), act, std::span<float>(out), heads, seqs, lengths);

Relationships. ml/linear.hpp (linear_sequence, the projections through a linalg backend), ml/norm.hpp, ml/attention.hpp (the same softmax arithmetic as attend, over strided heads), ml/jepa.hpp. Group: snicholls-core.

Implementations. One, on the host for any linalg::blas_backend; the projections are the backend's.

Guarantees. constexpr, no allocation; the caller's views. Each head's softmax takes its maximum score first, then sums e^(s - max) and the weighted values in row order.

Errors. Preconditions, asserted: the shapes; heads divides width; at least one valid row per sequence for the attentive probe (a sequence with none gives a zero y and passes no gradient).

Performance. Not benchmarked: an evaluation, run once per checkpoint; its products are the backend's.

Tests and demos. tests/ml/probe_test.cpp, demos/ml/probe_demo.cpp.

Dependencies. <cassert>, <cstddef>, <limits>, <span>, <type_traits>, linalg/backend.hpp, ml/linear.hpp, ml/norm.hpp.

Known issues. One query and depth one, V-JEPA's defaults (num_queries = 1, depth = 1); more queries are more calls.

Status. Experimental, new in 0.16.0.
