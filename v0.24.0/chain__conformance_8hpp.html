Detailed Description

snicholls::check_chain: the conformance kit of the chain capability.

Overview. Drives any chain_like implementation, a type or an object behind chain_interface, through the contract and says which check failed:

  • the name is not empty;
  • the native asset conforms to the asset contract;
  • an EVM chain's identifier is not zero.

No test framework is included.

const auto type_form = check_chain(chain::arbitrum{});
const chain_model<chain::arbitrum> model;
const auto virtual_form = check_chain(static_cast<const chain_interface&>(model));
