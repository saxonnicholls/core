Detailed Description

An owning list of writes, built from temporaries and kept; passes to apply() as std::span<const kv_write>.

Copies each key and value once, into storage that never moves, so the views it hands out stay valid until it is cleared or destroyed. A plain value type: move-only, not synchronised. For a batch whose bytes already live elsewhere, a std::array<kv_write, N> needs no allocation at all.
