Detailed Description

snicholls::math: one-dimensional root finding, constexpr: bisection, Brent's method, a safeguarded Newton iteration, and outward bracketing.

Overview. Solving f(x) = 0 for one unknown is the inner step of an implied volatility, a yield, a Kepler anomaly or a break-even. Every routine here is a constexpr function template on the number type T (float, double, long double, or a type of the caller's with std::numeric_limits) and on the callable, so a root can be found by the compiler for a constant table, or at run time on the hot path with no allocation.

  • bisect halves a bracket: one bit per evaluation, guaranteed. Use it when f is merely continuous or noisy.
  • brent is Brent's 1973 method (inverse quadratic interpolation, the secant step and bisection, with his safeguards): superlinear on smooth functions, never much worse than bisection. The default choice.
  • newton_safeguarded takes f and f' together and steps by Newton inside a bracket, falling back to bisection whenever the step leaves the bracket or does not halve the previous one (a stall). Use it when the derivative is cheap (an option's vega comes with its price).
  • bracket widens an interval around a guess until f changes sign, for the three above.

Each returns a root_result: the point, f there, the number of evaluations of f after the two endpoints, and a root_status.

// Kepler's equation M = E - e sin E: the eccentric anomaly of an orbit with e = 0.5 at mean anomaly 1,
// solved by the compiler.
constexpr auto kepler = math::brent([](double E) { return E - 0.5 * math::sin(E) - 1.0; }, 0.0, math::pi);
static_assert(kepler.status == math::root_status::converged);
static_assert(math::near(kepler.x, 1.4987011335178483, 1e-15));
// The implied volatility of an at-the-money one-year call priced 10.450583572185565 (S = K = 100, r = 5%),
// which is the Black-Scholes price at 20% volatility.
constexpr double price = 10.450583572185565;
const auto excess = [&](double sigma) { return bs_call(100, 100, 1, 0.05, sigma) - price; };
const auto iv = math::brent(excess, 0.01, 3.0, 1e-14);
// With the vega at hand, Newton's step, kept inside the bracket.
const auto with_vega = [&](double sigma) { return std::pair{excess(sigma), bs_vega(100, 100, 1, 0.05, sigma)}; };
const auto iv_newton = math::newton_safeguarded(with_vega, 0.01, 3.0, 0.5, 1e-14);

Relationships. Uses math/constexpr_math.hpp for abs and is_nan; math/special.hpp uses nothing from here. Group: snicholls-core.

Guarantees. constexpr, no allocation, no exceptions of their own (an exception from f propagates). Convergence is declared when the bracket's half-width is at most tolerance / 2 + 2 eps |x| (Brent's test; tolerance = 0 asks for the type's full precision), or f is exactly zero. A bracketing method keeps a sign change inside its interval throughout; the result is the evaluated point with the smaller |f|.

Errors. None thrown: root_status::not_bracketed when f(lo) and f(hi) do not differ in sign (or one is NaN), root_status::max_iterations when the budget runs out; the best point so far is still returned.

Performance. Not benchmarked; the cost is the evaluations of f, counted in iterations.

Tests and demos. tests/math/roots_test.cpp, demos/math/roots_demo.cpp.

Dependencies. <concepts>, <limits>, <type_traits>, <utility>, and math/constexpr_math.hpp.

Known issues. A root of even multiplicity has no sign change, so no bracketing method finds it; minimise |f| instead. Near a multiple root f is flat and dominated by rounding, so the bracket closes on a sign change of the rounding noise: the answer is as good as f's evaluation allows, no better.

Status. Experimental.
