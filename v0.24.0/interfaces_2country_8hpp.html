Detailed Description

snicholls::country_interface: the virtual twin of country_like, and the adapter between them.

Overview. For code that chooses a country at run time, from a form or a customer record, without templates. country_model<T> adapts any country_like type (one of country.hpp's types, or a caller's own) to the interface; the interface models country_like, so it goes back through any template written over the concept.

std::vector<std::unique_ptr<country_interface>> shipping;
shipping.push_back(std::make_unique<country_model<country::AU>>());
shipping.push_back(std::make_unique<country_model<country::DE>>());

Relationships. concepts/country.hpp, interfaces/named.hpp, interfaces/country_conformance.hpp, country.hpp. Group: snicholls-core.

Implementations. country_model<T>.

Guarantees. Every member is noexcept; the adapter is usable in constant expressions when T is. Views returned are valid while the object lives (for the generated types, for ever).

Errors. None.

Performance. One virtual call per member; not benchmarked.

Tests and demos. tests/interfaces/country_test.cpp, demos/interfaces/country_demo.cpp.

Dependencies. <cstdint>, <span>, <string_view>, concepts/country.hpp, interfaces/named.hpp.
