Detailed Description

snicholls::math: special functions for optimisation and statistics, constexpr and stable in the tails: Lambert W (both real branches), softplus, the logistic function, log Phi, and the entropy and Huber atoms.

Overview. These are the functions a convex model, a likelihood or a sizing rule is written in, each computed so that no intermediate overflows or cancels where the result itself is representable:

  • lambert_w0, lambert_wm1: the two real branches of W, the inverse of w e^w (Corless, Gonnet, Hare, Jeffrey and Knuth, On the Lambert W function, 1996). W solves x e^x = c, and with it Kelly sizing, the Wright omega, queue and growth equations in closed form.
  • softplus = log(1 + e^x), logistic = 1 / (1 + e^-x), log_logistic = log logistic(x): the smooth hinge and the sigmoid of a classifier, with neither tail overflowing.
  • log_normcdf = log Phi(x), accurate to the last digits for every x, where log(normal_cdf(x)) underflows to -inf below about -38: the probit log-likelihood, and SciPy's log_ndtr.
  • entr, rel_entr, kl_div, huber, xlogy: the atoms of CVXPY (and SciPy), with their conventions at 0 and infinity.

Every function is a template on its argument's type, as in math/constexpr_math.hpp: float, double, long double, or a type of the caller's with math_limits; an integer computes in double. The work is done in compute_type (float in double, rounded once), with constexpr_math's functions, so a constant evaluation uses its kernels and a run-time call <cmath>.

// x e^x = 5 has the one real solution W0(5); x e^x = -0.2 has two, W0(-0.2) and W-1(-0.2).
constexpr double x = math::lambert_w0(5.0);
constexpr double y0 = math::lambert_w0(-0.2), y1 = math::lambert_wm1(-0.2);
static_assert(math::near(x * math::exp(x), 5.0, 1e-15));
// softplus and the logistic function never overflow: log(1 + e^800) is 800, 1 / (1 + e^800) is 0.
constexpr double sp_hi = math::softplus(800.0), sp_lo = math::softplus(-40.0); // 800, e^-40
constexpr double lg_lo = math::logistic(-700.0), llg = math::log_logistic(-800.0); // e^-700, -800
// log Phi(-40): Phi(-40) is 3.7e-350, below the smallest double, so log(normal_cdf(-40)) is -inf.
constexpr double lp = math::log_normcdf(-40.0); // -804.6084420137538

Relationships. Built on math/constexpr_math.hpp (exp, log, log1p, sqrt, normal_cdf). math/roots.hpp is the general solver when no closed form exists. Group: snicholls-core.

Guarantees. Every function is constexpr and does not throw. NaN propagates. A domain error is NaN: lambert_w0 below -1/e, lambert_wm1 outside [-1/e, 0), huber with M < 0.

Errors. None: domain errors are NaN, poles are infinities, as in <cmath>.

Performance. Not benchmarked. lambert_w0 and lambert_wm1 cost a seed and two to four Halley steps, each an exp or a log; the others an exp, a log or both.

Tests and demos. tests/math/special_test.cpp, demos/math/special_demo.cpp.

Dependencies. <limits>, <type_traits>, and math/constexpr_math.hpp.

Known issues. Near the branch point -1/e, W(z) changes by the square root of a change in z, so a z rounded to the nearest double carries an error of about sqrt(eps) into W: inherent, not the method's. lambert_w0 above 1e300 (a double's; the type's largest value / 1e8 otherwise) returns the asymptotic series, about 1e-9 relative, because w e^w would overflow inside the iteration.

Status. Experimental.
