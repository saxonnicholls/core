Detailed Description

snicholls::tracking::covariance_intersection, optimal_omega and fast_ci_weights: fusing estimates whose cross-correlation is unknown, without becoming overconfident.

Overview. Two sensors watching the same target are not independent. They share the target's motion, the tracker's priors, perhaps the same splash, so fusing their tracks as if they were (adding information) double-counts and is overconfident. Covariance intersection is consistent for any cross-correlation: 

P⁻¹ = Σ ωᵢ Pᵢ⁻¹,   x = P Σ ωᵢ Pᵢ⁻¹ xᵢ,   Σ ωᵢ = 1, ωᵢ ≥ 0.
  • covariance_intersection(a, b, ω) and covariance_intersection(estimates, weights) for n.
  • optimal_omega(a, b, lo, hi, criterion): the ω in [lo, hi] that minimises tr P (or det P), by golden-section search, since both are unimodal in ω. The bounds encode trust: a camera still learning its pose can be held to ω ≤ 0.3.
  • fast_ci_weights(estimates, weights, lo, hi): the fast approximation ωᵢ ∝ 1 / tr Pᵢ (Niehsen 2002) for n sources, clamped to per-source bounds and renormalised.
// The radar is good in range (x), poor across it; the camera the other way round. Their errors are correlated
// by an unknown amount, so information is not simply added
const g2 radar{vec2{{100.2, 49.0}}, mat2{{1.0, 0.0, 0.0, 9.0}}};
const g2 camera{vec2{{99.0, 50.1}}, mat2{{6.0, 0.5, 0.5, 1.5}}};
const double w_trace = tr::optimal_omega(radar, camera).unwrap(); // least mean squared error
const double w_det = tr::optimal_omega(radar, camera, 0.0, 1.0, tr::ci_criterion::determinant).unwrap();
const double w_trusted = tr::optimal_omega(radar, camera, 0.0, 0.3).unwrap(); // the radar no more than 0.3
const auto fused = tr::covariance_intersection(radar, camera, w_trace).unwrap();
// Three sources: the fast weights ∝ 1 / tr P, the third (a drifting sensor) held to at most 0.2
const std::array<g2, 3> sources{radar, camera, g2{vec2{{100.5, 50.0}}, mat2{{0.5, 0.0, 0.0, 0.5}}}};
std::array<double, 3> weights{};
const std::array<double, 3> at_most{1.0, 1.0, 0.2};
const bool weighted = tr::fast_ci_weights<double, 2>(sources, weights, {}, at_most);
const auto fused3 = tr::covariance_intersection<double, 2>(sources, weights);

Relationships. tracking/gaussian.hpp, tracking/kalman.hpp (the information form, for independent sources). Stone Soup's ChernoffUpdater with ω, and CovarianceIntersection. Group: snicholls-core.

Guarantees. constexpr, noexcept for the standard floating-point types, no allocation. The fused covariance is consistent (it bounds the true error covariance) for any correlation, given consistent inputs.

Errors. linalg::error::not_positive_definite for an input covariance (or the fused information) without a Cholesky factor; linalg::error::dimension_mismatch for spans of different lengths or an empty set.

Performance. Not benchmarked: optimal_omega evaluates the fused trace about 60 times.

Tests and demos. tests/tracking/fusion_test.cpp, demos/tracking/fusion_demo.cpp.

Dependencies. <cstddef>, <cstdint>, <limits>, <span>, linalg/fixed.hpp, result.hpp, tracking/gaussian.hpp.

Known issues. None known.

Status. Experimental, new in 0.19.0.
