Detailed Description

SentencePiece's precompiled charsmap, viewed in place: a XOR-compressed compact double array of prefixes and the replacement strings they map to.

The blob is a little-endian uint32 byte count of the array, the array's packed uint32 entries, then the NUL-terminated replacements. Each entry packs a BASE (bits 10-30, shifted left 8 more when bit 9 is set), a LEAF flag (bit 8) and a LCHECK label (bits 0-7, with bit 31 set on value entries); a child of node s for byte c is at BASE(s) ^ c and holds LCHECK == c (Kanda 2018; SentencePiece's Darts-clone format).
