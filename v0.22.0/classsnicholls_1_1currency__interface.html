Detailed Description

A currency chosen at run time.

Single inheritance from asset_interface, with name() declared here rather than inherited from named_interface: a second base would need a thunk for the constexpr virtual name(), which GCC cannot compile (an internal compiler error in use_thunk). It still models has_name.
