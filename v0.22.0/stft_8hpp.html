Detailed Description

snicholls::signal short-time Fourier transform and its inverse, as torch.stft and torch.istft compute them, spectrograms, and their backward passes.

Overview. stft cuts a real signal into frames of n_fft samples every hop, multiplies each by a window and transforms it: with an rfft_plan the one-sided spectrum (n_fft / 2 + 1 bins), with an fft_plan the two-sided one (n_fft bins). As in torch.stft, center pads n_fft / 2 samples on each side first, by reflection (pad_mode::reflect, the default: x[-k] = x[k], the edge not repeated) or with zeros (pad_mode::constant); the number of frames is 1 + (padded length - n_fft) / hop; normalized multiplies each spectrum by n_fft^(-1/2). The output is frame-major, frames x bins (row t is frame t), the transpose of PyTorch's (bins, frames): each frame's spectrum is contiguous.

istft is torch.istft: each frame inverse-transformed, multiplied by the window, overlap-added, and divided by the overlap-added square of the window, then the centre padding removed. For a window and hop that satisfy NOLA (is_nola), istft(stft(x)) == x to rounding. The divisor is computed per sample from the window, so no envelope buffer is needed.

spectrogram gives |X| or |X|^2 frame by frame without storing the complex spectrum. Each function reads the padded signal through an index map, so no padded copy is made.

Gradients. stft_backward (the adjoint: each frame's rfft_backward, windowed and overlap-added back through the padding, reflected samples folded onto their sources), istft_backward, and power_backward / magnitude_backward for the spectrogram, with PyTorch's convention for complex gradients (g = dL/d re + i dL/d im).

// One second of a chirp from 500 Hz to 3 kHz at 8 kHz; frames of 256 samples every 64.
const std::size_t fs = 8000, n_fft = 256;
std::vector<double> x(fs);
for (std::size_t i = 0; i < fs; ++i) {
const double t = static_cast<double>(i) / static_cast<double>(fs);
x[i] = m::sin(2 * m::pi * (500.0 * t + 1250.0 * t * t));
}
const s::stft_options o{n_fft, 64, true, s::pad_mode::reflect, false};
constexpr auto window = s::make_window<double, 256>(s::hann{});
std::vector<cd> storage(s::rfft_plan<double>::storage_size(n_fft)), work(s::rfft_plan<double>::work_size(n_fft));
const s::rfft_plan<double> plan(n_fft, storage);
const std::size_t frames = s::stft_frames(x.size(), o), bins = plan.bins(); // 126 frames of 129 bins
std::vector<cd> spec(frames * bins);
s::stft(plan, std::span<const double>(x), std::span<const double>(window), std::span<cd>(spec), std::span<cd>(work), o);
std::vector<double> back(s::istft_length(frames, o)); // the signal's length again
s::istft(plan, std::span<const cd>(spec), std::span<const double>(window), std::span<double>(back), std::span<cd>(work), o);

Relationships. signal/fft.hpp (the plans), signal/window.hpp (the windows, is_nola), signal/mel.hpp (mel spectrograms and Whisper's front end on top of these). Group: snicholls-core.

Implementations. One-sided (rfft_plan) and two-sided (fft_plan) overloads of stft and istft; the backward passes are one-sided.

Guarantees. constexpr; no allocation (the caller gives the work buffer, plan.work_size() elements, or spectrogram_work_size for spectrogram). Complexity: frames x n_fft log n_fft; istft's divisor costs n_fft / hop multiply-adds per sample.

Errors. Preconditions, asserted: the plan's and the window's lengths are n_fft; hop >= 1; the output's size is stft_frames(length) x bins; reflection needs a signal longer than n_fft / 2, as in PyTorch; istft needs the window's overlap-added square above 1e-11 at every output sample (PyTorch raises there).

Performance. Not benchmarked separately: one real transform per frame (signal/fft.hpp's benchmark).

Tests and demos. tests/signal/stft_test.cpp (against a direct transform of each padded frame, round trips, torch.stft's frame counts, the backward passes against central differences), demos/signal/stft_demo.cpp.

Dependencies. <cassert>, <cstddef>, <span>, <type_traits>, signal/fft.hpp.

Known issues. A window shorter than n_fft (PyTorch's win_length) is not padded here: centre it in n_fft zeros first. Complex input and the two-sided backward passes are not provided.

Status. Experimental, new in 0.17.0.
