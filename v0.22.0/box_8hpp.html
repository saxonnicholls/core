Detailed Description

snicholls::geometry::box<T, D>, iou, giou, non_max_suppression and geo_box: axis-aligned boxes in any dimension, the overlap measures of object detection, and latitude-longitude boxes that cross the antimeridian.

Overview. Boxes are everywhere a thing occupies space: a detector's bounding boxes, a tracker's gates, a spatial index's nodes, a map's viewport.

  • box<T, D>: corners lo and hi (lo ≤ hi on every axis for a non-empty box), any arithmetic T (int for pixels, double for metres), any dimension. An aggregate, trivially copyable.
  • Conversions in the plane:
    • from corners (from_xyxy), from a corner and a size (from_xywh), and from YOLO's centre and size (from_cxcywh);
    • to_xyxy, to_xywh, to_cxcywh.
  • Measures: empty, extent, centre, volume (area in the plane), intersection, hull (the smallest box holding both), contains (a point or a box), intersects, expand, translate, bounding (of a set of points), and squared_distance (from a box to a point; zero inside). That last is what a spatial index's nearest search prunes with.
  • Overlap:
    • iou (intersection over union);
    • giou (generalised IoU, Rezatofighi et al. 2019: IoU - |C \ (A ∪ B)| / |C|, with C the hull);
    • non_max_suppression: greedy, by descending score, keeping a box unless it overlaps a kept one by more than a threshold (a detector's post-processing step).
  • geo_box<T>: south, west, north and east in radians, crossing the antimeridian when west > east.
    • contains, longitude_span, centre (on the shorter arc), extend (with a point);
    • from_degrees;
    • sample: a uniform point on the sphere within the box (latitude by asin of a uniform sine), with the caller's generator.

Boxes are closed and continuous: area is Π (hi - lo), so a pixel box [x1, x2] has width x2 - x1; add one yourself for inclusive pixel counts.

// A detector's output on a 640 x 480 frame, YOLO style: centre and size normalised to [0, 1], and a score
struct detection {
double cx, cy, w, h, score;
};
constexpr std::array<detection, 5> raw{{
{0.25, 0.50, 0.20, 0.40, 0.92}, // a person
{0.26, 0.51, 0.20, 0.40, 0.85}, // the same person, a second anchor
{0.70, 0.40, 0.30, 0.30, 0.78}, // a car
{0.72, 0.42, 0.30, 0.30, 0.40}, // the car again, weaker
{0.10, 0.10, 0.05, 0.05, 0.30}, // a lone weak box
}};
// To pixel corners: scale the centre-and-size box, then read its corners
std::array<b2d, raw.size()> boxes{};
std::array<double, raw.size()> scores{};
for (std::size_t i = 0; i < raw.size(); ++i) {
boxes[i] = geo::from_cxcywh(raw[i].cx * 640, raw[i].cy * 480, raw[i].w * 640, raw[i].h * 480);
scores[i] = raw[i].score;
}
// Greedy NMS at IoU 0.5: duplicates of a better box go, best first
std::array<std::uint32_t, raw.size()> kept{};
const std::size_t k = geo::non_max_suppression(std::span<const b2d>(boxes), std::span<const double>(scores), 0.5, std::span<std::uint32_t>(kept));
// Match the kept boxes to the ground truth by IoU; GIoU still ranks a miss by how far off it is
const b2d truth_person = geo::from_xywh(96.0, 144.0, 128.0, 192.0);
const b2d truth_car = geo::from_xyxy(544.0, 264.0, 352.0, 120.0); // corners in any order
const double person_iou = geo::iou(boxes[kept[0]], truth_person);
const double car_iou = geo::iou(boxes[kept[1]], truth_car);
const double lone_giou = geo::giou(boxes[kept[2]], truth_person);
// A coastline across the antimeridian: Fiji, 21° S to 12° S, 177° E to 178° W
auto fiji = geo::geo_box<double>::from_degrees(-21, 177, -12, -178);
fiji = fiji.extend(-19.0 * deg, -178.5 * deg); // inside already: unchanged
fiji = fiji.extend(-22.3 * deg, -176.2 * deg); // 'Ata, Tonga: 1.8° east is shorter than 353.2° west
const auto centre = fiji.centre();
st::wyrand g(2026);
const auto survey_point = fiji.sample(g); // a uniform point by area, for a survey

Relationships.

  • metric/concepts.hpp: bounding reads any point type through point_traits.
  • geometry/geodetic.hpp: radians and the ellipsoid; metric/geodesic.hpp: distances on the sphere.
  • stats/random.hpp: geo_box::sample's generator.
  • The R-tree to come indexes boxes.

Group: snicholls-core.

Guarantees. constexpr, noexcept for arithmetic T, no allocation (non_max_suppression uses the caller's span). IoU and GIoU are symmetric; IoU is in [0, 1], GIoU in (-1, 1], both 1 for equal non-empty boxes. Complexity: non_max_suppression O(n log n + n k) for k kept.

Errors. None. An empty box has volume 0, contains nothing, and its IoU with anything is 0; two empty boxes have IoU 0 and GIoU 0.

Performance. Not benchmarked: a few comparisons per box, per axis.

Tests and demos. tests/geometry/box_test.cpp, demos/geometry/box_demo.cpp.

Dependencies. <algorithm>, <array>, <concepts>, <cstddef>, <cstdint>, <numbers>, <span>, <type_traits>, math/constexpr_math.hpp, metric/concepts.hpp, stats/random.hpp.

Known issues. geo_box treats a box whose longitude span is the whole circle as west = -π, east = π; a box over a pole is a latitude cap (south or north at ±π/2).

Status. Experimental, new in 0.21.0.
