Detailed Description

wyrand, a fast 64-bit generator, and unbiased draws from any full-range generator.

Overview. Resampling spends its time drawing indices. std::mt19937_64 with std::uniform_int_distribution costs several nanoseconds per index, and the distribution's output is not specified by the standard, so the same seed gives different resamples on libstdc++, libc++ and MSVC. wyrand is the generator of wyhash (Wang Yi): one add and one 64 x 64 -> 128 multiply per 64 bits, passing BigCrush and PractRand. uniform_index is Lemire's nearly divisionless unbiased draw; uniform_index32 draws from 32 bits, so one 64-bit call gives two indices.

// The same seed gives the same draws on every platform, unlike std::uniform_int_distribution.
stats::wyrand g(2026);
const std::uint64_t die = stats::uniform_index(g, 6) + 1; // 1 .. 6, unbiased
const double u = stats::uniform_real(g); // [0, 1), 53 bits
std::array<int, 5> deck{1, 2, 3, 4, 5};
stats::shuffle(std::span<int>(deck), g);
// One stream per worker, from one seed.
stats::wyrand worker_3 = stats::wyrand::stream(2026, 3);

Any std::uniform_random_bit_generator of 32 or 64 full bits works (std::mt19937, std::mt19937_64, wyrand); the draws here are specified to the bit, so the same generator state gives the same draws everywhere.

Relationships. stats/bootstrap.hpp, stats/low_discrepancy.hpp, game/shapley.hpp's samplers; hash/wyhash.hpp for the mixer. Group: snicholls-core.

Guarantees. constexpr, noexcept, no allocation. wyrand is 8 bytes and trivially copyable; stream(seed, k) gives independent-looking generators for parallel work. Not cryptographic.

Errors. None: uniform_index of 0 is a precondition violation (asserted).

Performance. See stats/bootstrap.hpp and BENCHMARKS.md.

Tests and demos. tests/stats/random_test.cpp, demos/stats/random_demo.cpp.

Dependencies. <cassert>, <cstdint>, <limits>, <random> (for the concept only), <span>, <type_traits>, <utility>, detail/wide_mul.hpp, hash/wyhash.hpp.

Known issues. wyrand's period is 2^64, ample for resampling and Monte Carlo, not for cryptography.

Status. New in 0.5.0.
