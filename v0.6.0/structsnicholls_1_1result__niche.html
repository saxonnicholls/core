Detailed Description

template<class V>
struct snicholls::result_niche< V >

Opt-in niche for snicholls::result<V, E> with an empty E: a value of V that is never a valid success.

Specialise it with static constexpr V value (an invalid V, e.g. -1 for an index type). Then result<V, E> for any empty, trivially default-constructible E has exactly sizeof(V): the discriminant is "v == value". Constructing ok(value) is a precondition violation and terminates. Nothing in core specialises it: a raw pointer or integer has no invalid value (nullptr and -1 are valid successes), so a niche is sound only for a type whose invariant excludes one value.

The state is the value: a niche result whose V has been moved from reads as an error if the moved-from V equals the niche value (for example a handle whose move constructor leaves the source at -1, the niche). Do not use a niche result after moving its value out (std::move(r).unwrap()), only assign to it or destroy it.
