Detailed Description

snicholls::ml activations: sigmoid, softplus, logit, ReLU, ReLU², SiLU, GELU (exact and tanh) and the logit soft cap, each with its derivative, all constexpr.

Overview. The element-wise functions of a neural network, written once for every floating-point type and usable at compile time (a lookup table of GELU for an 8-bit format), at run time on the CPU, and from a GPU kernel. Each comes with its derivative for the backward pass. Where the output of the forward pass is what backpropagation keeps (sigmoid, tanh), the derivative also has a form that takes the output. Every function is computed in the form that cannot overflow or cancel:

  • sigmoid(x) is 1 / (1 + e^-x) for x >= 0 and e^x / (1 + e^x) below, so neither form overflows.
  • softplus(x) = max(x, 0) + log1p(e^-|x|) and log_sigmoid(x) = -softplus(-x), so a loss built on them never takes the log of an underflowed probability.
  • gelu(x) = x Φ(x) uses erfc for the normal CDF, accurate in the left tail; gelu_tanh (GPT-2's approximation) is computed as x · sigmoid(2u), which is identical to 0.5 x (1 + tanh u) and does not cancel for large negative x.
// A lookup table a kernel reads, computed by the compiler: GELU on [-4, 4] in steps of 1/2, in float.
constexpr auto gelu_table = [] {
std::array<float, 17> t{};
for (std::size_t i = 0; i < t.size(); ++i)
t[i] = ml::gelu(-4.0f + 0.5f * static_cast<float>(i));
return t;
}();
static_assert(gelu_table[8] == 0.0f);
// One neuron, y = sigmoid(w x + b), and the gradient of the loss (y - target)² / 2 in w, by the chain rule.
// The backward pass uses the output it kept: sigmoid_derivative_from_output(y).
constexpr double w = 0.8, b = -0.2, x = 1.5, target = 1.0;
constexpr double y = ml::sigmoid(w * x + b);
constexpr double dloss_dw = (y - target) * ml::sigmoid_derivative_from_output(y) * x;
// The same backward pass for the other activations: each comes with its derivative.
constexpr double grads[] = {ml::gelu_derivative(1.0), ml::gelu_tanh_derivative(1.0), ml::silu_derivative(1.0),
ml::relu_derivative(1.0), ml::relu_squared_derivative(1.0), ml::softcap_derivative(1.0, 15.0),
ml::sigmoid_derivative(1.0), ml::tanh_derivative_from_output(math::tanh(1.0))};

Relationships. Built on math/constexpr_math.hpp (exp, expm1, log1p, erfc, tanh). Used with ml/softmax.hpp and ml/norm.hpp. Group: snicholls-core.

Implementations. One each. A type of the caller's works through math_limits, as in snicholls::math.

Guarantees. Every function is constexpr and pure; NaN propagates. At run time the results are those of the <cmath> functions they call; at compile time they agree to a few units in the last place.

Errors. None: a domain error (logit outside [0, 1]) is NaN.

Performance. Benchmarked against the same formulas written by hand (benchmarks/ml/activations_benchmark.cpp, BENCHMARKS.md).

Tests and demos. tests/ml/activations_test.cpp, demos/ml/activations_demo.cpp.

Dependencies. <limits>, <type_traits>, snicholls/core/math/constexpr_math.hpp.

Known issues. relu and its derivative at exactly 0 take 0, as PyTorch does.

Status. Experimental, new in 0.6.0.
