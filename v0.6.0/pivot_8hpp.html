Detailed Description

stats::pivot: a pivot table whose rows, columns and measures are types, filled in one pass.

Overview. "P&L and mean return by currency and index" is a pivot: group the rows by two keys and aggregate two values in each group. Here the shape is a type and the work is one pass over the rows:

// Rows by currency, columns by index (read with std::get), P&L summed and return averaged
// (read by getters), every cell filled in one pass over the fills.
using by_currency_and_index = stats::pivot<fill, snicholls::meta::type_list<currency>, snicholls::meta::type_list<equity_index>,
stats::measure<pnl_of, stats::sum<double>>, stats::measure<ret_of, stats::mean<double>>>;
const std::vector<fill> fills{{currency::usd, equity_index::spx, {120}, {0.012}},
{currency::eur, equity_index::sx5e, {-40}, {-0.004}},
{currency::usd, equity_index::spx, {30}, {0.003}},
{currency::gbp, equity_index::ukx, {15}, {0.002}}};
by_currency_and_index today;
today.add_all(fills);
const auto usd_spx = today.value<0>({currency::usd, equity_index::spx}); // 150
const auto total = std::get<0>(today.total()).value(); // 125
// In parallel: each worker pivots its share, then the pivots merge.
by_currency_and_index worker_a, worker_b;
worker_a.add(fills[0]);
worker_b.add_all(std::vector<fill>(fills.begin() + 1, fills.end()));
worker_a.merge(worker_b);

Keys and cells print with their display attributes (display.hpp): declared once beside the key types and the measure's getter, the grid shows each currency in its colour and every P&L green or red through acout:

  • Keys. Rows and Columns are meta::type_lists. Each element is a key type, read from a row by std::get<K>(row) (a std::tuple of strong types); a getter, any default-constructible type callable with the row (a lambda's type, a struct reading a member); a name, by_name<"currency">, read by get<"currency">(row) as an object model with named fields provides; or a tag struct with a static get(row). A key that is a reflectable enumeration, a bool, or a type with a declared pivot_domain has a fixed set of values, so its cells are placed by arithmetic, with no hashing; any other key that can be hashed is given a place when first seen.
  • Measures. measure<Value, Accumulator>: the value, again a type read with get or a getter, and an accumulator from stats/accumulators.hpp (or any type with add and value). Every measure of every row is taken in the same pass. histogram gives each cell its distribution, collect keeps each cell's values for any statistic afterwards, and bootstrapped<Acc, B> gives each cell a Poisson bootstrap of its statistic in the same pass, each cell drawing its own stream.
  • Parallel. Each worker fills its own pivot from its share of the rows; merge combines them, exactly for counts, sums, minima and maxima, and to rounding for moments. Core has no threads; the caller brings them.

Relationships. stats/accumulators.hpp; meta/enums.hpp for enumeration keys and their names; meta/type_list.hpp. Group: snicholls-core.

Guarantees. add costs one lookup per key (a binary search for an enumeration, a hash for a key found at run time) and one add per measure; no allocation unless a new key widens a dimension. Cells are stored densely: their number is the product of the dimensions' sizes, so dimensions of modest size (currencies, indices, sectors, books) suit it, and an identifier per row does not. A row whose enumeration key is not an enumerator is counted in dropped() and not aggregated.

Errors. Compile errors with a message for a key that cannot be placed. std::bad_alloc.

Performance. benchmarks/stats/pivot_benchmark.cpp, P&L sum and return mean by currency and index over 1,000,000 rows, against the same loop written out, after a fairness check. Release, Apple clang 17, Xeon W-3245, 2026-11-07: by enumerations, 4.76 ms (210 million rows a second) against 4.67 ms by hand; by 32 desk names found at run time, 36.4 ms against 33.5 ms for a hand-written std::unordered_map.

Tests and demos. tests/stats/pivot_test.cpp, demos/stats/pivot_demo.cpp.

Dependencies. <algorithm>, <array>, <cassert>, <concepts>, <cstddef>, <cstdint>, <functional>, <optional>, <ostream>, <ranges>, <string_view>, <tuple>, <type_traits>, <unordered_map>, <utility>, <vector>, meta/concepts.hpp, meta/enums.hpp, meta/type_list.hpp, stats/accumulators.hpp.

Known issues. Not thread-safe: one pivot per worker, then merge.

Status. New in 0.5.0, experimental.
