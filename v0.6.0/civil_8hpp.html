Detailed Description

Proleptic Gregorian calendar arithmetic on plain integers.

Proleptic Gregorian calendar arithmetic on plain integers (Howard Hinnant, "chrono-Compatible Low-Level Date Algorithms", http://howardhinnant.github.io/date_algorithms.html):

snicholls::days_from_civil(2024, 2, 29) == 19782 // days since 1970-01-01
snicholls::civil_from_days(19782) == {2024, 2, 29}
snicholls::weekday_from_days(19782) == 4 // 0 = Sunday ... 6 = Saturday (C encoding)

Definition civil.hpp:108

The same algorithms std::chrono::year_month_day uses, without its range (year -32767..32767) or validity checks: constexpr, noexcept, branch-light, exact for every day count |z| < 2^60 (any snicholls::utc is within +-2^37 days). No validation: days_from_civil(2025, 2, 30) is 2025-03-02 - check with snicholls::last_day_of_month first when the input is untrusted. Year 0 is 1 BC (ISO 8601 / astronomical).
