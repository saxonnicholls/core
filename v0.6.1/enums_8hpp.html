Detailed Description

Enum reflection at compile time: names, values and parsing of an enumeration's enumerators.

Overview. enum_name(side::buy) is "buy", enum_cast<side>("sell") is side::sell, and enum_values_v<side> is every enumerator in order of value, all constexpr, from nothing but the enumeration's declaration. It replaces magic_enum: the compiler spells a non-type template argument in its function signature, and spells it as a name exactly when the value is an enumerator.

// Names, values and parsing straight from the declaration, at compile time.
static_assert(snicholls::enum_name(oms::status::filled) == "filled");
static_assert(snicholls::enum_count_v<oms::status> == 5);
// From the wire: a name becomes an enumerator, or nothing.
const auto parsed = snicholls::enum_cast<oms::status>("partially_filled");
const auto rubbish = snicholls::enum_cast<oms::status>("filed");
// Every enumerator, in order of value.
std::string all;
for (const oms::status s : snicholls::enum_values_v<oms::status>)
all += std::string(snicholls::enum_name(s)) + ' ';

The values from enum_range<E> are tried, -128 to 127 by default, cut to the underlying type. Specialise enum_range for an enumeration with values outside it: template <> struct snicholls::enum_range<venue> { static constexpr long long min = 0, max = 1000; };.

Relationships. meta/type_name.hpp, the same technique for types; acout.hpp prints a reflectable enumeration by its name; constexpr_map.hpp for names chosen by hand. Group: snicholls-core.

Guarantees. Everything is constexpr and noexcept; the tables are computed once per enumeration at compile time and live in static storage. Lookup by value is O(1), by name O(n).

Errors. enum_cast and enum_index return std::nullopt for a name or value that is not an enumerator; enum_name returns an empty view. An enumeration that cannot be reflected is a compile error with a message.

Performance. Compile time: one instantiation per value tried (256 by default) per enumeration. Run time: enum_index and enum_name are one table load (two bytes per value tried), enum_cast from a name a linear search.

Tests and demos. tests/meta/enums_test.cpp, demos/meta/enums_demo.cpp.

Dependencies. <array>, <cstddef>, <cstdint>, <limits>, <optional>, <string_view>, <type_traits>, <utility>.

Known issues.

  • An unscoped enumeration without a fixed underlying type (enum e { a, b };) is refused: forming one of its out-of-range values in a constant expression is undefined, and Clang rejects it. Give it one: enum e : int { a, b };. Every scoped enumeration qualifies.
  • Two enumerators with one value (aliases) reflect as one, under the name the compiler prints.
  • Flag enumerations (combinations of bits) are reflected as their individual enumerators only.
  • An enumeration local to a function cannot be reflected on every compiler.

Status. New in 0.5.0.
